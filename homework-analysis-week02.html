一、数列极限基础与性质
第 1 题 收敛数列重排不变性证明 必做题 教材习题
#1
设 limn→∞xn=a\lim_{n\to\infty} x_n = a，{yn}\{y_n\} 是 {xn}\{x_n\} 的任意重排（即存在双射 σ:ℕ→ℕ\sigma: \mathbb{N} \to \mathbb{N} 使得 yn=xσ(n)y_n = x_{\sigma(n)}）。
证明：limn→∞yn=a\lim_{n\to\infty} y_n = a。
💡 课本提示：利用数列极限的 ε−N\varepsilon-N 定义。因为 σ\sigma 是双射，原序列前 N0N_0 项的指标在重排后的位置只有有限个，取其最大值后即可控制剩余项。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
收敛数列的重排性质体现了极限行为只由「尾部」决定，与序列前有限项的次序完全无关。注意级数重排不一定保敛（Riemann 重排定理），但数列重排永远保敛。
【详细推理与解答】

证明：

1. 任取 ε>0\varepsilon > 0。由 limn→∞xn=a\lim_{n\to\infty} x_n = a，存在正整数 N0N_0，使得当 k>N0k > N_0 时，恒有：|xk−a|<ε|x_k - a| < \varepsilon

2. 考察集合 S={1,2,…,N0}S = \{1, 2, \dots, N_0\}。因为 σ:ℕ→ℕ\sigma: \mathbb{N} \to \mathbb{N} 是双射，原像集合 σ−1(S)={σ−1(1),σ−1(2),…,σ−1(N0)}\sigma^{-1}(S) = \{\sigma^{-1}(1), \sigma^{-1}(2), \dots, \sigma^{-1}(N_0)\} 是一个包含 N0N_0 个正整数的有限集。

3. 取 N=max{σ−1(1),…,σ−1(N0)}N = \max\{\sigma^{-1}(1), \dots, \sigma^{-1}(N_0)\}。当 n>Nn > N 时，n∉σ−1(S)n \notin \sigma^{-1}(S)，故必定有 σ(n)>N0\sigma(n) > N_0。

4. 于是当 n>Nn > N 时：|yn−a|=|xσ(n)−a|<ε|y_n - a| = |x_{\sigma(n)} - a| < \varepsilon由数列极限定义，limn→∞yn=a\lim_{n\to\infty} y_n = a。证毕。

第 2 题 数列极限典型计算与因式分解 必做题 计算大题
#2
求下列数列的极限：
(1) limn→∞(n+2−2n+1+n)n3\lim_{n\to\infty} (\sqrt{n+2} - 2\sqrt{n+1} + \sqrt{n}) \sqrt{n^3}；
(2) limn→∞(1−122)(1−132)⋯(1−1n2)\lim_{n\to\infty} \left(1 - \dfrac{1}{2^2}\right)\left(1 - \dfrac{1}{3^2}\right) \cdots \left(1 - \dfrac{1}{n^2}\right)；
(3) limn→∞1·3·5⋯(2n−1)2·4·6⋯(2n)\lim_{n\to\infty} \dfrac{1\cdot 3 \cdot 5 \cdots (2n-1)}{2 \cdot 4 \cdot 6 \cdots (2n)}；
(4) limn→∞(1+13+15+⋯+12n−1−12lnn)\lim_{n\to\infty} \left(1 + \dfrac{1}{3} + \dfrac{1}{5} + \cdots + \dfrac{1}{2n-1} - \dfrac{1}{2}\ln n\right)。
💡 课本提示：(1) 二阶差分，分子有理化；(2) 平方差分解连乘裂项；(3) 不等式夹逼放缩：2k−12k<2k−12k+1\frac{2k-1}{2k} < \sqrt{\frac{2k-1}{2k+1}}；(4) 利用调和数与 Euler 常数 γ\gamma 的关系。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
综合考查代数恒等变形、裂项相消、Wallis 积分放缩思路以及 Euler-Mascheroni 常数的定义技巧。
【详细推理与解答】

解：

(1) 记 f(x)=xf(x) = \sqrt{x}。原式括号内为二阶差分：(n+2−n+1)−(n+1−n)=1n+2+n+1−1n+1+n(\sqrt{n+2} - \sqrt{n+1}) - (\sqrt{n+1} - \sqrt{n}) = \frac{1}{\sqrt{n+2} + \sqrt{n+1}} - \frac{1}{\sqrt{n+1} + \sqrt{n}}通分分子有理化，或利用 Taylor 展开 1+x=1+12x−18x2+o(x2)\sqrt{1+x} = 1 + \frac{1}{2}x - \frac{1}{8}x^2 + o(x^2)：n+2−2n+1+n=n(1+2n−21+1n+1)=n(−14n2+o(1n2))=−14n3/2+o(n−3/2)\sqrt{n+2} - 2\sqrt{n+1} + \sqrt{n} = \sqrt{n}\left( \sqrt{1+\frac{2}{n}} - 2\sqrt{1+\frac{1}{n}} + 1 \right) = \sqrt{n}\left( -\frac{1}{4n^2} + o\left(\frac{1}{n^2}\right) \right) = -\frac{1}{4n^{3/2}} + o(n^{-3/2})乘以 n3=n3/2\sqrt{n^3} = n^{3/2}，得极限为 −14-\dfrac{1}{4}。

(2) 因式分解 1−1k2=(k−1)(k+1)k21 - \frac{1}{k^2} = \frac{(k-1)(k+1)}{k^2}。连乘积裂项：∏k=2n(k−1)(k+1)k2=(1·322)(2·432)(3·542)⋯((n−1)(n+1)n2)=12·n+1n\prod_{k=2}^n \frac{(k-1)(k+1)}{k^2} = \left(\frac{1\cdot 3}{2^2}\right)\left(\frac{2\cdot 4}{3^2}\right)\left(\frac{3\cdot 5}{4^2}\right)\cdots\left(\frac{(n-1)(n+1)}{n^2}\right) = \frac{1}{2} \cdot \frac{n+1}{n}当 n→∞n \to \infty 时，极限为 12\dfrac{1}{2}。

(3) 记 Pn=1·3⋯(2n−1)2·4⋯(2n)P_n = \frac{1\cdot 3 \cdots (2n-1)}{2\cdot 4 \cdots (2n)}。因为对任意 k≥1k \ge 1 均有 2k−12k<2k2k+1\frac{2k-1}{2k} < \frac{2k}{2k+1}，所以：Pn2<1·32·43·54·6⋯(2n−1)(2n+1)(2n)(2n+2)<12n+1P_n^2 < \frac{1\cdot 3}{2\cdot 4} \frac{3\cdot 5}{4\cdot 6} \cdots \frac{(2n-1)(2n+1)}{(2n)(2n+2)} < \frac{1}{2n+1}因此 0<Pn<12n+10 < P_n < \frac{1}{\sqrt{2n+1}}。由夹逼定理，limn→∞Pn=0\lim_{n\to\infty} P_n = 0。

(4) 已知调和级数部分和满足 ∑k=1m1k=lnm+γ+o(1)\sum_{k=1}^m \frac{1}{k} = \ln m + \gamma + o(1)。考察：∑k=1n12k−1=∑j=12n1j−∑k=1n12k=(ln(2n)+γ)−12(lnn+γ)+o(1)=ln2+12lnn+12γ+o(1)\sum_{k=1}^n \frac{1}{2k-1} = \sum_{j=1}^{2n} \frac{1}{j} - \sum_{k=1}^n \frac{1}{2k} = (\ln(2n) + \gamma) - \frac{1}{2}(\ln n + \gamma) + o(1) = \ln 2 + \frac{1}{2}\ln n + \frac{1}{2}\gamma + o(1)减去 12lnn\frac{1}{2}\ln n 后，极限为 ln2+γ2\ln 2 + \dfrac{\gamma}{2}。

第 3 题 两序列最大值与最小值的极限运算法则 必做题 定理证明
#3
设 limn→∞xn=a\lim_{n\to\infty} x_n = a 且 limn→∞yn=b\lim_{n\to\infty} y_n = b。证明：
(1) limn→∞max{xn,yn}=max{a,b}\lim_{n\to\infty} \max\{x_n, y_n\} = \max\{a, b\}；
(2) limn→∞min{xn,yn}=min{a,b}\lim_{n\to\infty} \min\{x_n, y_n\} = \min\{a, b\}。
💡 课本提示：利用实数的恒等式 max{u,v}=u+v+|u−v|2\max\{u, v\} = \frac{u+v+|u-v|}{2} 与 min{u,v}=u+v−|u−v|2\min\{u, v\} = \frac{u+v-|u-v|}{2}，结合绝对值函数的连续性与极限四则运算法则。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
巧妙利用代数绝对值恒等式将非线性分段函数转化为连续加减绝对值运算，避免讨论复杂的序列上下震荡交叉情况。
【详细推理与解答】

证明：

1. 对于任意实数 u,vu, v，有标准恒等式：max{u,v}=u+v+|u−v|2, min{u,v}=u+v−|u−v|2\max\{u, v\} = \frac{u + v + |u - v|}{2}, \quad \min\{u, v\} = \frac{u + v - |u - v|}{2}

2. 代入数列项：max{xn,yn}=xn+yn+|xn−yn|2\max\{x_n, y_n\} = \frac{x_n + y_n + |x_n - y_n|}{2}

3. 由极限四则运算法则，limn→∞(xn+yn)=a+b\lim_{n\to\infty} (x_n + y_n) = a + b。由反三角绝对值不等式：||xn−yn|−|a−b||≤|(xn−yn)−(a−b)|≤|xn−a|+|yn−b|||x_n - y_n| - |a - b|| \le |(x_n - y_n) - (a - b)| \le |x_n - a| + |y_n - b|因为当 n→∞n \to \infty 时右端趋于 00，故 limn→∞|xn−yn|=|a−b|\lim_{n\to\infty} |x_n - y_n| = |a - b|。

4. 综合得：limn→∞max{xn,yn}=a+b+|a−b|2=max{a,b}\lim_{n\to\infty} \max\{x_n, y_n\} = \frac{a + b + |a - b|}{2} = \max\{a, b\}同理可证 limn→∞min{xn,yn}=min{a,b}\lim_{n\to\infty} \min\{x_n, y_n\} = \min\{a, b\}。证毕。

二、递推数列与极限定理
第 4 题 两序列卷积加权平均的极限定理 (Toeplitz 卷积引理) 必做题 经典引理
#4
设 limn→∞xn=a\lim_{n\to\infty} x_n = a 且 limn→∞yn=b\lim_{n\to\infty} y_n = b。
证明：limn→∞x1yn+x2yn−1+⋯+xny1n=ab\lim_{n\to\infty} \frac{x_1 y_n + x_2 y_{n-1} + \cdots + x_n y_1}{n} = ab
💡 课本提示：令 xn=a+αn,yn=b+βnx_n = a + \alpha_n, y_n = b + \beta_n，其中 αn,βn→0\alpha_n, \beta_n \to 0。拆开展开式，利用收敛数列有界性及无穷小量的加权 Cesàro 平均趋于 0 进行证明。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
这是著名的 Toeplitz 矩阵卷积极限引理，是信号处理与离散卷积分析的基石定理。
【详细推理与解答】

证明：

1. 记 αn=xn−a\alpha_n = x_n - a，βn=yn−b\beta_n = y_n - b。则 limn→∞αn=0\lim_{n\to\infty} \alpha_n = 0，limn→∞βn=0\lim_{n\to\infty} \beta_n = 0。且 {αn},{yn}\{\alpha_n\}, \{y_n\} 均为收敛数列，因而是有界数列，设存在常数 M>0M > 0 使得对一切 kk 均有 |yk|≤M|y_k| \le M，|a|≤M|a| \le M。

2. 将分子展开：xkyn−k+1=(a+αk)yn−k+1=ayn−k+1+αkyn−k+1x_k y_{n-k+1} = (a + \alpha_k) y_{n-k+1} = a y_{n-k+1} + \alpha_k y_{n-k+1}求和除以 nn 得：1n∑k=1nxkyn−k+1=a(1n∑k=1nyk)+1n∑k=1nαkyn−k+1\frac{1}{n}\sum_{k=1}^n x_k y_{n-k+1} = a \left( \frac{1}{n}\sum_{k=1}^n y_k \right) + \frac{1}{n}\sum_{k=1}^n \alpha_k y_{n-k+1}

3. 由 Cesàro 算术平均极限性质，当 limn→∞yn=b\lim_{n\to\infty} y_n = b 时，其平均值 limn→∞1n∑k=1nyk=b\lim_{n\to\infty} \frac{1}{n}\sum_{k=1}^n y_k = b。故第一项极限为 abab。

4. 现证第二项趋于 0：任取 ε>0\varepsilon > 0。因为 αk→0\alpha_k \to 0，存在 N1N_1 使得当 k>N1k > N_1 时 |αk|<ε2M|\alpha_k| < \frac{\varepsilon}{2M}。对 n>N1n > N_1：|1n∑k=1nαkyn−k+1|≤Mn∑k=1N1|αk|+Mn∑k=N1+1n|αk|<Cn+M(n−N1)nε2M<Cn+ε2\left| \frac{1}{n}\sum_{k=1}^n \alpha_k y_{n-k+1} \right| \le \frac{M}{n}\sum_{k=1}^{N_1} |\alpha_k| + \frac{M}{n}\sum_{k=N_1+1}^n |\alpha_k| < \frac{C}{n} + \frac{M(n-N_1)}{n}\frac{\varepsilon}{2M} < \frac{C}{n} + \frac{\varepsilon}{2}令 n→∞n \to \infty，第一项 Cn→0\frac{C}{n} \to 0。故上式极限为 0。两部分相加得证极限为 abab。

第 5 题 算术几何平均不等式的一般证明与有理幂推导 必做题 核心定理
#5
设 n≥2n \ge 2，a1,a2,…,an≥0a_1, a_2, \dots, a_n \ge 0。算术几何平均不等式断言：(∏k=1nak)1/n≤1n∑k=1nak\left( \prod_{k=1}^n a_k \right)^{1/n} \le \frac{1}{n} \sum_{k=1}^n a_k且等号成立当且仅当 a1=a2=⋯=ana_1 = a_2 = \cdots = a_n。
(1) 请按照 Cauchy 前向-后向归纳法（Forward-Backward Induction）完成证明：先证 n=2n=2，再由 n=2kn=2^k 归纳到 n=2k+1n=2^{k+1}，最后由 nn 反向归纳到 n−1n-1；
(2) 利用几何平均不等式证明：对任意 α∈(0,1]\alpha \in (0, 1] 及 x>−1x > -1，恒有 (1+x)α−1≤αx(1+x)^\alpha - 1 \le \alpha x。
💡 课本提示：(1) 反向归纳时，在 n−1n-1 项后补充第 nn 项为前 n−1n-1 项的算术平均值 A=1n−1∑i=1n−1aiA = \frac{1}{n-1}\sum_{i=1}^{n-1} a_i；(2) 先设 α=pq\alpha = \frac{p}{q} 为有理数，取 qq 个数应用均值不等式，再由有理数稠密性过渡到实数。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
Cauchy 均值不等式证明是数学分析最美妙的构造性证明之一。由此可推出 Young 不等式、Hölder 不等式和 Minkowski 不等式。
【详细推理与解答】

证明：

(1) Cauchy 前向-后向归纳法：

• 当 n=2n=2 时：(a1−a2)2≥0⇔a1+a2≥2a1a2(\sqrt{a_1} - \sqrt{a_2})^2 \ge 0 \iff a_1 + a_2 \ge 2\sqrt{a_1 a_2}，等号成立当且仅当 a1=a2a_1 = a_2。

• 前向归纳：若 n=2kn=2^k 成立，对于 2k+12^{k+1} 个数，将其分为两组，每组 2k2^k 个数分别应用归纳假设，再对两组平均值应用 n=2n=2 的情形即可推出 2k+12^{k+1} 成立。

• 后向归纳：设对任意 nn 个数成立。给定 n−1n-1 个非负数 a1,…,an−1a_1, \dots, a_{n-1}，记其算术平均为 A=1n−1∑i=1n−1aiA = \frac{1}{n-1}\sum_{i=1}^{n-1} a_i。引入第 nn 个数 an=Aa_n = A。应用 nn 元均值不等式：(a1a2⋯an−1A)1/n≤a1+⋯+an−1+An=(n−1)A+An=A\left( a_1 a_2 \cdots a_{n-1} A \right)^{1/n} \le \frac{a_1 + \cdots + a_{n-1} + A}{n} = \frac{(n-1)A + A}{n} = A两边取 nn 次方：(a1⋯an−1)A≤An⇒a1⋯an−1≤An−1(a_1 \cdots a_{n-1}) A \le A^n \implies a_1 \cdots a_{n-1} \le A^{n-1}。两边开 n−1n-1 次方即得 (a1⋯an−1)1/(n−1)≤A(a_1 \cdots a_{n-1})^{1/(n-1)} \le A。故对所有正整数 nn 均成立。

(2) 证明幂不等式：先设 α=mn∈(0,1)\alpha = \frac{m}{n} \in (0, 1)（m<nm < n）。取 mm 个数等于 1+x1+x，n−mn-m 个数等于 11。应用 nn 元均值不等式：((1+x)m·1n−m)1/n≤m(1+x)+(n−m)·1n=1+mnx=1+αx\left( (1+x)^m \cdot 1^{n-m} \right)^{1/n} \le \frac{m(1+x) + (n-m)\cdot 1}{n} = 1 + \frac{m}{n}x = 1 + \alpha x左端即为 (1+x)m/n=(1+x)α(1+x)^{m/n} = (1+x)^\alpha。移项即得 (1+x)α−1≤αx(1+x)^\alpha - 1 \le \alpha x。再利用有理数在实数中的稠密性及指数函数的连续性，对任意无理数 α∈(0,1]\alpha \in (0, 1] 取有理数逼近极限，不等式保持成立。

第 6 题 基于示性函数的集合积分与容斥原理严格证明 必做题 测度论基础
#6
设 XX 为非空有限集合。对于任意函数 f:X→ℝf: X \to \mathbb{R}，定义积分 ∫Xf=∑i=1nf(xi)\int_X f = \sum_{i=1}^n f(x_i)，其中 X={x1,x2,…,xn}X = \{x_1, x_2, \dots, x_n\}。
(1) 设 A⊆XA \subseteq X，χA\chi_A 为 AA 的示性函数。证明：∫XχA=card(A)\int_X \chi_A = \text{card}(A)；
(2) 设 A,B⊆XA, B \subseteq X。证明：χA∪B=χA+χB−χA∩B\chi_{A\cup B} = \chi_A + \chi_B - \chi_{A\cap B}，并据此推出两集合容斥原理；
(3) 写出 nn 个子集 A1,A2,…,AnA_1, A_2, \dots, A_n 的通用容斥原理公式并利用示性函数代数恒等式给出证明。
💡 课本提示：示性函数满足 χAc=1−χA\chi_{A^c} = 1 - \chi_A 以及 χ⋂Ai=∏χAi\chi_{\bigcap A_i} = \prod \chi_{A_i}。由 De Morgan 律，χ⋃Ai=1−∏i=1n(1−χAi)\chi_{\bigcup A_i} = 1 - \prod_{i=1}^n (1 - \chi_{A_i})，展开乘积即得容斥原理。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
现代测度论与概率论的视角：计数不过是有限集上的计数测度积分。通过将布尔代数中的集合运算化为代数多项式，使容斥原理的组合证明降维成纯代数展开。
【详细推理与解答】

证明：

(1) 示性函数定义为：当 x∈Ax \in A 时 χA(x)=1\chi_A(x) = 1，当 x∉Ax \notin A 时 χA(x)=0\chi_A(x) = 0。根据定义：∫XχA=∑x∈XχA(x)=∑x∈A1+∑x∉A0=card(A)\int_X \chi_A = \sum_{x \in X} \chi_A(x) = \sum_{x \in A} 1 + \sum_{x \notin A} 0 = \text{card}(A)

(2) 对任意 x∈Xx \in X，逐点验证：

  • 若 x∈A∩Bx \in A \cap B，则 χA(x)=1,χB(x)=1,χA∩B(x)=1\chi_A(x)=1, \chi_B(x)=1, \chi_{A\cap B}(x)=1，右边为 1+1−1=1=χA∪B(x)1+1-1=1 = \chi_{A\cup B}(x)；
  • 若 x∈A∖Bx \in A \setminus B，则 χA=1,χB=0,χA∩B=0\chi_A=1, \chi_B=0, \chi_{A\cap B}=0，右边为 1+0−0=1=χA∪B(x)1+0-0=1 = \chi_{A\cup B}(x)；

第 8 题 两重迭代不动点与二次对合映射结构 选做题 思考题
#8
设 f:ℝ→ℝf: \mathbb{R} \to \mathbb{R}，已知复合映射 f(f(x))f(f(x)) 有且仅有两个相异的不动点 aa 与 bb（a≠ba \neq b）。
证明：或者 a,ba, b 本身都是 ff 的不动点；或者 f(a)=bf(a) = b 且 f(b)=af(b) = a。
💡 课本提示：利用不动点的迭代映射性质：如果 x∗x^* 是 f(f(x))f(f(x)) 的不动点，那么考察 f(x∗)f(x^*) 是否也是 f(f(x))f(f(x)) 的不动点。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
考查动力系统中的周期轨道（Period-2 Orbit）与不变集合性质。
【详细推理与解答】

证明：

1. 记 S={x∈ℝ∣f(f(x))=x}S = \{x \in \mathbb{R} \mid f(f(x)) = x\} 为 f∘ff \circ f 的不动点集。由题设，S={a,b}S = \{a, b\}（恰含两个元素）。

2. 对任意 x∗∈Sx^* \in S，考察其单次函数值 y=f(x∗)y = f(x^*)：f(f(y))=f(f(f(x∗)))=fBig(f(f(x∗))Big)=f(x∗)=yf(f(y)) = f(f(f(x^*))) = f\Big( f(f(x^*)) \Big) = f(x^*) = y这表明 y=f(x∗)y = f(x^*) 必定也落在不动点集合 SS 中！即 ff 将集合 S={a,b}S = \{a, b\} 映射到其自身：f(S)⊆Sf(S) \subseteq S。

3. 因此，f(a)f(a) 只能是 aa 或 bb，同时 f(b)f(b) 只能是 aa 或 bb：

  • 情形一：若 f(a)=af(a) = a，则由题意 aa 是 ff 的不动点。若 f(b)=af(b) = a，则 f(f(b))=f(a)=af(f(b)) = f(a) = a，但 f(f(b))=bf(f(b)) = b，推出 b=ab = a，与 a≠ba \neq b 矛盾！故必定 f(b)=bf(b) = b。此时 a,ba, b 都是 ff 的不动点；
  • 情形二：若 f(a)=bf(a) = b。因为 a≠ba \neq b，aa 不是 ff 的不动点。此时 f(b)=f(f(a))=af(b) = f(f(a)) = a。即 f(a)=bf(a) = b 且 f(b)=af(b) = a。

综上，只有这两种互斥情形。证毕。
