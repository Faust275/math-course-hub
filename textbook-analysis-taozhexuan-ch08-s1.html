§8.1 可数性

根据命题 3.6.14(c) 可知，如果 X 是有限集并且 Y 是 X 的真子集，那么 Y 与 X 的基数不相等。但对于无限集，情况就不是这样的。例如，由定理 3.6.12 可知，自然数集 N 是无限集。由命题 3.6.14(a) 可知，集合 N - {0} 也是无限集（为什么？），并且它还是 N 的真子集。然而，尽管集合 N - {0} 比 N“更小”，但它与 N 仍有相同的基数，因为定义为 f(n):=n+1f(n) := n + 1 的函数 f:N→N−{0}f: N \to N - \{0\} 是一个从 N 到 N - {0} 的双射（为什么？）。这是无限集的一个特点，参见习题 8.1.1。

现在我们来区分两种类型的无限集：可数集和不可数集。

定义 8.1.1概念定义

（可数集）集合 XX 是可数无限的（或简称为可数的），当且仅当 XX 与自然数集 N\mathbf{N} 有相等的基数。集合 XX 是至多可数的，当且仅当 XX 是可数的或 XX 是有限的。如果一个集合是无限的并且不是可数的，那么我们称该集合是不可数的。

注8.1.2 可数无限集也被称作可列集。

例 8.1.3经典例题

从前面的讨论中我们看到 N 是可数的，从而 N−{0}N - \{0\} 也是可数的。另一个可数集的例子是偶自然数集 {2n:n∈N}\{2n : n \in N\} ，因为函数 f(n):=2nf(n) := 2n 构成了 N 与偶自然数集之间的一个双射。（为什么？）

设 XX 是一个可数集，那么由定义可知，存在一个双射 f:N→Xf: \mathbf{N} \to X 。于是 XX 中的每一个元素都恰由一个自然数 nn 来决定并能够写成 f(n)f(n) 的形式。通俗地说，我们有

X={f(0),f(1),f(2),f(3),…}X = \{f (0), f (1), f (2), f (3), \dots \}

因此可数集能够被排成一个序列，从而我们有第零个元素 f(0)f(0) ，其后紧跟着第一个元素 f(1)f(1) ，然后紧跟着第二个元素 f(2)f(2) ，以此类推。这种方式使得所有的元素 f(0)f(0) 、 f(1)f(1) 、 f(2)f(2) 、……互不相同，并且它们共同填满了整个集合 X。（这就是为什么这些集合被称作是可数的，因为我们可以逐个地去数它们，从 f(0)f(0) 开始，然后是 f(1)f(1) ，以此类推。）

因此，为什么自然数集

N={0,1,2,3,…}\mathbf {N} = \{0, 1, 2, 3, \dots \}

正整数集

N−{0}={1,2,3,…}\mathbf {N} - \{0 \} = \{1, 2, 3, \dots \}

以及偶自然数集

{0,2,4,6,8,…}\{0, 2, 4, 6, 8, \dots \}

都是可数的就显而易见了。然而，整数集

Z={…,−3,−2,−1,0,1,2,3,…}\mathbf {Z} = \{\dots , - 3, - 2, - 1, 0, 1, 2, 3, \dots \}

有理数集

Q={0,1/4,−2/3,…}\mathbf {Q} = \{0, 1 / 4, - 2 / 3, \dots \}

以及实数集

R={0,2,−π,2.5,…}\mathbf {R} = \{0, \sqrt {2}, - \pi , 2. 5, \dots \}

是否可数就不那么明显了。例如，目前我们还不清楚能否把实数集排成一个序列 f(0),f(1),f(2),⋯f(0), f(1), f(2), \cdots 。稍后我们会给出这些问题的答案。

根据命题 3.6.4 和定理 3.6.12，我们知道可数集是无限集。然而是否所有的无限集都是可数的，我们尚不清楚。稍后我们同样会回答这些问题。首先，我们需要下面这个重要的原理。

命题 8.1.4命题

（良序原理）设 XX 是自然数集 N\mathbf{N} 的一个非空子集，那么恰好存在一个元素 n∈Xn\in X ，使得对所有的 m∈Xm\in X 都有 n≤mn\leqslant m 。换言之，任意一个元素为自然数的非空集合都有一个最小元素。

证明

参见习题8.1.2。

我们把由良序原理给出的元素 n 称作 X 的最小值，并记作 min(X)\min(X) 。例如，集合 {2,4,6,8,⋯}\{2,4,6,8,\cdots\} 的最小值是 2。这里的最小值显然与定义 5.5.10 中 X 的下确界是同一个值。（为什么？）

命题 8.1.5命题

设 XX 是自然数集 N\mathbf{N} 的一个无限子集，那么存在唯一一个递增的双射 f:N→Xf: \mathbf{N} \to X ，这里递增指的是对所有的 n∈Nn \in \mathbf{N} 都有 f(n+1)>f(n)f(n + 1) > f(n) 。特别地， XX 与 N\mathbf{N} 具有相等的基数，所以 XX 是可数的。

证明

我们给出这个证明的不完整框架，其中留下一些待补充的细节用问号“？”来标记。这些细节将在习题8.1.3中补充完整。

现在我们根据下述公式来递归地定义一个自然数序列 a0,a1,a2,⋯a_{0}, a_{1}, a_{2}, \cdots

an:=min{x∈X:对所有的m<n均有x≠am}a _ {n} := \min \{x \in X: \text {对所有的} m < n \text {均有} x \neq a _ {m} \}

直观地说， a0a_{0} 是 X 的最小元素； a1a_{1} 是 X 的第二小元素，即只要把 a0a_{0} 删除掉， a1a_{1} 就是 X 的最小元素； a2a_{2} 是 X 的第三小元素；以此类推。注意，为了定义 ana_{n} ，对于一切 m<nm < n 我们只需要知道 ama_{m} 值就可以了，因此这个定义是递归的。另外，因为 XX 是无限集，所以集合 {x∈X:对所有的m<n均有x≠am}\{x \in X : \text{对所有的} m < n \text{ 均有 } x \neq a_{m}\} 也是无限集（?），从而是非空的。因此根据良序原理，最小值 min{x∈X:对所有的m<n均有x≠am}\min\{x \in X : \text{对所有的} m < n \text{ 均有 } x \neq a_{m}\} 总是有意义的。

我们可以证明（？） (an)n=0∞(a_{n})_{n = 0}^{\infty} 是一个递增序列，即

a0<a1<a2<…a _ {0} < a _ {1} < a _ {2} < \dots

并且对所有的 n≠mn \neq m 均有 an≠ama_{n} \neq a_{m} （?）。此外，对于任意的自然数 nn ，均有（？） an∈Xa_{n} \in X 。

现在定义函数 f:N→Xf: N \rightarrow X 为 f(n):=anf(n) := a_{n} 。从上一段中我们知道 f 是一对一的。现在我们证明 f 是映上的。换言之，我们要证明对于每个 x∈Xx \in X 都存在一个 n 使得 an=xa_{n} = x 。

令 x∈Xx \in X ，利用反证法，假设对每一个自然数 nn 都有 an≠xa_n \neq x ，那么这表明（？）对于所有的 nn ， xx 都是集合 {x∈X:对所有的m<n均有x≠am}\{x \in X : \text{对所有的 } m < n \text{ 均有 } x \neq a_m\} 中的元素。根据 ana_n 的定义可知，这表明了对任意的自然数 nn 都有 x≥anx \geqslant a_n 。又因为 (an)n=0∞(a_n)_{n=0}^{\infty} 是一个递增序列，所以 an≥na_n \geqslant n （？），从而 x≥nx \geqslant n 对任意的自然数 nn 均成立。特别地，我们有 x≥x+1x \geqslant x + 1 ，这是一个矛盾。因此一定存在某个自然数 nn 使得 an=xa_n = x ，从而 ff 是映上的。

因为 f:N→Xf: \mathbf{N} \to X 既是一对一又是映上的，所以它是一个双射。因此，我们至少能够找到一个从 N\mathbf{N} 到 XX 的递增双射。现在利用反证法，假设存在另外一个从 N\mathbf{N} 到 XX 的递增双射 gg ，并且 gg 不等于 ff 。于是集合 {n∈N:g(n)≠f(n)}\{n \in \mathbf{N}: g(n) \neq f(n)\} 是非空的。定义 m:=min{n∈N:g(n)≠f(n)}m := \min\{n \in \mathbf{N}: g(n) \neq f(n)\} ，那么 g(m)≠f(m)=amg(m) \neq f(m) = a_m ，并且对所有的 n<mn < m 均有 g(n)=f(n)=ang(n) = f(n) = a_n 。但由此可知，必然有（？）

g(m)=min{x∈X:g(m)=\min\{x\in X: 对所有的 t<mt<m 均有 x≠at}=amx\neq a_{t}\}=a_{m}

这是一个矛盾，因此除了 f，不存在其他从 N 到 X 的递增双射。

由定义可知，有限集是至多可数的，于是得出下述推论。

推论 8.1.6推论

自然数集的所有子集都是至多可数的。

推论 8.1.7推论

如果 XX 是一个至多可数的集合，并且 YY 是 XX 的一个子集，那么 YY 也是至多可数的。

证明

如果 XX 是有限集，那么根据命题3.6.14(c)可以得出结论。假设 XX 是可数的，那么在 XX 和 N\mathbf{N} 之间存在一个双射 f:X→Nf: X \to \mathbf{N} 。因为 YY 是 XX 的子集并且 ff 是从 XX 到 N\mathbf{N} 的双射，所以把 ff 限制在 YY 上就得到了 YY 和 f(Y)f(Y) 之间的一个双射。（为什么是双射？）于是 f(Y)f(Y) 与 YY 有相同的基数，而 f(Y)f(Y) 是 N\mathbf{N} 的一个子集，从而根据推论8.1.6可知， f(Y)f(Y) 是至多可数的。因此 YY 也是至多可数的。

命题 8.1.8命题

设 YY 是一个集合，并且设 f:N→Yf: \mathbf{N} \to Y 是一个函数，那么 f(N)f(\mathbf{N}) 是至多可数的。

证明

参见习题8.1.4。

推论 8.1.9推论

设 XX 是一个可数集，并且设 f:X→Yf: X \to Y 是一个函数，那么 f(X)f(X) 是至多可数的。

证明

参见习题8.1.5。

命题 8.1.10命题

设 XX 是一个可数集，并且设 YY 也是一个可数集，那么 X∪YX \cup Y 是可数集。

证明

参见习题8.1.7。

总之，一个可数集的任何子集和象集都是至多可数的，并且有限个可数集的并集仍然是可数集。现在我们可以建立整数集的可数性。

推论 8.1.11推论

整数集 Z 是可数集。

证明

我们已经知道自然数集 N={0,1,2,3,⋯}N=\{0,1,2,3,\cdots\} 是可数集，那么集合 -N

−N:={−n:n∈N}={0,−1,−2,−3,…}- \mathbf {N} := \{- n: n \in \mathbf {N} \} = \{0, - 1, - 2, - 3, \dots \}

也是可数集，这是因为映射 f(n):=−nf(n) := -n 是 N 和 -N 之间的一个双射。由于整数集是 N 和 -N 的并集，所以根据命题 8.1.10 就可以推出要证明的结论。☐

为了建立有理数集的可数性，我们需要把可数性与笛卡儿积联系起来。特别地，我们要证明集合 N×N\mathbf{N} \times \mathbf{N} 是可数的。首先，我们需要一个预备引理。

引理 8.1.12命题/引理

集合

A:={(n,m)∈N×N:0≤m≤n}A := \{(n, m) \in \mathbf {N} \times \mathbf {N}: 0 \leqslant m \leqslant n \}

是可数集。

证明

递归地定义序列 a0,a1,a2,⋯a_{0}, a_{1}, a_{2}, \cdots ，其中 a0:=0a_{0} := 0 ，并且对任意的自然数 n 有 an+1:=an+n+1a_{n+1} := a_{n} + n + 1 。于是

a0=0,a1=0+1,a2=0+1+2,a3=0+1+2+3,…a _ {0} = 0, a _ {1} = 0 + 1, a _ {2} = 0 + 1 + 2, a _ {3} = 0 + 1 + 2 + 3, \dots

利用归纳法，我们可以证明 (an)n=0∞(a_{n})_{n = 0}^{\infty} 是递增的，即只要 n>mn > m ，就有 an>ama_{n} > a_{m} 。（为什么？）

现在定义函数 f:A→Nf: A \to \mathbf{N} 为

f(n,m):=an+mf (n, m) := a _ {n} + m

我们要证明 f 是一对一的。换言之，如果 (n,m)(n,m) 和 (n′,m′)(n',m') 是 A 中任意两个不同的元素，那么我们要证明 f(n,m)≠f(n′,m′)f(n,m) \neq f(n',m') 。

为了证明上述结论，设 (n,m)(n,m) 和 (n′,m′)(n',m') 是 AA 中两个不同的元素。那么存在三种情形： n′=n,n′>nn' = n, n' > n 以及 n′<nn' < n 。首先假设 n′=nn' = n ，那么我们一定有 m≠m′m \neq m' ，否则 (n,m)(n,m) 与 (n′,m′)(n',m') 就是相同的。于是 an+m≠an+m′a_n + m \neq a_n + m' ，从而 f(n,m)≠f(n′,m′)f(n,m) \neq f(n',m') ，这就是要证明的结果。

现在假设 n′>nn' > n ，于是 n′≥n+1n' \geqslant n + 1 ，从而

f(n′,m′)=an′+m′≥an′≥an+1=an+n+1f (n ^ {\prime}, m ^ {\prime}) = a _ {n ^ {\prime}} + m ^ {\prime} \geqslant a _ {n ^ {\prime}} \geqslant a _ {n + 1} = a _ {n} + n + 1

而根据 (n,m)∈A(n,m)\in A 可知， m≤n<n+1m\leqslant n < n + 1 ，从而

f(n′,m′)≥an+n+1>an+m=f(n,m)f (n ^ {\prime}, m ^ {\prime}) \geqslant a _ {n} + n + 1 > a _ {n} + m = f (n, m)

因此 f(n′,m′)≠f(n,m)f(n', m') \neq f(n, m) 。

对于 n′<nn' < n 的情形也可类似地证明，只需把上述论证过程中 nn 和 n′n' 互换即可。于是我们证明了 ff 是一对一的，所以 ff 是从 AA 到 f(A)f(A) 的双射，从而 AA 和 f(A)f(A) 有相同的基数。而 f(A)f(A) 是 N\mathbf{N} 的一个子集，进而根据推论8.1.6可知， f(A)f(A) 是至多可数的。因此 AA 是至多可数的。但 AA 显然不是有限集，（为什么？提示：如果 AA 是有限集，那么 AA 的任意一个子集都是有限集，从而 {(n,0):n∈ℕ}\{(n,0): n \in \mathbb{N}\} 是有限集，但这个集合明显是可数无限的，这就出现了矛盾）因此 AA 一定是可数集。

推论 8.1.13推论

集合 N×N\mathbf{N} \times \mathbf{N} 是可数集。

证明

我们已经知道集合

A:={(n,m)∈N×N:0≤m≤n}A := \{(n, m) \in \mathbf {N} \times \mathbf {N}: 0 \leqslant m \leqslant n \}

是可数集。这表明集合

B:={(n,m)∈N×N:0≤n≤m}B := \{(n, m) \in \mathbf {N} \times \mathbf {N}: 0 \leqslant n \leqslant m \}

也是一个可数集，这是因为定义为 f(n,m):=(m,n)f(n,m):= (m,n) 的映射 f:A→Bf:A\to B 是从 AA 到 BB 的双射。（为什么？）而由 N×N\mathbf{N}\times \mathbf{N} 是 AA 和 BB 的并集（为什么？）可知，从命题8.1.10中可以推出要证明的结论。

推论 8.1.14推论

如果 XX 和 YY 都是可数集，那么 X×YX \times Y 也是可数集。

证明

参见习题8.1.8。

推论 8.1.15推论

有理数集 Q\mathbf{Q} 是可数集。

证明

我们已经知道整数集 Z\mathbf{Z} 是可数集，那么非零整数集 Z−{0}\mathbf{Z} - \{0\} 也是可数集。（为什么？）根据推论8.1.14可知，集合

Z×(Z−{0})={(a,b):a,b∈Z,b≠0}\mathbf {Z} \times (\mathbf {Z} - \{0 \}) = \{(a, b): a, b \in \mathbf {Z}, b \neq 0 \}

是可数集。如果设 f:Z×(Z−{0})→Qf: \mathbf{Z} \times (\mathbf{Z} - \{0\}) \to \mathbf{Q} 为函数 f(a,b):=a/bf(a, b) := a / b （注意 ff 是有意义的，因为 bb 不等于零），那么从推论8.1.9可知， f(Z×(Z−{0}))f(\mathbf{Z} \times (\mathbf{Z} - \{0\})) 是至多可数的。而f(Z×(Z−{0}))=Qf(\mathbf{Z} \times (\mathbf{Z} - \{0\})) = \mathbf{Q} , (为什么? 这基本上就是有理数集 Q\mathbf{Q} 的定义) 于是 Q\mathbf{Q} 是至多可数的。但 Q\mathbf{Q} 不可能是有限集, 因为它包含了无限集 N\mathbf{N} 。因此, Q\mathbf{Q} 是可数集。

注8.1.16 因为有理数集是可数集，所以从原则上来说可以把有理数集排成一个序列：

Q={a0,a1,a2,a3,…}\mathbf {Q} = \left\{a _ {0}, a _ {1}, a _ {2}, a _ {3}, \dots \right\}

其中，序列中的每一项与其他任意一项都不相等，并且该序列穷尽了 Q 中的所有元素（即每一个有理数都成为序列中的某一项 ana_{n} ）。但是尝试真正地找到这样一个具体序列 a0,a1,⋯a_{0}, a_{1}, \cdots 是非常困难的（尽管这是有可能的），参见习题 8.1.10。
