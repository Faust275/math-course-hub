00:00:02—00:03:26 ｜ 从定义出发：用取整函数把函数极限化归到数列极限

上节课验证lim⁡n→∞a1/n=1\lim_{n\to\infty}a^{1/n}=1时引入过那个量（记作 Q ，落在 (0,1) 之间），当时并没有去追究 Q 本身是什么，只用到「 [x]≤x<[x]+1 」这一层关系：把 x 夹在 [x] 与 [x]+1 之间，再由 x>0 、 x→+∞ 时1x→0\frac1x\to0得到结论。「这个嘛，反正就是自然数了」是不算理由的。

马上就有人要继续问：你凭什么说这个东西是对的？「直到 Q 的……你凭什么说这个东西？」——到这一步为止，没有哪一个定理告诉你这个式子肯定对，教材上也没有现成的一条。你刚才用的夹逼准则，本身用掉的正是这一步。所以这也是分析的「灵活性」：理论（定义）告诉你这个对，而不是翻书翻出来的；很多 S 取同一个 ε 之类的细节，真要完全写严谨是比较啰嗦的，但思路必须说得清。

上节课已经交代过：你手头最强的工具就是定义——任意给定 ε>0 ，存在 N （或存在 δ ），使得当 x 充分大（或充分靠近x0x_0）时 |f(x)−A|<ε ；这里的 A 是与 x 无关的常数。要证明某个函数极限对，就得能写成「存在一个与 x 没关系的 A ，使 |f(x)−A|<ε 」，而不是想当然地套结论。

特别地：在没有单调性可用的情况下处理函数极限，就不要去考虑这个函数在整个定义域上的单调性，而是去找 [x] 与 [x]+1 这两个整数点上的函数值，用它们把函数夹在中间——因为整数点上的极限（数列极限）上节课已经算过了，是「免费」可用的。「idea 有了」只算懂了 90%，能把这个 idea 说清楚、写严谨，是剩下的 10%；后面每一个类似的极限，都要能这样交代一遍。

例题/证明 1（00:00:02）｜ 函数极限化归数列极限：以取整函数夹逼

命题 设数列an→A(n→∞)a_n\to A\ (n\to\infty)，函数 f 满足：对每个 x≥1 ，记 n=[x] ，有

an+1≤f(x)≤an.a_{n+1}\le f(x)\le a_n .
则lim⁡x→+∞f(x)=A\lim_{x\to+\infty}f(x)=A。

思路 把「 x 很大」翻译成「 n=[x] 很大」，于是 f(x) 被两个收敛到同一极限 A 的数列项夹住，再用夹逼准则（其证明本身也只用到定义）。

逐步推导

  1. 任给 ε>0 。由lim⁡n→∞an=A\lim_{n\to\infty}a_n=A，存在N1∈NN_1\in\mathbb N，使n≥N1n\ge N_1时|an−A|<ε|a_n-A|<\varepsilon，即A−ε<an<A+εA-\varepsilon<a_n<A+\varepsilon。
  2. 由lim⁡n→∞an+1=A\lim_{n\to\infty}a_{n+1}=A（同一数列去掉有限项，极限不变），存在N2∈NN_2\in\mathbb N，使n≥N2n\ge N_2时A−ε<an+1A-\varepsilon<a_{n+1}。
  3. 取N=max⁡{N1,N2}N=\max\{N_1,N_2\}，再取 X=N+1 （ X 只依赖于 ε ，与 x 无关）。
  4. 当 x>X 时， n=[x]≥N ，于是由条件
    A−ε<an+1≤f(x)≤an<A+ε.A-\varepsilon<a_{n+1}\le f(x)\le a_n<A+\varepsilon .
  5. 即 |f(x)−A|<ε 。

结论 按定义，lim⁡x→+∞f(x)=A\lim_{x\to+\infty}f(x)=A。

意义与易错点 这一步是把「函数极限」拆回「数列极限」的通用套路：不要求 f 单调，只要求它在相邻两个整数点之间被夹住。老师反复强调「直接从定义出发」——人家追问「你凭什么」时，答案只能是定义，不能是「书上有这个结论」。

00:03:30—00:05:43 ｜ 常用极限（一）：lim⁡x→+∞a1/x=1(a>0)\lim_{x\to+\infty}a^{1/x}=1\ (a>0)

这是第一个把上节课的数列极限搬成函数极限的例子：由lim⁡n→∞a1/n=1\lim_{n\to\infty}a^{1/n}=1得到lim⁡x→+∞a1/x=1\lim_{x\to+\infty}a^{1/x}=1。「其他的是不是都是类似的」——类似，但要注意「类似」不等于不用写；真正操作的时候，比较依赖 a>1 还是 a<1 ，这是技术层面的事，写的时候就得把情形讨论清楚。下面这个是第一个，后面 a<1 、x→−∞x\to-\infty、 x→0 都要按同样的讨论补上。

例题/证明 2（00:03:40）｜ 求lim⁡x→+∞a1/x(a>0)\lim_{x\to+\infty}a^{1/x}\ (a>0)

命题 对任意 a>0 ，lim⁡x→+∞a1/x=1\displaystyle\lim_{x\to+\infty}a^{1/x}=1。

思路 令 n=[x] ，则 n≤x<n+1 ，把1x\frac1x夹在1n+1\frac{1}{n+1}与1n\frac1n之间，从而把a1/xa^{1/x}夹在a1/(n+1)a^{1/(n+1)}与a1/na^{1/n}之间；两端都是整数点上的数列极限（已知为 1）。

逐步推导

  1. 先记上节课已证的数列结论：lim⁡n→∞a1/n=1(a>0)\lim_{n\to\infty}a^{1/n}=1\ (a>0)。其证明（[补全]，按数学上正确的方式补齐，不是当堂讲的，仅作自学参照）： a=1 时显然； a>1 时设a1/n=1+hna^{1/n}=1+h_n，hn>0h_n>0，由二项式展开
    公式
    a=(1+hn)n≥1+nhn⇒0<hn≤a−1n→0,a=(1+h_n)^n\ge 1+nh_n\quad\Longrightarrow\quad 0<h_n\le\frac{a-1}{n}\to0,
    故a1/n→1a^{1/n}\to1； 0<a<1 时令b=1a>1b=\frac1a>1，a1/n=1b1/n→1a^{1/n}=\frac1{b^{1/n}}\to1。
  2. 设 a>1 。对 x≥1 令 n=[x]≥1 ，则 n≤x<n+1 ，取倒数得
    公式
    1n+1<1x≤1n.\frac{1}{n+1}<\frac1x\le\frac1n .
  3. 因 a>1 ，指数函数t↦att\mapsto a^t严格递增，故
    a1/(n+1)<a1/x≤a1/n.a^{1/(n+1)}<a^{1/x}\le a^{1/n}.
  4. 任给 ε>0 。由lim⁡n→∞a1/n=1\lim_{n\to\infty}a^{1/n}=1，存在N1N_1使n≥N1n\ge N_1时a1/n<1+εa^{1/n}<1+\varepsilon；由lim⁡n→∞a1/(n+1)=1\lim_{n\to\infty}a^{1/(n+1)}=1，存在N2N_2使n≥N2n\ge N_2时a1/(n+1)>1−εa^{1/(n+1)}>1-\varepsilon。
  5. 取X=max⁡{N1,N2}+1X=\max\{N_1,N_2\}+1。当 x>X 时n=[x]≥max⁡{N1,N2}n=[x]\ge\max\{N_1,N_2\}，于是
    1−ε<a1/(n+1)<a1/x≤a1/n<1+ε,1-\varepsilon<a^{1/(n+1)}<a^{1/x}\le a^{1/n}<1+\varepsilon,
    即|a1/x−1|<ε\left|a^{1/x}-1\right|<\varepsilon。故lim⁡x→+∞a1/x=1(a>1)\lim_{x\to+\infty}a^{1/x}=1\ (a>1)。
  6. a=1 时a1/x≡1a^{1/x}\equiv1，结论显然。
  7. 设 0<a<1 。令b=1a>1b=\frac1a>1，则a1/x=1b1/xa^{1/x}=\dfrac{1}{b^{1/x}}。由第 5 步b1/x→1≠0b^{1/x}\to1\ne0，故a1/x→11=1a^{1/x}\to\frac11=1。（也可直接把第 3 步的不等号反向：a1/n≤a1/x<a1/(n+1)a^{1/n}\le a^{1/x}<a^{1/(n+1)}，两端仍趋于 1。）

结论 对一切 a>0 ，lim⁡x→+∞a1/x=1\lim_{x\to+\infty}a^{1/x}=1。

意义与易错点 ①「真正要操作的时候，比较依赖 a 大于一还是小于一」： a>1 与 0<a<1 时不等号方向相反，必须分情形写清楚，不能一句「类似地」带过。②「那你作为一个研究数学的，你到这儿停止吧？」——不能停：a1/xa^{1/x}只是原来数列结论的函数版，还得继续问 x→−∞ 、 x→0 、以及axa^x本身趋于各方向时的极限。

00:06:01—00:07:20 ｜ 记号约定、axa^x的定义域与 x→−∞ 的极限

记号约定（老师明确交代）：有些教材上带指数的东西写法比较松，本课程一律写成指数函数axa^x的形式；只要出现「有利的东西、有指数的东西」，全部写成指数函数，再按指数函数的定义域去讨论。

a>0 且 a≠1 时，指数函数axa^x的定义域就是整个实数R （高中已经学过，「于是一的话，这边也是整个实数」）。正因为定义域是整个 R ，才必须接着问「里面 x 趋于负无穷等于多少」——不能只算 x→+∞ 一端。

例题/证明 3（00:06:34）｜ lim⁡x→−∞a1/x=1\lim_{x\to-\infty}a^{1/x}=1与lim⁡x→∞a1/x=1\lim_{x\to\infty}a^{1/x}=1

命题 对 a>0 ，lim⁡x→−∞a1/x=1\displaystyle\lim_{x\to-\infty}a^{1/x}=1，从而两端相等，lim⁡x→∞a1/x=1\displaystyle\lim_{x\to\infty}a^{1/x}=1。

思路 做变量代换 t=−x （也可以说利用复合函数，或「像做题目时简单做一个变量代换」），把 x→−∞ 化回已经算过的 t→+∞ 。

逐步推导

  1. 令 t=−x 。当 x→−∞ 时 t→+∞ 。
  2. 公式
    a1/x=a−1/t=1a1/t(t>0).a^{1/x}=a^{-1/t}=\frac{1}{a^{1/t}}\qquad(t>0).
  3. 由证明 2，lim⁡t→+∞a1/t=1\lim_{t\to+\infty}a^{1/t}=1，且 1≠0 ，于是
    公式
    limx→−∞a1/x=limt→+∞1a1/t=11=1.\lim_{x\to-\infty}a^{1/x}=\lim_{t\to+\infty}\frac{1}{a^{1/t}}=\frac{1}{1}=1 .
  4. 逐行写成 ε 语言：任给 ε>0 ，由lim⁡t→+∞a1/t=1\lim_{t\to+\infty}a^{1/t}=1且 1>0 ，存在 T>0 使 t>T 时1−ε<a1/t<1+ε1-\varepsilon<a^{1/t}<1+\varepsilon；取 X=−T ，则 x<X 时 t=−x>T ，故11+ε<1a1/t<11−ε\frac{1}{1+\varepsilon}<\frac1{a^{1/t}}<\frac{1}{1-\varepsilon}，当 ε 取小时即得|a1/x−1|<ε′\left|a^{1/x}-1\right|<\varepsilon'，故极限为 1。
  5. 由证明 2（ x→+∞ 一端）与本步（ x→−∞ 一端）左右相等，都等于 1，故lim⁡x→∞a1/x=1\lim_{x\to\infty}a^{1/x}=1。

结论a1/xa^{1/x}在 +∞ 、 −∞ 两端的极限都是 1。

意义与易错点 「讲第一个就够了」——但下面这些不是提醒你，而是当数列变成函数时，这些常用极限略有不同：无穷远处的左、右极限全都带出来了，必须两端都交代。变量代换在这里是「低成本」的，但要清楚它用的是复合函数（或反函数）的道理，不是凭空换元。

00:07:29—00:10:01 ｜ 常用极限（二）：lim⁡x→0ax=1\lim_{x\to0}a^x=1、基本初等函数与 0<a<1 的处理

上面把无穷远处（ x→0 的倒数）的左右极限都带出来之后，就可以直接讨论 x→0 了。注意：我不是利用连续性——连续性还没讲，现在就是在求极限；可以用指数函数的变量代换，也可以用 ε 的语言重新说一遍。

例题/证明 4（00:07:56）｜ lim⁡x→0ax=1(a>0)\lim_{x\to0}a^x=1\ (a>0)

命题 对 a>0 ，lim⁡x→0ax=1\displaystyle\lim_{x\to0}a^x=1。

思路 令t=1xt=\frac1x，把axa^x写成a1/ta^{1/t}，用已证的lim⁡t→∞a1/t=1\lim_{t\to\infty}a^{1/t}=1；x→0+x\to0^+对应 t→+∞ ，x→0−x\to0^-对应 t→−∞ 。

逐步推导

  1. x≠0 时ax=a1/ta^x=a^{1/t}，其中t=1xt=\frac1x。
  2. 当x→0+x\to0^+时 t→+∞ ，由证明 2 得a1/t→1a^{1/t}\to1，故右极限为 1。
  3. 当x→0−x\to0^-时 t→−∞ ，由证明 3 得a1/t→1a^{1/t}\to1，故左极限为 1。
  4. 左右极限都存在且相等，故lim⁡x→0ax=1\lim_{x\to0}a^x=1。
  5. 用 ε - δ 语言重写一遍（[补全]，不是当堂讲的，仅作自学参照）：任给 ε>0 ，由lim⁡t→∞a1/t=1\lim_{t\to\infty}a^{1/t}=1，存在 T>0 使 |t|>T 时|a1/t−1|<ε\left|a^{1/t}-1\right|<\varepsilon；取δ=1T\delta=\frac1T，则 0<|x|<δ 时|1x|>T\left|\frac1x\right|>T，于是|ax−1|=|a1/(1/x)−1|<ε|a^x-1|=\left|a^{1/(1/x)}-1\right|<\varepsilon。这正是定义的写法。

结论lim⁡x→0ax=1\lim_{x\to0}a^x=1。

00:35:29—00:41:04 ｜ 几个常用极限的粗放推导：放缩与换元

承接前面函数极限的推导。经验告诉我们， ln⁡x 比幂函数跑得慢：当 x→+∞ 时 ln⁡x 也趋于 +∞ ，但ln⁡xx→0\dfrac{\ln x}{x}\to 0。处理这类「一个量趋于 +∞ 、另一个量趋于 0 」的商或乘积，最省事的办法是比较粗的放缩：把跑得慢的那一项用低阶项或常数控制住，剩下的交给夹逼准则。

19 世纪（约 1860—1870 年代 [?]）魏尔斯特拉斯（Weierstrass）构造出了处处连续、处处不可导的函数（00:59:02—01:00:24）：用参数化的级数，把幂函数（ana^{n}）放到 cos （三角函数）里面，形如∑ancos⁡(bnπx)\sum a^{n}\cos(b^{n}\pi x)，0<a<10<a<1， b 落在某些范围里。老师提醒：「你看这个玩意是不是又出现了一次 —— 一个数的多少次方，再把幂函数放在 cos 里面，也是靠这个长出来的、构造出来的」（00:59:49—01:00:08）。后面还有人改进，把充分必要条件都做了出来（00:59:44）。当 0<a<1 时它肯定是连续函数（01:00:33—01:00:57），而 b 在某些范围里就是处处不可导（01:01:02）。这个例子颠覆了人类对「函数」的直观印象：连续和可导完全可以分割开（01:01:16）。

到了 1940 年代 [?]，有了更高的观点（01:01:30—01:02:16）：对函数的认识不再停留在「逐点定义的一些函数」，而是把整个函数类（函数空间）当作对象；以前在整个实数集上变更一个函数，得到的还是这一类函数。这一章处理的就是整个函数类：讲连续函数的定义不是针对某一个函数，而是针对一类函数，把具有连续性质的函数挑出来放在一起，构成连续函数类（01:02:46—01:03:03）。「而且呢在处理这个小东西之前，就已经告诉你，不要把连续和可导混为一谈，可导是下一章要干的事情」（01:02:25）。

例题/证明 21（01:00:02）｜ 构造：Weierstrass 处处连续、处处不可导函数 [补全]

命题：构造一个在 R 上处处连续、但处处不可导的函数。

思路：把一列「频率越来越高、振幅越来越小」的三角函数叠加。振幅按几何级数衰减，保证级数一致收敛（从而连续）；频率按几何级数增长，保证差商不收敛（从而不可导）。老师当堂只报了名字、参数范围与大致形式，没有写出证明；下面的构造条件与推导要点是 [补全]，不是当堂讲的，仅作自学参照。

意义与易错点（老师点出）：它颠覆了人类对函数的直观印象 —— 连续与可导完全可以分割（01:01:16）；不要把连续和可导混为一谈，可导是下一章的事。

01:02:31—01:07:50 ｜ 在一点连续的定义：三件事、单侧连续与 ε - δ 语言

「下面就直接讲定义」（01:02:31）。希望大家掌握的是一个在集合上定义的函数在某一点连续（01:04:08）。前提是：函数在该点有定义，且极限存在（01:04:46）。

定义（01:04:52）：如果函数 f 在x0x_{0}这一点的极限等于 f 在这一点的值，即

公式
limx→x0f(x)=f(x0),\lim_{x\to x_{0}}f(x)=f(x_{0}),

就称 f 在x0x_{0}处连续。

单侧连续（01:05:06—01:05:40）：

  • 若 f 在x0x_{0}的左极限等于f(x0)f(x_{0})，即f(x0−0)=limx→x0−f(x)=f(x0)f(x_{0}-0)=\lim\limits_{x\to x_{0}^{-}}f(x)=f(x_{0})，称 f 在x0x_{0}处左连续；
  • 若 右极限 等于f(x0)f(x_{0})，即f(x0+0)=limx→x0+f(x)=f(x0)f(x_{0}+0)=\lim\limits_{x\to x_{0}^{+}}f(x)=f(x_{0})，称 f 在x0x_{0}处右连续。

于是 f 在x0x_{0}连续 ⇔ 既左连续又右连续 [补全]。

老师反问（01:05:50—01:06:12）：「你觉得乾隆为什么要走那么多路呢？」—— 一开始是因为函数极限这个概念没理清楚；一旦函数极限的概念清楚了，连续这个概念按正常逻辑顺理成章就定义出来了，「其实也就等于」一句「极限值等于函数值」而已。

回顾两个概念的差别，这是分析学的常规策略（01:06:21—01:06:55）：

  • 介绍邻域时，要求函数在x0x_{0}的一个邻域里都有定义；
  • 讨论 f 在x0x_{0}的极限时，只要求在 去心邻域U∘(x0)U^{\circ}(x_{0})里有定义，x0x_{0}本身有没有函数值无所谓；
  • 讨论 f 在x0x_{0} 连续时，「你这一点总要有函数值吧」，否则拿什么去跟极限比。

所以定义域在这里起了作用。于是「在一点连续」要凑齐三件事（01:07:07—01:07:15）：① f 在x0x_{0}（及其邻域）有定义；② limx→x0f(x)\lim\limits_{x\to x_{0}}f(x)存在；③ 极限值 = 函数值。

用 ε - δ 语言说就是（01:07:25—01:07:47）：

公式
∀ε>0,∃δ>0,使得当|x−x0|<δ时|f(x)−f(x0)|<ε.\forall\,\varepsilon>0,\ \exists\,\delta>0,\ \text{使得当}\ |x-x_{0}|<\delta\ \text{时}\ |f(x)-f(x_{0})|<\varepsilon.

与函数极限定义的差别在于：这里不去掉x=x0x=x_{0}（不要求0<|x−x0|0<|x-x_{0}|），因为当x=x0x=x_{0}时|f(x)−f(x0)|=0<ε|f(x)-f(x_{0})|=0<\varepsilon本来就成立（01:07:47）。

01:08:03—01:14:43 ｜ 定义在一般集合 D 上的连续、孤立点与 ε - δ 定义

现在要问（01:08:03）：如果 f 定义在一个集合 D 上，怎么说「 f 在集合上某一点连续」？写定义时要换一下写法。

回忆函数限制的记号（01:09:14—01:09:29）：f|Qf|_{Q}表示把定义在整个实数轴上的函数限制到有理数集 Q 上。例如常数函数 f≡1 定义在 R 上，限制到 Q 上就是「定义域为 Q 、取值全等于 1 」的函数。「我下面要给的这个定义，是想要为这样的函数和这样的函数都要可以服务的」—— 它们都是定义在一个集合上的函数（01:09:36—01:09:40）。

孤立点（01:09:49—01:10:19）：讲完聚点之后，孤立点是「买二送一送给你的」；聚点的一个强形式（或弱形式，字幕含混）就是孤立点。定义：若存在x0x_{0}的一个邻域，其中除了x0x_{0}自己以外没有集合 D 中其他的点，就称x0x_{0}是 D 的孤立点（01:10:07）。对于这种点，它也有这样的权利来讨论函数在这一点是不是连续（01:10:19）。老师强调（01:10:32—01:10:46）：「这个是非常重要的，并不是说我要搞怪」，把定义写成这样不是故意搞坏，它对后期的分析很重要（牵涉到相对邻域）。

正式定义（01:11:10—01:11:49）：设 f:D→R ，x0∈Dx_{0}\in D。若

公式
∀ε>0,∃δ>0,使得对一切x∈D,|x−x0|<δ⇒|f(x)−f(x0)|<ε,\forall\,\varepsilon>0,\ \exists\,\delta>0,\ \text{使得对一切}\ x\in D,\ |x-x_{0}|<\delta\ \Longrightarrow\ |f(x)-f(x_{0})|<\varepsilon,

就称 f 在x0x_{0}处（相对于 D ）连续。

与上一小节定义的第一点不同（01:11:59—01:12:33）：那时讨论x0x_{0}是否连续，要求 f 在x0x_{0}的一个邻域里都有定义；而现在 D不一定包含x0x_{0}的任何邻域（例如 D=Q 时，x0x_{0}的任意邻域里都有不属于 D 的无理数）。这更适合我们「在定义域上标准地定义函数」的做法；「你们说过他有资格，他就是有资格」，不管后面走到哪一步，这样的点都有资格来讨论是不是连续。

把 ε - δ 改写一下（01:12:54—01:13:51）：本来是在实数集里对x0x_{0}作一个半径 δ>0 的邻域Uδ(x0)U_{\delta}(x_{0})；现在要问的是这个邻域与 D 的交集Uδ(x0)∩DU_{\delta}(x_{0})\cap D里那些自变量，对应的函数值是否满足|f(x)−f(x0)|<ε|f(x)-f(x_{0})|<\varepsilon。因为 f 只定义在 D 上，只有交集中的点才有函数值可谈（01:13:51）。

由此反推（01:14:18—01:14:43）：根源其实出在极限上，式子还是

公式
limx→x0x∈Df(x)=f(x0),\lim_{\substack{x\to x_{0}\\ x\in D}}f(x)=f(x_{0}),

只是要把 x限制在 D 里。这个限制「写不写其实都没关系的」—— 本来一个函数就是要看它的定义域在哪里（01:14:40）；这里特意写出来，是为了强调定义（定义域）不一样（01:14:43）。

四、函数在一点的连续性与连续函数（01:14:56—01:52:28）

01:14:56—01:20:52 ｜ 函数在一点连续、孤立点与「集合上的连续函数」

前面一直在讲「函数在这一点的极限是否等于函数在这一点的函数值」，连续就是把这件事写成定义。沿用上一节的约定：设 f 是定义在集合 D⊂R 上的函数，x0∈Dx_0\in D。称 f 在x0x_0处连续，若

公式
∀ε>0,∃δ>0,当 x∈U(x0,δ)∩D 时 |f(x)−f(x0)|<ε.\forall\,\varepsilon>0,\ \exists\,\delta>0,\ \text{当 } x\in U(x_0,\delta)\cap D \text{ 时 } |f(x)-f(x_0)|<\varepsilon.

注意这里 x 取在U(x0,δ)∩DU(x_0,\delta)\cap D里，不要求x≠x0x\neq x_0；这与函数极限lim⁡x→x0f(x)\lim_{x\to x_0}f(x)的定义（要求去心邻域、x≠x0x\neq x_0）是唯一实质区别。因为x=x0x=x_0时|f(x0)−f(x0)|=0<ε|f(x_0)-f(x_0)|=0<\varepsilon恒成立，把x0x_0放进邻域里并不添麻烦，反而让孤立点也能讨论连续。

老师先问：设P0P_0是定义域 P 的孤立点， f 在P0P_0连续吗？—— 答：连续（见证明 1）。

接着老师反问：以前（按教材的标准定义）说孤立点不连续，是为什么？它违反的其实不是后面的 ε - δ 条件，而是前提。数学分析教材在定义「在一点连续」时，前提是函数要在这一点的整个邻域里都有定义；孤立点在邻域里除自身外没有定义域的点，按教材的说法「根本就没有资格进行后面的讨论」。我们的定义只要求x∈U(x0,δ)∩Dx\in U(x_0,\delta)\cap D，允许孤立点，所以没问题。——「有没有问题？没问题是吧。」

再补一个记号：定义 1.4.4[?] 讲的就是这件事——函数本来可以定义在一个更大的集合上，把这个定义在大集合上的函数限制到小集合上；若限制后的函数在小集合上连续，我们就称函数在这个小集合上连续。下面看例子。

例题/证明 22（01:14:56）｜ 孤立点处函数必连续

命题：设 f:P→R ，P0∈PP_0\in P是 P 的孤立点，则 f 在P0P_0处连续。

思路：孤立点意味着P0P_0附近有一个邻域，除了P0P_0本身再没有 P 的点；把 δ 取到这个邻域里，U(P0,δ)∩P={P0}U(P_0,\delta)\cap P=\{P_0\}，定义里的不等式自动成立。

逐步推导：

  1. 由P0P_0是 P 的孤立点，存在δ0>0\delta_0>0使得U(P0,δ0)∩P={P0}U(P_0,\delta_0)\cap P=\{P_0\}（这就是孤立点的定义：这一点的邻域交上 P 只剩它自己）。
  2. 任给 ε>0 ，取δ=δ0\delta=\delta_0。
  3. 当x∈U(P0,δ)∩P={P0}x\in U(P_0,\delta)\cap P=\{P_0\}时，必有x=P0x=P_0，于是
    |f(x)−f(P0)|=|f(P0)−f(P0)|=0<ε.|f(x)-f(P_0)|=|f(P_0)-f(P_0)|=0<\varepsilon.
  4. 故∀ε>0,∃δ=δ0>0,∀x∈U(P0,δ)∩P:|f(x)−f(P0)|<ε\forall\varepsilon>0,\ \exists\delta=\delta_0>0,\ \forall x\in U(P_0,\delta)\cap P:\ |f(x)-f(P_0)|<\varepsilon。

结论： f 在孤立点P0P_0处连续。

老师点出的意义 / 易错点：这里的「连续」是按我们「定义在集合上的函数、在该集合每点连续」的定义说的。若按教材「必须在点的邻域内处处有定义」的前提，孤立点连讨论的资格都没有——以前说「孤立点不连续」，违反的正是这一条前提，而不是 ε - δ 不等式。这提醒我们：连续性的结论会随定义域（集合）而变，讨论前先看函数在哪个集合上。

例题/证明 23（01:17:58）｜ 狄利克雷函数限制在有理数集上是连续函数

题目：狄利克雷函数 D(x) 是连续函数吗？老师随即纠正：「我随便问的，现在还没有进入『连续函数』这个概念，我进入的是『函数在某一点连续』。」要问的是：这个函数在有理数点处连续吗？

思路：把定义域看清楚。第一节课讲过D(x)={1,x∈Q0,x∉QD(x)=\begin{cases}1,&x\in\mathbb{Q}\\0,&x\notin\mathbb{Q}\end{cases}，但这里说的是定义域本来就限制在 Q 上的那个函数D|QD|_{\mathbb{Q}}，而不是「 R 上的 D 再限制到 Q 」。

逐步推导：

  1. 在 Q 上，D|Q(x)≡1D|_{\mathbb{Q}}(x)\equiv 1，即D|QD|_{\mathbb{Q}}是常值函数（值恒为 1）。
  2. 任取x0∈Qx_0\in\mathbb{Q}，任给 ε>0 ，取任意 δ>0 ；当x∈U(x0,δ)∩Qx\in U(x_0,\delta)\cap\mathbb{Q}时
    |D|Q(x)−D|Q(x0)|=|1−1|=0<ε.|D|_{\mathbb{Q}}(x)-D|_{\mathbb{Q}}(x_0)|=|1-1|=0<\varepsilon.
  3. 故D|QD|_{\mathbb{Q}}在 Q 的每一点都连续。

结论：D|QD|_{\mathbb{Q}}是 Q 上的连续函数（常值函数当然连续）。作为对照，若把 D 看成定义在 R 上的函数，它在任何点都不连续。

老师点出的意义 / 易错点：「你要分清楚啊」——并不是说 R 上的狄利克雷函数「限制在有理数集上」之后变连续了，而是这个函数一直就定义在 Q 上；在 Q 上看，它就是常值函数 1。连续与否是相对于定义域这个集合而言的，同一个解析式换一个定义域，结论可以完全相反。顺带给出以后的通用记号： f 是定义在集合 E 上的函数， f 在 E 上每一点连续，就称 f 是 E 上的连续函数。教材的标准定义不允许孤立点（要求邻域内处处有定义），我们的定义允许，所以「集合上的连续函数」这个概念与教材不冲突、且更一般。

然后老师给出「连续函数」的定位：函数在一点连续，是一个真正的定义；函数是一个连续函数，则是顺水推舟——要称 f 是 E 上的连续函数，只要遍历 E 的每一点、逐点验证连续即可。这个说法是通用的，后面闭区间、一般集合都这么用。

01:20:57—01:22:08 ｜ 闭区间上连续与端点的单侧连续

回到 x∈A 、 f 定义在 [a,b] 上的情形： f 是闭区间 [a,b] 上的连续函数，应当指 f 在 [a,b] 上每一点都连续。这里有一个小小的 technique 问题：按书上的教材，闭区间端点 a 处只能谈右连续、 b 处只能谈左连续（因为邻域交上 [a,b] 只剩单侧），教材要先单独定义单侧连续再处理端点。

例题/证明 30（01:43:13）｜ 复合函数连续性的 ε - δ 证明

命题：设g:Dg→Rg:D_g\to\mathbb{R}在x0∈Dgx_0\in D_g连续，f:Df→Rf:D_f\to\mathbb{R}在y0=g(x0)∈Dfy_0=g(x_0)\in D_f连续，且g(Dg)⊂Dfg(D_g)\subset D_f（复合 f∘g 有意义）。则 f∘g 在x0x_0连续。

思路：外层 f 给一个 ε ，先在y0y_0处「弹出」一个 η 邻域；内层 g 在x0x_0连续，再把这个 η 拉回到x0x_0的一个 δ 邻域；复合之后两个不等式串起来。

逐步推导：

  1. 任给 ε>0 。由 f 在y0y_0连续，存在 η>0 ，使
    y∈U(y0,η)∩Df⇒|f(y)−f(y0)|<ε.y\in U(y_0,\eta)\cap D_f\ \Longrightarrow\ |f(y)-f(y_0)|<\varepsilon.
  2. 对上述 η>0 ，由 g 在x0x_0连续，存在 δ>0 ，使
    公式
    x∈U(x0,δ)∩Dg⇒|g(x)−g(x0)|<η,即 g(x)∈U(y0,η).x\in U(x_0,\delta)\cap D_g\ \Longrightarrow\ |g(x)-g(x_0)|<\eta,\ \text{即 } g(x)\in U(y_0,\eta).

    |f(g(x))−f(g(x0))|=|f(y)−f(y0)|<ε.|f(g(x))-f(g(x_0))|=|f(y)-f(y_0)|<\varepsilon.

01:52:37—01:53:48 ｜ 连续是逐点的定义：严格单调函数的不连续点可以很多

说「一个函数在集合（区间）上连续」时，这句话其实是一个逐点的定义。它真正的定义是「在集合上每一点都连续」；所以要真正落实到证明的时候，必须把某一点x0x_0固定下来，逐点去验证。于是间断点不一定只有一个：有多少个不连续点，就关注多少个点，把这些点排除掉之后，剩下的点才谈得上连续。

最容易给出的「严格单调但不连续」的函数，它的不连续点就可以不止一个；事实上严格单调函数的不连续点可以有很多（至多可数，这是可选的结论，这里先不谈）。所以「严格单调」并不蕴含「连续」——这一点要记住，后面会反复用到。

01:58:55—02:00:11 ｜ 为什么把定义域取成开区间

定理里特意把定义域设成开区间 (a,b) 。若取闭区间 [a,b] ，端点 a 、 b 处只能取单侧邻域： a 处只有右邻域， b 处只有左邻域，连续就只能谈右连续、左连续， δ 邻域的取法要整个改成单侧，画出来的图也不一样。开区间把端点处的单侧连续问题回避掉了。

于是得到一个看起来有点奇怪的结论：在开区间上严格单调的函数（没有要求它连续），它的反函数定义在值域 f(I) 上，并且反函数在这个集合上是连续的。若把 f(I) 记成一个集合，反函数就定义在这个集合上。

02:00:11—02:07:39 ｜ 与教材定理的对照：条件、结论，以及「值域是区间」其实是假设

第一层次的理解：我们是用 ε - δ （邻域）的比较、直接从连续的定义出发，得到「区间上严格单调递增的函数必有反函数，且反函数连续」。

第二层次：把它与课本上的定理对照，让同学们「找不同」。课本定理的条件多了一条「连续」，而且它把「值域是一个区间」明明白白写进了条件里。老师核对定理编号（3.2 / 3.28 之类 [?]）、翻了三套教材后起初以为「值域是区间」是教材由连续推出的结论；再仔细看才发现：教材是把它作为假设给出的，不是结论——这正是教材的「诡谲之处」，老师也当场承认自己看书不仔细。

把两边摆在一起看：

  • 我们讲的定理 2′：条件里没有连续，结论里也没有（不要求原函数连续）；只要严格单调就足够。
  • 课本定理：闭（开）区间上连续且严格单调 ⇒ 反函数连续，且像（值域）是一个区间。

课本为什么需要「值域是区间」这一条？因为课本讲连续是「每一个点都要有一个（双侧）邻域抬出来」；只有值域是区间，反函数定义域里每一点才有完整的双侧邻域可用。而「连续 ⇒ 像是区间」本来该由后面的介值定理推出，课本直接把它假设进去，就绕开了还没讲的介值定理——所以教材比较狡猾。开区间与闭区间的差别倒不太本质，主要回避的是端点的左连续问题：端点一侧只有单侧邻域（一个是左邻、一个是右邻），闭区间上严格单调时端点处只能谈单侧连续。

若再假设 f 连续，就多得到一条：它的像（值域）是一个区间；这条要用后面的介值定理，放到讲介值定理时再补。要学会看书、学会「找不同」：同学们找出的「严格单调递增」等差别也对、也重要，但没把最要紧的那一条找出来——它在下面 02:12:20 的谬论里才会显出来。

02:07:39—02:12:20 ｜ 定理 2″：闭区间上连续且有反函数，则反函数连续

例题/证明 34（02:07:39）｜ 定理 2″：连续 + 有反函数 ⇒ 严格单调（反证法 + 介值定理）

命题　设 f∈C[a,b] 且 f 在 [a,b] 上有反函数（即 f 为单射），则 f 在 [a,b] 上必严格单调；再由定理 2′，反函数f−1f^{-1}在 f([a,b]) 上连续。

思路　反证。假设 f 不单调，则能在 [a,b] 上找到三个点x1<x2<x3x_1<x_2<x_3，其函数值先升后降（或先降后升），「比单调的情形更丰富」。在f(x2)f(x_2)与f(x1),f(x3)f(x_1),f(x_3)之间取一个中间值，用介值定理在(x1,x2)(x_1,x_2)与(x2,x3)(x_2,x_3)内各调出一点使函数值相等，这就与「 f 有反函数（单射）」矛盾。老师点明：这里「动了一下介值定理」，用了这个高级一点的工具；因为这个事实和本节讲的东西相关，就把它放在一起讲了，而介值定理要到后面才正式讲。知道介值定理的同学可以先自己尝试想一下这件事对不对。

逐步推导

  1. 反设 f 在 [a,b] 上不单调。[补全] 单调递增是「对所有x1<x2x_1<x_2都有f(x1)≤f(x2)f(x_1)\le f(x_2)」，这个「对所有点」要遍历到位；否定它即存在x1<x2<x3x_1<x_2<x_3使f(x2)f(x_2)不同时介于f(x1)f(x_1)与f(x3)f(x_3)之间。以下取先升后降的情形：
    公式
    f(x1)<f(x2)且f(x3)<f(x2).f(x_1)<f(x_2)\quad\text{且}\quad f(x_3)<f(x_2).
    （先降后升时把不等号反向、改用 min 与下界，论证完全一样。）
  2. 取 c 满足
    max⁡{f(x1),f(x3)}<c<f(x2),\max\{f(x_1),\,f(x_3)\}<c<f(x_2),
    这样的 c 存在，因为max⁡{f(x1),f(x3)}<f(x2)\max\{f(x_1),f(x_3)\}<f(x_2)。一开始找到的x1,x2,x3x_1,x_2,x_3函数值不一定相等，但用介值定理就一定能在两段里各挑出一点把函数值凑成相等。
  3. 在[x1,x2][x_1,x_2]上 f 连续，且f(x1)≤max⁡{f(x1),f(x3)}<c<f(x2)f(x_1)\le\max\{f(x_1),f(x_3)\}<c<f(x_2)。由介值定理，存在u∈(x1,x2)u\in(x_1,x_2)使 f(u)=c 。
  4. 在[x2,x3][x_2,x_3]上 f 连续，且f(x3)≤max⁡{f(x1),f(x3)}<c<f(x2)f(x_3)\le\max\{f(x_1),f(x_3)\}<c<f(x_2)。由介值定理，存在v∈(x2,x3)v\in(x_2,x_3)使 f(v)=c 。
  5. 于是 u<v 但 f(u)=f(v)=c ， f 不是单射，与「 f 有反函数」矛盾。
  6. 故反设不成立， f 在 [a,b] 上严格单调；再由定理 2′ 得f−1f^{-1}在 f([a,b]) 上连续。

结论　闭区间上的连续函数只要有反函数，就自动严格单调，反函数自动连续。

意义与易错点　「单调」的否定一定要写对：不能只盯着两个点，要找出三个点x1<x2<x3x_1<x_2<x_3使函数值先升后降或先降后升，再用介值定理把两个相等的函数值「调」出来，最后撞上单射这个条件。[补全]：以上 1—6 步中把「不单调」化成三个点、 c 的选取以及介值定理的逐段使用，是按数学上正确的方式补足的，不是当堂讲的，仅作自学参照；当堂口述的是「反证、假设不单调 ⇒ 存在三个点x1<x2<x3x_1<x_2<x_3使函数值先升后降 ⇒ 用介值定理找两个函数值相等的点 ⇒ 与有反函数矛盾 ⇒ 得严格单调」这条思路链。

例题/证明 35（02:12:20）｜ 找错：为什么不能把定义域换成任意集合

题目　若把定理 2′ 里的「区间」换成「任意集合」，对任意集合上的严格单调函数照样做一遍：先取反函数（仍严格单调），再取一次反函数回到原函数，套两次定理，就会「证明」出每一个严格单调函数都是（严格单调的）连续函数。这显然是谬论——前面刚说过严格单调函数的不连续点可以有很多。问：错在哪里？

思路　每一步看着都对，结论却肯定错，说明某一步偷偷用了一个没被写进条件的性质。刚才「找不同」时同学们找出的「严格单调递增」等差别也对、也重要，但没把最要紧的一条找出来：出发的集合必须是区间。

逐步推导

  1. 定理 2′ 的证明中，第 2 步取了X0±ε∈(a,b)X_0\pm\varepsilon\in(a,b)，第 3、4 步用了f(X0−ε)f(X_0-\varepsilon)、f(X0+ε)f(X_0+\varepsilon)并把Y0Y_0夹在中间；这些都要求X0X_0是区间的内点、两侧都还有定义域里的点。
  2. 「连续」的定义要在每一点给出双侧邻域；只有 f(I) 是区间时，反函数定义域里每点才有完整的双侧邻域可谈。
  3. 若出发的只是一个集合 E （不是区间）， f(E) 未必是区间；第二次把定理套在f−1:f(E)→Ef^{-1}:f(E)\to E上时，「连续」的邻域定义就无从依附，那一步是不合法的。
  4. 于是「如果区间这个条件不重要、只要求是一个集合，那这个证明就对了」——可一旦「对了」，就会得到「严格单调函数必连续」这个荒谬结论。可见「区间」这个条件不但重要，而且是证明中反复被用到的地方。

结论　定理 2′（以及定理 2″）的证明很强地依赖 [a,b] 是一个区间，必须把「定义域是区间」单独拎出来。

意义与易错点　老师让大家回去把证明过程逐步核对：「我在哪个地方利用了 [a,b] 是区间？」——这是大家容易犯错的地方：只看每一步的不等式都成立，却没注意每一步成立的前提条件。找不同要找到条件、结论里最要紧的那一条，而不是只找到表面上写着的差异。

02:15:47—02:20:31 ｜ 连续映射的逆未必连续：绕圆一周的反例

把几件事串起来看：前面有「出发是区间 + 严格单调」（定理 2′）、「出发是闭区间 + 连续 + 有反函数」（定理 2″）。现在换一个角度，从映射的角度问：出发集合是区间、映射连续、且是单射（有逆映射），逆映射是不是一定连续？此时单调性没有了（向量值映射没有单调性可言），但出发的确实是一个区间。

向量值函数（连续映射）的连续概念还没正式讲过，但可以依葫芦画瓢：连续无非就是「在这一点给像（目标）一个邻域，能不能在自变量那边产生一个 δ 邻域，使得这个邻域里的点映过去都落回给定的像邻域」——也就是「函数值抖一抖，自变量走一走，能不能回到这个函数值邻域里」。按这个定义去检验，就得到反例。

例题/证明 36（02:15:47）｜ 绕圆一周：连续单射的逆映射在粘连点不连续

构造　[补全] 取

02:20:31—02:24:42 ｜ 间断点的分类

间断点就快速讲一下，这里没多少新东西。我们学了连续：连续就是式子

公式
limx→x0f(x)=f(x0)\lim_{x\to x_0}f(x)=f(x_0)
成立。所谓间断点，就是这个式子不成立的点。式子不成立，分情况：

  • 极限lim⁡x→x0f(x)\lim_{x\to x_0}f(x) 存在（有限），但不等于该点的函数值f(x0)f(x_0)；若 f 在x0x_0干脆没有定义，这一项直接不成立，也就不必去谈相等了。这种叫可去间断点（有的教材归为第一类）。这类「差得稍微好一点」：函数在该点的极限是存在的，只是这一点的函数值没对上。

  1. 由重要极限lim⁡x→0sin⁡xx=1\lim_{x\to0}\dfrac{\sin x}{x}=1，故lim⁡x→0f(x)=1\lim_{x\to0}f(x)=1存在且有限。
  2. 但f(0)=0≠1=lim⁡x→0f(x)f(0)=0\neq 1=\lim_{x\to0}f(x)，即lim⁡x→0f(x)≠f(0)\lim_{x\to0}f(x)\neq f(0)，连续的定义式不成立。
  3. 极限存在、只是与该点函数值对不上，按分类 x=0 是可去间断点：只要把 f(0) 补改成 1 （当初若没在 0 定义，就把极限值补上去），函数就在 0 连续——「可去」即指这个间断可以被去掉。

结论x=0 是可去间断点。

易错点　判断时先算极限，再看该点取值；不要一见分母为 0 就以为极限不存在。这类间断「差得稍微好一点」，函数在该点的极限是存在的。

例题/证明 38（02:23:05）｜ 跳跃间断点：左右极限存在但不相等

题目　[补全] 当堂是按「左右极限存在、但不相等」的示意讲的，未写解析式；下面给出标准例子，不是当堂讲的，仅作自学参照：

公式
f(x)=sgn⁡(x)={1,x>0,0,x=0,−1,x<0.f(x)=\operatorname{sgn}(x)=\begin{cases}1,&x>0,\\ 0,&x=0,\\ -1,&x<0.\end{cases}
判断 x=0 的间断点类型。

思路　分别算左、右极限，看它们是否都存在、是否相等。

逐步推导

  1. 右极限f(0+)=lim⁡x→0+1=1f(0+)=\lim_{x\to0^+}1=1；左极限f(0−)=lim⁡x→0−(−1)=−1f(0-)=\lim_{x\to0^-}(-1)=-1。
  2. 左右极限都存在且有限，但 f(0+)=1≠−1=f(0−) ，故lim⁡x→0f(x)\lim_{x\to0}f(x)不存在。
  3. 按分类，左右极限存在但不相等 ⟹ x=0 是跳跃间断点（有的教材归为第一类）。

结论x=0 是跳跃间断点。

易错点　这类间断「长的样子」就是图像在那里跳一下，判别依据只有「左右极限都存在但不相等」，与该点函数值取多少无关（本例 f(0)=0 ，改成别的值也不影响类型）。别用「第一类、第二类」去硬记，按形态判最稳。

例题/证明 39（02:23:25）｜ 本性间断点：左右极限至少有一个不存在

题目　[补全] 当堂提到「这样的函数在 0 点的极限是不存在的，所以零点是它的本性间断点」，未写出解析式；下面给出标准例子，不是当堂讲的，仅作自学参照：

公式
f(x)=sin⁡1x,x≠0.f(x)=\sin\frac{1}{x},\qquad x\neq 0.
判断 x=0 的间断点类型。

思路　看 x→0 时函数值是否趋于定值；取两列都趋于 0 的点，使函数值趋于不同的数。

逐步推导

  1. 取xn=12nπ+π2→0x_n=\dfrac{1}{2n\pi+\frac{\pi}{2}}\to0，则f(xn)=sin⁡(2nπ+π2)=1→1f(x_n)=\sin\!\left(2n\pi+\tfrac{\pi}{2}\right)=1\to1。
  2. 取xn′=12nπ−π2→0x_n'=\dfrac{1}{2n\pi-\frac{\pi}{2}}\to0（ n 充分大），则f(xn′)=sin⁡(2nπ−π2)=−1→−1f(x_n')=\sin\!\left(2n\pi-\tfrac{\pi}{2}\right)=-1\to-1。
  3. 两列都趋于 0 而函数值趋于不同值，故lim⁡x→0f(x)\lim_{x\to0}f(x)不存在；并且 f(0+) 、 f(0−) 都不存在（在 −1 与 1 之间无限振荡）。
  4. 按分类，左右极限至少有一个不存在（这里两个都不存在）⟹ x=0 是本性间断点（有的教材归为第二类）。

结论x=0 是本性间断点。

易错点　真的就按「式子lim⁡x→x0f(x)=f(x0)\lim_{x\to x_0}f(x)=f(x_0)为什么不成立」来分类：是极限存在而值不对（可去）、是左右极限存在但不等（跳跃）、还是至少一个单侧极限根本不存在（本性）。不要去死记第一类第二类的编号，各教材并不一致。

有同学提问：「他在这一点不连续，不知道为什么（怎么）证明它不连续」；老师先确认「我不知道你要问的是什么」，再回应的要点是：这不是把点代进去算一个数值就能说清的事，要回到邻域 / δ 的定义上——「取 δ 还是不知道」，正是卡在这里。关键是看「这里面的哪些点能够落在这个（像的）邻域、这个集合上」，再取上面那个较小的量，经过 f 映射过去；也就是回到 ε - δ 定义里「给函数值一个邻域，看自变量能不能找一个 δ 邻域把像全部送回去」这句话上。
