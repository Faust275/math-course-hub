§11.6 傅里叶级数

除了幂级数,还有一种常用的函数级数就是三角级数

a0+∑n=1∞(ancosnx+bnsinnx),(11.6.1)a _ {0} + \sum_ {n = 1} ^ {\infty} \left(a _ {n} \cos n x + b _ {n} \sin n x\right),\tag{11.6.1}

其中 a0,a1,a2⋯,b1,b2⋯a_{0}, a_{1}, a_{2} \cdots, b_{1}, b_{2} \cdots 都是与 x 无关的常数，称为三角级数(11.6.1)的系数.

利用熟知的三角公式

acosx+bsinx=Asin(x+φ),a \cos x + b \sin x = A \sin (x + \varphi),

其中 A=a2+b2,φ=arcsinaAA = \sqrt{a^2 + b^2}, \varphi = \arcsin \frac{a}{A} , (11.6.1)式可以改写成

a0+∑n=1∞Ansin(nx+φn).(11.6. ')a _ {0} + \sum_ {n = 1} ^ {\infty} A _ {n} \sin (n x + \varphi_ {n}).\tag{11.6. '}

由于(11.6.1')式中的通项 Ansin(nx+φn)A_{n}\sin (nx + \varphi_{n}) 恰好表示以 AnA_{n} 为振幅， φn\varphi_{n} 为立相, 以 2πn\frac{2\pi}{n} 为周期的简谐振动, 所以(11.6.1')式表明, 三角级数实际上是无穷多个简谐波的叠加. 这也正是傅里叶级数的原始来源.

三角级数(11.6.1)的部分和

Sn(x)=a0+∑k=1n(akcoskx+bksinkx)S _ {n} (x) = a _ {0} + \sum_ {k = 1} ^ {n} \left(a _ {k} \cos k x + b _ {k} \sin k x\right)

称为 nn 阶三角多项式. 显然, 三角级数(11.6.1)的和函数 S(x)S(x) 存在时, 是一个周期为 2π2\pi 的函数. 与幂级数不同的是, S(x)S(x) 不但不是无穷次可微的, 甚至不是连续函数. 这非但不是缺点, 反而正是它的优点. 这使我们可以指望将较差的函数展开成形如(11.6.1)式的三角级数.

这个问题是在十九世纪初, 由当时还称不上数学家的法国人傅里叶 (Fourier) 最先解决的. 所以后人把这种从函数展开而得到的三角级数称为傅里叶级数.

当时,傅里叶在研究数学物理方程中的热传导方程时注意和发现了如下四点:

  1. 周期为 TT 的函数可以通过变量代换而化成周期为 2π2\pi 的函数；
  2. 非周期函数可以通过取它在区间 [a,b][a, b] 上的限制后进行周期延拓而化成周期为 b−ab - a 的周期函数；
  3. 周期为 2π2\pi 的函数在某些条件下可以展开成形如(11.6.1)式的三角级数；
  4. 热传导方程的某些定解问题可以通过分离变量和将已知函数展开成三角级数的方法来解决, 这就是后人所说的傅里叶方法.

然而, 傅里叶方法中的关键的第 3 点的证明不够严格. 他利用不严格的证明建立了在当时数学界看来不可思议的结果——用周期函数项的级数表达非周期函数, 进而用这个尚显靠不住的结果解决了重要的热传导方程的求解问题, 以致遭到当时数学界中许多名人, 包括一些权威人士的怀疑和否定. 直到多年以后, 这一开创性的成果才被逐渐醒悟过来的数学界所接受, 学习, 研究和发展并一发不可收拾. 直到形成一门独立的学科——调和分析, 而且直到今天, 这一理论还在蔓延和发展.

傅里叶本人与他的级数同时功成名就. 傅里叶得以名垂数学史册而傅里叶级数则成为分析学中不可缺少的重要组成部分, 特别是在偏微分方程的研究和求解过程中得到了极为广泛的应用.

一、傅里叶级数的引入

线性代数中讲过 nn 维欧氏空间, 其中的元素是 nn 维向量, 两个向量的内积定义为 nn 对相应分量的乘积之和. nn 维当然是有限维, 分析学中自然想到把 nn 维推广到无限维的情形, 并进一步地将离散表达的内积发展到连续表达的情形, 即用积分 ∫abf(x)g(x)dx\int_{a}^{b} f(x) g(x) \mathrm{d}x 来表示两个函数 f(x)f(x) 和 g(x)g(x) 的内积. 使这种内积有意义的函数组成一个函数空间. 傅里叶级数正是在这种意义下对函数进行讨论的. 至于对这种函数空间的进一步讨论, 已超出本书的范围, 将在以后的实变函数和泛函分析中继续进行.

在级数(11.6.1)中出现的函数1和所有的三角函数所组成的集合

{1,cosx,sinx,cos2x,sin2x,…,cosnx,sinnx,…}(11.6.2)\{1, \cos x, \sin x, \cos 2 x, \sin 2 x, \dots , \cos n x, \sin n x, \dots \}\tag{11.6.2}

称为三角函数系,它相当于向量空间中的一个基底.

定义 11.6.1概念定义

设 f(x)f(x) 和 g(x)g(x) 是 [a,b][a, b] 上的两个可积函数，如果

∫abf(x)g(x)dx=0,\int_ {a} ^ {b} f (x) g (x) \mathrm{d} x = 0,

则称函数 f(x)f(x) 与 g(x)g(x) 在 [a,b][a, b] 上正交. 如果函数系 {fn(x)}\{f_n(x)\} 中的任何两个函数都正交, 则称这个函数系为正交函数系.

定理 11.6.1核心定理
