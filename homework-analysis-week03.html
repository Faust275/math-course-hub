一、递推数列与渐近分析
第 1 题 Fibonacci 数列比值收敛于黄金分割率 必做题 📖 教材 第2章 🎬 09-22 课 🎬 09-24 课
#1
设 Fibonacci 数列 {Fn}\{F_n\} 定义为 F1=F2=1F_1 = F_2 = 1，Fn+2=Fn+1+FnF_{n+2} = F_{n+1} + F_n (n≥1n \ge 1)。
令 xn=Fn+1Fnx_n = \dfrac{F_{n+1}}{F_n}。证明数列 {xn}\{x_n\} 收敛，并求其极限。
💡 课本提示：由递推式得 xn+1=1+1xnx_{n+1} = 1 + \frac{1}{x_n}；利用分式线性变换（Möbius 变换）求不动点 ϕ=1+52\phi = \frac{1+\sqrt{5}}{2}，考察 |xn+1−ϕ|=|xn−ϕ|ϕxn|x_{n+1} - \phi| = \frac{|x_n - \phi|}{\phi x_n} 证明压缩收敛。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
黄金分割率（Golden Ratio）的连分数逼近。偶数项与奇数项分别单调递增和单调递减并夹逼于唯一正不动点。
【详细推理与解答】

解与证明：

1. 由递推关系式：

xn+1=Fn+2Fn+1=Fn+1+FnFn+1=1+1xnx_{n+1} = \frac{F_{n+2}}{F_{n+1}} = \frac{F_{n+1} + F_n}{F_{n+1}} = 1 + \frac{1}{x_n}

初始项 x1=1,x2=2,x3=32,x4=53,…x_1 = 1, x_2 = 2, x_3 = \frac{3}{2}, x_4 = \frac{5}{3}, \dots

，所有项均满足 1≤xn≤21 \le x_n \le 2。

2. 考察不动点方程：x=1+1x⇔x2−x−1=0x = 1 + \frac{1}{x} \iff x^2 - x - 1 = 0。正根为黄金分割数 ϕ=1+52≈1.618\phi = \frac{1 + \sqrt{5}}{2} \approx 1.618。

计算偏差距离：|xn+1−ϕ|=|1+1xn−(1+1ϕ)|=|1xn−1ϕ|=|xn−ϕ|ϕxn|x_{n+1} - \phi| = \left| 1 + \frac{1}{x_n} - \left(1 + \frac{1}{\phi}\right) \right| = \left| \frac{1}{x_n} - \frac{1}{\phi} \right| = \frac{|x_n - \phi|}{\phi x_n}

因为对一切 n≥2n \ge 2 均有 xn≥32x_n \ge \frac{3}{2}，且 ϕ>1.6\phi > 1.6，分母满足 ϕxn>1.6×1.5=2.4>2\phi x_n > 1.6 \times 1.5 = 2.4 > 2。记常数 k=12.4<12k = \frac{1}{2.4} < \frac{1}{2}：|xn+1−ϕ|≤k|xn−ϕ|≤kn−1|x2−ϕ||x_{n+1} - \phi| \le k |x_n - \phi| \le k^{n-1} |x_2 - \phi|

因为 0<k<10 < k < 1，当 n→∞n \to \infty 时 kn−1→0k^{n-1} \to 0。由夹逼定理：limn→∞|xn−ϕ|=0⇒limn→∞xn=ϕ=1+52\lim_{n\to\infty} |x_n - \phi| = 0 \implies \lim_{n\to\infty} x_n = \phi = \frac{1 + \sqrt{5}}{2}

证毕。

第 2 题 慢衰减非线性递推数列的 Stolz 渐近阶估计 必做题 📖 教材 第2章 🎬 09-22 课 🎬 09-24 课
#2
设 x0∈(0,1)x_0 \in (0, 1)，数列 {xn}\{x_n\} 满足 xn+1=xn(1−xn)x_{n+1} = x_n(1 - x_n) (n≥0n \ge 0)。
(1) 证明：limn→∞xn=0\lim_{n\to\infty} x_n = 0；
(2) 利用 Stolz 定理证明：limn→∞nxn=1\lim_{n\to\infty} nx_n = 1；
(3) 设调和数 Hn=∑k=1n1kH_n = \sum_{k=1}^n \frac{1}{k}，证明：limn→∞nxn−1Hn/n=−1\lim_{n\to\infty} \frac{nx_n - 1}{H_n / n} = -1，由此证明 1−nxn∼lnnn1 - nx_n \sim \frac{\ln n}{n}。
💡 课本提示：(1) 单调递减有下界 0；(2) 考虑倒数差 1xn+1−1xn=11−xn→1\frac{1}{x_{n+1}} - \frac{1}{x_n} = \frac{1}{1-x_n} \to 1，利用 Stolz 定理；(3) 进一步对偏差作高阶渐近展开。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
典型的弱非线性动力系统（Slow Invariant Manifold）。因为在不动点处导数为 1（非双曲不动点），收敛速度呈现慢如代数阶 1n\frac{1}{n} 的衰减行为。
【详细推理与解答】

(1) 证明：因为 x0∈(0,1)x_0 \in (0, 1)，由数学归纳法容易验证对一切 nn 恒有 xn∈(0,1)x_n \in (0, 1)。且 xn+1−xn=−xn2<0x_{n+1} - x_n = -x_n^2 < 0，数列严格单调递减且有下界 0。由单调有界定理，极限存在。令 limxn=L\lim x_n = L，代入 L=L(1−L)⇒L2=0⇒L=0L = L(1-L) \implies L^2 = 0 \implies L = 0。

(2) 证明：计算倒数的差分：

1xn+1−1xn=1xn(1−xn)−1xn=1−(1−xn)xn(1−xn)=11−xn\frac{1}{x_{n+1}} - \frac{1}{x_n} = \frac{1}{x_n(1 - x_n)} - \frac{1}{x_n} = \frac{1 - (1 - x_n)}{x_n(1 - x_n)} = \frac{1}{1 - x_n}

因为 limxn=0\lim x_n = 0，所以 limn→∞(1xn+1−1xn)=11−0=1\lim_{n\to\infty} \left(\frac{1}{x_{n+1}} - \frac{1}{x_n}\right) = \frac{1}{1 - 0} = 1。

由 Stolz 定理（∗∞\frac{*}{\infty} 型）：

limn→∞1/xnn=limn→∞(1xn+1−1xn)=1⇒limn→∞nxn=1\lim_{n\to\infty} \frac{1/x_n}{n} = \lim_{n\to\infty} \left(\frac{1}{x_{n+1}} - \frac{1}{x_n}\right) = 1 \implies \lim_{n\to\infty} nx_n = 1

(3) 证明：利用泰勒展开 11−xn=1+xn+O(xn2)\frac{1}{1-x_n} = 1 + x_n + O(x_n^2)

，累加求和得 1xn=n+lnn+O(1)\frac{1}{x_n} = n + \ln n + O(1)，交叉项相乘展开即得 1−nxn∼lnnn1 - nx_n \sim \frac{\ln n}{n}。证毕。

二、Toeplitz 矩阵加权平均理论
第 3 题 Toeplitz 正则矩阵极限保持定理与 Stolz 定理 必做题 📖 教材 第2章 🎬 09-22 课 🎬 09-24 课
#3
设有无穷下三角矩阵 (tnm)n≥m(t_{nm})_{n \ge m} 满足条件：
(i) 每一列元素趋于零：对任意固定 mm，limn→+∞tnm=0\lim_{n\to+\infty} t_{nm} = 0；
(ii) 各行元素绝对值之和有界：存在常数 K<+∞K < +\infty，使得对一切 nn，∑m=1n|tnm|≤K\sum_{m=1}^n |t_{nm}| \le K。
记 yn=∑m=1ntnmxmy_n = \sum_{m=1}^n t_{nm} x_m。证明：
(1) 若 limn→+∞xn=0\lim_{n\to+\infty} x_n = 0，则 limn→+∞yn=0\lim_{n\to+\infty} y_n = 0；
(2) 记 Tn=∑m=1ntnmT_n = \sum_{m=1}^n t_{nm}，若 limn→∞Tn=1\lim_{n\to\infty} T_n = 1 且 limxn=a\lim x_n = a 有限，则 limn→∞yn=a\lim_{n\to\infty} y_n = a；
(3) 说明 Stolz 定理是 Toeplitz 定理的直接推论。
💡 课本提示：利用分析学标准的 ε/2\varepsilon/2 裂项分割法：选足够大的 NN 控制后半段 |xm|<ε/(2K)|x_m| < \varepsilon/(2K)，再由列趋于零控制前半段有限项乘以 tnmt_{nm} 趋于零。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
泛函分析与求和法中的基础定理（Toeplitz-Silverman 定理）。它给出了无穷矩阵变换保持数列极限完全不变（即所谓正则变换 Regular Matrix）的充要条件。
【详细推理与解答】

(1) 证明：

任给 ε>0\varepsilon > 0。因为 xn→0x_n \to 0，存在正整数 NN，使得当 m>Nm > N 时，恒有 |xm|<ε2K|x_m| < \frac{\varepsilon}{2K}。

因为数列有界，记 M=max1≤m≤N|xm|M = \max_{1 \le m \le N} |x_m|。将 yny_n 拆为前后两部分（取 n>Nn > N）：

|yn|≤∑m=1N|tnm||xm|+∑m=N+1n|tnm||xm|≤M∑m=1N|tnm|+ε2K∑m=N+1n|tnm||y_n| \le \sum_{m=1}^N |t_{nm}||x_m| + \sum_{m=N+1}^n |t_{nm}||x_m| \le M \sum_{m=1}^N |t_{nm}| + \frac{\varepsilon}{2K}\sum_{m=N+1}^n |t_{nm}|

由条件 (ii)，后半部分 ≤ε2K·K=ε2\le \frac{\varepsilon}{2K} \cdot K = \frac{\varepsilon}{2}

。

由条件 (i)，每个固定的 m≤Nm \le N，都有 limn→∞tnm=0\lim_{n\to\infty} t_{nm} = 0。因此有限项之和 ∑m=1N|tnm|→0\sum_{m=1}^N |t_{nm}| \to 0。存在 N′>NN' > N，当 n>N′n > N' 时，该项 <ε2M< \frac{\varepsilon}{2M}。

故当 n>N′n > N' 时，总和 |yn|<ε2+ε2=ε|y_n| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon。由极限定义，limyn=0\lim y_n = 0。

(2) 证明：

写为 yn−a=∑m=1ntnmxm−a=∑m=1ntnm(xm−a)+a(Tn−1)y_n - a = \sum_{m=1}^n t_{nm} x_m - a = \sum_{m=1}^n t_{nm}(x_m - a) + a(T_n - 1)。

因为 xm−a→0x_m - a \to 0，由 (1) 知第一项趋于 0；第二项由 Tn→1T_n \to 1 亦趋于 0。两项相加即得 limyn=a\lim y_n = a。

(3) 说明：

Stolz 定理求 xnyn\frac{x_n}{y_n}（其中 yny_n 单调趋于 +∞+\infty），可取下三角矩阵 tnm=ym−ym−1ynt_{nm} = \frac{y_m - y_{m-1}}{y_n}。此时行和 Tn=ynyn=1T_n = \frac{y_n}{y_n} = 1，列极限 limn→∞ym−ym−1yn=0\lim_{n\to\infty} \frac{y_m - y_{m-1}}{y_n} = 0，满足 Toeplitz 条件，故 Stolz 定理是其直接推论。证毕。

三、上下极限与聚点集理论
第 4 题 上下极限的子列极限刻画与基本代数不等式 必做题 📖 教材 第2章 🎬 09-22 课 🎬 09-24 课
#4
设 {an},{bn}\{a_n\}, \{b_n\} 为有界数列。
(1) 证明：存在子列 {ank}\{a_{n_k}\} 使得 limk→∞ank=lim supn→∞an\lim_{k\to\infty} a_{n_k} = \varlimsup_{n\to\infty} a_n；
(2) 证明：lim infan+lim infbn≤lim inf(an+bn)≤lim infan+lim supbn≤lim sup(an+bn)≤lim supan+lim supbn\varliminf a_n + \varliminf b_n \le \varliminf (a_n + b_n) \le \varliminf a_n + \varlimsup b_n \le \varlimsup (a_n + b_n) \le \varlimsup a_n + \varlimsup b_n。
💡 课本提示：上极限是所有收敛子列极限的最大值，利用确界存在性构造逐步逼近的子列；利用尾部确界的次可加性证明不等式链。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
上极限（Limsup）与下极限（Liminf）在实数系不要求数列本身收敛的前提下，始终为任意有界数列赋予确定存在的界标，是实分析中处理发散数列的最重要工具。
【详细推理与解答】

(1) 证明：

记上极限 L=lim supan=limk→∞(supn≥kan)L = \varlimsup a_n = \lim_{k\to\infty} \left(\sup_{n \ge k} a_n\right)。由上极限的定义，对任意 ε>0\varepsilon > 0，区间 (L−ε,L+ε)(L-\varepsilon, L+\varepsilon) 内含有无穷多个项，且 L+εL+\varepsilon 之上有且仅有有限个项。

取 εk=1k\varepsilon_k = \frac{1}{k}。在 n>nk−1n > n_{k-1} 的下标中，必能选出项 anka_{n_k} 满足 |ank−L|<1k|a_{n_k} - L| < \frac{1}{k}。

由夹逼定理，该严格递增下标子列满足 limk→∞ank=L\lim_{k\to\infty} a_{n_k} = L。证毕。

(2) 证明：

对任意正整数 kk，当 n≥kn \ge k 时，显然有 an+bn≤supm≥kam+supm≥kbma_n + b_n \le \sup_{m \ge k} a_m + \sup_{m \ge k} b_m。

两端对 n≥kn \ge k 取上确界：

supn≥k(an+bn)≤supm≥kam+supm≥kbm\sup_{n \ge k} (a_n + b_n) \le \sup_{m \ge k} a_m + \sup_{m \ge k} b_m

两端令 k→∞k \to \infty

取极限，直接得到：lim sup(an+bn)≤lim supan+lim supbn\varlimsup(a_n + b_n) \le \varlimsup a_n + \varlimsup b_n。

其余各不等式通过考虑相反数序列 lim inf(−xn)=−lim supxn\varliminf(-x_n) = -\varlimsup x_n 即可完全对称证毕。

第 5 题 聚点集的闭性、最值与上下极限等价性 必做题 📖 教材 第2章 🎬 09-22 课 🎬 09-24 课
#5
设 {xn}\{x_n\} 是有界数列，记聚点集 A={a∈ℝ∣∃{xnk},xnk→a}A = \{a \in \mathbb{R} \mid \exists \{x_{n_k}\}, x_{n_k} \to a\}。证明：
(1) AA 是有界非空闭集；
(2) supA∈A\sup A \in A 且 infA∈A\inf A \in A（即 AA 有最大值和最小值）；
(3) lim supn→∞xn=maxA\varlimsup_{n\to\infty} x_n = \max A，lim infn→∞xn=minA\varliminf_{n\to\infty} x_n = \min A。
💡 课本提示：(1) 由 Bolzano-Weierstrass 定理保证非空，证明极限点的极限仍为极限点（对角线子列法）证明闭性；(2) 有界闭集必能达到最大最小值；(3) 结合上题子列极限刻画。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
深刻揭示了上极限与下极限的几何直观：上极限就是聚点集中最大的那个点，下极限就是聚点集中最小的那个点。
【详细推理与解答】

证明：

(1) 因为数列有界，存在闭区间 [m,M][m, M] 包含所有项。由 Bolzano-Weierstrass 定理，任何有界数列必有收敛子列，故聚点集 A≠∅A \neq \emptyset，且显然 A⊆[m,M]A \subseteq [m, M] 有界。

设 a∗a^* 是 AA 的极限点，即存在 aj∈Aa_j \in A 使得 aj→a∗a_j \to a^*。对每个 aja_j，存在原数列的子列收敛到它。利用 Cantor 对角线法选取项 xnjx_{n_j} 使得 |xnj−a∗|<1j|x_{n_j} - a^*| < \frac{1}{j}，则该新子列收敛于 a∗a^*，说明 a∗∈Aa^* \in A。故 AA 是闭集。

(2) 因为 AA 是 ℝ\mathbb{R} 上的非空有界闭集（紧集），由实数完备性定理，上确界 supA\sup A 与下确界 infA\inf A 必然属于集合 AA 本身，即集合能达到最大值与最小值。

(3) 由第 4 题 (1)，存在子列收敛到上极限 L=lim supxnL = \varlimsup x_n，故 L∈AL \in A。另一方面，对任意收敛子列极限 a∈Aa \in A，显然 a≤La \le L。因此 L=maxAL = \max A。同理下极限等于 minA\min A。证毕。

第 6 题 利用上下极限判定交错递推数列收敛 必做题 📖 教材 第2章 🎬 09-22 课 🎬 09-24 课
#6
设 a1>0a_1 > 0，数列 {an}\{a_n\} 满足递推关系：an+1=3an+2a_{n+1} = \dfrac{3}{a_n + 2} (n≥1n \ge 1)。
利用上极限和下极限严格证明 {an}\{a_n\} 收敛，并求其极限。
💡 课本提示：设 L=lim supan,l=lim infanL = \varlimsup a_n, l = \varliminf a_n；利用函数 f(x)=3x+2f(x) = \frac{3}{x+2} 在正半轴上严格单调递减的反序性，得出 L=3l+2L = \frac{3}{l+2} 与 l=3L+2l = \frac{3}{L+2}，相减证明 L=lL = l。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
上极限与下极限方法是解决交错振荡递推数列最强悍的通用武器。免去了繁琐的奇偶项单调性证明，直接利用反向包含关系锁死极限相等。
【详细推理与解答】

证明与求解：

由数学归纳法显然对一切 nn 有 an>0a_n > 0。且 an+1=3an+2<32a_{n+1} = \frac{3}{a_n + 2} < \frac{3}{2}，故数列有界。记 l=lim infanl = \varliminf a_n，L=lim supanL = \varlimsup a_n（0≤l≤L0 \le l \le L）。

考察函数 f(x)=3x+2f(x) = \frac{3}{x + 2}。由于 f′(x)=−3(x+2)2<0f'(x) = -\frac{3}{(x+2)^2} < 0，f(x)f(x) 在 (0,+∞)(0, +\infty) 上严格单调递减。

单调减函数将大项映射为小项、小项映射为大项，因此对上下极限产生反向映射：

L=lim supan+1=f(lim infan)=3l+2L = \varlimsup a_{n+1} = f(\varliminf a_n) = \frac{3}{l + 2}l=lim infan+1=f(lim supan)=3L+2l = \varliminf a_{n+1} = f(\varlimsup a_n) = \frac{3}{L + 2}

两式相减：

L−l=3l+2−3L+2=3(L−l)(l+2)(L+2)L - l = \frac{3}{l + 2} - \frac{3}{L + 2} = \frac{3(L - l)}{(l + 2)(L + 2)}(L−l)(1−3(l+2)(L+2))=0(L - l) \left(1 - \frac{3}{(l + 2)(L + 2)}\right) = 0

因为 l≥0,L≥0l \ge 0, L \ge 0，分母 (l+2)(L+2)≥2×2=4>3(l+2)(L+2) \ge 2 \times 2 = 4 > 3。所以括号内必有：

1−3(l+2)(L+2)≥1−34=14>01 - \frac{3}{(l + 2)(L + 2)} \ge 1 - \frac{3}{4} = \frac{1}{4} > 0

因此只能是 L−l=0⇒L=lL - l = 0 \implies L = l

设 f(x)=ax+bcx+df(x) = \dfrac{ax + b}{cx + d}（ad−bc≠0ad - bc \neq 0）为 Möbius 分式线性变换。
(1) 证明：若 f,hf, h 是分式线性变换，则逆变换 f−1f^{-1} 与复合变换 f∘hf \circ h 仍为分式线性变换；
(2) 记共轭变换 g=h∘f∘h−1g = h \circ f \circ h^{-1}，讨论通过共轭化将一般迭代化为乘法伸缩 g(y)=kyg(y) = ky 的分类方法。
💡 课本提示：分式线性变换与 2×22\times 2 可逆矩阵乘法群 PGL(2,ℝ)PGL(2, \mathbb{R}) 同构；不动点对应特征向量，利用不动点坐标作共轭基底变换。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
复分析、双曲几何与动力系统的核心交汇点。通过矩阵对角化把非线性分式迭代变成简单的等比数列，彻底统一了所有实数递推序列的收敛性分类。
【详细推理与解答】

证明与讨论：

(1) 建立分式线性变换与矩阵乘法的同态：令矩阵 A=(abcd)A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}。两变换复合 f1∘f2f_1 \circ f_2 对应矩阵乘积 A1A2A_1 A_2，逆变换对应逆矩阵 A−1A^{-1}。因为行列式不为零，逆矩阵存在，矩阵乘积仍可逆，故复合与逆仍是分式线性变换。

(2) 设 ff 的不动点满足 x=ax+bcx+d⇔cx2+(d−a)x−b=0x = \frac{ax+b}{cx+d} \iff cx^2 + (d-a)x - b = 0。

  • 若有两个相异实不动点 x1,x2x_1, x_2，构造双射 h(x)=x−x1x−x2h(x) = \frac{x - x_1}{x - x_2} 将不动点映射到 00 和 ∞\infty。此时共轭变换变为纯伸缩 g(y)=kyg(y) = ky（其中 k=f′(x1)k = f'(x_1)）。数列迭代化为等比数列 yn=kny0y_n = k^n y_0，其收敛性完全取决于乘子模长 |k|<1|k| < 1 还是 |k|>1|k| > 1（双曲型 Hyperbolic）；
  • 若有一个二重不动点，共轭化为平移 g(y)=y+cg(y) = y + c（抛物型 Parabolic）；
  • 若无实不动点，对应旋转（椭圆型 Elliptic）。
