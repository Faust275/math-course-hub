一、判断题（7 题）

1判断题
使用 printf 输出 int 类型变量时，应使用格式控制符 %f。
正确答案：×
该说法错误。int 用 %d，%f 用于浮点，类型不匹配会输出错误结果。
2判断题
使用 scanf 读取 int 类型变量 num 时，语句 scanf("%d", num); 无需添加取地址符 & 也能正确读值。
正确答案：×
该说法错误。scanf 需要变量地址，必须写 &num，否则行为未定义。
3判断题
若定义 float pi = 3.14;，则 printf("pi = %f\n", pi); 能正确输出 pi 的值。
正确答案：√
该说法正确。float 在 printf 中提升为 double，用 %f 即可正确输出。
4判断题
使用 printf 输出 double 类型变量 pi 时，printf("pi = %lf", pi); 是符合标准的写法。
正确答案：×
该说法错误。printf 输出 double 用 %f；%lf 是 scanf 读取 double 的格式，printf 里不是标准写法。
5判断题
读取基本数据类型变量（如 int、float）时，scanf 语句中变量名前必须添加取地址符 &。
正确答案：√
该说法正确。读取 int/float 等基本类型变量时，变量名前必须加取地址符 &。
6判断题
若定义 float salary = 5000.0;，则 printf("Salary: %.1f", salary); 能以“保留 1 位小数”的格式输出 salary。
正确答案：√
该说法正确。%.1f 指定保留 1 位小数。
7判断题
使用 scanf 同时读取 int 变量 age 和 float 变量 height 时，正确语句为 scanf("%d %lf", &age, &height);。
正确答案：×
该说法错误。float 对应 %f；%lf 只用于 double，且 height 是 float。

二、单选题（20 题）

1单选题
若 x 是 double 型变量，n 是 int 型变量，执行以下语句（　），并输入 3 1.25 后，x 的值是 1.25，n 的值是 3。
正确答案：A
正确答案 A。n 是 int 用 %d，x 是 double 用 %lf，顺序要与输入 3 1.25 对应。
2单选题
语句 printf("%5.2f", 4321.5678); 的输出结果是（　）。
正确答案：B
正确答案 B。%5.2f 的最小宽度为 5，数值本身 7 字符不会被截断，四舍五入得 4321.57。
3单选题
使用 scanf("X=%f，y＝%f", ＆x, &y)，要使 X、y 均为 1.25，正确的输入是（　）。
正确答案：C
正确答案 C。scanf 格式串中的普通字符必须原样输入，故要写 X＝1.25，y＝1.25。
4单选题
使用 scanf("a=%d,b=%d", &a, &b) 要使 a、b 均为 50，正确的输入是（　）。
正确答案：A
正确答案 A。格式串含 a= 与 ,b=，输入须原样匹配 a=50,b=50。
5单选题

正确答案 D。%f,%f 以逗号为分隔符，输入应为 11,22。
