# 数学课程讲义汇总站 · Math Course Hub

一个**纯静态、零外部依赖、可离线双击打开**的数学学习站点。整合课堂讲义、每周作业与四本「101 计划」核心教材的完整逐字阅读版。

## 内容一览

| 课程 | 讲义 | 每周作业 | 配套教材（全本逐字阅读） |
|------|------|----------|--------------------------|
| 分析学Ⅰ | 15 节 | 7 次 | 《数学分析》（李成章）、陶哲轩《实分析》 |
| 代数学 | 13 节 | 6 次 | 《代数学》（101 计划） |
| 几何学 | 15 节 | 6 次 | 《几何学基础》（盛茂、王作勤） |
| C 程序设计 | 8 节 | — | — |

- 教材共 **4 本、46 章、430+ 小节**，正文为 MinerU 解析后的**逐字原文**，公式在构建期全部转译为标准 **W3C MathML**（全站约 **4.7 万个公式块**），并自动做**卡片化**（定义 / 定理 / 公理 / 例题 / 证明 / 注 / 图）。
- 教材页面内置**荧光笔、波浪线、便签批注**、阅读进度、章节目录抽屉、字号缩放、**深浅色切换（含防闪烁）**。

## 特色功能

- **📚 教材 ↔ 讲义 ↔ 作业联动**：教材章页列出本课程全部讲义与作业，并可一键跳转；讲义页、作业页提供「📚 教材」反链。因讲义与作业均按课本顺序推进，链接顺序即知识脉络顺序。
- **🔍 全站跨课检索**：按课分片倒排索引，双击本地打开也能搜索（不依赖任何服务器）。
- **🖍️ 批注本地持久化**：高亮与笔记保存在浏览器本地。
- **📦 便携自包含**：`assets/` 内已本地化全部插图（几何 128 张、数分 40 张等），`vendor/mathjax` 为本地矢量渲染引擎；整站无任何外链请求。
- **🌗 深浅色**：首屏前应用主题，消除暗→亮闪烁。

## 目录说明

```
index.html            首页（四门课 + 全站检索）
course-*.html         课程页（讲义 / 作业 / 教材 三个视图）
lecture-*.html        单节讲义全文
homework-*.html       每周作业自测页
textbook-<书>-<章>.html  教材单章纯净阅读页
预览_单文件.html       资源全内联的单文件预览
data/                 结构索引、单节数据、倒排分片
assets/               讲义插图与教材插图（已本地化）
full/                 讲义原文（公式齐全、无导航）
vendor/mathjax/       本地 MathML → SVG 渲染引擎
```

## 技术说明

- 构建产物为纯静态 HTML/CSS/JS，无后端、无构建期外部依赖。
- 数学公式：MinerU 的 LaTeX → 自研 `tex2mathml` 深度转换 → MathML → 本地 MathJax (mml-svg) 矢量渲染。
- 教材正文严格保留原文，仅做结构包裹与公式转译；出版批次、二维码、索引与教材目录等无关内容已剔除。
