00:02:46—00:06:33 ｜ 从极限定义出发：本阶段的训练重点与后续脉络

上次课讲了数列极限的定义，并从定义出发推了一些性质。书上第二小节、以及第三小节里的乘积性质与四则运算，都要一并当作「从数列极限定义出发」的练习，打包在一起看，不要把它们当成一堆孤立定理去记。

做这些推导，本质上是在训练怎么用 ε-N 语言从定义出发论证，是在熟悉数列极限的定义。如果你已经很熟练，会觉得这些推导啰嗦；但对大多数同学来说，恰恰是通过亲手推导这些性质，才把定义变成自己的东西。我可以「后知后觉」地讲讲自己对数列极限的直观理解，每位老师也都会讲一些超出形式语言的直观，但直观要变成你自己的，得靠你自己动手过例题。课时有限，例题上免不了要取舍，所以更要把书上这些最基本的定理推导先自己过一遍。

具体的要求是：书上的定理推导，自己先过一遍，不是背，对着书检查这些「从定义出发的推导」自己是不是真的会了。这是比较基本的一关，要能做到脱稿、没有压力地独立完成，全部这些推导都要掌握到熟练。

后面接着要讲的：四则运算讲完之后讲单调有界原理，证明它当然要用确界原理，而确界原理背后是实数系的完备性；单调有界原理最后回答的是「什么样的数列收敛」，推它同样是在练习从极限定义出发。书上还会讲上、下极限——从概念本身说它并不算多么深刻（自有它深刻的地方），但这些推导一样要自己掌握、能熟练做出来。

这些性质做完之后，就可以用来求极限。但千万不要以为「书上把定义推完了，我只要记住这些定理在不在、结论是什么就够了」——完完全全不够，这种想法要不得。

00:06:47—00:08:23 ｜ 大学里「单调」的定义与高中不同

顺便专门提一件每次上完课都有同学（或老师）来问的事：你们高中「单调函数」是怎么定义的？和现在不一样，每次上课我容易忘，这里专门讲一下。

大学里的定义：设 f 定义在 D 上，若对任意x1,x2∈Dx_1, x_2 \in D，

x1≤x2⟹f(x1)≤f(x2),x_1 \le x_2 \implies f(x_1) \le f(x_2),

就称 f 是单调递增函数（单调递减把两个 ≤ 换成 ≥ ）。若进一步有x1<x2⟹f(x1)<f(x2)x_1 < x_2 \implies f(x_1) < f(x_2)，则称严格单调递增。

高中的单调用的是严格不等式，大学用的是非严格不等式 ≤ / ≥ ，差别就在这里。见过我的课之后你基本就明白：在大学里 f(x)≡2 既是单调递增也是单调递减，是单调函数；按高中的定义它却不是。以后读教材、和别人交流，一律按大学的定义理解。

例题/证明 1（00:06:47）｜ 常值函数 f(x)≡2 是不是单调函数？

题目： f(x)≡2 是不是单调函数？

思路：同一个函数，按高中定义和大学定义判断，结论不同。把两套定义逐条对照即可。

逐步推导：

  1. 高中（严格）定义：单调递增要求x1<x2⟹f(x1)<f(x2)x_1 < x_2 \implies f(x_1) < f(x_2)；单调递减要求x1<x2⟹f(x1)>f(x2)x_1 < x_2 \implies f(x_1) > f(x_2)。对 f(x)≡2 ，任取x1<x2x_1 < x_2都有f(x1)=f(x2)=2f(x_1) = f(x_2) = 2，两个严格不等式都不成立，故按高中定义不是单调函数。
  2. 大学（非严格）定义：任取x1≤x2x_1 \le x_2，f(x1)=2≤2=f(x2)f(x_1) = 2 \le 2 = f(x_2)，故 f 单调递增；同理f(x1)=2≥2=f(x2)f(x_1) = 2 \ge 2 = f(x_2)，故 f 也单调递减。按大学定义是单调函数（而且既递增又递减）。
  3. 按严格单调递增的定义（x1<x2⟹f(x1)<f(x2)x_1 < x_2 \implies f(x_1) < f(x_2)）判断， f(x)≡2 不是严格单调的。

结论： f(x)≡2 按高中定义不是单调函数，按大学定义是单调函数（同时单调递增、单调递减），但不是严格单调的。

意义与易错点：老师专门提这一句，是因为每届都有人来问「高中已经讲过单调了，怎么现在不一样」。差别全在 ≤ / ≥ 与 < / > 上，不在函数本身。以后遇到「单调」一律按大学的非严格定义理解；要强调严格时，明确说「严格单调」。

00:08:32—00:09:58 ｜ 周期函数：只关心是否具有周期性质

还有一件同类的事：你们对周期函数的定义和高中也略有不同。一般谈周期函数，习惯把它放在整个实数轴上：存在 T>0 ，使对定义域里一切 x 都有 f(x+T)=f(x) ；也就是在定义里能找到一个 T 让这个等式成立就行。

但具体以后要解方程、处理一个具体问题时，不要纠结于定义域是不是整个 ℝ 、是不是非要有最小正周期这类字眼：我只关心这个函数在我正在讨论的那一部分上表现出周期性质。跟别人交流时说「它是一个周期函数」，是因为它满足 f(x+T)=f(x) 这个性质。这不是考纲里要抠的事，也不会专门在这里设个坑考你「到底算不算周期函数」——高中里非要告诉你「这个是周期、那个不是」，大学里看它是否具有周期性质即可，重点在理解概念本身。

二、数列极限的四则运算（00:10:08—00:37:07）

00:10:08—00:11:04 ｜ 保号性与保序性：方向相反的两个性质

接着上次的话头：上次已经讲到夹逼性质（夹逼准则），现在来看四则运算。

先复习一个区别。上次我特别说过，把第一个性质（定理）归给保号性。保号性和保序性有什么区别？

  • 保序性是「由数列性质推极限性质」：若（充分大 n 时）an≤bna_n \le b_n，则lim⁡an≤lim⁡bn\lim a_n \le \lim b_n。注意由严格不等式an<bna_n < b_n一般只能推出非严格的lim⁡an≤lim⁡bn\lim a_n \le \lim b_n。
  • 保号性是「由极限性质推数列性质」，方向正好反过来：若lim⁡an=A>0\lim a_n = A > 0（严格大于 0），则某一项以后ana_n严格大于 0（与极限同号）；而且你能得到的比书上写的更多——某一项以后甚至有an>A/2a_n > A/2。

为什么能得到比书上更多的信息？因为定理证明过程中给出的信息本来就比书上写出来的保号性结论更强。这一点等一下讨论商、条件只给 B≠0 的时候就要用上。

00:11:53—00:14:15 ｜ 四则运算定理与「有限项」约定

四则运算这一部分有三个定理：和（加减）、积（乘）、商（除），合起来就是加减乘除。设

limn→∞xn=A,limn→∞yn=B,\lim_{n\to\infty} x_n = A, \qquad \lim_{n\to\infty} y_n = B,

则

  1. lim⁡(xn±yn)=A±B\lim(x_n \pm y_n) = A \pm B（实际证明时对更一般的αxn+βyn\alpha x_n + \beta y_n来做）；
  2. lim⁡(xnyn)=AB\lim(x_n y_n) = AB；
  3. 若 B≠0 ，则lim⁡xnyn=AB\lim \frac{x_n}{y_n} = \frac{A}{B}。

在证明之前先问一句：什么叫做四则运算？——加减乘除。那除了两项，3 个数列、3 项能不能做四则运算？也能。因为加法、乘法有结合律与交换律，虽然定理都写成两项的形式，但三项、任意有限项都对：「先做一次，再多做一步」，一步步用结合律归结到两项就行。

我真正想问的重点在这里：所谓四则运算，指的是有限次（有限项）的加减乘除。大家一听「四则运算」容易顺手就往很多项、甚至无穷多项上想，要记住这个「有限」——它只对有限项成立，不能推到无穷多项。这是记这些性质时必须一起记住的条件。

至于证明本身，没有什么新东西，就是熟练 ε-N 这一套论证。

00:14:15—00:23:27 ｜ 和的极限：从 ε-N 定义出发

第一个定理从定义硬做。下面先讲课堂上「心里怎么想到」的分析法，再讲正式写下来的综合法，最后讲不少同学会碰到的写法讲究与 α,β=0 的小技巧。

例题/证明 2（00:14:15）｜ 和的极限：αxn+βyn→αA+βB\alpha x_n + \beta y_n \to \alpha A + \beta B

命题：设lim⁡xn=A\lim x_n = A、lim⁡yn=B\lim y_n = B， α,β 为常数，则

limn→∞(αxn+βyn)=αA+βB.\lim_{n\to\infty}(\alpha x_n + \beta y_n) = \alpha A + \beta B.

取 α=1,β=±1 就是和、差的极限；老师直接对一般的线性组合来证。

思路（分析法）：要证的是：任给 ε>0 ，存在 N ，使 n≥N 时

|αxn+βyn−(αA+βB)|<ε.|\alpha x_n + \beta y_n - (\alpha A + \beta B)| < \varepsilon.

手里只有两条信息：xn→Ax_n \to A与yn→By_n \to B。办法是把这两条信息合在一起，再用三角不等式把 α,β 提到绝对值外面：

|αxn+βyn−(αA+βB)|=|α(xn−A)+β(yn−B)|≤|α||xn−A|+|β||yn−B|.|\alpha x_n + \beta y_n - (\alpha A + \beta B)| = |\alpha(x_n - A) + \beta(y_n - B)| \le |\alpha|\,|x_n-A| + |\beta|\,|y_n-B|.

α 全部用绝对值放掉， β 也全部用绝对值放掉，问题就化成分别控制|xn−A||x_n-A|与|yn−B||y_n-B|。

逐步推导（课堂上从结论倒推）：

  1. 任给 ε>0 。由xn→Ax_n \to A，存在N1N_1，使n≥N1n \ge N_1时|xn−A|<ε|x_n - A| < \varepsilon；由yn→By_n \to B，存在N2N_2，使n≥N2n \ge N_2时|yn−B|<ε|y_n - B| < \varepsilon。 —— 每用到一个数列的极限，就要产生一个相应的 N ；这一步虽然啰嗦，但一定要走，不能跳。老师特别说：这个啰嗦的东西不走，后面就没法把范围卡得越来越紧。
  2. 取N=max⁡{N1,N2}N = \max\{N_1, N_2\}，则 n≥N 时两个不等式同时成立：

|αxn+βyn−(αA+βB)|≤|α||xn−A|+|β||yn−B|<|α|ε+|β|ε=(|α|+|β|)ε.|\alpha x_n+\beta y_n-(\alpha A+\beta B)| \le |\alpha|\,|x_n-A| + |\beta|\,|y_n-B| < |\alpha|\varepsilon + |\beta|\varepsilon = (|\alpha|+|\beta|)\varepsilon.

  1. |α|+|β| 是常数。右端是「常数 ×ε 」，而定义里的 ε 是任给、遍历所有正数的，所以「对任意 ε>0 能使左端小于 (|α|+|β|)ε 」与「对任意 ε>0 能使左端小于 ε 」是同一件事（把 ε 换成 ε/(|α|+|β|+1) 即可）。老师点了一句：乘上一个常数没关系，这个一定要想通过去。
  2. 若 α=β=0 ，左端本来就是 0 ，等式恒成立，不会引起混淆。所以用 α,β 作参数的「粗犷」写法对 α,β 是否为零一概不用讨论，反而省事。

正式写证明的顺序（综合法）：上面讲的是「心里面怎么达到目的」的分析法；真要写成证明，按下面顺序读起来才顺眼：先写「任给 ε>0 」（这行肯定没错） → 由xn→Ax_n\to A得存在N1N_1 → 由yn→By_n\to B得存在N2N_2 → 取N=max⁡{N1,N2}N=\max\{N_1,N_2\}→\to n≥N 时放缩。助教也提醒过，现在还是要写仔细一点。我每次讲都偏分析，是想告诉你心里是怎么想的。

另一种写法与一个小技巧：不少同学受高中训练，希望式子里直接出现 ε 的「标准」形式，于是想写|xn−A|<ε2|α||x_n - A| < \frac{\varepsilon}{2|\alpha|}、|yn−B|<ε2|β||y_n - B| < \frac{\varepsilon}{2|\beta|}。这就有问题了：分母出现 |α|,|β| ，就得讨论 α=0 或 β=0 的情形，凭空多出麻烦。处理办法是「雕虫小技」——把分母里的 |α| 换成 |α|+1 ：找 N 时只要让

|xn−A|<ε2(|α|+1),|yn−B|<ε2(|β|+1),|x_n - A| < \frac{\varepsilon}{2(|\alpha|+1)}, \qquad |y_n - B| < \frac{\varepsilon}{2(|\beta|+1)},

则逐行验证有 [补全]

|α|⋅ε2(|α|+1)+|β|⋅ε2(|β|+1)<ε2+ε2=ε.|\alpha|\cdot\frac{\varepsilon}{2(|\alpha|+1)} + |\beta|\cdot\frac{\varepsilon}{2(|\beta|+1)} < \frac{\varepsilon}{2}+\frac{\varepsilon}{2} = \varepsilon.

因为|α||α|+1<1\frac{|\alpha|}{|\alpha|+1}<1恒成立， α=0 时也不出问题，不必再分类讨论。这种小技术高中里可能要专门开个专题讲，大学里看到老师这么处理一下就懂了，登不了大雅之堂。

说明：上面标 [补全] 的验证行，是按数学上正确的方式补足的课堂口述省略部分（板书并未逐行给出），不是当堂所讲，仅作自学参照。

结论：αxn+βyn→αA+βB\alpha x_n + \beta y_n \to \alpha A + \beta B，从而和、差的极限等于极限的和、差。

意义与易错点：

  • 全部从 ε-N 定义出发，没有用任何没证过的结论；核心动作就是「加一项减一项 + 三角不等式 + 把两个 N 取 max 」。
  • 每调用一次「某数列收敛」，就老老实实写出对应的 N ；把几个 N 合并时取最大值。
  • 「有限项」：正因为只对两个（从而有限个）数列做，才能这样取 max ；无穷多项时这一步失效。
  • 分析法（想）与综合法（写）顺序相反，别把心里的倒推直接当证明抄。

例题/证明 3（00:23:27）｜ 乘积的极限：xnyn→ABx_n y_n \to AB

例题/证明 4（00:26:49）｜ 商的极限：xnyn→AB(B≠0)\frac{x_n}{y_n} \to \frac{A}{B}\ (B\ne 0)

命题：设lim⁡xn=A\lim x_n = A、lim⁡yn=B\lim y_n = B，且 B≠0 ，则lim⁡xnyn=AB\lim \frac{x_n}{y_n} = \frac{A}{B}。

观察一：分母为什么有意义（保号性出场）

处理除法，式子里每一项都是xn/ynx_n / y_n，照理得先保证yn≠0y_n \ne 0才有定义。可定理的条件里并没有直接说yn≠0y_n \ne 0，只委婉地给了 B≠0 —— B 是{yn}\{y_n\}的极限，一个数列的极限不等于 0，于是保号性就出场了：

  • 若 B>0 ，由保号性，某一项以后yn>B/2>0y_n > B/2 > 0；
  • 若 B<0 ，某一项以后yn<B/2<0y_n < B/2 < 0（不会碰到 0）。

也就是存在N0N_0，n≥N0n \ge N_0时

|yn|>|B|2>0.|y_n| > \frac{|B|}{2} > 0.

这既保证了分母不为零，又给了分母一个正的、与 n 无关的下界。 B≠0 就是告诉你极限在数轴上离原点有距离，取这么一个邻域把 0 排除掉，某一项以后的尾巴全部落在这个邻域里。注意书上写保号性只告诉你yn>0y_n > 0，而证明过程中其实能得到更强的|yn|>|B|/2|y_n| > |B|/2（或 |B|/3 ，写 2 还是写 3 形式都一样）——证明给的信息比书上的结论更多，这里正好要用。

写这个观察也有层次：一般同学会分 B>0 、 B<0 两种情形，写「存在 N ， n≥N 时yn>0y_n>0」或「yn<0y_n<0」；思路更清楚、用得更熟的写法是直接写成|yn|>|B|/2|y_n| > |B|/2（或|yn|>|y_n|>某个正数），一个式子把两种情形都盖住。写成后者就上了一个 level。

还要点破一个让人不太舒服的地方： B≠0管不了前面有限项。y1,y2,…y_1, y_2, \dots里某一项等于 0 完全可能，那时xn/ynx_n/y_n的这一项就没有意义。严格写下来这样是不够严谨的；但数列极限考虑的只是「某一项以后」（尾巴），前面有限项有没有定义不影响极限。抓本质，这件事是能实现的：如果 B>0 ，某一项以后yn>0y_n>0；如果 B<0 ，某一项以后yn<0y_n<0，都是有意义的。

观察二：化归（归结）

高中里你们就训练过「约化 / 化归」：把除法写成乘法

xnyn=xn⋅1yn.\frac{x_n}{y_n} = x_n \cdot \frac{1}{y_n}.

乘积的极限（证明 3）已经证完，所以只要再证

套用乘积定理就得到AB\frac{A}{B}。老师特别提醒：化归的思想要放在心里；看第三条（商）的时候乘法已经证过了，我现在只证1/yn→1/B1/y_n \to 1/B就可以了，不必从头硬做。不写这个归结、直接硬证也不算差太远，但养成这个习惯，思路会上一个 level。

逐步推导（关键一步：1/yn→1/B1/y_n \to 1/B的 ε-N 论证）

  1. 任给 ε>0 。
  2. 由 B≠0 用保号性（取ε0=|B|/2\varepsilon_0 = |B|/2）：存在N1N_1，n≥N1n \ge N_1时|yn−B|<|B|/2|y_n - B| < |B|/2，于是

第 3 步得到的是|1yn−1B|<C|yn−B|\left|\frac{1}{y_n}-\frac{1}{B}\right| < C|y_n-B|，其中C=2/|B|2C = 2/|B|^2是常数。要把它变成定义要求的「 <ε 」，靠的是：定义中的 ε 是任给、遍历所有正数的，所以「对任意 ε>0 能使左端小于 Cε 」和「对任意 ε>0 能使左端小于 ε 」是同一件事—— ε 想变就变， Cε 同样遍历所有正数。

xnyn=xn⋅1yn→A⋅1B=AB.\frac{x_n}{y_n} = x_n \cdot \frac{1}{y_n} \to A \cdot \frac{1}{B} = \frac{A}{B}.

  • 保号性在证明中给出的|yn|>|B|/2|y_n| > |B|/2比书上的yn>0y_n > 0强；写 |B|/2 、 |B|/3 或别的等价形式都一样，本质是给分母一个正下界。
  • 前面有限项是否为零不必纠结，数列极限只看尾巴；但心里要清楚严格地说这里有个小缺口。
  • 除法定理的条件别漏掉 B≠0 ；也不要把「有限项四则运算」的「有限」忘了。

00:38:16—00:40:31 ｜ 四则运算法则只对有限多项成立

有同学问：四则运算（和的极限等于极限的和）能不能用在这个式子上？先看它错在哪里。

例题/证明 5（00:38:16）｜ 一个「每项极限都是 0」却不能逐项取极限的和式

题目：求 limn→∞(1n2+2n2+⋯+nn2).\lim_{n\to\infty}\left(\frac{1}{n^{2}}+\frac{2}{n^{2}}+\cdots+\frac{n}{n^{2}}\right).

思路：四则运算法则中「和的极限 = 极限的和」，前提是有限多项——项数固定、不随 n 变化。这里项数等于 n ，跟着极限过程一起增大，本质上是无限多项。

逐步推导：

  1. 逐项看：对固定的 k ，kn2→0\dfrac{k}{n^{2}}\to 0。若照搬四则运算，就会得到 0+0+⋯+0=0.0+0+\cdots+0=0.
  2. 但等号右边的「 0 」是把无穷多个极限相加，法则不允许。正确做法是先求和（有限项求和是代数恒等变形，随时可做）： 1n2+2n2+⋯+nn2=1+2+⋯+nn2=n(n+1)2n2=12+12n.\frac{1}{n^{2}}+\frac{2}{n^{2}}+\cdots+\frac{n}{n^{2}}=\frac{1+2+\cdots+n}{n^{2}}=\frac{n(n+1)}{2n^{2}}=\frac{1}{2}+\frac{1}{2n}.
  3. 于是 limn→∞(1n2+⋯+nn2)=limn→∞(12+12n)=12≠0.\lim_{n\to\infty}\left(\frac{1}{n^{2}}+\cdots+\frac{n}{n^{2}}\right)=\lim_{n\to\infty}\left(\frac12+\frac{1}{2n}\right)=\frac12\neq 0.

结论：极限是12\dfrac12，逐项取极限得到的 0 是错的。

易错点与意义：这种写法的迷惑性在于，看上去是「有限项相加」（写到第 n 项为止），但上标 n 跟着极限过程一起跑——「他的项数是不是跟着 n 的极限过程，这个项数越来越多」。四则运算只对固定有限项成立；只要遇到项数随 n 变化的和或积，就必须先求和、先变形、先放缩，化成固定有限个对象再取极限。

另：上节课乘法与除法的四则运算证明并没有写完整，除法是最后讲的（00:40:06—00:40:31），请回去把两个证明从头到尾自己梳理一遍。

00:40:34—00:42:52 ｜ 分子、分母同趋于正无穷的分式

例题/证明 6（00:40:34）｜ 分子分母各四项的三次分式

题目：分子是 n 的三次多项式（四项相加），分母也是 n 的三次多项式（四项相加），首项系数分别为 3 与 1 ，例如 limn→∞3n3+7n2+2n+7n3+100n2+n+4.\lim_{n\to\infty}\frac{3n^{3}+7n^{2}+2n+7}{n^{3}+100n^{2}+n+4}.

思路：分子、分母各自确实是有限四项相加，但每一项（连同整个分子、分母）都趋于 +∞ 。商的法则要求「分子的极限存在、分母的极限存在且不为 0」，这里两个极限都不是实数，法则不能用。办法是分子分母同除以最高次幂n3n^{3}，把每一项变成极限存在的量。

逐步推导：

  1. 同除以n3n^{3}（恒等变形）： 3n3+7n2+2n+7n3+100n2+n+4=3+7n+2n2+7n31+100n+1n2+4n3.\frac{3n^{3}+7n^{2}+2n+7}{n^{3}+100n^{2}+n+4}=\frac{3+\dfrac7n+\dfrac{2}{n^{2}}+\dfrac{7}{n^{3}}}{1+\dfrac{100}{n}+\dfrac{1}{n^{2}}+\dfrac{4}{n^{3}}}.
  2. 各项极限：常数 3 、 1 的极限是自身；由前面已证的1n→0\dfrac1n\to0及乘积法则，7n,2n2,7n3,100n,1n2,4n3→0\dfrac7n,\dfrac{2}{n^{2}},\dfrac{7}{n^{3}},\dfrac{100}{n},\dfrac{1}{n^{2}},\dfrac{4}{n^{3}}\to0。这些不必每次重新用定义证明。
  3. 现在分子极限 =3 ，分母极限 =1≠0 且存在，商的法则可用： limn→∞3+7n+2n2+7n31+100n+1n2+4n3=31=3.\lim_{n\to\infty}\frac{3+\dfrac7n+\dfrac{2}{n^{2}}+\dfrac{7}{n^{3}}}{1+\dfrac{100}{n}+\dfrac{1}{n^{2}}+\dfrac{4}{n^{3}}}=\frac{3}{1}=3.

结论：极限为 3 。

意义与易错点：分母趋于 +∞ 并不可怕，「并不是说你正无穷比正无穷就不能求」，关键是变形之后每一项的极限都要存在（特别是分母的极限要存在且非零），才能用四则运算。有了1nk→0\frac{1}{n^{k}}\to0这些已证结论作「速成」工具，以后处理这类分式就很快，不必每次回到 ε-N 定义。

00:42:55—00:44:40 ｜ 有理分式列的极限：按最高次数分类

例题/证明 7（00:43:00）｜ limn→∞a0nk+a1nk−1+⋯+akb0nm+b1nm−1+⋯+bm\lim\limits_{n\to\infty}\dfrac{a_0n^{k}+a_1n^{k-1}+\cdots+a_k}{b_0n^{m}+b_1n^{m-1}+\cdots+b_m}

  1. k=m ：分子分母同除以nkn^{k}， a0+a1n+⋯+aknkb0+b1n+⋯+bknk→a0b0.\frac{a_0+\dfrac{a_1}{n}+\cdots+\dfrac{a_k}{n^{k}}}{b_0+\dfrac{b_1}{n}+\cdots+\dfrac{b_k}{n^{k}}}\ \longrightarrow\ \frac{a_0}{b_0}.

例题/证明 17（01:29:05）｜ 收敛数列的任何子列收敛于同一极限（ε-N 证明）

例题/证明 19（01:44:09）｜ 由「每个子列含收敛于 A 的子子列」推出an→Aa_n\to A
