一、循环嵌套收尾：搬砖问题（多重循环的效率）（00:02:38—00:09:44）

00:02:38—00:03:39 ｜ 问题引入：45 人搬 45 块砖

上节课循环（循环嵌套）的尾巴还没讲完，先把最后一个例子收掉，再进入第五章函数。

问题（书上的「搬砖问题」）：男人、女人、小孩共 45 人搬 45 块砖。男人每人搬 3 块，女人每人搬 2 块，小孩两人抬 1 块（即一个小孩搬 0.5 块）。问有多少种组合，需要几个男人、几个女人、几个小孩才能正好把 45 块砖搬完。

00:03:39—00:05:50 ｜ 列方程与穷举法求解思路

设男人的个数为 xx、女人的个数为 yy、小孩的个数为 zz，则有不定方程组：

{x+y+z=453x+2y+12z=45\begin{cases} x + y + z = 45 \\ 3x + 2y + \dfrac{1}{2}z = 45 \end{cases}

其中 x,y,zx,y,z 均为正整数。这是不定方程（两个方程、三个未知数），理论上解可能很多，无法用中学那种解析法直接求出所有解。

工程中大量方程组（尤其是非线性方程组）无法解析求解，只能用数值求解：在已知的取值范围里「搜索」解。其中一种基本方法就是穷举法——把所有可能都试一遍，凡是满足两个方程的就是一组解。

00:05:50—00:07:08 ｜ 三重循环枚举程序

总共有 45 个人，因此男人、女人、小孩的个数各自都从 0 到 45。用三重循环枚举所有可能，逐一检验两个方程是否同时成立，成立就 printf 打印出来。这是最「笨」但也最「健壮、鲁棒」的方法——它保证不漏解。

int main(void)
{
int child, men, women;
for( men = 0; men <=45; men++ )
for( women = 0; women <=45; women++ )
for( child = 0; child <=45; child++ )
if( men + women + child == 45 && men*3 +
women*2 + child*0.5 == 45 )
printf("men=%d, women=%d, child=%d\n", men
, women, child);
return 0;
}

代码取自课件 ch04（1）.txt（例程 4-11）。

例题/证明 1（00:05:50）｜ 搬砖问题：三重循环枚举全部组合

  • 题目：男人、女人、小孩共 45 人搬 45 块砖，男人每人 3 块、女人每人 2 块、小孩两人 1 块，求所有组合。
  • 思路：三重循环枚举 x,y,z∈[0,45]x,y,z\in[0,45]，用 if 同时检验 x+y+z=45x+y+z=45 与 3x+2y+0.5z=453x+2y+0.5z=45。
  • 代码：见上方代码块（来自课件）。
  • 编译运行：gcc brick.c -o brick 后运行，屏幕依次打印出每一组满足方程的 men / women / child（如 men=0, women=15, child=30、men=3, women=12, child=30 等，共 9 组解）。
  • 易错点：循环变量范围是 0 到 45（含 45），共 46 个取值；浮点比较 child*0.5 要写对；三重 for 后面直接跟 if 与 printf，无大括号时只有 if 这一句属于最内层循环（此处 printf 紧跟 if 是其语句体）。

00:07:08—00:09:44 ｜ 效率分析与改进（二重循环）

三重循环总次数为 46×46×46=46346\times46\times46 = 46^3，数量很大。略作分析即可大幅降低计算量：

  • 男人每人搬 3 块，45 块砖最多 15 个男人，故 men 只需 0..15；
  • 女人每人搬 2 块，最多 22 个女人，故 women 只需 0..22；
  • 小孩个数由总数确定：z=45−x−yz = 45 - x - y，无需再循环。

于是三重循环降为二重循环，总次数仅 16×23=36816\times23 = 368，约为原来的 463/368≈27746^3 / 368 \approx 277 倍差距，效率提升巨大。

for( men = 0; men <=15; men++ )
for( women = 0; women <=22; women++ ) {
child = 45 - men - women;
if( men*3 + women*2 + child*0.5 ==45 )
printf("men = %d, women = %d, child = %d\n",
men, women, child);
}

代码取自课件 ch04（1）.txt（例程 4-11 改进程序）。

  • 老师提醒：平时写程序要养成两个习惯——（1）正确建模、正确编码；（2）主动分析并优化效率。看似简单的问题，也能施展聪明才智把效率大幅提升。多重循环要谨慎使用。

二、函数的概念、定义与圆柱体积例程（00:09:44—00:32:29）

00:09:44—00:12:13 ｜ 函数的作用：相对独立的程序模块

前面已学过 main 函数、库函数（如随机数 rand、设种子 srand、时间 time），也自己定义过求阶乘的 factorial 函数。今天正式讲函数的定义、调用、参数传递，以及结构化程序设计思想。

函数的作用：

  • 完成特定工作的相对独立的程序模块（如 printf 输出字符串与变量值，factorial 计算 n!n!）；
  • 写好后可在多处反复调用；
  • 把复杂程序拆成一个个较简单的函数集合，使程序更清晰、易维护、易模块化。

00:12:25—00:15:02 ｜ 例程：计算圆柱体积（函数声明、调用）

教材例程：输入圆柱半径与高，计算体积（V=πr2hV=\pi r^2 h）。若每次都手算 3.1415926 * r * r * h，容易出现不一致（有人写 3.14、有人写 3.1415）。通过函数调用统一计算，既准确又简洁。

#include <stdio.h>
double cylinder(double r, double h);// 函数申明
int main(void)
{
double height , radius , volume;
printf("输入半径和高度：");
scanf("%lf%lf", &radius , &height);
volume = cylinder(radius , height); // 函数调用
printf("圆柱体积是：%f\n", volume);
return 0;
}

代码取自课件 ch05.txt。

为什么要先「声明」再「调用」？ 编译器从上往下编译。当它编译到 volume = cylinder(radius, height); 这一句时，如果之前从未见过 cylinder 这个名字，它就不认识这是个什么——不像 double、= 这些语法元素它天生认识。函数声明 double cylinder(double r, double h); 等于先告诉编译器：「这是一个叫 cylinder 的函数，返回 double，有两个 double 参数」。编译器据此在调用处做类型检查：实际参数 radius、height 都是 double，与声明一致，于是放心通过、不报警告；若类型不符则提出警告或错误。

00:15:02—00:20:00 ｜ 函数定义：函数头、函数体与 return 语句

仅有声明还不够——老师打了比方：声明像「我说我有一辆法拉利」，但若根本没有这辆车，办活动时就进行不下去；程序里若只有函数声明、没有函数实现，编译不会成功。

// 函数cylinder , 计算圆柱体体积
double cylinder(double r, double h)
{
double result; // 定义局部变量
result = 3.14159265 * r * r * h;
// 计算
return result; // 函数返回语句
}

代码取自课件 ch05.txt。

函数定义的结构（函数首部 + 函数体，首部末尾不能有分号，否则就变成函数声明了）：

函数类型
函数名(形式参数表)
// --- 函数首部
{
// -\
函数实现语句
//
|- 函数体
}
  • 函数类型＝函数返回值的类型（int、float、double、char、指针、结构等）。若没有返回值，类型写 void。void 是 C 语言关键字，表示「空」。省略 void 时，C 默认返回值为 int（这是历史原因：早期大量函数返回 int）。
  • 函数名：满足标识符规则（字母、数字、下划线构成，以字母或下划线开头，不能以数字开头）。好的名字应「既简短又含义丰富」，采用动词或动名词结构（如 print、cylinder），让人顾名思义；像 cd 这种名词不好，看不出是求体积还是求表面积。
  • return 语句的两大作用：① 结束本函数的运行；② 设置函数的返回值。高中函数 y=f(x)y=f(x) 中，自变量是参数，函数值由 return 设定。

00:20:00—00:23:46 ｜ 函数名、形式参数表与 void 类型

  • 形式参数表：规定函数有哪些参数，用逗号隔开，每个参数单独给出「类型 名字」。参数个数可以是 0 到多个，如 getchar() 无参数，可写成 () 或 (void)（void 在此表示「空/无」）。
  • 可变参数函数：普通函数参数个数固定；但有一类函数参数个数不固定，例如 printf、scanf——我们一上来就学了最难的函数之一。这类「变参函数」本课程不介绍，感兴趣可自行学习（很少用）。
  • 无返回值的函数：类型必须写 void，return; 后不带表达式，仅用于结束函数运行。

00:23:46—00:26:27 ｜ 可变参数函数（printf / scanf）

进一步强调 printf 是参数个数不固定的典型：printf("Hello"); 只有字符串一个参数；printf("%d", x); 多一个 x；printf("%d %d %d", a, b, c); 又多两个。它们的格式串 %d 之后的实际参数个数完全可变。老师说这正是 C 里「最难的」函数形式，本课程不讲其实现。

00:26:27—00:29:06 ｜ 函数体的构成与无返回值的 return

函数体由一对大括号括起，一般由三部分组成：

  1. 变量的定义；
  2. 实现功能的语句；
  3. 返回语句 return。

无返回值的函数可以没有 return 语句。return 语句形式：

  • 无返回值：return;
  • 有返回值：return 表达式;（表达式可以是常量、变量，或运算结果；甚至可以是另一个函数调用，如 return g(x) + h(y);）

return 执行后：被调函数结束；若有表达式，先算其值再返回，作为函数值带回主调函数。return 只能返回一个值（C 语言函数只有一个返回值；与 Python 可返回多个值不同）。

00:29:06—00:32:29 ｜ 函数声明：作用、可省形参名、先声明后调用

声明就是把「函数头 + 分号」写出来，函数体可省。形参名在声明中可省：

double cylinder(double r, double h);
double cylinder(double , double); // 可省略形参名称
int prime(int n);
void pyramid(int n);

声明的作用与意义：告诉编译器函数的接口（名字、参数类型、参数个数），从而在调用时做语法/类型检查——函数是否存在、实参个数与类型是否匹配。若调用前既未定义也未声明，编译器报错。

  • 形参名在声明里可省（编译不需要名字），但老师建议不要省——写上 r、h 能让调用者知道第一参是「半径」、第二参是「高」，避免传反。
  • 声明可写在 main 外（全局可见），也可写在 main 内（仅该函数内可见，存在「可见性」区别），后面讲函数应用时会再遇到。
  • 也可先定义函数、后调用，编译器同样认识，不强制先声明。总之要让编译器在调用处「认识」这个函数。

例题/证明 1（00:12:25）｜ 计算圆柱体积：函数定义、声明与调用

  • 题目：输入圆柱半径与高，计算并输出体积 V=πr2hV=\pi r^2 h。
  • 代码：见上方「计算圆柱体积」主函数与 cylinder 函数实现（取自课件 ch05.txt）。
  • 编译运行：编译运行后，屏幕提示「输入半径和高度：」，例如输入 2 3（半径 2、高 3），输出 圆柱体积是：37.699112（π⋅22⋅3≈37.70\pi\cdot 2^2\cdot 3\approx 37.70）。

三、函数声明、调用与值传递机制（00:32:29—01:04:21）

00:32:29—00:36:34 ｜ 函数调用语法与函数声明的作用

调用函数：写函数名，把实际参数放进圆括号，如数学式 f(2, 1)、g(11, 20)。调用前必须先声明/定义，目的是让编译器知道「这是个函数，不是变量」。

  • 可以先声明后调用，也可以先定义后调用（如把被调函数写在 main 之前）。
  • 若事先「既没定义也没声明」，编译器报错。

00:36:34—00:37:48 ｜ 函数调用的几种形式

（课件列出）赋值形式、直接调用（返回值被抛弃）、实参形式（作为其他函数调用的实参）、表达式形式（作为操作数）。例如：

volume = cylinder(radius, height);              // 赋值形式
cylinder(radius, height);                        // 直接调用
printf("The answer is %f\n", cylinder(radius, height)); // 实参形式
sum = cylinder(1,2) + cylinder(3,4);            // 表达式形式

00:37:48—00:46:00 ｜ 参数传递：值传递（实参→形参）

函数调用时，实际参数（如 a、b、c）的值被复制给形式参数（如 r、h）。这种传递方式叫值传递（不是引用传递）。引用传递是给实参「取个别名」，形参和实参是同一个东西；而值传递是复制一份，函数内对形参的修改不会影响外部实参。

#include <stdio.h>
int f(int x)
{
x = x*x;
return x;
}
int main()
{
int a = 3, b;
b = f(a);
printf("%d,%d",a,b);
return 0;
}

代码取自课件 ch05.txt（值传递例程），输出为 3,9：形参 x 被改成 9，但实参 a 仍是 3。

例题/证明 1（00:38:46）｜ 函数调用过程与内存变化（以 cylinder 为例）

结合课件图 5-3（教材 116 页）分析 volume = cylinder(radius, height); 的执行过程：

  1. 从 main 开始往下执行，依次创建局部变量 height、radius、volume，执行 printf、scanf；
  2. 执行到 cylinder 调用：暂停 main，为 cylinder 分配内存、创建它的局部变量（含形式参数 r、h）；
  3. 把实参 radius、height 的值复制给形参 r、h；
  4. 执行 cylinder 内部语句，算得 result = 3.14159265 * r * r * h；
  5. 遇到 return result;：先计算表达式值，结束 cylinder，把该值作为函数返回值带回；
  6. 回到 main 暂停处，把返回值赋给 volume，继续执行。
  • 内存要点：形式参数在调用时变成被调函数内部的局部变量；实参值被复制进去，二者是不同的内存单元。函数返回后，被调函数的内存资源被释放，可被下次调用重新分配。

00:46:00—00:52:22 ｜ 内存分区：代码区、静态存储区与动态存储区

计算机内存由操作系统管理，粗略划分为：

  • 系统存储区：操作系统、语言系统自身；
  • 用户存储区（我们的程序所在）：
    • 程序区（代码区）：main 及所有自定义函数的二进制指令，固定不变，CPU 逐条取指执行；
    • 数据区：
      • 静态存储区：全局变量、静态变量（程序一运行就创建，一直存在）；
      • 动态存储区：函数的局部变量区（先 main 的变量区，再被调函数的变量区，层层嵌套；函数返回后该区被撤销、内存归还）。

变量数目在运行中随函数调用/返回而动态增减，故称「动态存储区」。

一个完全平方数 n=m2n=m^2 等于从 1 开始的连续奇数之和：1+3+5+⋯+(2m−1)1+3+5+\cdots+(2m-1)。因此不断从 nn 减去奇数 1,3,5,…1,3,5,\dots，若最终减到正好 0，则 nn 是完全平方数。

// n = m*m = 1 + 3 + ... + (2m-1)
int IsSquare(int n)
{
int i;
for( i=1; n>0; i=i+2 )
n = n-i;
return n==0;
}

例题/证明 2（01:09:21）｜ 完全平方数判断函数 IsSquare

  • 题目：定义 IsSquare(n)，判断 nn 是否为完全平方数（是返回 1，否返回 0）。
  • 思路：for(i=1; n>0; i=i+2) n = n - i; 依次减 1、3、5…；循环条件是 n>0（不是 i<=某值），只要还能减就继续；退出循环时若 n==0 则是平方数，n<0 则不是。
  • 返回值：return n==0; 是关系表达式，结果为逻辑值——C 中逻辑真为 1、逻辑假为 0（C 的逻辑值就是整数）。例如 n=9n=9：9−1=8, 8−3=5, 5−5=0，退出后 n==0 为真，返回 1。
  • 易错点：循环条件写成「i<=某上限」是错的——这里循环控制变量（i）与判断对象（n）是两回事；若 n 不是平方数，某次会减成负数，n>0 不成立退出，n==0 为假返回 0。

01:13:01—01:22:52 ｜ 例程 5-4：最大公约数 gcd（辗转相除法与优化）

给定两正整数 m,nm,n，求最大公约数。用辗转相除法。

int gcd(int m, int n)
{
int r;
if( m<n ) // 交换，保证m >= n
r = m, m = n, n = r;
r = m % n;
while( r ) { //while( r!=0 ) // 辗转相除法
m = n;
n = r;
r = m % n;
}
return n;
}

例题/证明 3（01:13:29）｜ 最大公约数计算函数 gcd（含优化）

  • 题目：定义 gcd(m,n) 返回两正整数最大公约数。
  • 思路（辗转相除法）：先保证 m≥nm\ge n（用逗号表达式 r=m, m=n, n=r; 一次交换）；r = m % n；当 r!=0 时，令 m=n, n=r, r=m%n 继续；r==0 时 n 即为最大公约数。
  • 老师课堂讨论与优化：
    • if(m<n) r=m, m=n, n=r; 这是逗号表达式（三句话用逗号连成一句，作用同分号分隔的三句），第六章会正式讲，这里先「挖个坑」。
    • while(r) 等价于 while(r!=0)；if(!m) 等价于 if(m==0)。逻辑值：非 0 即真、0 即假。
    • 优化版（课件）：先特判 if(!m) return n; else if(!n) return m;，再把 r=m%n 放进循环条件 while(r = m % n){ m=n; n=r; } return n;。这里 r = m % n 是赋值（不是关系表达式），先算余数再判非零。
    • Bug 讨论：若 m、n 同时为 0，则没有最大公约数，本函数不处理这种非正常情况（属于调用者责任）。优化版中 if(!m) return n; 当 m==0 时 r=m%n=0 直接返回 n，已被包含。
  • 易错点：把 while(r = m % n) 误写成 while(r == m % n)——那是关系比较而非赋值，逻辑全错（老师特意对比了作业中 if(x=0) 这种「故意写错」的赋值陷阱）。

五、结构化程序设计思想（01:29:33—01:35:35）

01:29:33—01:32:12 ｜ 结构化程序设计：自顶向下、逐步细化

有了函数就能实现结构化程序设计（Dijkstra, 1969）：把复杂问题求解划分为若干阶段，每个阶段易理解、易处理。基本步骤是自顶向下：问题 → 子问题 → 孙子问题 → … → 易解问题，每一次分解都是逐步求精、逐步细化。

例如判断素数：上层只把它当作「一个已解决的自问题」来用（prime(m)），而不必在主线里纠结判定细节——主线因而简洁。

以「学生成绩统计程序」为例：先分解为「成绩输入 / 数据计算（含课程平均分、学生平均分、分布统计）/ 数据查找 / 输出成绩」等模块，每个模块由一个函数完成。

  • 模块划分讲究「内部联系紧密、模块之间联系尽量简单」——就像把一块形状「在最窄处」分割，边界最少、耦合最低。
  • 模块可独立编码、方便多人合作；合作前要对变量/常量/函数命名风格统一。
  • 程序要有适当注释，利于维护扩展；缩进、一行一句、层次清楚。
  • 可读性第一，效率第二：在保证功能与合理性能前提下，可读性优先；不要为一点点效率把代码改得无法阅读。

六、局部变量与全局变量（01:35:35—01:53:58）

01:35:35—01:37:16 ｜ 局部变量：函数内与复合语句内

  • 函数内部定义的变量叫局部变量，作用范围是所在函数内，函数外不可用。
  • 复合语句内部定义的变量（如循环体里）也叫局部变量，作用范围是所在复合语句内；函数内局部变量在循环体可用，但循环体里的局部变量在循环体外不可用。

  • 函数内部的局部变量定义必须在函数开始处；复合语句的局部变量也要在复合语句开始处定义。

income( value );
else
expend( value );
printf("current cash: %.2f\n\n", cash);
}
return 0;
}

例题/证明 1（01:53:58）｜ 现金记账函数 income / expend（含超支处理）

  • 题目：用函数实现现金记账。操作类型 1=收入、2=支出、0=结束；输入金额，计算余额；支出超支时提示 Over expend! 并清零。
  • 思路：全局 cash 初值 0（全局变量默认初值 0）；income 用 cash += n；expend 用 cash -= n，若 cash<0 打印超支并 cash=0。主函数用 while(1) 死循环配合 break 减少逻辑层次与代码右移。
  • 老师强调——为何用函数操作全局变量：若在各处直接写 cash = cash - 20，那么「超支检测」要在很多地方重复写；封装成 expend 函数后，调用即自动完成异常检测与处理，主函数只需 expend(value)，干净且不易漏。
  • 易错点：+=、-= 复合赋值；cash -= n 后 cash 可能为负（本来没钱又消费），必须检测；while(1)+break 是常用控制结构。

01:57:48—02:01:25 ｜ 变量的生命周期：创建与销毁

变量对应若干存储单元，计算机会按变量类型适时创建（分配单元）与销毁（回收单元）。从创建到销毁的整个过程即生命周期。

  • 全局变量：程序运行时创建，程序结束后销毁 → 生命周期 = 整个程序执行期间。
  • 局部变量（函数内）：函数被调用时创建（含形式参数），函数返回后销毁 → 生命周期 = 函数执行期间。
  • 复合语句内的局部变量：进入复合语句时创建，退出时销毁。
  • 特别强调（循环体里的局部变量）：每次进入循环体都重新创建该变量（并初始化），循环结束就销毁；两次循环之间变量是不同的单元。例如 while(...){ int a=0; a++; } 循环 100 次，a 始终是 1——因为每次进入都新建 a 并置 0，退出即销毁。
  • 作用范围（空间） 与 生命周期（时间） 是两个不同维度。

02:01:25—02:07:40 ｜ 静态变量 static（静态局部 / 静态全局）

用 static 修饰变量即静态变量：

static double f = 1;   // 静态局部变量示例（见下例）
static int g;          // 静态全局变量
  • 静态局部变量：改变了局部变量的生命周期——不再在「进入时创建、退出时销毁」，而是程序一运行就在静态存储区创建，生命周期变为整个程序执行期间。例如 static double f = 1; 只在程序启动时初始化一次，之后调用不再重新创建。
  • 静态全局变量：全局变量生命周期本就是全程，故 static 不改变其生命周期，而是改变作用范围——从「整个程序」缩小为「从定义开始到本文件结束」，不能被其他 .c 文件使用，也不能声明为外部变量。
  • 多文件好处：合作编程序时，甲写 a.c、乙写 b.c，各自把只在本文件内部使用的全局变量加 static，互不干扰；若确需跨文件共享，则那个变量用真正的全局变量（不加 static），并事先约定。

例题/证明 2（02:01:55）｜ 静态变量阶乘 fact_s（生命周期演示）

#include <stdio.h>
double fact_s( int n );
int main(void)
{
int i, n = 30;
for( i = 1; i <= n; i ++ )
printf("%3d! = %.0f\n", i,fact_s(i));
return 0;
}

{

return f;
}

代码取自课件 ch05.txt（例程 5-9 阶乘计算）。

  • 题目/演示：用静态局部变量 f 累计阶乘。
  • 分析：f 是静态局部变量，程序启动时创建并初始化为 1，之后每次调用 fact_s 都复用同一单元，不清零。故 fact_s(1)=1, fact_s(2)=2, fact_s(3)=6, … 连续算出阶乘。若把 main 的循环改为「连续 3 次调用 fact_s(3)」，则返回值为 6, 18, 54（在上一结果上继续乘 3）。
  • 易错点：误以为静态局部变量每次调用都重新初始化；它与自动（auto）局部变量「进入创建、退出销毁」截然不同。

02:07:40—02:10:05 ｜ 变量的初值：全局/静态为 0，局部不确定

定义变量时可同时赋初值 类型名 变量名 = 初值;。若未赋初值：

  • 全局变量与静态变量：初值为「0」（程序启动时所有 bit 清 0），直到程序退出才销毁。
  • 局部变量：初值不确定（垃圾值/随机数，是之前程序留下的残留），进入时分配内存但不做任何清理，可能被创建多次、每次内存单元与初值都不同。

为何局部变量不自动清零？因为它频繁创建/销毁，每次都清零效率低；而全局/静态变量整个程序只创建一次，清零开销小。当然全局变量也可在定义时赋初值。

02:10:05—02:12:50 ｜ 作用范围与同名屏蔽规则

  • 作用范围：全局变量→整个程序；静态全局变量→本文件（定义处到文件尾）；函数局部变量→所在函数；复合语句局部变量→所在复合语句。
  • 同名屏蔽规则：允许不同范围变量重名；重名时内部变量屏蔽外部变量，小范围屏蔽大范围（复合语句局部屏蔽外层复合语句局部、屏蔽函数局部；函数局部屏蔽全局）。复合语句可嵌套，内部总是屏蔽外部。
  • 全局变量不能重名（静态全局变量除外）；同一文件里「一个全局变量 A + 一个静态全局变量 A」也不行；但不同文件可各有一个全局 A 与一个静态全局 A（静态全局屏蔽其他文件的同名全局，且不影响本文件使用）。规则核心：这样做若不影响使用、不产生歧义，就允许；若导致奇异，就不允许。

例题/证明 1（02:13:06）｜ .c 文件布局与 extern 外部变量声明

  • 题目/演示：展示标准 .c 文件布局，重点是 extern 声明外部变量。
  • 代码：见上方代码块（取自课件 ch05.txt）。
  • 分析：extern double remainValue; 声明 remainValue 是「外部变量」——它不是本文件定义的，而是其他 .c 文件定义的全局变量。extern 告诉编译器：「这个变量的类型和名字我知道，它在别处定义。」这样本文件就能使用它。

02:15:46—02:18:00 ｜ 外部变量 extern：声明与定义的区别

// 外部变量申明
extern int a;
  • 外部变量即「定义在其他文件中的全局变量」。要用它，须在使用前用 extern 声明。
  • 声明不能代替定义：声明只告诉编译器类型与名字，并不分配存储；该变量必须在某个 .c 文件里有且仅有一个定义（int a;）。
  • 老师比喻：10 个同学野炊，9 个人都「声明」要带一口锅，但若没人真正带锅（都只是声明、无定义），到了目的地大眼瞪小眼、做不成饭。全局变量同理——可以有多个文件声明它，但必须有且仅有一个文件定义它，否则链接阶段报错（找不到定义）。

例题/证明 1（02:18:07）｜ 变量初值与作用范围练习（x、a、b 的运行结果）

  • 题目：走读上方代码，求 printf("%d %d\n", a, x); 的输出。
  • 逐步分析：
    1. 全局 int x;（初值 0，在静态存储区）。
    2. main 局部 a = 1。
    3. x = a; → 全局 x = 1。
    4. a = f(); → 进入 f：其局部 int x = 4（屏蔽全局），return x 返回 4；a = 4。全局 x 不受影响，仍为 1（值传递/作用范围屏蔽）。
    5. 复合语句：局部 b = 2；b = a + b = 4 + 2 = 6；x = x + b → 这里的 x 是全局 x，x = 1 + 6 = 7。
    6. 打印 a 与全局 x：a=4, x=7。
  • 输出：4 7。
  • 易错点：以为 f 里的 x=4 改了全局 x（实际是局部屏蔽）；以为复合语句里的 x 是别处——它引用的是全局 x（内部无定义时向外层找）。

02:20:21—02:26:34 ｜ 课后练习：判断各位数字是否从小到大排列

教材 120 页一般习题第 2 题：判断一个整数的各位数字是否按从小到大排列（如 12345、1279 是，132 不是）。老师带领填空还原算法，要点如下：

  • 主函数里：定义全局变量用于结果、定义局部变量、调用判断函数（函数声明写在前，因为函数在 main 之后定义）；复合语句内可再定义局部变量参与计算。
  • 判断函数逻辑（按老师口述补全，[补全]：课件仅展示填空讨论、未给完整书码，以下为按讲解还原的标准实现）：
// [补全] 按课堂讲解还原：判断 n 的各位数字是否从小到大排列
// 思路：从个位起，每位都应 >= 高一位（即左读递增，右读递减）
int isOrder(int n)            // 函数名按学科习惯补全
{
int current = n % 10;        // 个位（最小权值位）
n = n / 10;                  // 去掉个位
while (n >= 10) {            // 老师强调应为 >= 10（原书/讨论中曾写 > 10，漏掉 m==10）
int old = n % 10;        // 当前更高一位
if (old > current)       // 高位比低位大 → 非升序
return 0;
current = old;
n = n / 10;
}
return 1;
}
  • 老师重点纠正：循环条件应为 m >= 10（或 m > 9）。若写成 m > 10，当数字恰为 10（各位「1」「0」）时会漏判——m 先 m/10 变 1，循环不进，直接 return 1，错误。应为 >= 10 才能正确处理两数位情形。
  • 关系表达式返回逻辑值：类似前面 IsSquare 的 return n==0;，这里 old > current 是关系表达式，真为 1、假为 0，作为 if 条件。
  • 注：上段 main 输出「从小到大排列」时走 if 分支、否则走 else；具体书本填空代码以教材 120 页为准（课件未完整给出）。
