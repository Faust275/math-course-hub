00:00:22—00:18:16 ｜ 复合函数求导公式：错误证法辨析与正确证明

先回顾复合函数求导公式：若 y=f(u) 在u0=g(x0)u_0=g(x_0)处可导， u=g(x) 在x0x_0处可导，则复合函数 F(x)=f(g(x)) 在x0x_0处可导，且

F′(x0)=f′(g(x0))g′(x0).F'(x_0)=f'(g(x_0))\,g'(x_0).

老师提醒：证明前必须保证两层复合有意义，即 g 在x0x_0的某个邻域内取值要落进 f 在u0u_0可导所要求的那个邻域里，否则复合本身没有意义。

例题/证明 1（00:02:13）｜ 复合函数求导公式的证明（含错误证法辨析）

  1. 命题（任务陈述）：在 f 于u0=g(x0)u_0=g(x_0)可导、 g 于x0x_0可导的条件下，证明(f∘g)′(x0)=f′(g(x0))g′(x0)(f\circ g)'(x_0)=f'(g(x_0))\,g'(x_0)。

  2. 思路：先用“最直白”的拆分去算极限，发现会卡住；再引入一个在u0u_0处补定义的小 o 型辅助函数，绕开分母可能为零的麻烦。

  3. 错误的证法（逐步推导）：

    • 想直接写 f(g(x))−f(g(x0))x−x0=f(g(x))−f(g(x0))g(x)−g(x0)⋅g(x)−g(x0)x−x0,\frac{f(g(x))-f(g(x_0))}{x-x_0} =\frac{f(g(x))-f(g(x_0))}{g(x)-g(x_0)}\cdot\frac{g(x)-g(x_0)}{x-x_0},然后让x→x0x\to x_0取极限。
    • 依据：若两个因子极限都存在，则乘积极限等于极限乘积。
    • 问题：当 x 在x0x_0的去心邻域内变动时， g(x) 可能无穷多次等于g(x0)g(x_0)，于是g(x)−g(x0)=0g(x)-g(x_0)=0，第一个分式的分母反复为零，该分式在那些点根本没有定义，无法取极限。
    • 结论：这是一个伪证，不能用。

  4. 正确的证法（逐步推导）：

    • 定义辅助函数（把可导性写成带小 o 的恒等式，并在u0u_0处补定义）： φ(u)={f(u)−f(u0)u−u0,u≠u0,f′(u0),u=u0.\varphi(u)= \begin{cases} \dfrac{f(u)-f(u_0)}{u-u_0}, & u\neq u_0,\\[6pt] f'(u_0), & u=u_0. \end{cases} 依据： f 在u0u_0可导⇒lim⁡u→u0φ(u)=f′(u0)=φ(u0)\Rightarrow \lim_{u\to u_0}\varphi(u)=f'(u_0)=\varphi(u_0)，故 φ 在u0u_0连续；且对u0u_0邻域内任意 u 有 f(u)−f(u0)=φ(u)(u−u0),f(u)-f(u_0)=\varphi(u)(u-u_0),这一等式在u=u0u=u_0时也成立（两边都是 0 ）。
    • 同理对 g 写出 g(x)−g(x0)=ψ(x)(x−x0),ψ(x0)=g′(x0),g(x)-g(x_0)=\psi(x)(x-x_0),\qquad \psi(x_0)=g'(x_0),且 ψ 在x0x_0连续。
    • 代入u=g(x) ： f(g(x))−f(g(x0))=φ(g(x))(g(x)−g(x0))=φ(g(x))ψ(x)(x−x0).f(g(x))-f(g(x_0))=\varphi(g(x))\,(g(x)-g(x_0)) =\varphi(g(x))\,\psi(x)\,(x-x_0).注意这里即使g(x)=g(x0)g(x)=g(x_0)等式仍成立，彻底避开了分母为零。
    • 两边除以x−x0x-x_0（x≠x0x\neq x_0）： f(g(x))−f(g(x0))x−x0=φ(g(x))ψ(x).\frac{f(g(x))-f(g(x_0))}{x-x_0}=\varphi(g(x))\,\psi(x).
    • 取极限x→x0x\to x_0：
      • 因 g 可导 ⇒ g 连续，故g(x)→g(x0)g(x)\to g(x_0)；
      • φ 在u0u_0连续⇒φ(g(x))→φ(g(x0))=f′(u0)=f′(g(x0))\Rightarrow \varphi(g(x))\to \varphi(g(x_0))=f'(u_0)=f'(g(x_0))；
      • ψ(x)→ψ(x0)=g′(x0)\psi(x)\to \psi(x_0)=g'(x_0)。
    • 于是 (f∘g)′(x0)=f′(g(x0))g′(x0).(f\circ g)'(x_0)=f'(g(x_0))\,g'(x_0).

  5. 结论：复合函数求导公式成立。

  6. 老师点出的易错点：

    • 这个补定义φ(u0)=f′(u0)\varphi(u_0)=f'(u_0)只是“补一个小缺口，本身不改变任何事实，却是证明能否走通的关键；后面许多地方（如隐函数、反函数求导）都会用到这种“把导数写成恒等式再补定义”的技巧。
    • 不能图省事直接把x−x0x-x_0除掉去算极限，否则会出现分母为零的坏东西。
    • 课上布置了约十个复合/基本求导的计算题，但堂上不再逐题演算，需要大家自己练熟。

00:18:16—00:21:21 ｜ 反函数求导公式（作为复合函数求导的推论）

例题/证明 2（00:18:28）｜ 反函数求导公式

  1. 命题：设 y=f(x) 在区间上严格单调、可导，且f′(x)≠0f'(x)\neq 0，其反函数为x=f−1(y)x=f^{-1}(y)。则 (f−1)′(y)=1f′(x),x=f−1(y).(f^{-1})'(y)=\frac{1}{f'(x)},\qquad x=f^{-1}(y).

  2. 思路：利用复合函数求导公式，把“原函数与反函数互为复合得恒等”这一关系对 y 求导。

  3. 逐步推导：

    • 在相应区间上，恒等式f(f−1(y))=yf(f^{-1}(y))=y成立。
    • 两边关于 y 求导，依据复合函数求导公式（把f−1(y)f^{-1}(y)看成内层）： f′(f−1(y))⋅(f−1)′(y)=1.f'(f^{-1}(y))\cdot (f^{-1})'(y)=1.
    • 因f′(x)≠0f'(x)\neq 0，解得 (f−1)′(y)=1f′(x),x=f−1(y).(f^{-1})'(y)=\frac{1}{f'(x)},\quad x=f^{-1}(y).

  4. 结论：反函数求导公式是复合函数求导公式的直接推论。

  5. 老师点出的意义：最重要的不是记住这个公式本身，而是理解“反函数求导”与“复合函数求导”是同一件事的两面——把 y=y(x) 想成由约束确定的关系，代回原方程再求导即可，不必死记公式。

00:21:21—00:52:35 ｜ 基本初等函数的导数（幂、指数、对数、三角、双曲、反三角）

老师强调：基本初等函数的求导是“常规动作，但其中幂函数最“既简单又麻烦”——简单在它是单项式，麻烦在参数 α 不同时定义域与可导性结论不同，需要分类讨论。

例题/证明 3（00:22:09）｜ 幂函数的导函数（按 α 分类）

  1. 题目：求f(x)=xαf(x)=x^{\alpha}的导函数，并讨论 x=0 处的可导性。

  2. 思路：先处理 x≠0 （直接套用幂法则），再单独讨论 x=0 处按定义取极限，按 α 的取值分类。

  3. 逐步推导：

    • 当 x≠0 时，由标准极限lim⁡h→0(x+h)α−xαh=αxα−1\displaystyle\lim_{h\to 0}\frac{(x+h)^{\alpha}-x^{\alpha}}{h}=\alpha x^{\alpha-1}，得 (xα)′=αxα−1.(x^{\alpha})'=\alpha x^{\alpha-1}.
    • 当 x=0 （要求 α>0 时 0 才在定义域内）：按定义 f′(0)=limx→0xα−0x−0=limx→0xα−1.f'(0)=\lim_{x\to 0}\frac{x^{\alpha}-0}{x-0}=\lim_{x\to 0}x^{\alpha-1}.
      • 若 α=1 ，则f′(0)=lim⁡x→01=1f'(0)=\lim_{x\to 0}1=1；
      • 若 α>1 ，则f′(0)=0f'(0)=0；
      • 若 0<α<1 ，则极限为 +∞ ，在 0 处不可导（导数非有限）。
    • 老师补充：对分数幂如x5/13x^{5/13}（分母为奇数），定义域可延伸到 x<0 ，此时还可讨论左导数；结论仍是“只要落在定义域内，求导公式xα−1x^{\alpha-1}可用。

  4. 结论： (xα)′=αxα−1(x≠0 且落在定义域内),(x^{\alpha})'=\alpha x^{\alpha-1}\quad (x\neq 0\text{ 且落在定义域内}),在 x=0 处：可导且导数为 1 （ α=1 ）或 0 （α>1\alpha>1）； 0<α<1 时导数无限（不可导）。

  5. 老师点出的易错点：很多同学只背“幂函数导数是αxα−1\alpha x^{\alpha-1}，却忽略 x=0 这个点要单独按定义检查，而且必须先确认该点是否在定义域里。

例题/证明 4（00:30:31）｜ 绝对值函数 |x| 与 ln⁡|x| 的导数

  1. 题目：求 |x| 与 ln⁡|x| 的导函数。

  2. 思路：从导函数角度看，在某点求导只与该点附近的函数值有关，因此必须按正负两支分别处理。

  3. 逐步推导：

    • |x|={x,x>0−x,x<0|x|=\begin{cases}x,&x>0\\-x,&x<0\end{cases}，故 |x|′={1,x>0−1,x<0,|x|'=\begin{cases}1,&x>0\\-1,&x<0\end{cases},在 x=0 处不可导（左右导数分别为 1 与 −1 ）。
    • ln⁡|x|={ln⁡x,x>0ln⁡(−x),x<0\ln|x|=\begin{cases}\ln x,&x>0\\\ln(-x),&x<0\end{cases}。
      • x>0x>0：(ln⁡x)′=1/x(\ln x)'=1/x；
      • x<0x<0：(ln⁡(−x))′=1−x⋅(−1)=1/x(\ln(-x))'=\frac{1}{-x}\cdot(-1)=1/x。 所以在整个 x≠0 上， (ln⁡|x|)′=1x.(\ln|x|)'=\frac{1}{x}.

  4. 结论：|x|′=sgn⁡(x)(x≠0)|x|'=\operatorname{sgn}(x)\;(x\neq 0)；(ln⁡|x|)′=1/x(x≠0)(\ln|x|)'=1/x\;(x\neq 0)。

  5. 老师点出的意义：这里体现了“导函数是逐点概念”——虽然 |x| 与 ln⁡|x| 的分段表达式不同，但求导时每一点只关心它所在的支，公式 1/x 在正负两侧共用。后面做不定积分、对数求导法时，必须清醒地意识到 ln⁡|x| 的导数在 x>0 与 x<0 都是 1/x 。

例题/证明 5（00:33:01）｜ 三角函数导数（ tan⁡x,cot⁡x,sec⁡x,csc⁡x ）

  1. 题目：推导 tan⁡x,cot⁡x,sec⁡x,csc⁡x 的导数。

  2. 思路：把它们写成 sin⁡x,cos⁡x 的商，用商法则（四则运算）逐项求。

  3. 逐步推导：

    • tan⁡x=sin⁡xcos⁡x\tan x=\dfrac{\sin x}{\cos x}。依据商法则(u/v)′=(u′v−uv′)/v2(u/v)'=(u'v-uv')/v^2： (tan⁡x)′=cos⁡x⋅cos⁡x−sin⁡x⋅(−sin⁡x)cos⁡2x=cos⁡2x+sin⁡2xcos⁡2x=1cos⁡2x=sec⁡2x.(\tan x)'=\frac{\cos x\cdot\cos x-\sin x\cdot(-\sin x)}{\cos^2 x} =\frac{\cos^2x+\sin^2x}{\cos^2x}=\frac{1}{\cos^2x}=\sec^2x.
    • cot⁡x=cos⁡xsin⁡x\cot x=\dfrac{\cos x}{\sin x}： (cot⁡x)′=−sin⁡x⋅sin⁡x−cos⁡x⋅cos⁡xsin⁡2x=−1sin⁡2x=−csc⁡2x.(\cot x)'=\frac{-\sin x\cdot\sin x-\cos x\cdot\cos x}{\sin^2x} =-\frac{1}{\sin^2x}=-\csc^2x.
    • sec⁡x=1cos⁡x\sec x=\dfrac{1}{\cos x}： (sec⁡x)′=0⋅cos⁡x−1⋅(−sin⁡x)cos⁡2x=sin⁡xcos⁡2x=sec⁡xtan⁡x.(\sec x)'=\frac{0\cdot\cos x-1\cdot(-\sin x)}{\cos^2x} =\frac{\sin x}{\cos^2x}=\sec x\tan x.
    • csc⁡x=1sin⁡x\csc x=\dfrac{1}{\sin x}： (csc⁡x)′=0⋅sin⁡x−1⋅cos⁡xsin⁡2x=−cos⁡xsin⁡2x=−csc⁡xcot⁡x.(\csc x)'=\frac{0\cdot\sin x-1\cdot\cos x}{\sin^2x} =-\frac{\cos x}{\sin^2x}=-\csc x\cot x.

  4. 结论： (tan⁡x)′=sec⁡2x,(cot⁡x)′=−csc⁡2x,(sec⁡x)′=sec⁡xtan⁡x,(csc⁡x)′=−csc⁡xcot⁡x.(\tan x)'=\sec^2x,\quad (\cot x)'=-\csc^2x,\quad (\sec x)'=\sec x\tan x,\quad (\csc x)'=-\csc x\cot x.

  5. 老师点出的意义：这些公式是“谁是谁的导函数”要反过来记——后面求原函数、分部积分时默认你已经算过一遍并能反查。例如知道sec⁡2x\sec^2x是 tan⁡x 的导数，则 tan⁡x 是sec⁡2x\sec^2x的一个原函数。

例题/证明 6（00:38:02）｜ 双曲函数导数（ sinh⁡x,cosh⁡x,tanh⁡x ）

  1. 题目：求双曲正弦、余弦、正切的导数。

  2. 思路：用定义sinh⁡x=ex−e−x2,cosh⁡x=ex+e−x2\sinh x=\dfrac{e^x-e^{-x}}{2},\ \cosh x=\dfrac{e^x+e^{-x}}{2}，直接求导。

  3. 逐步推导：

    • (sinh⁡x)′=ex−(−e−x)2=ex+e−x2=cosh⁡x(\sinh x)'=\dfrac{e^x-(-e^{-x})}{2}=\dfrac{e^x+e^{-x}}{2}=\cosh x；
    • (cosh⁡x)′=ex−e−x2=sinh⁡x(\cosh x)'=\dfrac{e^x-e^{-x}}{2}=\sinh x；
    • tanh⁡x=sinh⁡xcosh⁡x\tanh x=\dfrac{\sinh x}{\cosh x}，用商法则： (tanh⁡x)′=cosh⁡x⋅cosh⁡x−sinh⁡x⋅sinh⁡xcosh⁡2x=cosh⁡2x−sinh⁡2xcosh⁡2x=1cosh⁡2x=sech⁡2x.(\tanh x)'=\frac{\cosh x\cdot\cosh x-\sinh x\cdot\sinh x}{\cosh^2x} =\frac{\cosh^2x-\sinh^2x}{\cosh^2x}=\frac{1}{\cosh^2x}=\operatorname{sech}^2x.

  4. 结论： (sinh⁡x)′=cosh⁡x,(cosh⁡x)′=sinh⁡x,(tanh⁡x)′=sech⁡2x.(\sinh x)'=\cosh x,\quad (\cosh x)'=\sinh x,\quad (\tanh x)'=\operatorname{sech}^2x.

  5. 老师点出的意义：双曲函数与三角函数“很像但不完全一样”——(sinh⁡x)′=cosh⁡x(\sinh x)'=\cosh x没有负号，而(sin⁡x)′=cos⁡x(\sin x)'=\cos x；(cosh⁡x)′=sinh⁡x(\cosh x)'=\sinh x也没有负号（不像(cos⁡x)′=−sin⁡x(\cos x)'=-\sin x）。 tanh⁡x 的导数形式与 tan⁡x 类似（都是“平方”形式），但符号为正。

例题/证明 7（00:42:00）｜ 反三角函数导数（以 arctan⁡x 与 arcsin⁡x 为例）

  1. 题目：求 arctan⁡x 与 arcsin⁡x 的导函数，并讨论端点 x=±1 。

  2. 思路：用反函数求导公式；端点处公式分母为 0 ，必须改用定义。

  3. 逐步推导：

    • 对 y=arctan⁡x ，即 x=tan⁡y,y∈(−π/2,π/2) 。由反函数求导公式： (arctan⁡x)′=1(tan⁡y)′=1sec⁡2y=11+tan⁡2y=11+x2,x∈ℝ.(\arctan x)'=\frac{1}{(\tan y)'}=\frac{1}{\sec^2y}=\frac{1}{1+\tan^2y}=\frac{1}{1+x^2},\qquad x\in\mathbb{R}.
    • 对 y=arcsin⁡x ，即 x=sin⁡y,y∈(−π/2,π/2) 。 (arcsin⁡x)′=1(sin⁡y)′=1cos⁡y=11−sin⁡2y=11−x2,x∈(−1,1).(\arcsin x)'=\frac{1}{(\sin y)'}=\frac{1}{\cos y}=\frac{1}{\sqrt{1-\sin^2y}}=\frac{1}{\sqrt{1-x^2}},\qquad x\in(-1,1).
    • 端点讨论： x=±1 时公式11−x2\dfrac{1}{\sqrt{1-x^2}}分母为 0 ，反函数求导定理“不负责”这一点。函数在 x=±1 有定义（如 arcsin⁡(1)=π/2 ），其导数要用定义算，结果为 +∞ （切线竖直），不能套用上面的开区间公式。

  4. 结论： (arctan⁡x)′=11+x2(∀x∈ℝ),(arcsin⁡x)′=11−x2(x∈(−1,1)).(\arctan x)'=\frac{1}{1+x^2}\ (\forall x\in\mathbb{R}),\qquad (\arcsin x)'=\frac{1}{\sqrt{1-x^2}}\ (x\in(-1,1)).在 x=±1 处导数不存在有限值（为无穷），须用定义处理。

  5. 老师点出的易错点：定理只保证开区间 (−1,1) 内的公式；有人想直接把 x=−1 代进 arcsin 的反函数求导式得到“倒数，那是错的，必须用定义。

00:52:35—01:05:22 ｜ 隐函数及其求导

老师回顾：隐函数由方程 F(x,y)=0 确定——在某个区间 (a,b) 上，每个 x 通过方程确定唯一的 y=y(x) ；之所以叫“隐，是因为往往显化不出来（写不出 y= 显式表达式），但定性地知道“一个 x 对应一个 y 。

例题/证明 8（00:57:02）｜ 隐函数求导：由x2+y2=1x^2+y^2=1求y′y'

  1. 题目：设方程x2+y2=1x^2+y^2=1在区间上确定隐函数 y=y(x) （如取上半支y=1−x2y=\sqrt{1-x^2}），求y′y'。

  2. 思路：把 y 看成 x 的函数代回原方程，两边对 x 求导（用到复合函数求导），再解出y′y'。

  3. 逐步推导：

    • 将 y=y(x) 代入：x2+(y(x))2=1x^2+(y(x))^2=1。
    • 两边关于 x 求导，依据复合函数求导（(y2)′=2y⋅y′(y^2)'=2y\cdot y'）： 2x+2y⋅y′=0.2x+2y\cdot y'=0.
    • 解出y′=−xyy'=-\dfrac{x}{y}（其中 y≠0 ）。

  4. 结论：y′=−xyy'=-\dfrac{x}{y}（在上半支即y=1−x2y=\sqrt{1-x^2}时，等价于y′=−x/1−x2y'=-x/\sqrt{1-x^2}）。

  5. 老师点出的意义：

    • 隐函数求导“本质上还是复合函数求导的一个应用”——心里想着把 y=y(x) 代回原方程，得到恒等式再求导，不需要死记公式。
    • 一般情形需要偏导数工具才能严格讨论“是否存在唯一隐函数，那是数学分析最重要的定理之一（后面 PDE 也会用到）；目前在没有偏导数工具时，只做“假设隐函数已存在，计算其导数”这一层。

01:05:22—01:23:57 ｜ 对数求导法

对数求导法适合“幂指混合、乘除开方嵌套”的函数：先取对数（注意加绝对值）化为四则运算，再两边求导。

例题/证明 9（01:05:43）｜ 对数求导法例一（乘除与复合）

  1. 题目：对形如y=exsin⁡xx2+3xy=\dfrac{e^x\sin x}{x^2+3x}的函数求导。

  2. 思路：直接按商法则会很繁琐；先取对数化为加减，再求导、回代。

  3. 逐步推导：

    • 两边取对数（ln⁡|y|=ln⁡|ex|+ln⁡|sin⁡x|−ln⁡|x2+3x|\ln|y|=\ln|e^x|+\ln|\sin x|-\ln|x^2+3x|）： ln⁡|y|=x+ln⁡|sin⁡x|−ln⁡|x|−ln⁡|x+3|.\ln|y|=x+\ln|\sin x|-\ln|x|-\ln|x+3|.
    • 两边关于 x 求导，依据(ln⁡|u|)′=u′/u(\ln|u|)'=u'/u： y′y=1+cos⁡xsin⁡x−1x−1x+3=1+cot⁡x−1x−1x+3.\frac{y'}{y}=1+\frac{\cos x}{\sin x}-\frac{1}{x}-\frac{1}{x+3} =1+\cot x-\frac{1}{x}-\frac{1}{x+3}.
    • 回代 y 得 y′=y(1+cot⁡x−1x−1x+3)=exsin⁡xx(x+3)(1+cot⁡x−1x−1x+3).y'=y\Bigl(1+\cot x-\frac{1}{x}-\frac{1}{x+3}\Bigr) =\frac{e^x\sin x}{x(x+3)}\Bigl(1+\cot x-\frac{1}{x}-\frac{1}{x+3}\Bigr).

  4. 结论：上式即所求导数。

  5. 老师点出的意义：对数求导法把“商的求导”化简成“加减后的乘除，书写上简洁很多；但它本质上仍只是四则运算与复合函数求导，不引入新原理。

例题/证明 10（01:11:29）｜ 对数求导法例二（含绝对值与符号变化点，须用定义补算）

  1. 题目：对带多个一次因式的乘除型函数（如y=(x+1)(x+2)3(x+4)2y=\dfrac{(x+1)(x+2)^3}{(x+4)^2}之类 [?]）用对数求导法，并讨论公式失效的点。

  2. 思路：取 ln⁡|y| 化为各因式对数之和；注意公式只在 y≠0 且绝对值符号“不翻转”的局部区间有效，遇到 y=0 或符号变化点必须用定义单独计算。

  3. 逐步推导：

    • 取对数（用ln⁡|u|′=1/u\ln|u|'=1/u）： ln⁡|y|=ln⁡|x+1|+3ln⁡|x+2|−2ln⁡|x+4|,\ln|y|=\ln|x+1|+3\ln|x+2|-2\ln|x+4|, y′y=1x+1+3x+2−2x+4.\frac{y'}{y}=\frac{1}{x+1}+\frac{3}{x+2}-\frac{2}{x+4}.于是 y′=y(1x+1+3x+2−2x+4).y'=y\Bigl(\frac{1}{x+1}+\frac{3}{x+2}-\frac{2}{x+4}\Bigr).
    • 关键点：上式只在各因式非零且局部符号不变处成立。若某点使 y=0 （如 x=−1 使分子为零），则y′/yy'/y无意义，公式失效，必须改用导数定义计算该点导数；实录中老师以 x=−1 与另一取值点（如 x=4 处算得y′(4)=100y'(4)=100[?]）说明“对数求导法不适用的点要靠定义补算。
    • 依据：取绝对值会“损失信息”——把分段符号藏在 |y| 里，导致在符号翻转点或零点处公式覆盖不到，这正是用技巧换来的代价。

  4. 结论：对数求导法的公式在 y≠0 且局部符号恒定的区间有效；在 y=0 或符号变化点，必须用定义求导数。

  5. 老师点出的易错点：和前面 |⋅| 求导一样，每次动手前先搞清楚“定义域与符号”——不能盲目套 ln⁡|y| 的公式到所有点。

例题/证明 11（01:19:14）｜ 复合/链导例：含1a+x2\dfrac{1}{\sqrt{a+x^2}}的反导数定式

  1. 题目：用复合函数求导计算形如1a+x2\dfrac{1}{\sqrt{a+x^2}}的导数，并指出其反导数定式。

  2. 思路：把a+x2\sqrt{a+x^2}看成(a+x2)1/2(a+x^2)^{1/2}，依次用幂函数与复合函数求导。

  3. 逐步推导：

    • 设y=(a+x2)1/2y=(a+x^2)^{1/2}，则 y′=12(a+x2)−1/2⋅2x=xa+x2.y'=\frac{1}{2}(a+x^2)^{-1/2}\cdot 2x=\frac{x}{\sqrt{a+x^2}}.
    • 对y=1a+x2=(a+x2)−1/2y=\dfrac{1}{\sqrt{a+x^2}}=(a+x^2)^{-1/2}： y′=−12(a+x2)−3/2⋅2x=−x(a+x2)3/2.y'=-\frac{1}{2}(a+x^2)^{-3/2}\cdot 2x=-\frac{x}{(a+x^2)^{3/2}}.
    • 老师指出：这类“1a+x2\dfrac{1}{a+x^2}型”的反导数（如∫1a+x2dx=1aarctan⁡xa+C\displaystyle\int\frac{1}{a+x^2}\,dx=\frac{1}{\sqrt a}\arctan\frac{x}{\sqrt a}+C）在后续求不定积分、定积分时是高频定式，求逆时默认你已经熟练。

  4. 结论：(a+x2)′=xa+x2(\sqrt{a+x^2})'=\dfrac{x}{\sqrt{a+x^2}}；((a+x2)−1/2)′=−x(a+x2)3/2\bigl((a+x^2)^{-1/2}\bigr)'=-\dfrac{x}{(a+x^2)^{3/2}}。

参数方程 x=x(t),y=y(t) 确定 y 与 x 的（隐式）函数关系。老师建议：先“形式上”推导公式，再回头做严格化（要求 x(t) 有反函数，即x′(t)≠0x'(t)\neq0、严格单调）。

例题/证明 12（01:24:48）｜ 参数方程求导公式与实例

  1. 题目：由参数方程x=et+2,y=sin⁡tx=e^t+2,\ y=\sin t确定函数 y=y(x) ，求dydx\dfrac{dy}{dx}。

  2. 思路：形式上dydx=dy/dtdx/dt\dfrac{dy}{dx}=\dfrac{dy/dt}{dx/dt}；严格化需先证明 x=x(t) 有可导反函数 t=t(x) ，再视为复合函数求导。

  3. 逐步推导：

    • 形式推导： dydx=dy/dtdx/dt=cos⁡tet.\frac{dy}{dx}=\frac{dy/dt}{dx/dt}=\frac{\cos t}{e^t}.
    • 严格化：
      • x′(t)=et>0x'(t)=e^t>0，故x(t)=et+2x(t)=e^t+2严格单调递增，从而在区间上有反函数 t=t(x) ；
      • 由反函数求导，t′(x)=1/x′(t)=1/et=1/(x−2)t'(x)=1/x'(t)=1/e^t=1/(x-2)；
      • 把 y=sin⁡t 看成 y=sin⁡(t(x)) ，复合函数求导： dydx=cos⁡(t(x))⋅t′(x)=cos⁡(ln⁡(x−2))⋅1x−2.\frac{dy}{dx}=\cos(t(x))\cdot t'(x)=\cos(\ln(x-2))\cdot\frac{1}{x-2}.
    • 与形式结果一致（代入t=ln⁡(x−2),et=x−2t=\ln(x-2),\ e^t=x-2即得 cos⁡t/(x−2) ）。

  4. 结论： dydx=cos⁡tet=cos⁡(ln⁡(x−2))x−2.\frac{dy}{dx}=\frac{\cos t}{e^t}=\frac{\cos(\ln(x-2))}{x-2}.

  5. 老师点出的意义：参数方程求导“就是复合函数求导/反函数求导的应用。严格化时需要用到上节课的结论——严格单调（导数恒正）的函数有反函数，且反函数可导。先形式推导、再补严格条件，是处理复杂分析问题的常用策略。

例题/证明 13（01:41:33）｜ 含参曲线族y=xαy=x^{\alpha}在公共点处的切线

  1. 题目：考察随参数 α 变化的曲线族y=xαy=x^{\alpha}；所有曲线都过点 (1,1) ，讨论它们在该点处的导数/切线 [?]。

  2. 思路：逐条求y′(1)y'(1)，用分析语言（导数=切线斜率）回答几何问题——这正是“解析几何”：用分析的工具解几何问题。

  3. 逐步推导：

    • 由例题 3 的幂函数求导，(xα)′=αxα−1(x^{\alpha})'=\alpha x^{\alpha-1}。
    • 在 x=1 处，y′(1)=α⋅1α−1=αy'(1)=\alpha\cdot 1^{\alpha-1}=\alpha。

  4. 结论：曲线族y=xαy=x^{\alpha}均过 (1,1) ，在该点切线斜率为 α 。

  5. 老师点出的意义：把“几何的相切”翻译成“分析的导数相等，是解析几何的核心思路。

01:48:51—01:59:33 ｜ 用导数比较函数大小与单调性的例题

例题/证明 14（01:48:51）｜ 用导数证明在 (0,π/2) 上 sin⁡x<x<tan⁡x

  1. 题目：证明在区间 (0,π/2) 内， sin⁡x<x<tan⁡x 。

  2. 思路：作差构造辅助函数，用“导函数严格大于 0⇒ 严格单调递增”来判断大小。注意与中学不同，大学里要明确写出连续性区间与可导区间。

  3. 逐步推导：

    • 令 f(x)=x−sin⁡x ，定义域含 [0,π/2] ，且 f 连续、f′(x)=1−cos⁡x>0f'(x)=1-\cos x>0于 (0,π/2) 。依据：若函数在闭区间连续、开区间可导且导数恒正，则严格递增。
      • f(0)=0 ，故对 x∈(0,π/2) 有 f(x)>f(0)=0 ，即 x>sin⁡x 。
    • 令 g(x)=tan⁡x−x ，同样在 [0,π/2) 连续、g′(x)=sec⁡2x−1=tan⁡2x>0g'(x)=\sec^2x-1=\tan^2x>0于 (0,π/2) 。
      • g(0)=0 ，故 g(x)>0 ，即 tan⁡x>x 。
    • 合并得 sin⁡x<x<tan⁡x 。

  4. 结论：在 (0,π/2) 上严格成立 sin⁡x<x<tan⁡x 。

  5. 老师点出的意义与延伸：

    • 与高中不同，大学必须主动说明“在哪个区间连续、哪个开区间可导、端点如何处理”——定理要求闭区间连续、开区间导数正，才能把端点包进来；否则端点不连续时单调性结论不成立。
    • 这是从高中“舒适环境里推导”到大学“先确认环境再推导”的思维转变。
    • 讲完后可进一步自问（思考题）：比较 sin⁡x 与x−x36x-\dfrac{x^3}{6}、比较 tan⁡x 与某展开式等——辅助函数可添 sin⁡x/x 、tan⁡x/x\tan x/x、(tan⁡x−sin⁡x)/x3(\tan x-\sin x)/x^3等，沿不同辅助线得到不同估计。

01:59:33—02:08:55 ｜ 高阶导数与CkC^k连续可导函数空间

老师引入：若 f 在x0x_0的某邻域每点可导，就得到一阶导函数f′f'；若f′f'在该邻域每点也可导，就得到二阶导函数f″f''，依此递推得到 n 阶导数。记号：f(n)f^{(n)}或f(k)f^{(k)}。

例题/证明 15（02:00:15）｜ 高阶导数定义与y=x99y=x^{99}的 100 阶导数

  1. 题目：说明高阶导数的归纳定义，并求y=x99y=x^{99}的 100 阶导数。

  2. 思路：高阶导数就是“低一阶导函数再求一次导数”；对多项式，求导次数超过次数后归零。

  3. 逐步推导：

    • 定义（归纳）：要求 f 在x0x_0附近 (n−1) 阶可导，且 (n−1) 阶导函数在x0x_0可导，则称该值为 n 阶导数f(n)(x0)f^{(n)}(x_0)。
    • 对y=x99y=x^{99}： y′=99x98,y″=99⋅98x97,…,y(99)=99!,y(100)=0.y'=99x^{98},\ y''=99\cdot98\,x^{97},\ \dots,\ y^{(99)}=99!,\ y^{(100)}=0.通项：(xm)(k)=m!(m−k)!xm−k(k≤m)(x^m)^{(k)}=\dfrac{m!}{(m-k)!}x^{m-k}\ (k\le m)，且当 k>m 时为 0 。

  4. 结论：y=x99y=x^{99}的 100 阶导数为 0 ；一般地，多项式每多求一次导数，次数降 1 ，超过次数后恒为 0 。

  5. 老师点出的意义：不要被表面“看起来会无限进行下去”骗到——多项式的高阶导数必然在某阶后归零；这个结论对理解函数空间很重要。

例题/证明 16（02:10:25）｜ 反例：可导但导函数不连续的函数（说明C1C^1真包含于“可导）

  1. 题目：构造一个处处可导、但其导函数不连续的函数，说明“可导”不蕴含“导函数连续。

  2. 思路：用振荡型分段函数，在 0 处用定义算导数，在 0 外常规求导，再考察导函数在 0 处的极限。

  3. 逐步推导：

    • 定义 f(x)={x2sin⁡1x,x≠0,0,x=0.f(x)= \begin{cases} x^2\sin\dfrac{1}{x}, & x\neq 0,\\[6pt] 0, & x=0. \end{cases}

    • 在 x=0 ，用定义： f′(0)=limh→0h2sin⁡(1/h)−0h=limh→0hsin⁡1h=0(有界量乘无穷小).f'(0)=\lim_{h\to0}\frac{h^2\sin(1/h)-0}{h} =\lim_{h\to0}h\sin\frac{1}{h}=0\quad(\text{有界量乘无穷小}).故 f 处处可导。
    • 但f′f'在 0 不连续：取xn=12πnx_n=\dfrac{1}{2\pi n}，则cos⁡(1/xn)=cos⁡(2πn)=1\cos(1/x_n)=\cos(2\pi n)=1，于是 f′(xn)=2xnsin⁡(2πn)−1→−1≠f′(0)=0.f'(x_n)=2x_n\sin(2\pi n)-1\;\to\;-1\neq f'(0)=0.故lim⁡x→0f′(x)\lim_{x\to0}f'(x)不存在，f′f'在 0 不连续。

  4. 结论： f 可导但f′∉C0f'\not\in C^0，即“可导” ⇏ “导函数连续。由此引入函数空间CkC^k（ k 阶连续可导）： C0⊃C1⊃C2⊃⋯⊃C∞,C^0\supset C^1\supset C^2\supset\cdots\supset C^\infty,且包含都是真包含（Ck+1⊊CkC^{k+1}\subsetneq C^k）。上述反例正是把“导函数不连续”的那类函数排除在C1C^1之外。

例题/证明 18（02:22:34）｜ 莱布尼茨公式（乘积的 n 阶导数）

  1. 命题：若 f,g 均 n 阶可导，则 (fg)(n)=∑k=0n(nk)f(k)g(n−k).(fg)^{(n)}=\sum_{k=0}^{n}\binom{n}{k}f^{(k)}g^{(n-k)}.

  2. 思路：系数与二项式展开同形，用归纳法证明。

  3. 逐步推导：

    • n=1n=1：(fg)′=f′g+fg′(fg)'=f'g+fg'，成立。
    • 设对 n 成立，则对 n+1 ： (fg)(n+1)=ddx∑k=0n(nk)f(k)g(n−k)=∑k=0n(nk)(f(k+1)g(n−k)+f(k)g(n−k+1)).(fg)^{(n+1)}=\frac{d}{dx}\sum_{k=0}^{n}\binom{n}{k}f^{(k)}g^{(n-k)} =\sum_{k=0}^{n}\binom{n}{k}\bigl(f^{(k+1)}g^{(n-k)}+f^{(k)}g^{(n-k+1)}\bigr).
    • 把两项分别合并下标：第一项令 j=k+1 ，第二项保持 k ，利用帕斯卡恒等式 (nk−1)+(nk)=(n+1k),\binom{n}{k-1}+\binom{n}{k}=\binom{n+1}{k},可得 (fg)(n+1)=∑k=0n+1(n+1k)f(k)g(n+1−k).(fg)^{(n+1)}=\sum_{k=0}^{n+1}\binom{n+1}{k}f^{(k)}g^{(n+1-k)}.
    • 归纳完成。

  4. 结论：莱布尼茨公式成立，其系数(nk)\binom{n}{k}与二项式系数一致。
