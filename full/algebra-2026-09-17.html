一、实数集的不可数性（续上节课）（00:00:23—00:18:03）

00:00:23—00:07:34 ｜ 上节课遗留：实数集不可数（对角线法的缺陷）

本节课先收尾上节课遗留的结论——证明实数集（只需证 (0,1) 区间）不可数。平移、去掉有限个点都不改变一个集合是否可数，因此只证 B=(0,1) 不可数即可。

下面先讲一个“大体对、但其实不严谨”的二进制对角线证明，说明它的漏洞，并提示可以用十进制规避 0.999…=1 的麻烦。

证明 1（00:01:22）｜ 二进制对角线法“证明”实数可数及其漏洞

命题／任务：尝试用反证法 + 对角线法证明 (0,1) 中的实数可列（可数）。

思路：假设 (0,1) 中实数可列，记为x1,x2,…x_1,x_2,\ldots；把每个xnx_n写成二进制小数，然后构造一个与每一项都在某一位不同的新小数 y ，从而引出矛盾。

逐步推导：

  1. 假设 (0,1) 中实数可列：x1,x2,x3,…x_1,x_2,x_3,\ldots。
  2. 每个xnx_n写成二进制小数xn=0.xn1xn2xn3…x_n=0.x_{n1}x_{n2}x_{n3}\ldots，其中xnk∈{0,1}x_{nk}\in\{0,1\}。
  3. 构造y=0.y1y2y3…y=0.y_1y_2y_3\ldots，令yn=1−xnny_n=1-x_{nn}（即修改对角线上第 n 位数字）。
  4. 于是 y 的第 n 位与xnx_n的第 n 位不同，似乎有y≠xny\neq x_n对所有 n 成立，与“已穷尽所有实数”矛盾。

结论：该论证不严谨，推不出矛盾。

易错点（老师点出）：二进制展开不唯一。例如 0.0111…=0.1000…=12,0.0111\ldots = 0.1000\ldots = \frac12,即一个实数可以有两种二进制表示。因此“ y 与每个xnx_n在某一位不同”并不能保证y≠xny\neq x_n，因为xnx_n可能换一种展开后恰好等于 y 。这个证明有漏洞，无法成立。

修补提示：改用十进制可规避——例如规定“若xnn=5x_{nn}=5则取yn=4y_n=4，否则取yn=5y_n=5”，即可避开 9 的循环展开。但这个修补不在课上展开。

00:07:34—00:18:03 ｜ 用基数与映射证明 [0,1] 不可数

改用上节课的基数事实：|𝒫(X)|=2|X|>|X||\mathcal P(X)|=2^{|X|}>|X|（Cantor 定理）。把 [0,1] 与全体二进制序列集2N2^{\mathbb N}联系起来，通过一个“几乎双射”的满射（每点原像至多 2 个）把不可数性传过去。

证明 2（00:07:53）｜ 用基数与映射证明 [0,1] 不可数

命题／任务：证明 [0,1] （从而 R ）不可数。

思路：先证全体二进制序列集2N2^{\mathbb N}不可数；再定义满射F:2N→[0,1]F:2^{\mathbb N}\to[0,1]把序列映为二进制小数；说明 F 虽非单射，但每点原像至多 2 个；于是若 [0,1] 可数则会推出矛盾。

逐步推导：

  1. 记2N={所有 N→{0,1} 的映射}2^{\mathbb N}=\{\text{所有 }\mathbb N\to\{0,1\}\text{ 的映射}\}，即全体二进制序列，其基数为2ℵ02^{\aleph_0}。
  2. 由 Cantor 定理|2N|>|N||2^{\mathbb N}|>|\mathbb N|，故2N2^{\mathbb N}不可数。
  3. 定义F:2N→[0,1]F:2^{\mathbb N}\to[0,1]，把序列(x1,x2,…)(x_1,x_2,\ldots)映为二进制小数 F((xn))=∑n=1∞xn2n.F((x_n))=\sum_{n=1}^{\infty}\frac{x_n}{2^n}.
  4. F 是满射：每个 [0,1] 中的数都至少有一个二进制展开。
  5. F 不是单射，但每点原像至多 2 个（二进制展开至多两种，形如0.01¯=0.10¯0.0\overline{1}=0.1\overline{0}）。
  6. 反设 [0,1] 可数。则 2N=⋃y∈[0,1]F−1(y)2^{\mathbb N}=\bigcup_{y\in[0,1]}F^{-1}(y)是可数个（每个至多二元）集合的并，从而可数。这与第 2 步2N2^{\mathbb N}不可数矛盾。

结论： [0,1] 不可数，故 R 不可数。

意义：ℵ0\aleph_0是可数无穷的基数；连续统c=2ℵ0c=2^{\aleph_0}严格大于ℵ0\aleph_0。连续统假设（CH）断言在ℵ0\aleph_0与2ℵ02^{\aleph_0}之间不存在别的基数。

二、关系：等价关系、划分与偏序（00:18:03—01:12:59）

00:18:03—00:28:44 ｜ 关系的定义与映射的图像

在讨论正式的代数结构前，先回顾集合上的“关系”。

  • 关系的定义：设 A,B 为非空集合， A×B 的任一子集 R 称为 A 到 B 的一个关系。若 A=B ，则 A×A 的子集称为 A 上的一个关系。注意笛卡尔积的元素是有序对 (a,b) ，顺序有讲究，例如“ ≤ ”不能颠倒。
  • 映射的图像作为关系：给定映射 f:A→B ，其图像 graph⁡(f)={(a,f(a))∣a∈A}⊆A×B\operatorname{graph}(f)=\{(a,f(a))\mid a\in A\}\subseteq A\times B是一个关系。例如平方函数y=x2y=x^2的图像是抛物线。
  • 特征：作为关系， graph⁡(f) 满足“第一分量唯一确定第二分量”（映射的单值性），且 A 中每点都出现。

练习 1（00:25:08）｜ 关系来自函数图像的充要条件

命题／任务：给定关系 R⊆A×B ，何时存在映射 f:A→B 使 R=graph⁡(f) ？

思路：把投影π1:A×B→A,π1(a,b)=a\pi_1:A\times B\to A,\ \pi_1(a,b)=a限制在 R 上，要求该限制是到 A 的双射。

逐步推导：

  1. 必要性：若 R=graph⁡(f) ，则对每个 a∈A 存在唯一的 b=f(a) 使 (a,b)∈R ；故投影π1|R:R→A\pi_1|_R:R\to A既满又单，是双射。
  2. 充分性：若π1|R:R→A\pi_1|_R:R\to A是双射，则对每个 a 有唯一 b 使 (a,b)∈R ；定义 f(a)=b ，则 graph⁡(f)=R 。

结论：充要条件是π1|R:R→A\pi_1|_R:R\to A为双射，等价于 (i) 每个 a∈A 都出现（投影满），(ii) 同一 a 对应的 b 唯一（单值性）。

00:28:44—00:54:56 ｜ 等价关系、等价类与商集

考虑集合 A 上的特殊关系——等价关系。

  • 等价关系：设 ∼ 是 A 上的关系，记作 a∼b 。若满足
    • 自反性： ∀a∈A,a∼a （含对角线）；
    • 对称性： a∼b⟹b∼a ；
    • 传递性： a∼b 且 b∼c⟹a∼c ， 则称 ∼ 为 A 上的等价关系。
  • 等价类：对 a∈A ，记 [a]={b∈A∣b∼a}[a]=\{b\in A\mid b\sim a\}为 a 的等价类。由自反性 a∈[a] ；由对称性与传递性， [a]=[b]⇔a∼b 。
  • 代表元：等价类记号中的 a 不唯一，类中任一元素都可作为代表元。
  • 商集： A/∼={[a]∣a∈A} ，是 A 的幂集的一个子集。
  • 自然映射： π:A→A/∼,π(a)=[a] 是满射，其纤维π−1([a])=[a]\pi^{-1}([a])=[a]（作为 A 的子集）。注意商集中的元素 [a] 同时具有“商集元素”和“原集合子集”双重含义。

证明 1（00:38:13）｜ 不同的等价类要么不交、要么相等

命题／任务：设 [a],[b] 是两个等价类，则 [a]∩[b]≠⌀⟹[a]=[b].[a]\cap[b]\neq\varnothing\implies [a]=[b].

思路：利用对称性与传递性，证明互相包含。

逐步推导：

  1. 设 c∈[a]∩[b] ，则 c∼a 且 c∼b 。
  2. 任取 x∈[a] ，则 x∼a 。由 c∼a 得 a∼c （对称），又 c∼b ，由传递得 x∼b ，故 x∈[b] 。所以 [a]⊆[b] 。
  3. 同理可得 [b]⊆[a] 。

结论： [a]=[b] 。不同等价类两两不交，这是商集构成“划分”的基础。

例题 1（00:41:49）｜ 模 n 同余关系与Zn\mathbb Z_n

命题／任务：固定正整数 n ，在 Z 上定义 a≡b(mod⁡n)⇔n∣(a−b).a\equiv b\pmod n\iff n\mid(a-b).证明它是等价关系，并求商集。

思路：验证三条性质；用带余除法说明每个等价类恰含 n 个元素。

逐步推导：

  1. 自反： n∣(a−a)=0 。对称： n∣(a−b)⟹n∣(b−a) 。传递： n∣(a−b),n∣(b−c)⟹n∣(a−c) 。故为等价关系。
  2. 等价类记作 [a]=a+nZ={a+nk∣k∈Z} 。
  3. 带余除法：任一整数 a 除以 n 余 r∈{0,1,…,n−1} ，故 a≡r(mod⁡n) 。因此 Z 被分成 n 个互不相交的等价类 [0],[1],…,[n−1] 。
  4. 商集记为Zn={[0],[1],…,[n−1]}\mathbb Z_n=\{[0],[1],\ldots,[n-1]\}，共 n 个元素。自然映射π:Z→Zn,π(a)=[a]\pi:\mathbb Z\to\mathbb Z_n,\ \pi(a)=[a]。
  5. 例： n=2 时 [0] 为偶数类、 [1] 为奇数类； n=3 时分为余 0 、余 1 、余 2 三类。

结论： Z=[0]⊔[1]⊔⋯⊔[n−1] （不交并），即 Z 的一个划分。

00:54:56—00:59:20 ｜ 划分与等价关系的一一对应

  • 划分的定义：一组非空子集{Ai}i∈I\{A_i\}_{i\in I}（Ai⊆AA_i\subseteq A非空），满足 A=⨆i∈IAiA=\bigsqcup_{i\in I}A_i（两两不交且并为 A ），则称{Ai}\{A_i\}为 A 的一个划分。不交并记作 ⊔ 。
  • 等价关系 ↔ 划分：等价类给出 A 的一个划分；反之，给定划分，可定义 a∼b⇔a,b 属于同一个AiA_i，则该等价关系的等价类恰为给定划分。二者本质是一回事。
  • 映射的纤维给出划分：对 f:A→B ，每个 b∈Im⁡(f) 的原像f−1(b)f^{-1}(b)非空且两两不交，并起来是 A 。对应的等价关系为a∼a′⇔f(a)=f(a′)a\sim a'\iff f(a)=f(a')。

00:59:20—01:12:59 ｜ 偏序与全序

另一种重要的关系是偏序。

  • 偏序：在 A 上定义关系 ≤⊆A×A ，若满足
    • 自反： ∀a,a≤a ；
    • 反对称： a≤b 且 b≤a⟹a=b ；
    • 传递： a≤b 且 b≤c⟹a≤c ， 则称 ≤ 为偏序（partial order）。
  • 为何叫“偏”序：并不要求任意两个元素都可比较。典型例子是集合的包含关系 ⊆ 在幂集 𝒫(A) 上：自反、反对称（互相包含则相等）、传递都成立，但任取两个子集未必有包含关系。
  • 全序：若任意 a,b 都有 a≤b 或 b≤a ，则称全序。例如 R 在通常 ≤ 下是全序； C 没有天然全序。
  • 字典序：在R2\mathbb R^2上定义 (x1,x2)≤(y1,y2)⇔x1<y1或(x1=y1 且 x2≤y2).(x_1,x_2)\le(y_1,y_2)\iff x_1<y_1\ \text{或}\ (x_1=y_1\text{ 且 }x_2\le y_2).这是偏序，且任意两点可比较，故是R2\mathbb R^2上的全序（类似词典排序）。
  • 提及 Zorn 引理与选择公理（公理，无法从更基本原理证明或否定），后续用到再讲。

反例 1（01:05:13）｜ C 上按模长定义的关系不是偏序

命题／任务：在 C 上令z1≤z2⇔|z1|≤|z2|z_1\le z_2\iff |z_1|\le|z_2|，验证它不满足偏序的反对称性。

思路：逐条代入偏序定义。

逐步推导：

  1. 自反： |z|≤|z| ✓。
  2. 传递：|z1|≤|z2||z_1|\le|z_2|且|z2|≤|z3|⟹|z1|≤|z3||z_2|\le|z_3|\implies|z_1|\le|z_3| ✓。
  3. 反对称：需 a≤b 且 b≤a⟹a=b 。取z1=1,z2=−1z_1=1,\ z_2=-1，则 |1|=|−1| ，故 1≤−1 且 −1≤1 ，但 1≠−1 。反对称不成立。

结论：此关系是预序而非偏序。意义：说明 C 上没有“自然”的偏序，需用字典序等方式人为引入全序。

例题 1（01:08:37）｜ R2\mathbb R^2上的字典序是全序

命题／任务：验证R2\mathbb R^2上字典序 (x1,x2)≤(y1,y2)⇔x1<y1或(x1=y1 且 x2≤y2)(x_1,x_2)\le(y_1,y_2)\iff x_1<y_1\ \text{或}\ (x_1=y_1\text{ 且 }x_2\le y_2)是一个全序。

思路：先验证偏序的三条，再说明任意两点可比较。

逐步推导：

  1. 自反显然：取等号成立。
  2. 反对称：若(x1,x2)≤(y1,y2)(x_1,x_2)\le(y_1,y_2)且(y1,y2)≤(x1,x2)(y_1,y_2)\le(x_1,x_2)，则x1=y1x_1=y_1且x2=y2x_2=y_2，故两点相等。
  3. 传递：逐级比较第一、第二坐标即可。
  4. 全序性：任取两点，若第一坐标不同则大小已定；若第一坐标相同则比较第二坐标，总有一方成立。

结论：字典序是R2\mathbb R^2上的一个全序（任意两点可比）。

三、整数的最大公因数与同余（01:13:09—01:55:27）

01:13:09—01:17:55 ｜ 最大公因数的定义

以整数为最基础的例子引入抽象代数概念（带余除法已讲）。

最大公因数的定义：设a1,…,ana_1,\ldots,a_n为整数且不全为 0 （至少两个）。整数 d 称为它们的最大公因数，若

  1. d∣aid\mid a_i对所有 i=1,…,n 成立（是公因数）；
  2. 若另一个整数 e 也整除所有aia_i，则 e∣d 。

记作d=gcd⁡(a1,…,an)d=\gcd(a_1,\ldots,a_n)。若限定取正的，则存在且唯一（唯一性只差一个正负号）。

01:17:55—01:33:02 ｜ 最大公因数存在性与 Bézout 恒等式

存在性可用两种思路：对两个正整数用辗转相除法；或更一般地，用良序原理在“整系数线性组合”中找最小正元。

证明 1（01:24:11）｜ 最大公因数存在且可表为整系数线性组合

命题／任务：证明gcd⁡(a1,…,an)\gcd(a_1,\ldots,a_n)存在，且取正的 gcd 可写成 d=t1a1+⋯+tnan,ti∈Zd=t_1a_1+\cdots+t_na_n,\qquad t_i\in\mathbb Z（Bézout 恒等式）。

思路：考虑所有整系数线性组合构成的集合 I ，取其正元素子集，由良序原理取最小正元 d ；再证 d 既是公因数又是最大的。

逐步推导：

  1. 令 I={s1a1+⋯+snan∣si∈Z}.I=\{s_1a_1+\cdots+s_na_n\mid s_i\in\mathbb Z\}.因aia_i不全为 0 ，取一个非零者变号即得正整数，故I∩Z>0≠⌀I\cap\mathbb Z_{>0}\neq\varnothing。
  2. 由良序原理，正整数的非空子集有最小元，记 d=t1a1+⋯+tnand=t_1a_1+\cdots+t_na_n为其中最小的正元素。
  3. 证 d 是公因数：反设d∤a1d\nmid a_1。由带余除法a1=qd+ra_1=qd+r，其中 0<r<d 。则 r=a1−qd=a1−q(t1a1+⋯+tnan)r=a_1-qd=a_1-q(t_1a_1+\cdots+t_na_n)仍是整系数线性组合，故 r∈I 且 0<r<d ，与 d 的最小性矛盾。故d∣aid\mid a_i全部。
  4. 证 d 是最大的：若e∣aie\mid a_i全部，则 e 整除任意整系数线性组合，特别 e∣d 。

结论： d 是最大公因数，且存在整数tit_i使d=∑tiaid=\sum t_ia_i。唯一性：正 gcd 唯一，只差正负号。

易错点：实际求解系数要用辗转相除法（欧几里得算法）反复操作；上面的存在性证明是“构造性”地指出 d 来自线性组合集，却不给出具体系数。

01:33:02—01:44:07 ｜ 互素、素数整除性质与 Euclid 引理

  • 互素：a1,…,ana_1,\ldots,a_n 互素指gcd⁡(a1,…,an)=1\gcd(a_1,\ldots,a_n)=1（注意不是两两互素）。等价于存在整数使 t1a1+⋯+tnan=1.t_1a_1+\cdots+t_na_n=1.
  • 算术基本定理（已自由使用）：每个大于 1 的整数可唯一写成素数乘积；唯一性的关键一步是下面素数的整除性质。

证明 2（01:38:58）｜ Euclid 引理：素数整除乘积则整除某一因子

命题／任务：设 p 为素数， p∣ab ，则 p∣a 或 p∣b 。

思路：若 p∤a ，则 gcd⁡(p,a)=1 ，可线性表出 1 ，两边乘 b 推出 p∣b 。

逐步推导：

  1. 假设 p∤a 。因 p 是素数， gcd⁡(p,a) 只能是 1 或 p ；又 p∤a ，故 gcd⁡(p,a)=1 。
  2. 于是存在整数 r,s 使 rp+sa=1 。
  3. 两边乘 b ： rpb+sab=b 。
  4. 左边两项都被 p 整除（第一项显然；第二项 p∣ab 给出 p∣sab ），故 p∣b 。

结论：若 p∣ab 且 p∤a ，则 p∣b 。这是算术基本定理唯一性的基础步骤。

01:44:07—01:55:27 ｜ 同余类的运算与费马小定理

先确立同余类上运算的合法性（良定性），再用它证明费马小定理。 Z 模 n 的同余类集是群与环最基础的例子；模素数 p 时还有更强的域结构。

证明 3（01:48:13）｜ 同余类上加法与乘法定义的良定性

命题／任务：在Zn\mathbb Z_n上定义 [a]+[b]=[a+b],[a]⋅[b]=[ab].[a]+[b]=[a+b],\qquad [a]\cdot[b]=[ab].证明这两个定义不依赖于代表元的选取（即“良定”）。

思路：若a≡a′,b≡b′(mod⁡n)a\equiv a',\ b\equiv b'\pmod n，需证a+b≡a′+b′a+b\equiv a'+b'且ab≡a′b′ab\equiv a'b'。

逐步推导：

  1. 由a≡a′a\equiv a'知n∣(a−a′)n\mid(a-a')；由b≡b′b\equiv b'知n∣(b−b′)n\mid(b-b')。
  2. 加减法：(a+b)−(a′+b′)=(a−a′)+(b−b′)(a+b)-(a'+b')=(a-a')+(b-b')被 n 整除，故[a+b]=[a′+b′][a+b]=[a'+b']。
  3. 乘法：ab−a′b′=a(b−b′)+b′(a−a′)ab-a'b'=a(b-b')+b'(a-a')被 n 整除，故[ab]=[a′b′][ab]=[a'b']。

结论：同余类上的加、乘定义合法（良定）。由此Zn\mathbb Z_n上可自然做加减乘。

证明 4（01:44:44）｜ 费马小定理（同余类论证）

命题／任务（费马小定理）：设 p 为素数， a 为整数。 - 若 p∤a ，则ap−1≡1(mod⁡p)a^{p-1}\equiv1\pmod p； - 更一般地，对任意 a 有ap≡a(mod⁡p)a^p\equiv a\pmod p。

思路：考虑非零同余类集合 Zp*={[1],…,[p−1]} （共 p−1 个）。用 [a] （其中 p∤a ）去乘全体，得到的是同一集合的重排；比较乘积即可，最后消去 (p−1)! 。

逐步推导：

  1. 当 p∤a 时， [a],[2a],…,[(p−1)a] 两两不同余 (mod⁡p) （否则 p∣(i−j)a 推出 p∣(i−j) ，与 1≤i<j≤p−1 矛盾），故恰是 Zp* 的一个排列。
  2. 因此乘积相等： [1]⋯[p−1]=[a]p−1⋅([1]⋯[p−1]).[1]\cdots[p-1]=[a]^{p-1}\cdot([1]\cdots[p-1]).即(p−1)!≡ap−1(p−1)!(mod⁡p)(p-1)!\equiv a^{p-1}(p-1)!\pmod p。
  3. 因 p 是素数且 1,…,p−1 均不被 p 整除，有 p∤(p−1)! 。于是可消去该因子，得 ap−1≡1(mod⁡p).a^{p-1}\equiv1\pmod p.
  4. 若 p∣a ，则 a≡0(mod⁡p) ，两边显然有ap≡a(mod⁡p)a^p\equiv a\pmod p。

结论：费马小定理成立。用同余类（群）语言可简洁地得到证明，比初等数论的纯整除论证更清晰。

四、复数复习与素数（01:55:35—02:06:00）

01:55:35—02:01:16 ｜ 复数的运算与极坐标

  • 基本形式：复数 z=x+iy ，其中i2=−1i^2=-1，可视为二维平面（复平面）。
  • 四则运算：除法用共轭化简。若 w=u+iv≠0 ，则 x+iyu+iv=(x+iy)(u−iv)u2+v2.\frac{x+iy}{u+iv}=\frac{(x+iy)(u-iv)}{u^2+v^2}.共轭z¯=x−iy\overline{z}=x-iy满足zz¯=|z|2z\overline z=|z|^2（ |z| 为模长）。
  • 极坐标与欧拉公式：记 r=|z| ，辐角为 θ ，则 z=r(cos⁡θ+isin⁡θ)=reiθ.z=r(\cos\theta+i\sin\theta)=re^{i\theta}.其中cos⁡θ+isin⁡θ=eiθ\cos\theta+i\sin\theta=e^{i\theta}（欧拉公式）； θ 可取自长度 2π 的区间（因周期性）。

02:01:16—02:06:00 ｜ 素数相关话题

作业会涉及同余、素数与复数的小练习。课上讨论了几个经典结果（部分在面试中常被问到）。

证明 1（02:01:52）｜ 素数有无穷多个（欧几里得证法）

命题／任务：证明素数有无穷多个。

思路：反证，构造一个不在已知列表中的素因子。

逐步推导：

  1. 反设素数只有有限个：p1,p2,…,pmp_1,p_2,\ldots,p_m。
  2. 令N=p1p2⋯pm+1N=p_1p_2\cdots p_m+1。
  3. N>1 ，故有素因子 q 。但 q 必不等于任何pip_i（否则 q∣N 且q∣p1⋯pmq\mid p_1\cdots p_m，推出 q∣1 ，矛盾）。
  4. 故存在新的素数 q ，与“只有有限个”矛盾。

结论：素数无穷多。此证法用到了“素数整除乘积则整除一因子”的性质。

证明 2（02:02:39）｜ 模 4 余 3 的素数有无穷多个

命题／任务：证明形如 4k+3 的素数有无穷多个。

思路：类似欧几里得，但构造 N≡3(mod⁡4) ，并说明其素因子中必有 ≡3(mod⁡4) 者。

逐步推导：

  1. 反设这种素数只有有限个：q1,…,qmq_1,\ldots,q_m（每个qi≡3(mod⁡4)q_i\equiv3\pmod4）。
  2. 令N=4(q1q2⋯qm)−1N=4(q_1q_2\cdots q_m)-1，则 N≡−1≡3(mod⁡4) 。
  3. 若 N 的所有素因子都 ≡1(mod⁡4) ，则它们的乘积也 ≡1(mod⁡4) ，与 N≡3(mod⁡4) 矛盾。
  4. 故 N 至少有一个素因子 q≡3(mod⁡4) ；且 q 不等于任何已列的qiq_i（否则 q∣N 且q∣4(q1⋯qm)q\mid4(q_1\cdots q_m)，推出 q∣1 ，矛盾）。

结论：形如 4k+3 的素数无穷多。

讨论：模 4 余 1 的情形不能用同样方法——因为偶数个 ≡−1(mod⁡4) 的因子相乘仍可为 ≡1(mod⁡4) ，原论证失效，该问题困难得多。更一般地，Dirichlet 定理说“首项与公差互素的等差数列含无穷多素数”（需用复分析、 L 函数等工具，本科数论可证）；陶哲轩的工作给出“存在任意长的素数等差数列”。作业只需做模 3 的情形。

五、域、群的定义与例子（02:06:00—02:28:15）

02:06:00—02:15:54 ｜ 域与群的定义

  • 域（传统定义）：复数域 C 的包含 0,1 且对四则运算封闭的子集。本课采用更一般的抽象定义，不预设它是 C 的子集——例如模素数 p 的同余类集Zp\mathbb Z_p也是一个域，但它不在 C 中。
  • 群：先讲群，再讲环；域是环的一种（结构更多）。

群的定义：设 G 为非空集合，配一个二元运算⋅:G×G→G （抽象运算，记作乘法 a⋅b 或 a*b ；不假设与数字乘法有关）。若满足 - 结合律： (a⋅b)⋅c=a⋅(b⋅c) ； - 单位元：存在 e∈G ，使 ∀a∈G,e⋅a=a⋅e=a ； - 逆元： ∀a∈G,∃b∈G 使 a⋅b=b⋅a=e ，

则称 (G,⋅) 是一个群。若不引起歧义，也简称 G 是群。

交换群 / Abel 群：若运算还满足交换律 a⋅b=b⋅a ，称为交换群（Abel 群）。为方便，常把交换群的运算记作加法，称为加群，单位元记作 0 ，逆元记作 −a 。

02:15:54—02:22:02 ｜ 群的基本性质与常见例子

逐一验证熟悉例子是否成群：

  • (Z,+)(\mathbb Z,+)、(Q,+)(\mathbb Q,+)、(R,+)(\mathbb R,+)、 (C,+) 都是交换群（加群）：单位元 0 ， a 的逆元为 −a 。
  • (Zn,+)(\mathbb Z_n,+)是交换群：单位元 [0] ， [a] 的逆元为 [−a] 。
  • (R∖{0},⋅)(\mathbb R\setminus\{0\},\cdot)、(Q∖{0},⋅)(\mathbb Q\setminus\{0\},\cdot)、 (C∖{0},⋅) 是交换群：单位元 1 。
  • (Z,⋅)不是群：有单位元 1 ，但除 ±1 外没有逆元。
  • (R,⋅)不是群：因为 0 没有逆元；挖掉 0 后（即 R∖{0} ）才成群。
  • (Z∖{0},⋅)不是群：除 ±1 外多数元素无逆元。

02:22:02—02:28:15 ｜ 对称群SnS_n（非交换群的例子）

至此举的例子运算都是交换的（Abel 型）。更丰富的例子来自非交换群。

例题 1（02:22:29）｜ 对称群SnS_n是一个群

命题／任务：设 X={1,2,…,n} ，考虑 X 到自身的所有双射（置换）构成的集合，运算取映射复合。证明它是一个群，并说明当 n≥3 时非交换。

思路：验证群的三条性质；双射的复合仍双射，映射复合满足结合律，恒等映射是单位元，双射有逆映射。

逐步推导：

  1. 封闭性：两个双射的复合仍是双射，故仍在集合中。
  2. 结合律：映射复合天然满足 (f∘g)∘h=f∘(g∘h) 。
  3. 单位元：恒等映射 id 满足 id∘f=f∘id=f 。
  4. 逆元：双射 f 有逆映射f−1f^{-1}，且f∘f−1=f−1∘f=idf\circ f^{-1}=f^{-1}\circ f=\mathrm{id}。

结论：该集合在映射复合下构成一个群，记作SnS_n（对称群）。有限情形下，SnS_n恰有 n 个元素的全体排列，共 n! 个元素。当 n≥3 时运算不交换（非 Abel 群）。

意义：同余类集Zn\mathbb Z_n给出群与环最基础的例子；对称群SnS_n给出最重要的非交换群例子，后续会反复出现。
