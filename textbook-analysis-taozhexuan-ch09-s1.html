§9.1 实直线的子集

在分析学中，我们通常不会对整个实直线 R 进行研究，而是研究实直线的某些特定子集，比如正实轴 {x∈R:x>0}\{x \in R : x > 0\} 。另外，我们偶尔也与 6.2 节中定义的广义实直线 R∗R^{*} 打交道，或者在它的子集中展开研究。

实直线显然有无穷多个子集。事实上，康托尔定理（定理8.3.1，参见习题8.3.4）表明了实直线子集的个数甚至比实数的还要多。但是实直线（和广义实直线）的一些特殊子集才是我们经常遇到的，其中区间就是一种这样的集合。

定义 9.1.1概念定义

（区间）设 a,b∉R∗a, b \notin \mathbf{R}^* 是广义实数，我们定义闭区间 [a,b][a, b] 为

[a,b]:={x∈R∗:a≤x≤b}[ a, b ] := \{x \in \mathbf {R} ^ {*}: a \leqslant x \leqslant b \}

半开区间 [a,b)[a,b) 和 (a,b](a,b] 为

[a,b):={x∈R∗:a≤x<b};(a,b]:={x∈R∗:a<x≤b}[ a, b) := \{x \in \mathbf {R} ^ {*}: a \leqslant x < b \}; (a, b ] := \{x \in \mathbf {R} ^ {*}: a < x \leqslant b \}

开区间 (a,b)(a,b) 为

(a,b):={x∈R∗:a<x<b}(a, b) := \{x \in \mathbf {R} ^ {*}: a < x < b \}

我们称 a 为这些区间的左端点，b 为这些区间的右端点。

注9.1.2这里我们再一次使用了圆括号。例如，现在我们既可以用(2,3)表示一个从2到3的开区间，也可以用它来表示笛卡儿平面 R2≔R×R\mathbf{R}^2\coloneqq \mathbf{R}\times \mathbf{R} 上的一个有序对。这或许会导致歧义，但你应该能够从上下文中了解圆括号所表达的意思。在某些教材中，使用反向的中括号代替圆括号来解决这个问题，例如 [a,b)[a,b) 就变成了 [a,b[,(a,b][a,b[,(a,b] 就是 ]a,b]]a,b] ，而 (a,b)(a,b) 就记作 ]a,b[]a,b[ 。

例 9.1.3经典例题

如果 a 和 b 是实数（即它们既不等于 +∞+\infty ，也不等于 −∞-\infty ），那么所有上述区间都是实直线的子集，例如 [2,3)={x∈R:2≤x<3}[2,3)=\{x\in\mathbf{R}:2\leqslant x<3\} 。正实轴 {x∈R:x>0}\{x\in\mathbf{R}:x>0\} 就是开区间 (0,+∞)(0,+\infty) ，而非负实轴 {x∈R:x≥0}\{x\in\mathbf{R}:x\geqslant0\} 就是一个半开区间 [0,+∞)[0,+\infty) 。类似地，负实轴 {x∈R:x<0}\{x\in\mathbf{R}:x<0\} 是 (−∞,0)(-\infty,0) ，并且非正实轴 {x∈R:x≤0}\{x\in\mathbf{R}:x\leqslant0\} 是 (−∞,0](-\infty,0] 。最后，实直线 R 本身是开区间 (−∞,+∞)(-\infty,+\infty) ，而广义实直线 R∗R^{*} 是闭区间 [−∞,+∞][-\infty,+\infty] 。有时候我们称其中一个端点是无限 (+∞(+\infty 或 −∞)-\infty) 的区间为半无限区间，称两个端点都是无限的区间为双无限区间；而其余所有的区间都被称为有界区间。所以 [2,3)[2,3) 是有界区间，正实轴和负实轴都是半无限区间，而 R 和 R∗R^{*} 都是双无限区间。

例 9.1.4经典例题

如果 a > b，那么四个区间 [a,b][a, b] 、 [a,b)[a, b) 、 (a,b](a, b] 和 (a,b)(a, b) 都是空集（为什么？）。如果 a = b，那么三个区间 [a,b)[a, b) 、 (a,b](a, b] 和 (a,b)(a, b) 都是空集，而 [a,b][a, b] 就是一个单元素集 {a}\{a\} 。（为什么？）因此，我们称这些区间是退化的。我们所学习的分析理论的绝大部分（但并非全部）内容都限制在非退化的区间上。

当然，区间并不是实直线唯一一个有意义的子集。其他重要的例子包括自然数集 N、整数集 Z 以及有理数集 Q。通过使用并集和交集（参见 3.1 节）这样的运算，我们还可以构造其他集合，例如我们可以求出两个区间不连通的并集，如 (1,2)∪[3,4](1,2) \cup [3,4] ，或者考虑 -1 和 1 之间（包含端点在内）的有理数集合 [−1,1]∩Q[-1,1] \cap Q 。利用这些运算，我们显然可以构造出无限多个集合。

就像实数序列存在极限点一样，实数集也有附着点，现在我们来定义附着点。

定义 9.1.5概念定义

（ε-附着点）设 X 是 R 的子集，ε > 0，并且设 x∈Rx \in R 。我们称 x 是 ε-附着于 X 的，当且仅当存在一个 y∈Xy \in X 是 ε-接近于 x 的（即 |x−y|≤ε|x - y| \leqslant \varepsilon ）。

注 9.1.6深入诠释

术语 “ ε\varepsilon -附着于” 不是文献中的标准术语，但是我们简单地用它来定义附着点的概念，其中附着点是一个标准术语。

例 9.1.7经典例题

点 1.1 是 0.5-附着于开区间 (0,1)(0,1) 的，但不是 0.1-附着于这个区间的。（为什么？）点 1.1 是 0.5-附着于有限集 {1,2,3}\{1,2,3\} 的。点 1 是 0.5-附着于 {1,2,3}\{1,2,3\} 的。（为什么？）

定义 9.1.8概念定义

（附着点）设 XX 是 R\mathbf{R} 的一个子集，并且设 x∈Rx \in \mathbf{R} 。我们称 xx 是 XX 的一个附着点，当且仅当对于任意的 ε>0\varepsilon > 0 ， xx 都是 ε\varepsilon -附着于 XX 的。

例 9.1.9经典例题

对于任意的 ε>0\varepsilon > 0 ，数字1都是 ε\varepsilon -附着于开区间 (0,1)(0,1) 的，（为什么？）从而 1 是 (0,1)(0,1) 的一个附着点。类似地，点 0.5 也是 (0,1)(0,1) 的一个附着点。但数字 2 不是（例如）0.5-附着于 (0,1)(0,1) 的，因此 2 不是 (0,1)(0,1) 的附着点。

定义 9.1.10概念定义

（闭包）设 X 是 R 的一个子集。X 的闭包，有时记作 X¯\overline{X} ，是指由 X 的全体附着点所构成的集合。

引理 9.1.11命题/引理

（闭包的初等性质）设 X 和 Y 是 R 的任意两个子集，那么 X⊆X¯X \subseteq \overline{X} ， X∪Y¯=X¯∪Y¯\overline{X \cup Y} = \overline{X} \cup \overline{Y} ，且 X∩Y¯⊆X¯∩Y¯\overline{X \cap Y} \subseteq \overline{X} \cap \overline{Y} 。如果 X⊆YX \subseteq Y ，那么 X¯⊆Y¯\overline{X} \subseteq \overline{Y} 。

证明

参见习题9.1.2。

现在我们来计算一些闭包。

引理 9.1.12命题/引理

（区间的闭包）设 a < b 是实数，并且设 I 是四个区间 (a,b)(a, b) 、 (a,b](a, b] 、 [a,b)[a, b) 和 [a,b][a, b] 中的任意一个。那么 I 的闭包是 [a,b][a, b] 。类似地， (a,+∞)(a, +\infty) 或 [a,+∞)[a, +\infty) 的闭包是 [a,+∞)[a, +\infty) ，而 (−∞,a)(-\infty, a) 或 (−∞,a](-\infty, a] 的闭包是 (−∞,a](-\infty, a] 。最后， (−∞,+∞)(-\infty, +\infty) 的闭包是 (−∞,+∞)(-\infty, +\infty) 。

证明

我们只证明这些结论中的一个，即 (a,b)(a,b) 的闭包是 [a,b][a,b] 。其他的结论可以类似地证明（或者利用习题9.1.1）。

我们首先证明 [a,b][a, b] 的每一个元素都是附着于 (a,b)(a, b) 的。设 x∈[a,b]x \in [a, b] ，如果 x∈(a,b)x \in (a, b) ，那么它肯定是附着于 (a,b)(a, b) 的。如果 x=bx = b ，那么 xx 也是附着于 (a,b)(a, b) 的。（为什么？）当 x=ax = a 时也有类似的结论。因此 [a,b][a, b] 中的每一点都是附着于 (a,b)(a, b) 的。

现在我们证明附着于 (a,b)(a, b) 的每一个点 xx 都属于 [a,b][a, b] 。利用反证法，假设 xx 不属于 [a,b][a, b] ，于是要么 x>bx > b ，要么 x<ax < a 。如果 x>bx > b ，那么 xx 不是 (x−b)(x - b) -附着于 (a,b)(a, b) 的（为什么？），从而 xx 不是 (a,b)(a, b) 的附着点。类似地，如果 x<ax < a ，那么 xx 不是 (a−x)(a - x) -附着于 (a,b)(a, b) 的，从而 xx 不是 (a,b)(a, b) 的附着点。这个矛盾说明 xx 实际上属于 [a,b][a, b] ，结论得证。

引理 9.1.13命题/引理

N 的闭包是 N, Z 的闭包是 Z, Q 的闭包是 R, R 的闭包是 R。空集 ∅\varnothing 的闭包是 ∅\varnothing 。

证明

参见习题9.1.3。

下面的引理证明了集合 X 的附着点可以作为 X 中元素的极限而得到。

引理 9.1.14命题/引理

设 XX 是 R\mathbf{R} 的子集，并且设 x∈Rx \in \mathbf{R} 。那么 xx 是 XX 的一个附着点，当且仅当存在一个完全由 XX 中元素构成的序列 (an)n=0∞(a_n)_{n=0}^{\infty} 收敛于 xx 。

证明

参见习题9.1.5。

定义 9.1.15概念定义

如果 E¯=E\overline{E}=E ，那么子集 E⊆RE\subseteq R 是闭的，即 E 的所有附着点都包含在 E 中。

例 9.1.16经典例题

根据引理 9.1.12 可知, 如果 a < b 是实数, 那么 [a,b][a, b] 、 [a,+∞)[a, +\infty) 、 (−∞,a](-\infty, a] 和 (−∞,+∞)(-\infty, +\infty) 都是闭的, 而 (a,b)(a, b) 、 (a,b](a, b] 、 [a,b)[a, b) 、 (a,+∞)(a, +\infty) 和 (−∞,a)(-\infty, a) 都不是闭的。根据引理 9.1.13 可知, N、Z、R 和 ∅\varnothing 都是闭的, 但 Q 不是闭的。

根据引理 9.1.14，我们可以用序列来定义闭包。

推论 9.1.17推论

设 XX 是 R\mathbf{R} 的子集，如果 XX 是闭的，并且 (an)n=0∞(a_{n})_{n = 0}^{\infty} 是一个由 XX 中的元素构成的收敛序列，那么 limn→∞an\lim_{n\to \infty}a_n 也属于 XX 。反过来，如果每一个由 XX 中元素构成的收敛序列 (an)n=0∞(a_{n})_{n = 0}^{\infty} 的极限也都属于 XX ，那么 XX 一定是闭的。

在下一章学习微分时，我们需要把“附着点”的概念替换成一个与它有着密切联系的概念，即极限点。

定义 9.1.18概念定义

（极限点）设 X 是实直线的一个子集，我们称 x 是 X 的极限点（或聚点），当且仅当 x 是 X∖{x}X \setminus \{x\} 的一个附着点。如果 x∈Xx \in X ，并且存在某个 ε>0\varepsilon > 0 使得 |x−y|>ε|x - y| > \varepsilon 对所有的 y∈X∖{x}y \in X \setminus \{x\} 均成立，那么我们称 x 是 X 的孤立点。

例 9.1.19经典例题

设 X 是集合 X=(1,2)∪{3}X = (1, 2) \cup \{3\} ，那么 3 是 X 的附着点，但不是 X 的极限点，因为 3 不附着于 X−{3}=(1,2)X - \{3\} = (1, 2) ，但 3 是 X 的一个孤立点。另外，2 是 X 的一个极限点，因为 2 是附着于 X−{2}=XX - \{2\} = X 的，但 2 不是孤立点。（为什么？）

注9.1.20 根据引理9.1.14可知， xx 是 XX 的极限点，当且仅当存在一个完全由 XX 中不同于 xx 的元素构成的序列 (an)n=0∞(a_{n})_{n = 0}^{\infty} ，并且该序列收敛于 xx 。这表明附着点组成的集合可以分成两部分，一部分是由极限点组成的集合，另一部分是由孤立点组成的集合（习题9.1.9）。

接下来我们定义有界集合的概念。

定义 9.1.22概念定义

（有界集合）如果存在某个实数 M>0M > 0 使得 X⊂[−M,M]X \subset [-M, M] ，那么实直线的子集 XX 是有界的。

例 9.1.23经典例题

对于任意的实数 a、b，区间 [a,b][a,b] 都是有界的，因为它被包含在 [−M,M][-M,M] 中，其中 M:=max{|a|,|b|}M:=\max\{|a|,|b|\} 。然而，半无限区间 [0,+∞)[0,+\infty) 是无界的。（为什么？）事实上，所有的半无限区间和双无限区间都是无界的。集合 N、Z、Q 和 R 都是无界的。（为什么？）

关于闭的有界集合的一个基本性质如下。

定理 9.1.24核心定理

（直线上的海涅-博雷尔定理）设 XX 是 R\mathbf{R} 的一个子集，那么下面两个命题是等价的：

  1. XX 是闭的且有界的。
  2. 给定任意一个在 XX 中取值（即对所有的 nn 均有 an∈Xa_{n} \in X ）的实数序列 (an)n=0∞(a_{n})_{n=0}^{\infty} ，存在它的一个子序列 (anj)j=0∞(a_{n_{j}})_{j=0}^{\infty} 收敛于 XX 中的某个数 LL 。

注 9.1.25深入诠释

这个定理在本章的后面几节中将起到关键作用。用距离空间拓扑学的语言来说，该定理断定了实直线的任意一个闭的且有界的子集都是紧的，参见11.7节。这个定理更一般的形式是由爱德华·海涅（1821—1881）和埃米尔·博雷尔（1871—1956）给出的，参见定理11.7.7。
