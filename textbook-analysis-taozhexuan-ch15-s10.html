§15.6 说一说复数

为了更深入地学习，我们还要用到复数系 C，它是实数系 R 的延拓。对这个重要数系的全面讨论（它特别地成为一个专门的数学分支，叫作复分析）超出了本书的范围。在这里，我们需要对这个数系有一些基本了解，这是因为它涉及一个非常有用的数学运算，即复指数函数 z↦exp(z)z \mapsto \exp(z) 。该运算推广了在上一节中引入的实指数函数 x↦exp(x)x \mapsto \exp(x) 。

通俗地说，我们把复数定义如下。

定义 15.6.1概念定义

（复数的非正式定义）复数系 C 是全体形如 a+bia + bi 的数所构成的集合，其中 a、b 都是实数，i 是 -1 的平方根，即 i2=−1i^{2} = -1 。

然而，这个定义并不十分令人满意，因为它没有解释如何进行加法、乘法运算，以及如何比较两个复数的大小。为了严格地构造出复数系，我们首先引入复数 a+bia + b\mathrm{i} 的形式化概念，并把它暂时记作 (a,b)(a,b) 。这类似于我们在第4章中构造整数系Z时所做的事情。在引入真正的减法 a−ba - b 之前，我们需要减法的形式化概念 a−ba - b 。这也像在构造有理数时，先引入一个形式除法 a//ba / / b ，然后再用真正的除法 a/ba / b 来代替它。这还类似于我们构造实数系时所采用的方法，在定义真正的极限 limn→∞an\lim_{n\to \infty}a_n 之前，首先定义形式极限 LIMn→∞an\mathrm{LIM}_{n\to \infty}a_n 。

定义 15.6.2概念定义

（复数的正式定义）复数就是形如 (a,b)(a,b) 的有序对，其中 a、b 都是实数。例如， (2,4)(2,4) 是一个复数。称两个复数 (a,b)(a,b) 和 (c,d)(c,d) 是相等的，当且仅当 a=c 且 b=d。例如， (2+1,3+4)=(3,7)(2+1,3+4)=(3,7) ，但 (2,1)≠(1,2)(2,1)\neq(1,2) 且 (2,4)≠(2,−4)(2,4)\neq(2,-4) 。全体复数的集合记作 C。

此时，复数系 C 和笛卡儿积 R2=R×RR^{2} = R \times R （也称作笛卡儿平面）还没区分开来。但是，我们将在复数系中引入大量的运算，特别是复数的乘法运算，而笛卡儿平面 R2R^{2} 中却没有这些运算。因此，我们可以把复数系 C 看成是配备了大量附加结构的笛卡儿平面 R2R^{2} 。我们首先考虑加法运算和负运算。根据复数的非正式定义，我们希望有

(a,b)+(c,d)=(a+bi)+(c+di)=(a+c)+(b+d)i=(a+c,b+d)(a, b) + (c, d) = (a + b \mathrm{i}) + (c + d \mathrm{i}) = (a + c) + (b + d) \mathrm{i} = (a + c, b + d)

而且类似地有

−(a,b)=−(a+bi)=(−a)+(−b)i=(−a,−b)- (a, b) = - (a + b \mathrm{i}) = (- a) + (- b) \mathrm{i} = (- a, - b)

这里的推导使用了复数的非正式定义，但这些等式尚未被严格地证明。然而，我们可以利用上述法则来定义加法运算和负运算的概念，从而就能把这些等式简单地编排进复数系中。

定义 15.6.3概念定义

（复数的加法运算、负运算以及零）如果 z=(a,b)z=(a,b) 和 w=(c,d)w=(c,d) 是两个复数，那么它们的和 z+wz+w 就被定义为复数 z+w:=(a+c,b+d)z+w:=(a+c,b+d) 。例如， (2,4)+(3,−1)=(5,3)(2,4)+(3,-1)=(5,3) 。此外，z 的负数 -z 被定义为复数 −z:=(−a,−b)-z:=(-a,-b) 。例如， −(3,−1)=(−3,1)-(3,-1)=(-3,1) 。我们还把复数零 0C0_{C} 定义为复数 0C=(0,0)0_{C}=(0,0) 。

如果 z=z′z = z' 且 w=w′w = w' ，那么 z+w=z′+w′z + w = z' + w' 。容易看出，在这个意义下，加法运算的概念是有意义的。负运算有类似的结论。复数的加法运算、负运算以及复数零都满足通常的运算定律。

引理 15.6.4命题/引理

（复数系是一个加法群）如果 z1z_{1} 、 z2z_{2} 、 z3z_{3} 都是复数，那么它们就具有可交换性 z1+z2=z2+z1z_{1} + z_{2} = z_{2} + z_{1} ，结合性 (z1+z2)+z3=z1+(z2+z3)(z_{1} + z_{2}) + z_{3} = z_{1} + (z_{2} + z_{3}) ，恒等性 z1+0C=0C+z1=z1z_{1} + 0_{C} = 0_{C} + z_{1} = z_{1} 以及逆元性 z1+(−z1)=(−z1)+z1=0Cz_{1} + (-z_{1}) = (-z_{1}) + z_{1} = 0_{C} 。

定义 15.6.5概念定义

（复数的乘法运算）如果 z=(a,b)z=(a,b) 和 w=(c,d)w=(c,d) 都是复数，那么两者的乘积 zw 被定义为复数 zw:=(ac−bd,ad+bc)zw:=(ac-bd,ad+bc) 。此外，我们还引入复数的单位元 1C:=(1,0)1_{C}:=(1,0) 。

容易看出这个运算的定义是有意义的，它也满足通常的运算定律。

引理 15.6.6命题/引理

如果 z1z_{1} 、 z2z_{2} 、 z3z_{3} 都是复数，那么它们就具有可交换性 z1z2=z2z1z_{1}z_{2}=z_{2}z_{1} ，结合性 (z1z2)z3=z1(z2z3)(z_{1}z_{2})z_{3}=z_{1}(z_{2}z_{3}) ，恒等性 z11C=1Cz1=z1z_{1}1_{C}=1_{C}z_{1}=z_{1} ，以及分配性 z1(z2+z3)=z1z2+z1z3z_{1}(z_{2}+z_{3})=z_{1}z_{2}+z_{1}z_{3} 和 (z2+z3)z1=z2z1+z3z1(z_{2}+z_{3})z_{1}=z_{2}z_{1}+z_{3}z_{1} 。

参见习题 15.6.2。

上述引理还可以写成更简洁的形式，即 C 是一个交换环。我们通常把 z+(−w)z+(-w) 简写成 z-w。

现在我们把实数系 R 等同于复数系 C 的一个子集，让每一个实数 x 都等同于一个复数 (x,0)(x,0) ，于是 x≡(x,0)x \equiv (x,0) 。注意，这里的等同关系与相等是一致的（因此 x = y，当且仅当 (x,0)=(y,0)(x,0) = (y,0) ）；其中加法运算满足 x1+x2=x3x_{1} + x_{2} = x_{3} ，当且仅当 (x1,0)+(x2,0)=(x3,0)(x_{1},0) + (x_{2},0) = (x_{3},0) ；负运算满足 x = -y，当且仅当 (x,0)=−(y,0)(x,0) = -(y,0) ；乘法运算满足 x1x2=x3x_{1}x_{2} = x_{3} ，当且仅当 (x1,0)(x2,0)=(x3,0)(x_{1},0)(x_{2},0) = (x_{3},0) 。因此，我们不必再区分“实数加法运算”和“复数加法运算”。类似地，也不必区分实数和复数的相等、负运算以及乘法运算。例如，为了计算 3(2,4)，我们可以让实数 3 等同于复数 (3,0)，然后计算出 (3,0)(2,4)=(3×2−0×4,3×4+0×2)=(6,12)(3,0)(2,4) = (3 \times 2 - 0 \times 4, 3 \times 4 + 0 \times 2) = (6,12) 。还要注意， 0≡0C0 \equiv 0_{C} 和 1≡1C1 \equiv 1_{C} ，于是我们可以删除 0C0_{C} 的下标 C 而只写 0，删除单位元 1C1_{C} 的下标 C 而只写 1。

现在我们定义 i 为复数 i:=(0,1)i := (0,1) 。这样我们就可以把复数的非正式定义重新写成下面这个引理。

引理 15.6.7命题/引理

每一个复数 z∈Cz \in \mathbf{C} 都可以写成 z=a+biz = a + bi ，其中 a,ba, b 是唯一确定的一对实数。另外， i2=−1\mathrm{i}^2 = -1 ，且 −z=(−1)z-z = (-1)z 。

证明

参见习题 15.6.3。

根据这个引理，我们现在可以把复数写成更常用的 a+bia + bi ，并从此丢弃掉形式符号 (a,b)(a, b) 。

定义 15.6.8概念定义

（实部和虚部）如果 z=a+biz = a + bi 是一个复数，其中 a、b 都是实数，那么我们把 a 称作 z 的实部，并记作 ℜ(z):=a\Re(z) := a ；把 b 称作 z 的虚部，并记作 ℑ(z):=b\Im(z) := b 。例如， ℜ(3+4i)=3\Re(3 + 4i) = 3 且 ℑ(3+4i)=4\Im(3 + 4i) = 4 。一般地， z=ℜ(z)+iℑ(z)z = \Re(z) + i\Im(z) 。注意，z 是实数当且仅当 ℑ(z)=0\Im(z) = 0 。我们称 z 是虚数，当且仅当 ℜ(z)=0\Re(z) = 0 。例如，4i 是一个虚数，但 3+4i3 + 4i 既不是实数也不是虚数，而 0 既是实数又是虚数。我们把 z 的复共轭 z¯\bar{z} 定义为复数 z¯:=ℜ(z)−iℑ(z)\bar{z} := \Re(z) - i\Im(z) 。例如， 3+4i¯=3−4i,i¯=−i\overline{3 + 4i} = 3 - 4i, \overline{i} = -i 以及 3¯=3\overline{3} = 3 。

复共轭运算具有一些很好的性质。

在定义15.3.1中，我们定义了有理数 xx 的绝对值 |x||x| 的概念，并把该定义以明显的方式推广到实数上。但是，绝对值的概念无法直接推广到复数上，因为绝大部分复数既不是正的，也不是负的。（例如，我们既不能把i当作正数，也不能把i看作负数。其中的部分原因参见习题15.6.15。）不过，我们仍然可以对复数定义绝对值的概念，方法是把习题5.6.3中的公式 |x|=x2|x| = \sqrt{x^2} 进行推广。

定义 15.6.10概念定义

（复数的绝对值）如果 z=a+biz = a + bi 是一个复数，那么 z 的绝对值 |z||z| 就被定义为实数 |z|:=a2+b2=(a2+b2)1/2|z| := \sqrt{a^{2} + b^{2}} = (a^{2} + b^{2})^{1/2} 。

由习题 5.6.3 可知，这个绝对值的概念推广了实数绝对值的概念。绝对值还有其他一些好的性质。

我们可以利用绝对值的概念来定义倒数。

定义 15.6.12概念定义

（复数的倒数）如果 z 是一个非零的复数，那么 z 的倒数 z−1z^{-1} 就被定义为复数 z−1:=|z|−2z¯z^{-1} := |z|^{-2}\overline{z} 。（注意，根据引理 15.6.11，因为 |z||z| 是一个正实数，所以 |z|−2|z|^{-2} 被定义为一个正实数是有意义的。）例如， (1+2i)−1=|1+2i|−2(1−2i)=(12+22)−1(1−2i)=15−25i(1 + 2\mathrm{i})^{-1} = |1 + 2\mathrm{i}|^{-2}(1 - 2\mathrm{i}) = (1^2 + 2^2)^{-1}(1 - 2\mathrm{i}) = \frac{1}{5} - \frac{2}{5}\mathrm{i} 。当 z 为零，即 z = 0 时，我们不定义 0−10^{-1} 。

我们观察到，实数系和复数系实际上非常相似。它们都遵守类似的运算定律，并有相似的度量空间结构。事实上，我们在本书中已经证明的有关实值函数的很多结论也都适用于复值函数。我们只需要把证明中的“实数”简单地替换成“复数”，并保持其余的证明不变就可以了。也就是说，我们总能把一个复值函数 ff 划分成实部 ℜ(f)\Re(f) 和虚部 ℑ(f)\Im(f) ，于是 f=ℜ(f)+iℑ(f)f = \Re(f) + \mathrm{i}\Im(f) 。这样就可以从相应的实值函数 ℜ(f)\Re(f) 和 ℑ(f)\Im(f) 的结论中推导出关于复值函数 ff 的结论。例如，第14章中的逐点收敛和一致收敛理论，以及本章中的幂级数理论都可以毫无困难地推广到复值函数上。因此，我们完全可以按照定义实指数函数的方法来定义复指数函数。

定义 15.6.15概念定义

（复指数函数）如果 zz 是一个复数，那么我们把函数 exp(z)\exp (z) 定义为

exp(z):=∑n=0∞znn!\exp (z) := \sum_ {n = 0} ^ {\infty} \frac {z ^ {n}}{n !}

我们可以叙述并证明关于复数级数的比值判别法，并利用它来证明对于任意的 z,exp(z)z, \exp(z) 都是收敛的。实际上，定理15.5.2中的许多性质都仍然成立：例如， exp(z+w)=exp(z)exp(w)\exp(z + w) = \exp(z)\exp(w) ，参见习题15.6.16。（其他性质将要用到复微分和复积分，但这些内容超出了本书的范围。) 另外一个有用的结果是 exp(z)¯=exp(z¯)\overline{\exp(z)} = \exp(\overline{z}) ，它可以通过对部分和 ∑n=0Nznn!\sum_{n=0}^{N} \frac{z^n}{n!} 取共轭，然后再取当 N→∞N \to \infty 时的极限而得到。

复对数函数事实上会更微妙一些，主要因为 exp 不再是可逆的，同时还因为关于对数函数的各种幂级数都只有一个有限的收敛半径（它不像 exp 那样，有一个无限的收敛半径）。这种相当微妙的情形超出了本书的范围，我们对此不再进行讨论。
