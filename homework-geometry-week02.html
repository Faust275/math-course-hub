第 1 题 平行六面体仿射标架下的向量分量与顶点坐标 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#1
在平行六面体 ABCD−EFGHABCD-EFGH 中，平行四边形 CGHDCGHD 的中心为 PP，并设 EF→=e→1\overrightarrow{EF}=\vec e_1，EH→=e→2\overrightarrow{EH}=\vec e_2，EA→=e→3\overrightarrow{EA}=\vec e_3。
(1) 求向量 AP→\overrightarrow{AP}，FP→\overrightarrow{FP} 关于标架 {A;e→1,e→2,e→3}\{A; \vec e_1, \vec e_2, \vec e_3\} 的分量；
(2) 求 △BEP\triangle BEP 三个顶点及其重心关于 {A;e→1,e→2,e→3}\{A; \vec e_1, \vec e_2, \vec e_3\} 的坐标。
💡 课本提示：注意标架原点取在 AA。根据平行六面体各棱向量与基底 e→1,e→2,e→3\vec e_1, \vec e_2, \vec e_3 的关系，先求出中心 PP 的位置向量 AP→\overrightarrow{AP}。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
在空间仿射标架下，求点的坐标本质上就是求原点到该点的有向位置向量关于三基底向量的线性表出系数。中心点 PP 作为对角线中点可直接由中点向量公式得到。
【详细推理与解答】

(1) 解：

建立以 AA 为原点、{e→1,e→2,e→3}\{\vec e_1, \vec e_2, \vec e_3\} 为基底的标架。

平行六面体中：AB→=EF→=e→1\overrightarrow{AB} = \overrightarrow{EF} = \vec e_1，AD→=EH→=e→2\overrightarrow{AD} = \overrightarrow{EH} = \vec e_2，AE→=−e→3\overrightarrow{AE} = -\vec e_3。

由平行四边形 CGHDCGHD 的几何中心定义，PP 是线段 CHCH 或 DGDG 的中点。因 AC→=e→1+e→2\overrightarrow{AC} = \vec e_1 + \vec e_2，AH→=AD→+DH→=e→2−e→3\overrightarrow{AH} = \overrightarrow{AD} + \overrightarrow{DH} = \vec e_2 - \vec e_3，故：

AP→=12(AC→+AH→)=12((e→1+e→2)+(e→2−e→3))=12e→1+e→2−12e→3\overrightarrow{AP} = \frac{1}{2}(\overrightarrow{AC} + \overrightarrow{AH}) = \frac{1}{2}((\vec e_1 + \vec e_2) + (\vec e_2 - \vec e_3)) = \frac{1}{2}\vec e_1 + \vec e_2 - \frac{1}{2}\vec e_3

因此向量 AP→\overrightarrow{AP}

关于标架的分量为：(12,1,−12)\left(\dfrac{1}{2}, 1, -\dfrac{1}{2}\right)。

对于 FP→\overrightarrow{FP}，注意 AF→=AE→+EF→=e→1−e→3\overrightarrow{AF} = \overrightarrow{AE} + \overrightarrow{EF} = \vec e_1 - \vec e_3，故：

FP→=AP→−AF→=(12e→1+e→2−12e→3)−(e→1−e→3)=−12e→1+e→2+12e→3\overrightarrow{FP} = \overrightarrow{AP} - \overrightarrow{AF} = \left(\frac{1}{2}\vec e_1 + \vec e_2 - \frac{1}{2}\vec e_3\right) - (\vec e_1 - \vec e_3) = -\frac{1}{2}\vec e_1 + \vec e_2 + \frac{1}{2}\vec e_3

因此向量 FP→\overrightarrow{FP}

关于标架的分量为：(−12,1,12)\left(-\dfrac{1}{2}, 1, \dfrac{1}{2}\right)。

(2) 解：

关于标架 {A;e→1,e→2,e→3}\{A; \vec e_1, \vec e_2, \vec e_3\}：

  • AB→=e→1⇒B(1,0,0)\overrightarrow{AB} = \vec e_1 \implies B(1, 0, 0)；
  • AE→=−e→3⇒E(0,0,−1)\overrightarrow{AE} = -\vec e_3 \implies E(0, 0, -1)；
  • 由 (1) 知 AP→=12e→1+e→2−12e→3⇒P(12,1,−12)\overrightarrow{AP} = \frac{1}{2}\vec e_1 + \vec e_2 - \frac{1}{2}\vec e_3 \implies P\left(\frac{1}{2}, 1, -\frac{1}{2}\right)。

设 △BEP\triangle BEP 的重心为 GG。由三角形重心坐标公式：

xG=1+0+1/23=12, yG=0+0+13=13, zG=0+(−1)+(−1/2)3=−12x_G = \frac{1 + 0 + 1/2}{3} = \frac{1}{2},\quad y_G = \frac{0 + 0 + 1}{3} = \frac{1}{3},\quad z_G = \frac{0 + (-1) + (-1/2)}{3} = -\frac{1}{2}

因此重心坐标为：G(12,13,−12)G\left(\dfrac{1}{2}, \dfrac{1}{3}, -\dfrac{1}{2}\right)

。

g→1=13(r→2+r→3+r→4)\vec g_1 = \frac{1}{3}(\vec r_2 + \vec r_3 + \vec r_4)

在线段 A1G1A_1G_1 上取点 MM，使其分线段所成比为 A1M:MG1=3:1A_1M : MG_1 = 3 : 1（定比分点比 λ=3\lambda = 3）。由定比分点公式：

OM→=r→1+3g→11+3=14r→1+34[13(r→2+r→3+r→4)]=14(r→1+r→2+r→3+r→4)\overrightarrow{OM} = \frac{\vec r_1 + 3\vec g_1}{1 + 3} = \frac{1}{4}\vec r_1 + \frac{3}{4}\left[\frac{1}{3}(\vec r_2 + \vec r_3 + \vec r_4)\right] = \frac{1}{4}(\vec r_1 + \vec r_2 + \vec r_3 + \vec r_4)

同理，对于另外三个顶点 A2,A3,A4A_2, A_3, A_4 及其对面重心 G2,G3,G4G_2, G_3, G_4，线段 AiGiA_iG_i 上分比为 3:13:1 的分点位置向量均同样给出：

14(r→1+r→2+r→3+r→4)\frac{1}{4}(\vec r_1 + \vec r_2 + \vec r_3 + \vec r_4)

此式关于四个顶点下标 1,2,3,41, 2, 3, 4 完全对称，因此四条连线 A1G1,A2G2,A3G3,A4G4A_1G_1, A_2G_2, A_3G_3, A_4G_4 必交于唯一的公共点 MM（四面体质心），且 MM 到顶点的距离是到对面重心距离的 3 倍。

若四个顶点的坐标分别为 Ai(xi,yi,zi)A_i(x_i, y_i, z_i)，则交点 MM 的坐标为：

M(x1+x2+x3+x44,y1+y2+y3+y44,z1+z2+z3+z44)M\left(\frac{x_1+x_2+x_3+x_4}{4}, \frac{y_1+y_2+y_3+y_4}{4}, \frac{z_1+z_2+z_3+z_4}{4}\right)

第 3 题 两两相交 60 度角向量和模长计算 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#3
已知向量 a→,b→,c→\vec a, \vec b, \vec c 两两相成 60∘60^\circ 角，且 |a→|=4|\vec a|=4，|b→|=2|\vec b|=2，|c→|=6|\vec c|=6。
求 p→=a→+b→+c→\vec p = \vec a + \vec b + \vec c 的长度。
💡 课本提示：利用模长与内积的关系 |p→|2=p→·p→|\vec p|^2 = \vec p \cdot \vec p，将 (a→+b→+c→)2(\vec a+\vec b+\vec c)^2 按双线性展开，代入两两夹角的内积值 a→·b→=|a→||b→|cos60∘\vec a\cdot\vec b = |\vec a||\vec b|\cos 60^\circ。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
求多个向量线性组合的模长，标准步骤是先求模的平方，展开为各向量自模长平方加上两两交叉项的二倍，最后开平方根。
【详细推理与解答】

解：

因为 a→,b→,c→\vec a, \vec b, \vec c 两两夹角均为 60∘60^\circ，且 cos60∘=12\cos 60^\circ = \frac{1}{2}，各对向量内积为：

a→·b→=|a→||b→|cos60∘=4×2×12=4\vec a \cdot \vec b = |\vec a||\vec b|\cos 60^\circ = 4 \times 2 \times \frac{1}{2} = 4b→·c→=|b→||c→|cos60∘=2×6×12=6\vec b \cdot \vec c = |\vec b||\vec c|\cos 60^\circ = 2 \times 6 \times \frac{1}{2} = 6c→·a→=|c→||a→|cos60∘=6×4×12=12\vec c \cdot \vec a = |\vec c||\vec a|\cos 60^\circ = 6 \times 4 \times \frac{1}{2} = 12

计算 p→=a→+b→+c→\vec p = \vec a + \vec b + \vec c 的模长平方：

|p→|2=(a→+b→+c→)·(a→+b→+c→)=|a→|2+|b→|2+|c→|2+2(a→·b→+b→·c→+c→·a→)|\vec p|^2 = (\vec a + \vec b + \vec c) \cdot (\vec a + \vec b + \vec c) = |\vec a|^2 + |\vec b|^2 + |\vec c|^2 + 2(\vec a \cdot \vec b + \vec b \cdot \vec c + \vec c \cdot \vec a)|p→|2=42+22+62+2(4+6+12)=16+4+36+2(22)=56+44=100|\vec p|^2 = 4^2 + 2^2 + 6^2 + 2(4 + 6 + 12) = 16 + 4 + 36 + 2(22) = 56 + 44 = 100

因此，p→\vec p

的长度为：

|p→|=100=10|\vec p| = \sqrt{100} = 10
第 4 题 等边三角形边向量内积循环和 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#4
已知等边三角形 ABCABC 的边长为 11，且 BC→=a→\overrightarrow{BC}=\vec a，CA→=b→\overrightarrow{CA}=\vec b，AB→=c→\overrightarrow{AB}=\vec c。
求 a→·b→+b→·c→+c→·a→\vec a \cdot \vec b + \vec b \cdot \vec c + \vec c \cdot \vec a。
💡 课本提示：注意 a→,b→,c→\vec a, \vec b, \vec c 首尾相接闭合，a→+b→+c→=0→\vec a+\vec b+\vec c = \vec 0。或者注意首尾相接两向量夹角是外角 120∘120^\circ 而非内角 60∘60^\circ。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
闭合多边形外角陷阱是向量初学者的高频易错点。最优雅且绝不会算错夹角的方法是直接利用 a→+b→+c→=0→\vec a+\vec b+\vec c=\vec 0 的模长平方展开。
【详细推理与解答】

解（方法一：模长平方恒等式法）：

因为首尾相接构成的三角形是闭合回路：

a→+b→+c→=BC→+CA→+AB→=0→\vec a + \vec b + \vec c = \overrightarrow{BC} + \overrightarrow{CA} + \overrightarrow{AB} = \vec 0

两端取模长平方：

|a→+b→+c→|2=|0→|2=0|\vec a + \vec b + \vec c|^2 = |\vec 0|^2 = 0|a→|2+|b→|2+|c→|2+2(a→·b→+b→·c→+c→·a→)=0|\vec a|^2 + |\vec b|^2 + |\vec c|^2 + 2(\vec a \cdot \vec b + \vec b \cdot \vec c + \vec c \cdot \vec a) = 0

已知等边三角形边长为 11

，即 |a→|=|b→|=|c→|=1|\vec a|=|\vec b|=|\vec c|=1，代入得：

12+12+12+2(a→·b→+b→·c→+c→·a→)=01^2 + 1^2 + 1^2 + 2(\vec a \cdot \vec b + \vec b \cdot \vec c + \vec c \cdot \vec a) = 03+2(a→·b→+b→·c→+c→·a→)=0⇒a→·b→+b→·c→+c→·a→=−323 + 2(\vec a \cdot \vec b + \vec b \cdot \vec c + \vec c \cdot \vec a) = 0 \implies \vec a \cdot \vec b + \vec b \cdot \vec c + \vec c \cdot \vec a = -\frac{3}{2}

解（方法二：直接定义计算法）：

把 a→=BC→\vec a = \overrightarrow{BC} 与 b→=CA→\vec b = \overrightarrow{CA} 平移至同一起点 CC，夹角为其外角 θ=180∘−60∘=120∘\theta = 180^\circ - 60^\circ = 120^\circ。

a→·b→=|a→||b→|cos120∘=1×1×(−12)=−12\vec a \cdot \vec b = |\vec a||\vec b|\cos 120^\circ = 1 \times 1 \times \left(-\frac{1}{2}\right) = -\frac{1}{2}

同理 b→·c→=−12\vec b \cdot \vec c = -\frac{1}{2}，c→·a→=−12\vec c \cdot \vec a = -\frac{1}{2}。三项相加即得 −32-\dfrac{3}{2}。

第 5 题 两垂直正交条件求解两向量夹角 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#5
已知向量 a→+3b→\vec a + 3\vec b 与 7a→−5b→7\vec a - 5\vec b 垂直，且 a→−4b→\vec a - 4\vec b 与 7a→−2b→7\vec a - 2\vec b 垂直。
求 a→\vec a 与 b→\vec b 的夹角。
💡 课本提示：垂直条件 ⇔\iff 内积为零。将两个内积展开，列出关于 |a→|2|\vec a|^2、|b→|2|\vec b|^2 和 a→·b→\vec a\cdot\vec b 的齐次线性方程组，消元求出模长比例与夹角余弦值。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
两个垂直条件提供了两个关于内积的双线性约束，从而确定了模长比值 |a→|/|b→||\vec a| / |\vec b| 以及 cosθ\cos\theta。
【详细推理与解答】

解：

由已知，两个内积均为零：

(a→+3b→)·(7a→−5b→)=0⇒7|a→|2+16(a→·b→)−15|b→|2=0 (1)(\vec a + 3\vec b) \cdot (7\vec a - 5\vec b) = 0 \implies 7|\vec a|^2 + 16(\vec a \cdot \vec b) - 15|\vec b|^2 = 0\quad (1)(a→−4b→)·(7a→−2b→)=0⇒7|a→|2−30(a→·b→)+8|b→|2=0 (2)(\vec a - 4\vec b) \cdot (7\vec a - 2\vec b) = 0 \implies 7|\vec a|^2 - 30(\vec a \cdot \vec b) + 8|\vec b|^2 = 0\quad (2)

由式 (1) 减去式 (2)：

46(a→·b→)−23|b→|2=0⇒a→·b→=12|b→|246(\vec a \cdot \vec b) - 23|\vec b|^2 = 0 \implies \vec a \cdot \vec b = \frac{1}{2}|\vec b|^2

将 a→·b→=12|b→|2\vec a \cdot \vec b = \frac{1}{2}|\vec b|^2 代入式 (1)：

7|a→|2+16(12|b→|2)−15|b→|2=0⇒7|a→|2−7|b→|2=0⇒|a→|=|b→|7|\vec a|^2 + 16\left(\frac{1}{2}|\vec b|^2\right) - 15|\vec b|^2 = 0 \implies 7|\vec a|^2 - 7|\vec b|^2 = 0 \implies |\vec a| = |\vec b|

根据夹角余弦公式：

cosθ=a→·b→|a→||b→|=12|b→|2|b→|2=12\cos\theta = \frac{\vec a \cdot \vec b}{|\vec a||\vec b|} = \frac{\frac{1}{2}|\vec b|^2}{|\vec b|^2} = \frac{1}{2}

因为几何向量夹角范围 θ∈[0,π]\theta \in [0, \pi]

，故 θ=π3\theta = \dfrac{\pi}{3}（即 60∘60^\circ）。

第 6 题 向量在轴上的正射影与线性组合夹角 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#6
(1) 在直角坐标系下，已知 a→=(4,−3,2)\vec a = (4, -3, 2)，b→=(2,−1,−2)\vec b = (2, -1, -2)，求向量 a→\vec a 在 b→\vec b 上的射影 projb→a→\mathrm{proj}_{\vec b}\vec a；
(2) 已知 |a→|=3|\vec a|=3，|b→|=2|\vec b|=2，∠(a→,b→)=π3\angle(\vec a, \vec b)=\frac{\pi}{3}，求 3a→+2b→3\vec a+2\vec b 与 2a→−3b→2\vec a-3\vec b 的内积和夹角。
💡 课本提示：(1) 正射影公式为 projb→a→=a→·b→|b→|\mathrm{proj}_{\vec b}\vec a = \frac{\vec a\cdot\vec b}{|\vec b|}；(2) 先由双线性展开求内积，再分别求两向量模长，最后套夹角余弦公式。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
解析几何中射影（投影值）是一个带符号的标量；注意射影与射影向量的区别。第 (2) 问考查内积代数运算律在抽象模长与夹角计算中的综合应用。
【详细推理与解答】

(1) 解：

计算内积与底向量模长：

a→·b→=4×2+(−3)×(−1)+2×(−2)=8+3−4=7\vec a \cdot \vec b = 4 \times 2 + (-3) \times (-1) + 2 \times (-2) = 8 + 3 - 4 = 7|b→|=22+(−1)2+(−2)2=4+1+4=3|\vec b| = \sqrt{2^2 + (-1)^2 + (-2)^2} = \sqrt{4 + 1 + 4} = 3

因此，a→\vec a

在 b→\vec b 上的射影为：

projb→a→=a→·b→|b→|=73\mathrm{proj}_{\vec b}\vec a = \frac{\vec a \cdot \vec b}{|\vec b|} = \frac{7}{3}

(2) 解：

已知 |a→|=3,|b→|=2,cosπ3=12⇒a→·b→=3×2×12=3|\vec a|=3, |\vec b|=2, \cos\frac{\pi}{3}=\frac{1}{2} \implies \vec a\cdot\vec b = 3 \times 2 \times \frac{1}{2} = 3。

记 u→=3a→+2b→\vec u = 3\vec a+2\vec b，v→=2a→−3b→\vec v = 2\vec a-3\vec b。内积为：

b→×c→=a→×b→\vec b \times \vec c = \vec a \times \vec b
