一、函数极限的高级计算
第 1 题 典型三角与连乘函数极限计算 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#1
计算下面各极限：
(1) limn→+∞sin(πn2+1)\lim_{n\to+\infty} \sin(\pi\sqrt{n^2 + 1})；
(2) limn→+∞(n+xn−1)n\lim_{n\to+\infty}\left(\dfrac{n+x}{n-1}\right)^n；
(3) limn→+∞cosx2cosx4⋯cosx2n\lim_{n\to+\infty} \cos\dfrac{x}{2} \cos\dfrac{x}{4} \cdots \cos\dfrac{x}{2^n}；
(4) limn→+∞nsin(2πn!e)\lim_{n\to+\infty} n\sin(2\pi n! e)。
💡 课本提示：(1) 利用诱导公式 sin(πn2+1)=(−1)nsin(π(n2+1−n))\sin(\pi\sqrt{n^2+1}) = (-1)^n \sin(\pi(\sqrt{n^2+1}-n)) 有理化；(2) 化为 (1+1/n)n(1+1/n)^n 的标准复合指数形式；(3) 两边同乘 sin(x/2n)\sin(x/2^n) 裂项倍角相消；(4) 将自然数 ee 展开为 Taylor 级数余项。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
四大著名极限计算：诱导公式相消、重要极限 ex+1e^{x+1}、Euler 连乘余弦恒等式 sinxx\frac{\sin x}{x}，以及利用 Taylor 级数截断计算阶乘调制正弦极限。
【详细推理与解答】

(1) 解：

因为 n2+1=n+(n2+1−n)\sqrt{n^2+1} = n + (\sqrt{n^2+1} - n)，利用诱导公式：

sin(πn2+1)=sin(nπ+π(n2+1−n))=(−1)nsin(πn2+1+n)\sin(\pi\sqrt{n^2+1}) = \sin(n\pi + \pi(\sqrt{n^2+1}-n)) = (-1)^n \sin\left(\frac{\pi}{\sqrt{n^2+1}+n}\right)

当 n→∞n \to \infty

时，πn2+1+n→0\frac{\pi}{\sqrt{n^2+1}+n} \to 0。由 sinu∼u\sin u \sim u：

|sin(πn2+1)|∼π2n→0⇒limn→+∞sin(πn2+1)=0|\sin(\pi\sqrt{n^2+1})| \sim \frac{\pi}{2n} \to 0 \implies \lim_{n\to+\infty} \sin(\pi\sqrt{n^2+1}) = 0

(2) 解：

变形为：

n+xn−1=1+x+1n−1=1+x+1n+O(n−2)\frac{n+x}{n-1} = 1 + \frac{x+1}{n-1} = 1 + \frac{x+1}{n} + O(n^{-2})limn→+∞(1+x+1n−1)n=limn→+∞[(1+x+1n−1)n−1x+1]n(x+1)n−1=ex+1\lim_{n\to+\infty}\left(1 + \frac{x+1}{n-1}\right)^n = \lim_{n\to+\infty}\left[\left(1 + \frac{x+1}{n-1}\right)^{\frac{n-1}{x+1}}\right]^{\frac{n(x+1)}{n-1}} = e^{x+1}

(3) 解：

利用倍角公式 cosu=sin2u2sinu\cos u = \frac{\sin 2u}{2\sin u}。两端乘上 sinx2n\sin\frac{x}{2^n}：

(cosx2cosx4⋯cosx2n)sinx2n=12nsinx\left(\cos\frac{x}{2} \cos\frac{x}{4} \cdots \cos\frac{x}{2^n}\right) \sin\frac{x}{2^n} = \frac{1}{2^n} \sin x

两边除以 sinx2n\sin\frac{x}{2^n}：

Pn=sinx2nsin(x/2n)=sinxx·x/2nsin(x/2n)P_n = \frac{\sin x}{2^n \sin(x/2^n)} = \frac{\sin x}{x} \cdot \frac{x/2^n}{\sin(x/2^n)}

当 n→∞n \to \infty

时，x/2nsin(x/2n)→1\frac{x/2^n}{\sin(x/2^n)} \to 1。因此极限为 sinxx\dfrac{\sin x}{x}（若 x=0x=0，恒等于 1）。

(4) 解：

将 ee 用级数展开：e=∑k=0n1k!+1(n+1)!+1(n+2)!+…e = \sum_{k=0}^n \frac{1}{k!} + \frac{1}{(n+1)!} + \frac{1}{(n+2)!} + \dots

n!e=(整数M)+1n+1+1(n+1)(n+2)+…n! e = \left(\text{整数} M\right) + \frac{1}{n+1} + \frac{1}{(n+1)(n+2)} + \dots

乘上 2π2\pi 整数周期消去：

sin(2πn!e)=sin(2πM+2πn+1+O(n−2))=sin(2πn+1+O(n−2))=2πn+1+O(n−2)\sin(2\pi n! e) = \sin\left(2\pi M + \frac{2\pi}{n+1} + O(n^{-2})\right) = \sin\left(\frac{2\pi}{n+1} + O(n^{-2})\right) = \frac{2\pi}{n+1} + O(n^{-2})

乘上 nn

取极限：

limn→+∞nsin(2πn!e)=limn→+∞2πnn+1=2π\lim_{n\to+\infty} n\sin(2\pi n! e) = \lim_{n\to+\infty} \frac{2\pi n}{n+1} = 2\pi

二、间断点分类与连续性判定
第 4 题 函数间断点分类分析 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#4
指出下面函数的间断点及其类型：
(1) f(x)=x[x]f(x) = x[x]；
(2) f(x)=sgn(sinx)f(x) = \mathrm{sgn}(\sin x)；
(3) f(x)={e1/x,x≠00,x=0f(x) = \begin{cases} e^{1/x}, & x \neq 0 \\ 0, & x = 0 \end{cases}。
💡 课本提示：(1) 在非零整数点左右极限不同（第一类跳跃间断点），但在 0 处连续；(2) 在 π\pi 的整数倍处左右符号相反；(3) 右极限为 +∞+\infty（第二类无穷间断点）。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
间断点分类（第一类：可去间断点、跳跃间断点；第二类：无穷间断点、振荡间断点）的综合判定。
【详细推理与解答】

(1) f(x)=x[x]f(x) = x[x]：

  • 取整函数在非整数点处连续，故可能间断点仅为整数点 x=k∈ℤx = k \in \mathbb{Z}；
  • 当 k=0k = 0 时：f(0−)=limx→0−x(−1)=0f(0^-) = \lim_{x\to 0^-} x(-1) = 0，f(0+)=limx→0+x(0)=0=f(0)f(0^+) = \lim_{x\to 0^+} x(0) = 0 = f(0)，在 x=0x=0 处连续；
  • 当 k∈ℤ∖{0}k \in \mathbb{Z} \setminus \{0\} 时：f(k+)=k·k=k2f(k^+) = k \cdot k = k^2，f(k−)=k(k−1)=k2−kf(k^-) = k(k-1) = k^2 - k。左右极限均存在但不相等（跳跃度 |k|>0|k| > 0），为第一类跳跃间断点。

(2) f(x)=sgn(sinx)f(x) = \mathrm{sgn}(\sin x)：

  • 间断点为 sinx=0\sin x = 0 的点，即 x=kπx = k\pi (k∈ℤk \in \mathbb{Z})；
  • 在 x=2mπx = 2m\pi 处：左侧 sinx<0⇒f=−1\sin x < 0 \implies f=-1，右侧 sinx>0⇒f=1\sin x > 0 \implies f=1。左右极限分别为 −1-1 和 11；
  • 在一切 x=kπx = k\pi 处均为第一类跳跃间断点。

(3) f(x)={e1/x,x≠00,x=0f(x) = \begin{cases} e^{1/x}, & x \neq 0 \\ 0, & x = 0 \end{cases}：

  • 间断点仅在 x=0x = 0 处；
  • 考察左极限：x→0−x \to 0^- 时，1x→−∞⇒e1/x→0=f(0)\frac{1}{x} \to -\infty \implies e^{1/x} \to 0 = f(0)；
  • 考察右极限：x→0+x \to 0^+ 时，1x→+∞⇒e1/x→+∞\frac{1}{x} \to +\infty \implies e^{1/x} \to +\infty；
  • 右极限不存在且发散至无穷大，故 x=0x = 0 为第二类无穷间断点。
第 5 题 单调函数连续性充要条件定理证明 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#5
设 ff 在 [a,b][a, b] 上单调增加。证明：ff 在 [a,b][a, b] 上连续当且仅当它的像集 f([a,b])=[f(a),f(b)]f([a, b]) = [f(a), f(b)]。
💡 课本提示：必要性由介值定理保证；充分性利用反证法：若存在间断点 x0x_0，由于单调性该点必为跳跃间断点，其跳跃区间 (f(x0−),f(x0+))(f(x_0^-), f(x_0^+)) 中的值无法被取到，导致像集出现空隙产生矛盾。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
单调函数最核心的拓扑特征。单调函数的间断点只可能是跳跃间断点，而连续函数把闭区间映射为闭区间，没有缝隙直接排除了跳跃间断点的存在。
【详细推理与解答】

证明：

必要性（⇒\implies）：

设 ff 在 [a,b][a, b] 连续。因为 ff 单调递增，f(a)f(a) 为最小值，f(b)f(b) 为最大值。由闭区间连续函数的介值定理（Darboux 定理），ff 能取到介于 f(a)f(a) 和 f(b)f(b) 之间的任何实数，故值域 f([a,b])=[f(a),f(b)]f([a, b]) = [f(a), f(b)]。

充分性（⇐\impliedby）：

用反证法。设 f([a,b])=[f(a),f(b)]f([a, b]) = [f(a), f(b)]，假设 ff 在 [a,b][a, b] 上存在某个间断点 x0x_0。

因为 ff 是单调递增函数，它在任意点的左右单侧极限必存在且满足：

f(x0−)≤f(x0)≤f(x0+)f(x_0^-) \le f(x_0) \le f(x_0^+)

若 ff 在 x0x_0 不连续，则必有 f(x0−)<f(x0+)f(x_0^-) < f(x_0^+)（跳跃间断）。

考察开区间 J=(f(x0−),f(x0+))∖{f(x0)}J = (f(x_0^-), f(x_0^+)) \setminus \{f(x_0)\}。因为 JJ 是非空开区间，且对任意 x<x0x < x_0 有 f(x)≤f(x0−)f(x) \le f(x_0^-)，对任意 x>x0x > x_0 有 f(x)≥f(x0+)f(x) \ge f(x_0^+)，所以在区间 JJ 中的任何数都无法在 [a,b][a, b] 中找到原像！

这表明像集 f([a,b])f([a, b]) 缺少了开区间 JJ 中的点，不是一个连通闭区间，与已知条件 f([a,b])=[f(a),f(b)]f([a, b]) = [f(a), f(b)] 产生矛盾！

因此假设不成立，ff 在 [a,b][a, b] 上处处连续。证毕。

第 6 题 单调函数跳跃间断点的可数性证明 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#6
证明：单调函数的不连续点集至多是可数的。
💡 课本提示：单调函数的每个间断点 xx 对应一个不退化的互不相交开区间 (f(x−),f(x+))(f(x^-), f(x^+))；由有理数在实数中的稠密性，在每个开区间中挑选一个有理数建立单射。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
现代实分析的经典结论。通过将间断点与互不相交的开区间一一对应，再利用有理数集 ℚ\mathbb{Q} 的可数性，得出单调函数绝不可能有不可数个间断点。
【详细推理与解答】

证明：

不妨设 ff 在定义域区间 II 上单调递增。记其所有不连续点组成的集合为 DD。

由单调函数性质，对任意 x∈Dx \in D，ff 在 xx 处的单侧极限必存在，且因不连续必成立严格不等式：

f(x−)<f(x+)f(x^-) < f(x^+)

令对应的开区间为 Ix=(f(x−),f(x+))I_x = (f(x^-), f(x^+))。由单调性，当 x1<x2x_1 < x_2 时，显然有 f(x1+)≤f(x2−)f(x_1^+) \le f(x_2^-)，因此不同的间断点所对应的开区间两两互不相交：

x1≠x2⇒Ix1∩Ix2=∅x_1 \neq x_2 \implies I_{x_1} \cap I_{x_2} = \emptyset

由有理数集 ℚ\mathbb{Q} 在实数集中的稠密性，在每个非空开区间 IxI_x 中必至少包含一个有理数，记为 r(x)∈Ix∩ℚr(x) \in I_x \cap \mathbb{Q}。

因为各区间两两不相交，当 x1≠x2x_1 \neq x_2 时，r(x1)≠r(x2)r(x_1) \neq r(x_2)。这便建立了从间断点集 DD 到有理数集 ℚ\mathbb{Q} 的一个单射映射 x↦r(x)x \mapsto r(x)。

因为有理数集 ℚ\mathbb{Q} 是可数集，可数集的子集至多可数。因此单调函数的不连续点集 DD 至多是可数的。证毕。

#7

解：

1. 当 x0=0x_0 = 0 时，对一切 nn 有 xn=0x_n = 0，极限显然为 0。

0<xn+1=sin(xn)<xn0 < x_{n+1} = \sin(x_n) < x_n

数列 {xn}\{x_n\}

两端取连续函数正弦极限：L=sinLL = \sin L。方程在 [0,1][0, 1] 内的唯一解为 L=0L = 0。

3. 当 x0<0x_0 < 0 时，由正弦函数奇函数性质 sin(−t)=−sint\sin(-t) = -\sin t，同样对称收敛到 0；对任意实数 xx，初次迭代后均落入 [−1,1][-1, 1]。
