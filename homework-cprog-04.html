一、判断题（9 题）

1判断题
C 语言中 do-while 语句的循环体至少会执行一次，因为它是先执行循环体再判断条件。
正确答案：√
该说法正确。do-while 先执行循环体再判断条件，故至少执行一次。
2判断题
在 C 语言循环体中，break 语句的功能是跳过当前循环的剩余部分，直接开始下一次循环。
正确答案：×
该说法错误。跳过本次剩余语句进入下一次循环的是 continue，break 会终止循环。
3判断题
for 语句的三个表达式（初始化、条件判断、增量/减量）之间必须用分号 ; 分隔，否则会出现语法错误。
正确答案：√
该说法正确。for 的三个表达式之间必须用分号 ; 分隔。
4判断题
循环体中的 continue 语句只会终止当前一次循环的执行，不会影响整个循环的后续次数。
正确答案：√
该说法正确。continue 只结束当前一次迭代，不影响后续循环次数。
5判断题
do-while 语句的循环条件后面可以省略分号，编译器会自动补充，不会影响程序运行。
正确答案：×
该说法错误。do-while 的条件右括号后必须写分号，省略会编译报错。
6判断题
在多层嵌套循环中，单个 break 语句可以一次性跳出所有嵌套层级的循环。
正确答案：×
该说法错误。break 只跳出最近的一层循环，不能一次跳出所有嵌套层。
7判断题
break 语句既可以用于跳出循环，也可以用于跳出 switch 语句，但作用范围仅限最近的循环或 switch。
正确答案：√
该说法正确。break 可用于循环和 switch，作用范围仅限最近的那个。
8判断题
while 循环中执行 continue 语句后，会跳过循环体剩余代码，直接重新判断循环条件。
正确答案：√
该说法正确。while 中执行 continue 会跳过剩余代码，直接重新判断条件。
9判断题
for 语句的三个表达式都可以省略，例如 for(;;) 表示无限循环，需在循环体内通过 break 控制结束。
正确答案：√
该说法正确。for(;;) 三个表达式全省略即无限循环，需在体内用 break 结束。

二、单选题（10 题）

1单选题
do-while 循环的核心特点是？
正确答案：A
正确答案 A。do-while 先执行后判断，循环体至少执行一次。
2单选题
for 语句的初始化、条件判断、增量/减量三个表达式之间，必须使用哪种符号分隔？
正确答案：C
正确答案 C。三个表达式用分号 ; 分隔。
3单选题
以下代码最终会输出多少个 *？
for (int i = 0;
i < 2;
i++) {
for (int j = 0;
j < 3;
j++) {
printf("*");
}
}
正确答案：B
正确答案 B。外层 2 次 × 内层 3 次，共输出 6 个星号。
4单选题
for 循环的三个表达式中，允许省略的是？
正确答案：A
正确答案 A。for 的初始化、条件、增量三个表达式都可省略。
5单选题
while 循环中执行 continue 语句后，程序会？
正确答案：C
正确答案 C。continue 跳过循环体剩余代码，直接重新判断循环条件。
6单选题
while(0) 对应的循环体执行情况是？
正确答案：B
正确答案 B。while(0) 条件恒假，循环体一次也不执行。
7单选题
for 循环的增量表达式中，能否同时修改多个变量？（如实现 i 递增、j 递减）
正确答案：B
正确答案 B。增量表达式可用逗号运算符同时修改多个变量。
8单选题
在 while 循环中，若循环体中仅在 continue 语句后修改循环变量（如下所示），该循环会出现什么问题？
int i = 0;
while (i < 5) {
continue;
i++;
}
正确答案：D
正确答案 D。循环变量的修改写在 continue 之后永远执行不到，导致死循环。
9单选题
在多层嵌套循环中，内层循环的 break 语句对上层循环的影响是？
正确答案：B
正确答案 B。内层 break 只结束内层循环，外层继续执行剩余迭代。
10单选题
break 语句的主要功能是？
正确答案：D
正确答案 D。break 跳出当前所在的循环或 switch，继续执行其后的代码。
