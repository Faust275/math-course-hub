第 1 题 极大线性无关组唯一性的结构限制定理 (习题 5.1 第 4 题) 必做题 教材习题 5.1.4
#1
设α1,α2,…,αr为线性空间V中不同向量.求证：若α1,α2,…,αr的极大线 性无关组是唯一的，则向量组α1,α2,··,αr要么秩为r,要么秩为r-1且其中有一个 向量为0.
💡 课本提示：若极大无关组唯一，说明任何不在该组中的向量都必须只能是零向量！否则若存在非零外向量，可替换构造出另一个不同的极大无关组。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
拟阵理论与线性空间基底的刚性定理：基底几乎从来不是唯一的，除非整个集合本身就已线性无关或只差一个零向量。
【详细推理与解答】

证明：

1. 设向量组 S={α1,α2,…,αr}S = \{\alpha_1, \alpha_2, \dots, \alpha_r\} 的秩为 kk。设其极大线性无关组为 BB（含有 kk 个向量）。

2. 若 k=rk = r，则整个向量组本身就是线性无关的，其唯一的极大线性无关组就是它自身，此时秩为 rr。

3. 若 k<rk < r，设存在不属于 BB 的向量 v∈S∖Bv \in S \setminus B。因为 BB 是极大线性无关组，vv 可由 BB 线性表示：v=∑bi∈Bcibiv = \sum_{b_i \in B} c_i b_i

  • 若存在某个 cj≠0c_j \neq 0，则由 Steinitz 替换定理，可用 vv 替换 bjb_j，得到一个新的极大线性无关组 B'=(B∖{bj})∪{v}B' = (B \setminus \{b_j\}) \cup \{v\}。因为 v∉Bv \notin B，故 B'≠BB' \neq B！这与极大线性无关组唯一矛盾！
  • 因此，对任意 bi∈Bb_i \in B，在上述表示中所有系数必须全为 0，即必须有 v=0v = 0。

4. 题设向量两两不同，故最多只能有一个零向量 0∈S0 \in S。因此 S∖B={0}S \setminus B = \{0\}，推出 |S|=k+1=r|S| = k + 1 = r，即秩为 r−1r - 1 且多出的那个向量就是 0。证毕。

#2

💡 课本提示：计算两向量组之间的变换矩阵：全 1 矩阵减去单位阵 J−InJ - I_n。计算其行列式 (n−1)(−1)n−1≠0(n-1)(-1)^{n-1} \neq 0 证明变换可逆。

【解题思路分析】

【详细推理与解答】

3. 因此行列式为：detA=(n−1)(−1)n−1\det A = (n - 1)(-1)^{n-1} 当 n≥2n \ge 2 时，detA≠0\det A \neq 0，故矩阵 AA 严格可逆！

4. 因为过渡矩阵可逆，向量组 β\beta 与 α\alpha 可以互相线性表出，故两向量组等价。证毕。

第 5 题 矩阵对易子生成空间的维数定理 (习题 5.2 第 10 题) 必做题 教材习题 5.2.10
#5
设W是Fn×n中所有形如AB-BA(A,B∈Fn×n)的矩阵生成的子空间，求 证：dimW=n2-1.
💡 课本提示：所有对易子 AB−BAAB - BA 的迹均为 0，故 W⊆ker(tr)W \subseteq \ker(\text{tr})。只需显式构造出 ker(tr)\ker(\text{tr}) 的一组基均是对易子，维数即为 n2−1n^2 - 1。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾

单李代数 mathfraksln(F)=[mathfrakgln(F),mathfrakgln(F)]\mathfrak{sl}_n(F) = [\mathfrak{gl}_n(F), \mathfrak{gl}_n(F)] 的换位子代数维数定理。
【详细推理与解答】

证明：

1. 由前面的习题已知，对任意方阵 A,BA, B，恒有 tr(AB−BA)=0\text{tr}(AB - BA) = 0。因此生成子空间 W⊆ker(tr)={X∈Fn×n∣tr(X)=0}W \subseteq \ker(\text{tr}) = \{X \in F^{n \times n} \mid \text{tr}(X) = 0\}。

2. 迹映射 tr:Fn×n→F\text{tr}: F^{n \times n} \to F 是非零线性泛函，其核空间的维数为 dimker(tr)=n2−1\dim \ker(\text{tr}) = n^2 - 1。故 dimW≤n2−1\dim W \le n^2 - 1。

3. 现证 ker(tr)⊆W\ker(\text{tr}) \subseteq W：只需证明 ker(tr)\ker(\text{tr}) 的标准基元素均可写成对易子：

  • 非对角元 EijE_{ij}（i≠ji \neq j）：取 A=Eii,B=EijA = E_{ii}, B = E_{ij}，则 AB−BA=Eij−0=Eij∈WAB - BA = E_{ij} - 0 = E_{ij} \in W；
  • 对角差元 Eii−Ei+1,i+1E_{ii} - E_{i+1, i+1}：取 A=Ei,i+1,B=Ei+1,iA = E_{i, i+1}, B = E_{i+1, i}，则 AB−BA=Eii−Ei+1,i+1∈WAB - BA = E_{ii} - E_{i+1, i+1} \in W。

4. 这两类矩阵共有 (n2−n)+(n−1)=n2−1(n^2 - n) + (n - 1) = n^2 - 1 个，且显然线性无关，构成了 ker(tr)\ker(\text{tr}) 的一组基。由于它们全落在 WW 中，故 W=ker(tr)W = \ker(\text{tr})，维数严格等于 n2−1n^2 - 1。证毕。

第 6 题 有限幂集对称差空间的基与维数 (习题 5.2 第 11 题) 必做题 教材习题 5.2.11
#6
设X为n元集.求Z?上线性空间2×的一组基和维数.
💡 课本提示：单元素子集全体 {{x1},{x2},…,{xn}}\{\{x_1\}, \{x_2\}, \dots, \{x_n\}\} 构成基底，空间与 ℤ2n\mathbb{Z}_2^n 自然同构，维数为 nn。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
将集合论中的有限幂集布尔环自然同构于模 2 域上的 nn 维向量空间。
【详细推理与解答】

解与证明：

1. 设 X={x1,x2,…,xn}X = \{x_1, x_2, \dots, x_n\}。由第 1 章习题，幂集 2X2^X 在对称差加法与 ℤ2\mathbb{Z}_2 标量乘法下构成向量空间。

2. 考察单点集族 B={{x1},{x2},…,{xn}}\mathcal{B} = \{\{x_1\}, \{x_2\}, \dots, \{x_n\}\}：

  • 线性无关：设 ∑i=1nci{xi}=∅\sum_{i=1}^n c_i \{x_i\} = \emptyset（ci∈{0,1}c_i \in \{0, 1\}）。因单点集不相交，对称差即为非交并，只有当所有 ci=0c_i = 0 时并集才为空集；
  • 生成全空间：任意子集 A⊆XA \subseteq X 均可唯一写成包含在其中的单点集的无交并，即对称差：A=Δxi∈A{xi}A = \Delta_{x_i \in A} \{x_i\}。

3. 故 B\mathcal{B} 是 2X2^X 的一组基，其维数为 |B|=n|\mathcal{B}| = n。结论成立。
