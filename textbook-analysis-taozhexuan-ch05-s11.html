§5.6 实数的指数运算，I

在 4.3 节中，我们定义了指数运算 xnx^{n} ，其中 x 是有理数且 n 是自然数，或者 x 是不为零的有理数且 n 是整数。既然有了实数上的所有算术运算（而且命题 5.4.7 保证了有理数的算术性质对于实数仍然成立），那么我们就可以类似地定义实数的指数运算。

定义 5.6.1概念定义

（实数的自然数次幂）设 x 是一个实数，为了把 x 升到 0 次幂，我们定义 x0:=1x^{0} := 1 。现在递归地假设对于某个自然数 n 已经定义了 xnx^{n} ，那么我们定义 xn+1:=xn×xx^{n+1} := x^{n} \times x 。

定义 5.6.2概念定义

（实数的整数次幂）设 x 是一个非零实数，那么对任意的负整数 -n，我们定义 x−n:=1/xnx^{-n} := 1/x^{n} 。

命题 5.6.3命题

把命题4.3.10和命题4.3.12中的有理数 xx 、y替换成实数 xx 、y之后，这两个命题中的所有性质依然成立。

我们不给出这个命题的实际证明，而是给出一个元证明（这是一种追求证明自身的本质而非实数和有理数本质的论证）。

元证明：通过观察命题4.3.10和命题4.3.12的证明过程可知，它们依赖于有理数的代数法则和序的定律（命题4.2.4和命题4.2.9）。但是根据命题5.3.11、命题5.4.7以及恒等式 xx−1=x−1x=1xx^{-1} = x^{-1}x = 1 ，我们了解到所有这些代数法则和序的定律对于实数仍然成立，就如同对有理数成立一样。于是为了使 x,yx, y 为实数时结论依然成立，我们可以修改命题4.3.10和命题4.3.12的证明过程。

现在考虑非整数次幂的指数运算。我们从 n 次根的概念开始，这个概念可以利用上确界来定义。

定义 5.6.4概念定义

设 x≥0x \geqslant 0 是一个非负实数，且 n≥1n \geqslant 1 是一个正整数，我们定义 x1/nx^{1/n} （也称作 xx 的 n\pmb{n} 次根）为

x1/n:=sup{y∈R:y≥0且yn≤x}x ^ {1 / n} := \sup \{y \in \mathbf {R}: y \geqslant 0 \text {且} y ^ {n} \leqslant x \}

我们一般把 x1/2x^{1 / 2} 写作 x\sqrt{x} 。

注意深入诠释

我们不定义负数的 n 次根。实际上，本书剩余部分也不会定义负数的 n 次根（只有定义了复数，我们才可以定义负数的 n 次根，但我们不会涉及这些内容）。

引理 5.6.5命题/引理

（n 次根的存在性）设 x≥0x \geqslant 0 是一个非负实数，且 n≥1n \geqslant 1 是一个正整数，那么集合 E:={y∈R:y≥0且yn≤x}E := \{y \in R : y \geqslant 0 \text{ 且 } y^{n} \leqslant x\} 是非空的并且是有上界的。特别地， x1/nx^{1/n} 是一个实数。

证明

由于集合 E 中包含 0（为什么？），所以它确实是非空的。现在我们证明它有一个上界。分成两种情况： x≤1x \leqslant 1 和 x > 1 来考虑。首先考虑当 x≤1x \leqslant 1 时的情况，此时我们断定集合 E 是以 1 为上界的。为了证明这一点，我们利用反证法，假设存在一个元素 y∈Ey \in E 满足 y > 1，那么 yn>1y^{n} > 1 ，（为什么？）从而 yn>xy^{n} > x ，这是一个矛盾。因此 E 存在一个上界。现在考虑当 x > 1 时的情况，此时我们断定集合 E是以 xx 为上界的。为了得出该结论，我们利用反证法，假设存在一个元素 y∈Ey \in E 满足 y>xy > x 。因为 x>1x > 1 ，所以 y>1y > 1 。又由于 y>xy > x 且 y>1y > 1 ，所以 yn>xy^n > x （为什么？），这是一个矛盾。所以在上述两种情况下， EE 都是有上界的，从而 x1/nx^{1/n} 是实数。

下面我们列出 n 次根的一些基本性质。

引理 5.6.6命题/引理

设 x,y≥0x, y \geqslant 0 是非负实数，且 n,m≥1n, m \geqslant 1 是正整数。

  1. 如果 y=x1/ny = x^{1 / n} ，那么 yn=xy^n = x 。
  2. 反过来，如果 yn=xy^n = x ，那么 y=x1/ny = x^{1/n} 。
  3. x1/nx^{1 / n} 是一个非负实数。
  4. x>yx > y ，当且仅当 x1/n>y1/nx^{1 / n} > y^{1 / n}
  5. 如果 x>1x > 1 ，那么 x1/kx^{1 / k} 是关于 kk 的一个减函数。如果 x<1x < 1 ，那么 x1/kx^{1 / k} 是关于 kk 的一个增函数。如果 x=1x = 1 ，那么对所有的 kk 均有 x1/k=1x^{1 / k} = 1 。
  6. (xy)1/n=x1/ny1/n(xy)^{1/n}=x^{1/n}y^{1/n}
  7. (x1/n)1/m=x1/nm(x^{1/n})^{1/m}=x^{1/nm}
证明

参见习题5.6.1。

善于观察的读者可能会注意到，当 x=1x = 1 时，这里 x1/nx^{1 / n} 的定义与我们前面给出的 xnx^n 的概念可能不一致，但容易证明 x1/1=x=x1x^{1 / 1} = x = x^1 ，（为什么？）所以并不存在不一致的情况。

从引理 5.6.6(b) 中推出的一个结论是下面的消去律：如果 y 和 z 是正的且 yn=zny^{n}=z^{n} ，那么 y=z。（为什么这个结论是从引理 5.6.6(b) 中推导出的？）注意，这个消去律仅当 y 和 z 都为正数时才成立。例如， (−3)2=32(-3)^{2}=3^{2} ，但我们不能由此推断 -3=3。

现在我们定义如何把一个正数 x 升到 q 次幂。

定义 5.6.7概念定义

设 x>0x > 0 是一个正实数， qq 是一个有理数。为了定义 xqx^q ，我们记 q=a/bq = a / b ，其中 aa 是整数且 bb 是正整数，并定义

xq:=(x1/b)ax ^ {q} := (x ^ {1 / b}) ^ {a}
注意深入诠释

每一个有理数 qq 不管是正的、负的还是零，都可以写成一个整数 aa 和一个正整数 bb 之比的形式 a/ba / b 。（为什么？）但是形式为 a/ba / b 的有理数 qq 的表达方式不止一种，如 1/21 / 2 也可以写成 2/42 / 4 或 3/63 / 6 。为了保证这个定义是明确的，我们需要证明不同的表达式 a/ba / b 给出 xqx^q 的公式是相同的。

引理 5.6.8命题/引理

设 a、 a′a' 是整数，b、 b′b' 是正整数，并且满足 a/b=a′/b′a/b = a'/b' 。设 x 是一个正实数，那么 (x1/b′)a′=(x1/b)a(x^{1/b'})^{a'} = (x^{1/b})^a 。

证明

存在三种情况： a=0,a>0a = 0, a > 0 和 a<0a < 0 。如果 a=0a = 0 ，那么一定有 a′=0a' = 0 ，（为什么？）从而 (x1/b′)a′(x^{1 / b'})^{a'} 和 (x1/b)a(x^{1 / b})^a 都等于1，于是结论得证。

现在假设 a>0a > 0 ，那么 a′>0a' > 0 （为什么？）且 ab′=ba′ab' = ba' 。记 y:=x1/(ab′)=x1/(ba′)y := x^{1/(ab')} = x^{1/(ba')} 。根据引理5.6.6(g)， y=(x1/b′)1/ay = (x^{1/b'})^{1/a} 和 y=(x1/b)1/a′y = (x^{1/b})^{1/a'} ；由引理5.6.6(a)可得 ya=x1/b′y^a = x^{1/b'} 和 ya′=x1/by^{a'} = x^{1/b} 。于是

(x1/b′)a′=(ya)a′=yaa′=(ya′)a=(x1/b)a(x ^ {1 / b ^ {\prime}}) ^ {a ^ {\prime}} = (y ^ {a}) ^ {a ^ {\prime}} = y ^ {a a ^ {\prime}} = (y ^ {a ^ {\prime}}) ^ {a} = (x ^ {1 / b}) ^ {a}

这就是要证明的结论。

最后假设 a<0，那么 (−a)/b=(−a′)/b(-a)/b=(-a')/b 。而 -a 是正的，利用前面当 a>0 时的情况，我们有 (x1/b′)−a′=(x1/b)−a(x^{1/b'})^{-a'}=(x^{1/b})^{-a} 。对该等式两端同时取倒数就得到要证明的结论。

因此对于任意的有理数 q,xqq, x^q 是定义明确的。注意，这个新定义与我们给出的 x1/nx^{1/n} 的旧定义是一致的（为什么？），而且它与我们给出的 xnx^n 的旧定义也是一致的（为什么？）。

关于有理数次幂的一些基本事实。

引理 5.6.9命题/引理

设 x, y > 0 是正实数，且 q 和 r 是有理数。

  1. xqx^{q} 是一个正实数。
  2. xq+r=xqxrx^{q + r} = x^q x^r 且 (xq)r=xqr(x^{q})^{r} = x^{qr}
  3. x−q=1/xqx^{-q}=1/x^{q}
  4. 如果 q>0q > 0 ，那么 x>yx > y 当且仅当 xq>yqx^q > y^q 。
  5. 如果 x>1x > 1 ，那么 xq>xrx^q > x^r 当且仅当 q>rq > r 。如果 x<1x < 1 ，那么 xq>xrx^q > x^r 当且仅当 q<rq < r 。
证明

参见习题 5.6.2。

我们还必须做出实数次幂的指数运算，即我们还必须定义 xyx^{y} ，其中 x>0x > 0 且 yy 是一个实数。但我们把这部分内容推迟到6.7节，在我们正式给出极限的概念之后。
