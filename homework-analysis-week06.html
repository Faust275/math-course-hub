一、集合直径与闭集套定理
第 1 题 实数子集直径有限与有界性的等价证明 必做题 📖 教材 第4章 🎬 10-29 课
#1
设 E⊂ℝE \subset \mathbb{R}，令 diam(E)=sup{|x−y|∣x,y∈E}\mathrm{diam}(E) = \sup\{|x - y| \mid x, y \in E\} 称为 EE 的直径。
证明：EE 为有界集当且仅当 diam(E)<+∞\mathrm{diam}(E) < +\infty。
💡 课本提示：若 EE 有界，落在某个区间 [m,M][m, M] 内，直径 ≤M−m<+∞\le M - m < +\infty；若直径有限，固定一点 x0∈Ex_0 \in E，所有点都在 [x0−D,x0+D][x_0 - D, x_0 + D] 内。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
度量空间中直径与有界性概念的初等实数形式。它是将实数有界性推广到一般度量空间的唯一标准拓扑桥梁。
【详细推理与解答】

证明：

充分性（⇐\impliedby）：

设 diam(E)=D<+∞\mathrm{diam}(E) = D < +\infty。若 E=∅E = \emptyset，显然有界。若 E≠∅E \neq \emptyset，任取一点 x0∈Ex_0 \in E。

对任意 x∈Ex \in E，由直径定义：|x−x0|≤D⇒x0−D≤x≤x0+D|x - x_0| \le D \implies x_0 - D \le x \le x_0 + D。

这表明集合 EE 完全包含在有限闭区间 [x0−D,x0+D][x_0 - D, x_0 + D] 之内，故 EE 是有界集。

必要性（⇒\implies）：

设 EE 为有界集，即存在有限实数 m,Mm, M 使得对任意 x∈Ex \in E 均有 m≤x≤Mm \le x \le M。

对任意 x,y∈Ex, y \in E：|x−y|≤M−m|x - y| \le M - m。两端取上确界：

diam(E)=supx,y∈E|x−y|≤M−m<+∞\mathrm{diam}(E) = \sup_{x, y \in E} |x - y| \le M - m < +\infty

综上，等价性成立。证毕。

第 2 题 闭集套定理严格证明（修正题干结论） 必做题 📖 教材 第4章 🎬 10-27 课
#2
证明闭集套定理（Cantor 闭集套定理）：设 En⊂ℝE_n \subset \mathbb{R} 为一列非空有界闭集满足：
(a) En+1⊆EnE_{n+1} \subseteq E_n (n≥1n \ge 1)；
(b) limn→+∞diam(En)=0\lim_{n\to+\infty} \mathrm{diam}(E_n) = 0。
证明：存在唯一的点 c∈⋂n=1∞Enc \in \bigcap_{n=1}^\infty E_n（即交集非空且为单点集 ⋂n=1∞En={c}\bigcap_{n=1}^\infty E_n = \{c\}，原题干漏标无穷交，已予纠正）。
💡 课本提示：在每个 EnE_n 中任取一点 xnx_n 构成数列；利用直径趋于 0 证明 {xn}\{x_n\} 是 Cauchy 列，由实数完备性收敛到点 cc；再由闭集性质证明 c∈Enc \in E_n。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
实数完备性核心定理（Cantor Intersection Theorem）。闭集性保证了极限点不流失到集合外部，直径趋于 0 保证了交集唯一性。
【详细推理与解答】

证明：

1. 构造点序列：因为每个 EnE_n 非空，对每个正整数 nn 任选一点 xn∈Enx_n \in E_n。

2. 证明 {xn}\{x_n\} 是 Cauchy 列：任给 ε>0\varepsilon > 0。由条件 (b) limdiam(En)=0\lim \mathrm{diam}(E_n) = 0，存在正整数 NN，使得当 n≥Nn \ge N 时 diam(En)<ε\mathrm{diam}(E_n) < \varepsilon。

对任意 m>n≥Nm > n \ge N，由降链包含条件 Em⊆EnE_m \subseteq E_n，故 xm∈Em⊆Enx_m \in E_m \subseteq E_n。因此 xm,xnx_m, x_n 均属于 EnE_n：

|xn−xm|≤diam(En)<ε|x_n - x_m| \le \mathrm{diam}(E_n) < \varepsilon

这表明 {xn}\{x_n\} 是实数 Cauchy 列。由实数系完备性，极限存在，记 limn→∞xn=c\lim_{n\to\infty} x_n = c。

3. 证明 cc 属于所有 EnE_n：任取固定的正整数 kk。当 n≥kn \ge k 时，所有 xn∈En⊆Ekx_n \in E_n \subseteq E_k。子列尾部都在闭集 EkE_k 内。因为 EkE_k 是闭集，序列极限必落在 EkE_k 中，故 c∈Ekc \in E_k。对一切 kk 均成立，故 c∈⋂n=1∞Enc \in \bigcap_{n=1}^\infty E_n。

4. 唯一性：若还有一点 c′∈⋂n=1∞Enc' \in \bigcap_{n=1}^\infty E_n，则对一切 nn 有 c,c′∈En⇒|c−c′|≤diam(En)→0c, c' \in E_n \implies |c - c'| \le \mathrm{diam}(E_n) \to 0。故 |c−c′|=0⇒c=c′|c - c'| = 0 \implies c = c'。

结论：交集存在唯一公共点 ⋂n=1∞En={c}\bigcap_{n=1}^\infty E_n = \{c\}。证毕。

第 3 题 有界发散数列必含两个不同极限的子列（修正题干） 必做题 📖 教材 第4章
#3
若 {an}\{a_n\} 是有界但发散的数列，证明：它必含有收敛于不同极限的两个收敛子列（原题干语病已纠正）。
💡 课本提示：利用上下极限理论：数列发散说明上极限 LL 严格大于下极限 ll；由上极限和下极限的子列刻画，分别选出收敛于 LL 和收敛于 ll 的子列。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
题干语病修正。有界数列收敛当且仅当上极限等于下极限，发散即意味着聚点集中至少包含两个不同的点。
【详细推理与解答】

证明：

因为数列 {an}\{a_n\} 有界，其上极限 L=lim supanL = \varlimsup a_n 与下极限 l=lim infanl = \varliminf a_n 均为有限实数，且恒有 l≤Ll \le L。

若假设 l=Ll = L，根据实数完备性定理，有界数列的上极限等于下极限是数列收敛的充要条件，则必有 liman=L\lim a_n = L，这与已知条件“数列 {an}\{a_n\} 发散”直接矛盾！

因此，必有 l<Ll < L（上极限严格大于下极限）。

由上下极限的子列极限性质：

  • 存在子列 {ank}\{a_{n_k}\} 满足 limk→∞ank=L\lim_{k\to\infty} a_{n_k} = L；
  • 存在子列 {amk}\{a_{m_k}\} 满足 limk→∞amk=l\lim_{k\to\infty} a_{m_k} = l。

因为 l≠Ll \neq L，这两个子列收敛于不同的实数值。证毕。

二、实数完备性与不动点理论
第 4 题 闭区间自映射不动点定理证明 必做题 📖 教材 第4章
#4
设 [a,b][a, b] 是 ℝ\mathbb{R} 上的有限闭区间，f:[a,b]→[a,b]f: [a, b] \to [a, b] 连续。证明：ff 在 [a,b][a, b] 上必有不动点，即存在 ξ∈[a,b]\xi \in [a, b] 使得 f(ξ)=ξf(\xi) = \xi。
💡 课本提示：构造辅助函数 g(x)=f(x)−xg(x) = f(x) - x；验证端点处 g(a)≥0g(a) \ge 0 且 g(b)≤0g(b) \le 0，直接应用零点存在定理。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
一维 Brouwer 不动点定理。拓扑学与非线性分析的入门奠基定理，连续自映射不能把闭区间撕裂，必有固定点。
【详细推理与解答】

证明：

构造连续辅助函数：g(x)=f(x)−xg(x) = f(x) - x（x∈[a,b]x \in [a, b]）。

考察区间端点处的取值：

  • 在左端点 x=ax = a 处：因为 f([a,b])⊆[a,b]f([a, b]) \subseteq [a, b]，所以 f(a)≥af(a) \ge a，故 g(a)=f(a)−a≥0g(a) = f(a) - a \ge 0；
  • 在右端点 x=bx = b 处：同理 f(b)≤bf(b) \le b，故 g(b)=f(b)−b≤0g(b) = f(b) - b \le 0。

分类讨论：

  • 若 g(a)=0g(a) = 0，则取 ξ=a\xi = a 即满足 f(a)=af(a) = a；
  • 若 g(b)=0g(b) = 0，则取 ξ=b\xi = b 即满足 f(b)=bf(b) = b；
  • 若 g(a)>0g(a) > 0 且 g(b)<0g(b) < 0：因为 g(x)g(x) 是闭区间 [a,b][a, b] 上的连续函数且在两端点严格异号，由连续函数的介值定理（零点存在定理），必存在内点 ξ∈(a,b)\xi \in (a, b) 使得 g(ξ)=0g(\xi) = 0。

即 f(ξ)−ξ=0⇒f(ξ)=ξf(\xi) - \xi = 0 \implies f(\xi) = \xi。结论得证。证毕。

第 5 题 Banach 压缩映像原理严格证明 必做题 📖 教材 第4章
#5
（压缩映像原理）设 f:ℝ→ℝf: \mathbb{R} \to \mathbb{R}，且存在常数 λ∈(0,1)\lambda \in (0, 1) 使得对任意 x,y∈ℝx, y \in \mathbb{R}，恒有：
|f(x)−f(y)|≤λ|x−y||f(x) - f(y)| \le \lambda |x - y|
称 ff 为严格压缩映射。证明：ff 在 ℝ\mathbb{R} 上有且仅有唯一的不动点。
💡 课本提示：任取初值 x0x_0，迭代生成序列 xn=f(xn−1)x_n = f(x_{n-1})；利用公比 λ<1\lambda < 1 的等比数列证明 {xn}\{x_n\} 是 Cauchy 列，由实数完备性收敛；由绝对值距离反向不等式证明唯一性。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
度量空间分析的核心大定理（Banach Fixed Point Theorem）。其构造性证明不仅给出了存在性与唯一性，更提供了几何级数快速收敛的数值计算算法。
【详细推理与解答】

证明：

1. 存在性：

任取初值 x0∈ℝx_0 \in \mathbb{R}，迭代定义数列 xn=f(xn−1)x_n = f(x_{n-1}) (n≥1n \ge 1)。

由压缩条件：|xn+1−xn|=|f(xn)−f(xn−1)|≤λ|xn−xn−1|≤…≤λn|x1−x0||x_{n+1} - x_n| = |f(x_n) - f(x_{n-1})| \le \lambda |x_n - x_{n-1}| \le \dots \le \lambda^n |x_1 - x_0|。

对任意正整数 pp：|xn+p−xn|≤∑k=nn+p−1|xk+1−xk|≤|x1−x0|∑k=nn+p−1λk<|x1−x0|λn1−λ|x_{n+p} - x_n| \le \sum_{k=n}^{n+p-1} |x_{k+1} - x_k| \le |x_1 - x_0| \sum_{k=n}^{n+p-1} \lambda^k < |x_1 - x_0| \frac{\lambda^n}{1 - \lambda}

因为 0<λ<10 < \lambda < 1，当 n→∞n \to \infty 时 λn→0\lambda^n \to 0。因此 {xn}\{x_n\} 是 Cauchy 列。由实数完备性，极限存在，记 limn→∞xn=ξ\lim_{n\to\infty} x_n = \xi。

在递推式 xn+1=f(xn)x_{n+1} = f(x_n) 两边取极限。因为压缩映射必然是一致连续函数，极限与函数符号可交换：ξ=limn→∞xn+1=limn→∞f(xn)=f(limn→∞xn)=f(ξ)\xi = \lim_{n\to\infty} x_{n+1} = \lim_{n\to\infty} f(x_n) = f\left(\lim_{n\to\infty} x_n\right) = f(\xi)

故 ξ\xi 是 ff 的一个不动点。

2. 唯一性：

设还有不动点 η\eta 满足 f(η)=ηf(\eta) = \eta。由压缩条件：|ξ−η|=|f(ξ)−f(η)|≤λ|ξ−η|⇒(1−λ)|ξ−η|≤0|\xi - \eta| = |f(\xi) - f(\eta)| \le \lambda |\xi - \eta| \implies (1 - \lambda)|\xi - \eta| \le 0

因为 1−λ>01 - \lambda > 0 且距离非负，必有 |ξ−η|=0⇒ξ=η|\xi - \eta| = 0 \implies \xi = \eta。唯一性得证。证毕。

第 6 题 连续函数不存在恰好二对一映射定理证明 必做题 📖 教材 第4章
#6
证明：对任意区间 I⊂ℝI \subset \mathbb{R}，不存在 II 上的连续函数使得任意函数值恰好被取到两次。
💡 课本提示：用反证法：若每个值恰好取两次，设局域极大值点 x1,x2x_1, x_2，极大值必相等；分析两极大值之间的极小值，导出存在某个函数值被取到 3 次或无法取到的拓扑矛盾。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
拓扑动力学中的惊艳定理。连续函数的折返结构必然导致局部极值与介值定理之间产生奇偶重数的拓扑锁定，无法实现处处偶数重覆盖。
【详细推理与解答】

证明：

用反证法。假设存在区间 II 上的连续函数 ff，使得对值域中每一个值 y∈f(I)y \in f(I)，原像集合 f−1(y)f^{-1}(y) 恰好含有 2 个不同的点。

1. 设 y0∈f(I)y_0 \in f(I)，其原像点为 a<ba < b（f(a)=f(b)=y0f(a) = f(b) = y_0）。

在闭区间 [a,b][a, b] 上，ff 是连续函数，必能取到最大值 MM 和最小值 mm。因为每个值只能被取到两次，m<y0<Mm < y_0 < M（若 M=y0M=y_0，则在 [a,b][a,b] 内只能恒等于 y0y_0 产生无穷多原像，矛盾）。

2. 设最大值在 x1∈(a,b)x_1 \in (a, b) 处取得，即 f(x1)=Mf(x_1) = M。由二对一假设，必定存在另一个不同的点 x2∉[a,b]x_2 \notin [a, b] 满足 f(x2)=Mf(x_2) = M。不妨设 x2>bx_2 > b。

3. 考察从 x1x_1 到 x2x_2 的函数变化：在区间 [x1,b][x_1, b] 上，函数值从 MM 下降到 y0y_0；在区间 [b,x2][b, x_2] 上，函数值从 y0y_0 上升到 MM。

由介值定理，对于介于 y0y_0 和 MM 之间的任意数值 c∈(y0,M)c \in (y_0, M)：

  • 在区间 (x1,b)(x_1, b) 内存在一点 c1c_1 使得 f(c1)=cf(c_1) = c；
  • 在区间 (b,x2)(b, x_2) 内存在一点 c2c_2 使得 f(c2)=cf(c_2) = c。

又因为在区间 (a,x1)(a, x_1) 内函数从 y0y_0 上升到 MM，由介值定理，必还存在第三个点 c3∈(a,x1)c_3 \in (a, x_1) 使得 f(c3)=cf(c_3) = c！

这三个点互不相同：a<c3<x1<c1<b<c2<x2a < c_3 < x_1 < c_1 < b < c_2 < x_2。这表明数值 cc 至少被取到了 3 次！这与“每个值恰好被取到 2 次”的假设严重矛盾！

因此，不存在这样的连续函数。证毕。
