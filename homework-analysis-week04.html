第 1 题 三次递推方程数列的收敛性与极限求解 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#1
设实数列 {xn}\{x_n\} 满足方程：
xn3+(n1/n+2+3n)xn2+(1n+2n1/n+n1−nn+1)xn+n1/n+n1−nn+1n2=0x_n^3 + \left(n^{1/n} + 2 + \frac{3}{n}\right)x_n^2 + \left(\frac{1}{n} + 2n^{1/n} + n^{\frac{1-n}{n}} + 1\right)x_n + n^{1/n} + n^{\frac{1-n}{n}} + \frac{1}{n^2} = 0
证明：数列 {xn}\{x_n\} 收敛，并求其极限。
💡 课本提示：利用重要极限 limn→∞n1/n=1\lim_{n\to\infty} n^{1/n} = 1 与 limn→∞n1−nn=limn1/nn=0\lim_{n\to\infty} n^{\frac{1-n}{n}} = \lim \frac{n^{1/n}}{n} = 0，将三次多项式因式分解或取极限方程 (x+1)2(x+1)=0(x+1)^2(x+1) = 0。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
系数依赖于 nn 的代数方程求根极限。通过对参数取极限，利用代数方程根关于系数的连续依赖性（隐函数定理或连续性定理）判定根的渐近行为。
【详细推理与解答】

解与证明：

1. 考察方程中各项系数当 n→∞n \to \infty 时的极限：

limn→∞n1/n=1, limn→∞3n=0, limn→∞n1−nn=limn→∞n1/nn=1∞=0\lim_{n\to\infty} n^{1/n} = 1,\quad \lim_{n\to\infty} \frac{3}{n} = 0,\quad \lim_{n\to\infty} n^{\frac{1-n}{n}} = \lim_{n\to\infty} \frac{n^{1/n}}{n} = \frac{1}{\infty} = 0

因此当 n→∞n \to \infty 时，多项式的系数分别趋于：

  • xn2x_n^2 的系数：lim(n1/n+2+3/n)=1+2+0=3\lim (n^{1/n} + 2 + 3/n) = 1 + 2 + 0 = 3；
  • xnx_n 的系数：lim(1/n+2n1/n+n1−nn+1)=0+2(1)+0+1=3\lim (1/n + 2n^{1/n} + n^{\frac{1-n}{n}} + 1) = 0 + 2(1) + 0 + 1 = 3；
  • 常数项：lim(n1/n+n1−nn+1/n2)=1+0+0=1\lim (n^{1/n} + n^{\frac{1-n}{n}} + 1/n^2) = 1 + 0 + 0 = 1。

2. 极限多项式方程为：

x3+3x2+3x+1=0⇔(x+1)3=0x^3 + 3x^2 + 3x + 1 = 0 \iff (x + 1)^3 = 0

该三次方程具有三重实根 x=−1x = -1

。由代数方程根关于连续系数的连续依赖性定理，原方程的实根必收敛于极限方程的实根。

结论：数列 {xn}\{x_n\} 收敛，且 limn→∞xn=−1\lim_{n\to\infty} x_n = -1。

第 2 题 利用 Bernoulli 不等式证明数 e 的单调收敛性 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#2
(1) 求证伯努利不等式：对一切 λ>−1\lambda > -1 且正整数 nn 恒有 (1+λ)n≥1+nλ(1 + \lambda)^n \ge 1 + n\lambda；
(2) 利用伯努利不等式严格证明数列 an=(1+1n)na_n = \left(1 + \frac{1}{n}\right)^n 严格单调递增，而 bn=(1+1n)n+1b_n = \left(1 + \frac{1}{n}\right)^{n+1} 严格单调递减，进而证明两个数列均收敛且极限相等（该公共极限即为欧拉自然常数 ee）。
💡 课本提示：考虑比值 anan−1=(1+1/n)n(1+1/(n−1))n−1=(1−1n2)nnn−1\frac{a_n}{a_{n-1}} = \frac{(1+1/n)^n}{(1+1/(n-1))^{n-1}} = \left(1 - \frac{1}{n^2}\right)^n \frac{n}{n-1}，将 (1−1n2)n\left(1 - \frac{1}{n^2}\right)^n 用伯努利不等式放缩。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
微积分学最经典的构造证明之一。无需依赖二项式定理的繁琐阶乘放缩，仅凭一次伯努利不等式便同时锁死 ana_n 与 bnb_n 的单调性与有界性。
【详细推理与解答】

证明：

(1) 伯努利不等式已在第一周作业中通过数学归纳法完成严格证明，在此直接引用：当 λ>−1\lambda > -1 时，(1+λ)n≥1+nλ(1+\lambda)^n \ge 1 + n\lambda。

(2) 证明 {an}\{a_n\} 单调递增：

计算相邻两项的比值（取 n≥2n \ge 2）：

anan−1=(n+1n)n(nn−1)n−1=(n+1n·n−1n)nnn−1=(1−1n2)nnn−1\frac{a_n}{a_{n-1}} = \frac{\left(\frac{n+1}{n}\right)^n}{\left(\frac{n}{n-1}\right)^{n-1}} = \left(\frac{n+1}{n} \cdot \frac{n-1}{n}\right)^n \frac{n}{n-1} = \left(1 - \frac{1}{n^2}\right)^n \frac{n}{n-1}

因为 −1n2>−1-\frac{1}{n^2} > -1，由伯努利不等式（严格不等号，因 n≥2n \ge 2）：

(1−1n2)n>1−n·1n2=1−1n=n−1n\left(1 - \frac{1}{n^2}\right)^n > 1 - n \cdot \frac{1}{n^2} = 1 - \frac{1}{n} = \frac{n-1}{n}

代入比值式中：

anan−1>n−1n·nn−1=1⇒an>an−1\frac{a_n}{a_{n-1}} > \frac{n-1}{n} \cdot \frac{n}{n-1} = 1 \implies a_n > a_{n-1}

故 {an}\{a_n\}

严格单调递增。

证明 {bn}\{b_n\}

单调递减：

同理考察比值倒数 bn−1bn\frac{b_{n-1}}{b_n}

：

bn−1bn=(nn−1)n(n+1n)n+1=(n2n2−1)n+1n−1n=(1+1n2−1)n+1n−1n\frac{b_{n-1}}{b_n} = \frac{\left(\frac{n}{n-1}\right)^n}{\left(\frac{n+1}{n}\right)^{n+1}} = \left(\frac{n^2}{n^2-1}\right)^{n+1} \frac{n-1}{n} = \left(1 + \frac{1}{n^2-1}\right)^{n+1} \frac{n-1}{n}

由伯努利不等式：(1+1n2−1)n+1>1+n+1n2−1=1+1n−1=nn−1\left(1 + \frac{1}{n^2-1}\right)^{n+1} > 1 + \frac{n+1}{n^2-1} = 1 + \frac{1}{n-1} = \frac{n}{n-1}

。

bn−1bn>nn−1·n−1n=1⇒bn<bn−1\frac{b_{n-1}}{b_n} > \frac{n}{n-1} \cdot \frac{n-1}{n} = 1 \implies b_n < b_{n-1}

故 {bn}\{b_n\} 严格单调递减。

收敛且极限相等：因为对一切 nn，显然 a1≤an<bn≤b1=4a_1 \le a_n < b_n \le b_1 = 4，两数列均单调有界，极限存在。又因为 bn=an(1+1n)b_n = a_n\left(1 + \frac{1}{n}\right)，两端取极限：limn→∞bn=limn→∞an·(1+0)=limn→∞an=e\lim_{n\to\infty} b_n = \lim_{n\to\infty} a_n \cdot (1 + 0) = \lim_{n\to\infty} a_n = e

证毕。

第 3 题 Cauchy 收敛原理判定级数与振荡数列 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#3
用 Cauchy 收敛原理判定下列数列的敛散性：
(1) xn=1+12+…+1n−2nx_n = 1 + \dfrac{1}{\sqrt{2}} + \dots + \dfrac{1}{\sqrt{n}} - 2\sqrt{n}；
(2) xn={1+1n,n为偶数1n2,n为奇数x_n = \begin{cases} 1 + \dfrac{1}{n}, & n \text{ 为偶数} \\ \dfrac{1}{n^2}, & n \text{ 为奇数} \end{cases}。
💡 课本提示：(1) 计算增量 xn+p−xnx_{n+p} - x_n 并利用微分中值定理有理化控制在 1n3/2\frac{1}{n^{3/2}} 阶；(2) 取相差 1 的奇偶项，其差值趋于 1，说明存在固定下界 ε0=12\varepsilon_0 = \frac{1}{2} 破坏 Cauchy 准则。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
Cauchy 准则的实战应用：证明数列收敛需要给出一致的绝对控制，证明发散只需抓取两组无穷序列构造违背 Cauchy 准则的非零间距反例。
【详细推理与解答】

(1) 解（证明收敛）：

计算相邻项的单步差分：

xn+1−xn=1n+1−2(n+1−n)=1n+1−2n+1+nx_{n+1} - x_n = \frac{1}{\sqrt{n+1}} - 2(\sqrt{n+1} - \sqrt{n}) = \frac{1}{\sqrt{n+1}} - \frac{2}{\sqrt{n+1} + \sqrt{n}}=n+1+n−2n+1n+1(n+1+n)=n−n+1n+1(n+1+n)=−1n+1(n+1+n)2= \frac{\sqrt{n+1} + \sqrt{n} - 2\sqrt{n+1}}{\sqrt{n+1}(\sqrt{n+1} + \sqrt{n})} = \frac{\sqrt{n} - \sqrt{n+1}}{\sqrt{n+1}(\sqrt{n+1} + \sqrt{n})} = -\frac{1}{\sqrt{n+1}(\sqrt{n+1} + \sqrt{n})^2}

因此 |xn+1−xn|<14n3/2|x_{n+1} - x_n| < \frac{1}{4n^{3/2}}。对任意正整数 pp：

|xn+p−xn|≤∑k=nn+p−1|xk+1−xk|<14∑k=n∞1k3/2|x_{n+p} - x_n| \le \sum_{k=n}^{n+p-1} |x_{k+1} - x_k| < \frac{1}{4}\sum_{k=n}^\infty \frac{1}{k^{3/2}}

因为 pp

-级数 ∑k−3/2\sum k^{-3/2}

收敛，余项对足够大的 nn 可小于任意给定的 ε>0\varepsilon > 0。由 Cauchy 收敛准则，数列 {xn}\{x_n\} 必然收敛。

(2) 解（证明发散）：

取 ε0=12\varepsilon_0 = \frac{1}{2}。对任意给定的正整数 NN，取偶数 n>Nn > N，取 m=n+1m = n+1（奇数）。此时：

|xn−xn+1|=|(1+1n)−1(n+1)2||x_n - x_{n+1}| = \left| \left(1 + \frac{1}{n}\right) - \frac{1}{(n+1)^2} \right|

当 n≥2n \ge 2

时，1+1n−1(n+1)2>1−19=89>12=ε01 + \frac{1}{n} - \frac{1}{(n+1)^2} > 1 - \frac{1}{9} = \frac{8}{9} > \frac{1}{2} = \varepsilon_0。

这表明无论 NN 多大，总能找到距离大于 12\frac{1}{2} 的项，违反了 Cauchy 收敛准则。因此数列 {xn}\{x_n\} 发散。

第 4 题 次可加数列极限存在性（Fekete 引理）证明 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#4
设非负数列 {xn}\{x_n\} 满足次可加条件：对任何正整数 m,n∈Nm, n \in \mathbb{N}，都有：0≤xm+n≤xm+xn0 \le x_{m+n} \le x_m + x_n求证：极限 limn→+∞xnn\lim_{n\to+\infty} \dfrac{x_n}{n} 必然存在，且等于下确界 infn≥1xnn\inf_{n \ge 1} \dfrac{x_n}{n}。
💡 课本提示：著名的 Fekete 次可加引理。固定正整数 mm，将任意 nn 写为带余除法 n=qm+rn = qm + r (0≤r<m0 \le r < m)；由次可加性 xn≤qxm+xrx_n \le q x_m + x_r，两端除以 nn 后令 n→∞n\to\infty 取上极限。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
动力系统、遍历理论与组合极值论中的至尊引理（Fekete's Subadditive Lemma）。广泛应用于拓扑熵、Lyapunov 指数与连通分形维数的严格定义。
【详细推理与解答】

证明：

因为对一切 nn 有 xn≥0x_n \ge 0，数列 {xnn}\left\{\frac{x_n}{n}\right\} 有下界 0。由实数确界原理，下确界必存在，记：

L=infn≥1xnn≥0L = \inf_{n \ge 1} \frac{x_n}{n} \ge 0

1. 任给 ε>0\varepsilon > 0。由下确界定义，存在某个固定的正整数 mm，使得：

xmm<L+ε\frac{x_m}{m} < L + \varepsilon

2. 对任意充分大的正整数 nn

，利用带余除法将 nn

用 mm 表示：n=qm+rn = qm + r（其中商 q=⌊n/m⌋q = \lfloor n/m \rfloor，余数 0≤r<m0 \le r < m）。

由次可加性条件 xm+n≤xm+xnx_{m+n} \le x_m + x_n，对 qq 次累加：

xn=xqm+r≤xqm+xr≤qxm+xrx_n = x_{qm + r} \le x_{qm} + x_r \le q x_m + x_r

两端除以 n=qm+rn = qm + r：

xnn≤qxm+xrn=qmn·xmm+xrn\frac{x_n}{n} \le \frac{q x_m + x_r}{n} = \frac{qm}{n} \cdot \frac{x_m}{m} + \frac{x_r}{n}

记 M=max0≤r<mxrM = \max_{0 \le r < m} x_r

（因 mm

是固定的，这只是有限个常数的最大值）。因为 limn→∞qmn=1\lim_{n\to\infty} \frac{qm}{n} = 1 且 limn→∞xrn≤limn→∞Mn=0\lim_{n\to\infty} \frac{x_r}{n} \le \lim_{n\to\infty} \frac{M}{n} = 0。

对不等式两端令 n→∞n \to \infty 取上极限：

lim supn→∞xnn≤1·xmm+0=xmm<L+ε\varlimsup_{n\to\infty} \frac{x_n}{n} \le 1 \cdot \frac{x_m}{m} + 0 = \frac{x_m}{m} < L + \varepsilon

3. 由 ε>0\varepsilon > 0

的任意性，令 ε→0\varepsilon \to 0 得：lim supn→∞xnn≤L\varlimsup_{n\to\infty} \frac{x_n}{n} \le L。

另一方面，由下确界的定义，对一切 nn 恒有 xnn≥L\frac{x_n}{n} \ge L，故下极限 lim infn→∞xnn≥L\varliminf_{n\to\infty} \frac{x_n}{n} \ge L。

因此：L≤lim infn→∞xnn≤lim supn→∞xnn≤LL \le \varliminf_{n\to\infty} \frac{x_n}{n} \le \varlimsup_{n\to\infty} \frac{x_n}{n} \le L。

上极限等于下极限，极限严格存在且等于下确界：limn→∞xnn=infn≥1xnn\lim_{n\to\infty} \frac{x_n}{n} = \inf_{n\ge 1} \frac{x_n}{n}。证毕。

第 5 题 用分析定义证明函数极限 必做题 📖 教材 第3章 🎬 10-22 课 🎬 10-27 课
#5
按 ε−δ\varepsilon-\delta 定义证明下列极限：
(1) limx→3x2−9x2+x−12=67\lim_{x\to 3} \dfrac{x^2 - 9}{x^2 + x - 12} = \dfrac{6}{7}；
(2) limx→0x[1x]=1\lim_{x\to 0} x \left[\dfrac{1}{x}\right] = 1。
💡 课本提示：(1) 因式分解消去零因子 (x−3)(x-3)，限制 |x−3|<1|x-3|<1 控制分母远离 0；(2) 利用取整函数夹逼不等式 1x−1<[1x]≤1x\frac{1}{x} - 1 < [\frac{1}{x}] \le \frac{1}{x}。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
严谨分析学的基本功。处理有理分式时，先取初步半径 δ0\delta_0 控制分母界，再选取主导偏差因子完成放缩。
【详细推理与解答】

(1) 证明：

因式分解分子与分母：

x2−9x2+x−12=(x−3)(x+3)(x−3)(x+4)=x+3x+4 (x≠3)\frac{x^2 - 9}{x^2 + x - 12} = \frac{(x - 3)(x + 3)}{(x - 3)(x + 4)} = \frac{x + 3}{x + 4}\quad (x \neq 3)

计算与目标极限 67\frac{6}{7} 的差值：

|x+3x+4−67|=|7(x+3)−6(x+4)7(x+4)|=|x−3|7|x+4|\left| \frac{x + 3}{x + 4} - \frac{6}{7} \right| = \left| \frac{7(x + 3) - 6(x + 4)}{7(x + 4)} \right| = \frac{|x - 3|}{7|x + 4|}

先取初步限制 δ1=1\delta_1 = 1。当 0<|x−3|<10 < |x - 3| < 1 时，2<x<4⇒6<x+4<82 < x < 4 \implies 6 < x + 4 < 8，故分母 7|x+4|>427|x + 4| > 42：

|x−3|7|x+4|<|x−3|42\frac{|x - 3|}{7|x + 4|} < \frac{|x - 3|}{42}

任给 ε>0\varepsilon > 0，取 δ=min{1,42ε}\delta = \min\{1, 42\varepsilon\}。当 0<|x−3|<δ0 < |x - 3| < \delta 时，恒有：

|x2−9x2+x−12−67|<42ε42=ε\left| \frac{x^2 - 9}{x^2 + x - 12} - \frac{6}{7} \right| < \frac{42\varepsilon}{42} = \varepsilon

由极限定义，原式得证。

(2) 证明：

由取整函数性质，对一切 t=1xt = \frac{1}{x}，有 t−1<[t]≤tt - 1 < [t] \le t，即：

1x−1<[1x]≤1x\frac{1}{x} - 1 < \left[\frac{1}{x}\right] \le \frac{1}{x}

当 x>0x > 0

时，同乘 xx

得 1−x<x[1/x]≤1⇒−x<x[1/x]−1≤01 - x < x[1/x] \le 1 \implies -x < x[1/x] - 1 \le 0

；

当 x<0x < 0

时，同乘 xx

变号得 1≤x[1/x]<1−x⇒0≤x[1/x]−1<−x=|x|1 \le x[1/x] < 1 - x \implies 0 \le x[1/x] - 1 < -x = |x|。

综合可知对一切 x≠0x \neq 0，恒有 |x[1/x]−1|≤|x||x[1/x] - 1| \le |x|。任给 ε>0\varepsilon > 0，取 δ=ε\delta = \varepsilon。当 0<|x|<δ0 < |x| < \delta 时，必有 |x[1/x]−1|<ε|x[1/x] - 1| < \varepsilon。证毕。

#6
求下列各函数的极限与左右极限：
(1) limx→+∞xαax\lim_{x\to+\infty} \dfrac{x^\alpha}{a^x}（α>0,a>1\alpha > 0, a > 1）；

(1) 解：

记 a=1+ha = 1 + h（h>0h > 0）。取正整数 k>αk > \alpha，当 x>kx > k 时由二项式展开：ax>(⌊x⌋k+1)hk+1∼Cxk+1a^x > \binom{\lfloor x \rfloor}{k+1} h^{k+1} \sim C x^{k+1}。

0<xαax<xαCxk+1=1Cxk+1−α→0 (x→+∞)0 < \frac{x^\alpha}{a^x} < \frac{x^\alpha}{C x^{k+1}} = \frac{1}{C x^{k+1-\alpha}} \to 0\quad (x \to +\infty)

因此 limx→+∞xαax=0\lim_{x\to+\infty} \frac{x^\alpha}{a^x} = 0。

(2) 解：

令 t=lnxt = \ln x。当 x→+∞x \to +\infty 时 t→+∞t \to +\infty，且 x=etx = e^t：

(lnx)αxβ=tα(et)β=tα(eβ)t\frac{(\ln x)^\alpha}{x^\beta} = \frac{t^\alpha}{(e^t)^\beta} = \frac{t^\alpha}{(e^\beta)^t}

因为 β>0\beta > 0

，底数 eβ>1e^\beta > 1。由第 (1) 问的结论，多项式除以指数函数趋于 0，故该极限为 00。

(3) 解：

  • 右极限：x→0+x \to 0^+ 时，f(x)=xsin1xf(x) = x\sin\frac{1}{x}。因为 |sin1x|≤1|\sin\frac{1}{x}| \le 1 为有界量，xx 为无穷小量，无穷小与有界量之积仍为无穷小，故 f(0+)=limx→0+xsin1x=0f(0^+) = \lim_{x\to 0^+} x\sin\frac{1}{x} = 0。
