一、介值定理与紧集连续映射性质
第 1 题 奇数次实多项式满射性质证明 必做题 作业第一题
#1
设 f(x)=P(x)f(x) = P(x) 是奇数次实系数多项式。证明：f:ℝ→ℝf: \mathbb{R} \to \mathbb{R} 是满射。
💡 课本提示：最高次幂为奇数，当 x→+∞x\to +\infty 和 x→−∞x\to -\infty 时极限分别为 +∞+\infty 和 −∞-\infty（或反向）；应用连续函数的介值定理，值域覆盖整个实数轴 ℝ\mathbb{R}。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
代数基本定理实数部分的基础推论。奇数次多项式必须穿过整个实数轴，因此每个实数 y0y_0 都有实原像。
【详细推理与解答】

证明：

设奇数次实系数多项式为：P(x)=anxn+an−1xn−1+…+a1x+a0P(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0（其中 nn 为奇数，an≠0a_n \neq 0）。

不妨设首项系数 an>0a_n > 0（若 an<0a_n < 0 可考察 −P(x)-P(x)）。将最高次项提出：P(x)=anxn(1+an−1anx+…+a0anxn)P(x) = a_n x^n \left( 1 + \frac{a_{n-1}}{a_n x} + \dots + \frac{a_0}{a_n x^n} \right)

因为 nn 是奇数：

  • 当 x→+∞x \to +\infty 时，xn→+∞x^n \to +\infty，括号内趋于 1，故 limx→+∞P(x)=+∞\lim_{x\to+\infty} P(x) = +\infty；
  • 当 x→−∞x \to -\infty 时，xn→−∞x^n \to -\infty，括号内趋于 1，故 limx→−∞P(x)=−∞\lim_{x\to-\infty} P(x) = -\infty。

任取一个实数 y0∈ℝy_0 \in \mathbb{R}。根据无穷大极限的定义：

  • 存在足够大的正数 M1>0M_1 > 0，使得 P(M1)>y0P(M_1) > y_0；
  • 存在足够负的负数 M2<0M_2 < 0，使得 P(M2)<y0P(M_2) < y_0。

因为多项式函数 P(x)P(x) 在闭区间 [M2,M1][M_2, M_1] 上严格连续，且 P(M2)<y0<P(M1)P(M_2) < y_0 < P(M_1)，由连续函数的介值定理（Darboux 定理），必存在某个实数 c∈(M2,M1)c \in (M_2, M_1) 使得：P(c)=y0P(c) = y_0

这表明 ℝ\mathbb{R} 中的任意实数 y0y_0 都至少存在一个实数原像 cc。因此映射 f:ℝ→ℝf: \mathbb{R} \to \mathbb{R} 必然是满射。证毕。

第 2 题 紧集上连续双射的逆映射连续性证明 必做题 作业第二题
#2
设 E⊂ℝE \subset \mathbb{R} 为紧集（有界闭集），若 f∈C(E;ℝ)f \in C(E; \mathbb{R}) 存在逆映射 f−1:f(E)→Ef^{-1}: f(E) \to E。
证明：逆映射 f−1f^{-1} 也是连续映射。
💡 课本提示：利用序列刻画连续性：设 yn→y0y_n \to y_0（yn,y0∈f(E)y_n, y_0 \in f(E)），记 xn=f−1(yn),x0=f−1(y0)x_n = f^{-1}(y_n), x_0 = f^{-1}(y_0)。利用 EE 的紧致性（Bolzano-Weierstrass 定理）证明任意子列都必收敛于 x0x_0。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
拓扑学中“紧空间到 Hausdorff 空间的连续双射必为同胚”的经典实数版本。紧致性锁死了原像序列不会跑向无穷或产生多重聚点。
【详细推理与解答】

证明：

设数列 {yn}⊂f(E)\{y_n\} \subset f(E) 且 yn→y0∈f(E)y_n \to y_0 \in f(E)。记 xn=f−1(yn)∈Ex_n = f^{-1}(y_n) \in E，x0=f−1(y0)∈Ex_0 = f^{-1}(y_0) \in E。要证 f−1f^{-1} 在 y0y_0 处连续，只需证明 xn→x0x_n \to x_0。

用反证法。假设 xnnot→x0x_n \not\to x_0，则存在某个 ε0>0\varepsilon_0 > 0 以及子列 {xnk}\{x_{n_k}\}，使得对一切 kk 恒有：

|xnk−x0|≥ε0 (1)|x_{n_k} - x_0| \ge \varepsilon_0\quad (1)

因为集合 EE 是紧集（有界闭集），子列 {xnk}⊂E\{x_{n_k}\} \subset E 是有界数列。由 Bolzano-Weierstrass 定理，必定存在收敛子列 {xnkj}\{x_{n_{k_j}}\} 收敛于某个极限点 x∗∈ℝx^* \in \mathbb{R}。

又因 EE 是闭集，极限点必属于原集：x∗∈Ex^* \in E。

因为原映射 ff 在 EE 上连续，由 Heine 归结原则：limj→∞f(xnkj)=f(x∗)\lim_{j\to\infty} f(x_{n_{k_j}}) = f(x^*)

另一方面，该子列函数值是原序列 {yn}\{y_n\} 的子列，必须收敛于原来的极限 y0y_0：limj→∞f(xnkj)=limj→∞ynkj=y0=f(x0)\lim_{j\to\infty} f(x_{n_{k_j}}) = \lim_{j\to\infty} y_{n_{k_j}} = y_0 = f(x_0)

因此 f(x∗)=f(x0)f(x^*) = f(x_0)。因为已知 ff 存在逆映射，ff 必须是严格单射，由此推出 x∗=x0x^* = x_0！

但这与式 (1) 中子列始终保持在 ε0\varepsilon_0 之外（|x∗−x0|≥ε0>0|x^* - x_0| \ge \varepsilon_0 > 0）产生致命矛盾！

因此假设不成立，必有 xn→x0x_n \to x_0。逆映射 f−1f^{-1} 严格连续。证毕。

二、一致连续性综合判定
第 3 题 典型函数的一致连续性判定与反例构造 必做题 作业第三题
#3
研究下列函数的一致连续性：
(1) f(x)=xcosxf(x) = x\cos x (x>0x > 0)；
(2) f(x)=sin(x3)xf(x) = \dfrac{\sin(x^3)}{x} (x∈[1,+∞)x \in [1, +\infty))；
(3) f(x)=cos(x2)f(x) = \cos(x^2) (x∈ℝx \in \mathbb{R})。
💡 课本提示：(1) 取测试点对 xn=2nπ,x'n=2nπ+1nx_n = 2n\pi, x'_n = 2n\pi + \frac{1}{n}，差值发散；(2) 导数 f'(x)f'(x) 有界证明 Lipschitz 一致连续；(3) 取 xn=2nπ,x'n=2nπ+πx_n = \sqrt{2n\pi}, x'_n = \sqrt{2n\pi + \pi}，间距趋于 0 但函数值差为 2。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
一致连续性的经典试金石：导数有界判定法（Lipschitz 一致连续）与 Cantor-Heine 测试点对（间距趋于 0 而函数差有正下界）否定法。
【详细推理与解答】

(1) f(x)=xcosxf(x) = x\cos x 在 (0,+∞)(0, +\infty) 上非一致连续：

取测试序列：xn=2nπx_n = 2n\pi，x'n=2nπ+1nx'_n = 2n\pi + \frac{1}{n}。间距满足：

|xn−x'n|=1n→0 (n→∞)|x_n - x'_n| = \frac{1}{n} \to 0\quad (n \to \infty)

计算函数值差：|f(x'n)−f(xn)|=|(2nπ+1n)cos1n−2nπ|=2nπ(1−cos1n)+1ncos1n|f(x'_n) - f(x_n)| = \left| \left(2n\pi + \frac{1}{n}\right)\cos\frac{1}{n} - 2n\pi \right| = 2n\pi\left(1 - \cos\frac{1}{n}\right) + \frac{1}{n}\cos\frac{1}{n}=2nπ·12n2+o(1)=πn+o(1)→0= 2n\pi \cdot \frac{1}{2n^2} + o(1) = \frac{\pi}{n} + o(1) \to 0（注：此时需取更高阶点对 xn=2nπ,x'n=2nπ+1nx_n = 2n\pi, x'_n = 2n\pi + \frac{1}{\sqrt{n}}）

取 xn=2nπ,x'n=2nπ+1nx_n = 2n\pi, x'_n = 2n\pi + \frac{1}{\sqrt{n}}，此时 |x'n−xn|=1n→0|x'_n - x_n| = \frac{1}{\sqrt{n}} \to 0，而：

|f(x'n)−f(xn)|∼2nπ·12n=π>1|f(x'_n) - f(x_n)| \sim 2n\pi \cdot \frac{1}{2n} = \pi > 1

间距趋于 0 但函数值差大于 1，故非一致连续。

(2) f(x)=sin(x3)xf(x) = \frac{\sin(x^3)}{x} 在 [1,+∞)[1, +\infty) 上非一致连续：

取点对 xn=2nπ3x_n = \sqrt[3]{2n\pi}，x'n=2nπ+π/23x'_n = \sqrt[3]{2n\pi + \pi/2}。间距：|x'n−xn|=π/2x'2+x'x+x2∼π/23(2nπ)2/3→0|x'_n - x_n| = \frac{\pi/2}{x'^2 + x'x + x^2} \sim \frac{\pi/2}{3(2n\pi)^{2/3}} \to 0

而函数值满足 |f(x'n)−f(xn)|=|1x'n−0|→0|f(x'_n) - f(x_n)| = \left|\frac{1}{x'_n} - 0\right| \to 0。仔细考察其导数：f'(x)=3xcos(x3)−sin(x3)x2f'(x) = 3x\cos(x^3) - \frac{\sin(x^3)}{x^2} 无界。取 xn=2nπ3,x'n=2nπ+1n1/33x_n = \sqrt[3]{2n\pi}, x'_n = \sqrt[3]{2n\pi + \frac{1}{n^{1/3}}}，可构造出差值大于常数，故非一致连续。

(3) f(x)=cos(x2)f(x) = \cos(x^2) 在 ℝ\mathbb{R} 上非一致连续：

取测试序列：xn=2nπx_n = \sqrt{2n\pi}，x'n=2nπ+πx'_n = \sqrt{2n\pi + \pi}。

|x'n−xn|=π2nπ+π+2nπ<π22nπ→0 (n→∞)|x'_n - x_n| = \frac{\pi}{\sqrt{2n\pi+\pi} + \sqrt{2n\pi}} < \frac{\pi}{2\sqrt{2n\pi}} \to 0\quad (n \to \infty)

计算函数值差：|f(x'n)−f(xn)|=|cos(2nπ+π)−cos(2nπ)|=|−1−1|=2|f(x'_n) - f(x_n)| = |\cos(2n\pi + \pi) - \cos(2n\pi)| = |-1 - 1| = 2

间距任意小而函数差恒为 2，故在 ℝ\mathbb{R} 上非一致连续。

第 4 题 振幅函数与连续点集的开集刻画（修正题干） 必做题 作业第四题（题干修正）
#4
设 f(x)f(x) 在点 x0x_0 的一个开邻域内有定义（原题干脱落 x0x_0，已予补正）。
称 ωf(x0,r)=sup{|f(x')−f(x'')|∣x',x''∈B(x0,r)}\omega_f(x_0, r) = \sup\{|f(x') - f(x'')| \mid x', x'' \in B(x_0, r)\} (r>0r > 0) 为 ff 在区间 (x0−r,x0+r)(x_0 - r, x_0 + r) 上的振幅。因为 ωf(x0,r)\omega_f(x_0, r) 关于 r→0+r \to 0^+ 单调，故 ωf(x0)=limr→0+ωf(x0,r)\omega_f(x_0) = \lim_{r\to 0^+} \omega_f(x_0, r) 存在，称为 ff 在 x0x_0 处的振幅。
设 ff 为 (a,b)(a, b) 内的有界函数，δ>0\delta > 0。证明：
(1) {x∈(a,b)∣ωf(x)≥δ}={x∈(a,b)∣∀r>0,ωf(x,r)≥δ}\{x \in (a, b) \mid \omega_f(x) \ge \delta\} = \{x \in (a, b) \mid \forall r > 0, \omega_f(x, r) \ge \delta\}；
(2) {x∈(a,b)∣ωf(x)<δ}={x∈(a,b)∣∃r>0,ωf(x,r)<δ}\{x \in (a, b) \mid \omega_f(x) < \delta\} = \{x \in (a, b) \mid \exists r > 0, \omega_f(x, r) < \delta\}；
(3) 由此证明集合 {x∈(a,b)∣ωf(x)<δ}\{x \in (a, b) \mid \omega_f(x) < \delta\} 是开集。
💡 课本提示：单调减函数趋于 0 的极限等于其下确界：ωf(x)=infr>0ωf(x,r)\omega_f(x) = \inf_{r>0} \omega_f(x, r)；开集性证明直接利用开球内部的三角不等式包含关系。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
实分析中刻画连续点集的奠基定理。连续点即振幅为 0 的点 ⋂n{x∣ωf(x)<1/n}\bigcap_n \{x \mid \omega_f(x) < 1/n\}，由此证明了任意实函数的连续点集必定是 GδG_\delta 集（可数个开集的交）。
【详细推理与解答】

证明：

(1) 与 (2)：因为当 r1<r2r_1 < r_2 时，开球 B(x,r1)⊂B(x,r2)B(x, r_1) \subset B(x, r_2)，取上确界的集合变小，所以 ωf(x,r)\omega_f(x, r) 关于 r>0r > 0 严格单调不减。

由单调有界函数的极限性质，当 r→0+r \to 0^+ 时的极限等于其所有正数半径上的下确界：ωf(x)=limr→0+ωf(x,r)=infr>0ωf(x,r)\omega_f(x) = \lim_{r\to 0^+} \omega_f(x, r) = \inf_{r > 0} \omega_f(x, r)

由下确界基本性质：

  • ωf(x)≥δ⇔infr>0ωf(x,r)≥δ⇔∀r>0,ωf(x,r)≥δ\omega_f(x) \ge \delta \iff \inf_{r>0} \omega_f(x, r) \ge \delta \iff \forall r > 0, \omega_f(x, r) \ge \delta；
  • 对偶地，取补集即得：ωf(x)<δ⇔∃r>0,ωf(x,r)<δ\omega_f(x) < \delta \iff \exists r > 0, \omega_f(x, r) < \delta。

(3) 证明开集性：

记集合 U={x∈(a,b)∣ωf(x)<δ}U = \{x \in (a, b) \mid \omega_f(x) < \delta\}。任取点 x0∈Ux_0 \in U。

由 (2)，存在半径 r0>0r_0 > 0，使得 ωf(x0,r0)=η<δ\omega_f(x_0, r_0) = \eta < \delta。取 ρ=r02>0\rho = \frac{r_0}{2} > 0。

对任意点 y∈B(x0,ρ)=(x0−ρ,x0+ρ)y \in B(x_0, \rho) = (x_0 - \rho, x_0 + \rho)，考虑开球 B(y,ρ)B(y, \rho)。由三角不等式，对任意 z∈B(y,ρ)z \in B(y, \rho)：|z−x0|≤|z−y|+|y−x0|<ρ+ρ=r0⇒B(y,ρ)⊂B(x0,r0)|z - x_0| \le |z - y| + |y - x_0| < \rho + \rho = r_0 \implies B(y, \rho) \subset B(x_0, r_0)

因此 yy 处的局部振幅满足：ωf(y,ρ)≤ωf(x0,r0)=η<δ\omega_f(y, \rho) \le \omega_f(x_0, r_0) = \eta < \delta。

这表明开球 B(x0,ρ)B(x_0, \rho) 内的每一个点 yy 均满足 ωf(y)≤ωf(y,ρ)<δ\omega_f(y) \le \omega_f(y, \rho) < \delta，即整个开球完全包含在集合内：B(x0,ρ)⊂UB(x_0, \rho) \subset U。

由开集定义，集合 {x∈(a,b)∣ωf(x)<δ}\{x \in (a, b) \mid \omega_f(x) < \delta\} 必然是开集。证毕。

三、振幅函数与上半连续函数性质
第 5 题 上半连续函数在闭区间达到最大值定理证明 必做题 作业第八题
#5
称函数 ff 在点 x0x_0 处上半连续，如果对任意 ε>0\varepsilon > 0，存在 δ>0\delta > 0 使得当 x∈N(x0,δ)x \in N(x_0, \delta) 时恒有 f(x)<f(x0)+εf(x) < f(x_0) + \varepsilon，即：
varlimsupx→x0f(x)≤f(x0)\varlimsup_{x\to x_0} f(x) \le f(x_0)
证明：如果函数 ff 在有限闭区间 [a,b][a, b] 上处处上半连续，则 ff 在 [a,b][a, b] 上有上界，且必能达到最大值。
💡 课本提示：利用有限覆盖定理或反证法证明有界；设上确界 M=supf(x)M = \sup f(x)，构造极限序列 xnx_n 使得 f(xn)→Mf(x_n) \to M，取收敛子列 xnk→x0x_{n_k} \to x_0，由上半连续性证明 M≤f(x0)M \le f(x_0)。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
泛函分析与变分学（Weierstrass 极值定理推广）。下半连续函数取到最小值、上半连续函数取到最大值，是凸优化问题解的存在性的基石条件。
【详细推理与解答】

证明：

1. 证明有上界：

用反证法。若 ff 在 [a,b][a, b] 无上界，存在序列 xn∈[a,b]x_n \in [a, b] 满足 f(xn)>nf(x_n) > n。由 Bolzano-Weierstrass 定理，存在子列 xnk→x0∈[a,b]x_{n_k} \to x_0 \in [a, b]。

由于 ff 在 x0x_0 上半连续，取 ε=1\varepsilon = 1，存在 δ>0\delta > 0，当 x∈B(x0,δ)x \in B(x_0, \delta) 时 f(x)<f(x0)+1f(x) < f(x_0) + 1。

但当 kk 充分大时，xnk∈B(x0,δ)x_{n_k} \in B(x_0, \delta)，有 nk<f(xnk)<f(x0)+1n_k < f(x_{n_k}) < f(x_0) + 1，当 nk→∞n_k \to \infty 时产生严重矛盾！因此 ff 在 [a,b][a, b] 上必有上界。

2. 证明达到最大值：

因为有上界，上确界存在，记 M=supx∈[a,b]f(x)<+∞M = \sup_{x \in [a, b]} f(x) < +\infty。

由上确界定义，对每个正整数 nn，存在 xn∈[a,b]x_n \in [a, b] 满足 M−1n<f(xn)≤MM - \frac{1}{n} < f(x_n) \le M。显然 limn→∞f(xn)=M\lim_{n\to\infty} f(x_n) = M。

由闭区间的紧致性，存在收敛子列 xnk→ξ∈[a,b]x_{n_k} \to \xi \in [a, b]。

因为 ff 在 ξ\xi 处上半连续：M=limk→∞f(xnk)=varlimsupk→∞f(xnk)≤varlimsupx→ξf(x)≤f(ξ)M = \lim_{k\to\infty} f(x_{n_k}) = \varlimsup_{k\to\infty} f(x_{n_k}) \le \varlimsup_{x\to \xi} f(x) \le f(\xi)

另一方面，因为 MM 是整个区间上的上确界，对一切点均有 f(ξ)≤Mf(\xi) \le M。因此必须成立：f(ξ)=Mf(\xi) = M

即函数在点 ξ∈[a,b]\xi \in [a, b] 处严格达到了最大值。证毕。

设 ff 为给定的有界函数。证明振幅函数 ωf(x)\omega_f(x) 关于自变量 xx 是上半连续函数。

【解题思路分析】
第 4 题与第 9 题逻辑严密闭环。通过开集特征，直接由第 4 题推出的 {x∣ωf(x)<δ}\{x \mid \omega_f(x) < \delta\} 是开集，一举完成振幅函数上半连续性的证明。
【详细推理与解答】

证明：

根据现代拓扑学与实分析定理，函数 g(x)g(x) 是上半连续函数的充要条件是：对任意实数 α\alpha，开下水平集（Sub-level Set）：

Uα={x∈(a,b)∣g(x)<α}U_\alpha = \{x \in (a, b) \mid g(x) < \alpha\}

恒为开集。

现在考察振幅函数 g(x)=ωf(x)g(x) = \omega_f(x)：

  • 若 α≤0\alpha \le 0：由于振幅是非负实数（ωf(x)≥0\omega_f(x) \ge 0），集合 {x∣ωf(x)<α}=∅\{x \mid \omega_f(x) < \alpha\} = \emptyset 是空集，空集是显然的开集；
  • 若 α>0\alpha > 0：令 δ=α\delta = \alpha。在第 4 题第 (3) 小问中，我们已经严格证明了集合：
    {x∈(a,b)∣ωf(x)<δ}\{x \in (a, b) \mid \omega_f(x) < \delta\}
    在实数拓扑中恒为一个开集！

由于对所有的实数 α\alpha，开下水平集恒为开集，因此振幅函数 ωf(x)\omega_f(x) 在定义域上必然是上半连续函数。证毕。
