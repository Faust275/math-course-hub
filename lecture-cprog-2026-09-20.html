一、常量、变量与算术／赋值运算（00:00:06—00:16:13）

00:00:06—00:01:51 ｜ 常量：整数、浮点数、字符与字符串

本课从「数据」讲起。程序处理的常量分几类：整数常量、双精度浮点数常量、单精度浮点数常量、字符常量、字符串常量。字符常量用一对单引号括起来，字符串常量用一对双引号括起来——老师特别强调：单引号里的 '0' 是字符 '0'（其 ASCII 码为 48），不加单引号的 0 是整数 0，二者完全不同；而光写 A 不加引号，编译器会把它当成一个标识符（标志符），不是字符常量。

双精度浮点数常量：3.14, 123.45
单精度浮点数常量：3.14f, 123.45f
字符常量：'0', 'a', 'A', '>'
字符串常量："China", " 中国共产党万岁"

00:01:51—00:08:11 ｜ 变量定义、初值与内存（垃圾值）

编译器处理程序的第一步是词法分析：把整个程序（字符序列）分解成单词（token），区分哪些是标识符、哪些是运算符／分隔符、哪些是保留字；被双引号或单引号引起来的内容是字符／字符串常量，而没被引起来的 A 则是标识符。C 语言没有原生的「字符串类型」，字符串本质是指针类型；而单个字符用 char。

变量定义的语法很简单：先写类型名，再写变量名列表，最后以分号结束；同类型的多个变量可以写在同一行，用逗号隔开。标识符（变量名）必须以字母或下划线开头，由字母、数字、下划线组成。

double area;
/* 定义1 个double 变量*/
int celsius , fahr, n; /* 定义3 个int 变量*/

代码取自课件 ch02.txt（第 9 页，变量的定义）

定义时还可同时赋初值：

float x, value = 1.0f;/* 定义2 个float 变量
其中value 的初值为1.0 */

代码取自课件 ch02.txt（第 10 页，带初值的变量定义）

老师的重点提醒：创建变量 = 向内存要一块空间并给它起个名字。例如 float x; 向内存申请 4 个字节（32 个比特），x 只是这块空间的名字。如果定义时不给初值，这块空间里原来是什么就是什么——上一届同学留下的「垃圾」，这叫垃圾值。全局变量在程序一启动时被自动清零；而函数内部的局部变量不会清零，它的值就是不可预测的垃圾值。老师说这就像开学分宿舍，好学生学校会打扫，但局部变量「宿舍」里原来是什么垃圾就是什么垃圾，千万别指望它等于零。

00:08:29—00:12:42 ｜ 算术运算符：单目／双目与整数除法

最基本的算术运算是加、减、乘、除、取余、相反数。其中减号有两种身份：

  • a - b 是双目运算符（两个操作数）；
  • -x（相反数）是单目运算符（一个操作数）。

C 语言的一条铁律：所有单目运算符的优先级都高于所有双目运算符。

老师反复强调的整数运算陷阱：整数除以整数的结果还是整数，只保留商，丢弃余数。例如 5 / 9 的结果是 0，9 / 2 的结果是 4，绝不会是 4.5 或 5.5。

5*(fahr-32)/9 与 5/9*(fahr-32)

代码取自课件 ch02.txt（第 11 页，算术运算）

上面两个表达式结果不同：5*(fahr-32)/9 先算乘法得到整数再除 9，而 5/9*(fahr-32) 因为 5/9 先做整数除法得到 0，整条式子结果恒为 0。另一个规则：操作数类型必须相同，结果类型也相同；double 与 double 运算结果还是 double。当写 100 + 3.14 时之所以合法，是因为编译器做了自动类型转换：把整数 100 临时变成 100.0 再相加。

例题／演示 1（00:11:08）｜ 整数除法与类型自动转换（5/9 = 0）

题目：验证「整数除以整数结果为整数」以及「不同类型自动转换」。

思路：用几个典型算式说明整数除法丢弃余数，再用一个整加浮的例子说明自动类型转换。

步骤（代码与讲解）：照课件第 11 页，重点记住： - int / int 的结果是 int； - 5 / 9 的结果为 0（商为 0，余数 5 被丢弃）； - 10 / 4.0 = 10.0 / 4.0 = 2.5（编译器把整数 10 自动转成 10.0）。

结论：写表达式的顺序会影响结果。5/9*x 永远为 0；而 x/9*5 先除后乘，结果可能非零。整数运算时绝不要期望得到小数。

易错点：初学者常把 5/9 误当成 0.555…。记住商保留整数即可；要得小数，至少一个操作数写成浮点形式（如 5.0/9）。

二、格式化输出 printf 与分支语句 if–else（00:16:13—00:46:00）

00:16:13—00:20:54 ｜ printf 格式字符串与格式符

printf 的最简单形式只输出一个字符串；更一般的形式是「格式控制字符串 + 输出列表」：

printf("华氏=%d, 摄氏=%d\n", fahr, celsius);

代码取自课件 ch02.txt（第 13 页，格式化输出函数）

格式控制字符串里有两种字符： - 普通字符——原样输出； - 格式字符（以 % 开头）——按格式输出列表中对应的值。

常用格式字符：%d（整数）、%c（字符）、%s（字符串）、%f（浮点数，float 与 double 通用）。

printf("华氏=%d, 摄氏=%d\n", fahr, celsius);

代码取自课件 ch02.txt（第 13 页，格式化输出函数）

输出结果是 华氏=100, 摄氏=37；\n 是不可见的换行符。

老师强调的格式符与变量一一对应规则：

int a = 123, b = 456;
printf("%d, %d;", a, b); // 输出123, 456;
printf("%d;", a, b);
// 输出123;
printf("%d %d;", b);
// 输出456 不可测内容;

代码取自课件 ch02.txt（第 14 页，格式字符数量对应）

讲解：格式字符串决定输出什么、输出多少。第一行两个 %d 依次取 a、b → 123, 456;；第二行只有一个 %d，b 多余、不被输出 → 123;；第三行有两个 %d 但只给了一个变量 b，第一个 %d 输出 456，第二个 %d 没有对应变量，输出不可测内容。

例题／演示 1（00:18:50）｜ printf 格式符数量对应（a=123, b=456）

题目：理解格式字符与输出列表必须一一对应。

思路：通过三组对照实验观察「格式符多／少」的后果。

步骤（代码见上）：

  1. 两个 %d 配 a, b → 正常输出 123, 456;；
  2. 一个 %d 配 a, b → 只输出 a，b 被忽略 → 123;；
  3. 两个 %d 只配 b → 第一个正常，第二个对应不到变量，输出不可测内容。

结论：格式字符的个数决定了输出什么；变量多了不输出，变量少了则多余格式符输出不可测内容。

易错点：「输出内容由格式字符串决定，不由变量决定」。不要以为把变量写在输出列表里就一定会打印出来。

00:20:54—00:28:14 ｜ 浮点数输出宽度、四舍五入与转义字符

浮点数输出可用 %n.mf 控制： - n：输出内容最少占据 n 个字符，不足时左边补空格； - m：小数部分保留 m 位，不足时右侧补 0； - 输出浮点数时会做四舍五入。

float x = 3.1415926;
printf("pi=%f,%5.3f,%8.2f", x, x, x);

代码取自课件 ch02.txt（第 16 页，%n.mf 控制）

输出结果是：pi=3.141593,3.142, 3.14（最后一段前面有 4 个空格，因总宽 8、内容 3.14 占 4 位，左边补 4 空格）。%f 默认保留 6 位小数，故 3.141593；%5.3f 是「总宽至少 5、小数 3 位」→ 3.142（四舍五入）；%8.2f → 3.14。

老师提醒：若 n 小于实际所需宽度（如 2.0f 实际要 4 位），不会报错，而是原样输出——「最少占 n 位」而非「最多占 n 位」。

例题／演示 2（00:23:00）｜ 浮点数输出宽度与四舍五入（pi = 3.1415926）

题目：观察 %f、%5.3f、%8.2f 对同一浮点数的不同输出。

思路：固定 x = 3.1415926，用三种格式符打印，比较小数位与总宽度。

步骤（代码见上）：编译运行后输出 pi=3.141593,3.142, 3.14。

结论：%f 默认 6 位小数；%m.nf 中 n 控制小数位并四舍五入，m 控制最小总宽、不足左补空格。

易错点：%5.3f 的 5 是「总宽 5」不是「小数点前 5 位」；3.142 实际占 5 个字符（3、.、1、4、2），正好满足。

\n 是转义字符（反斜杠 + n = newline），作用是把后续输出移到下一行：

printf("Hello");
printf("World");
以上代码输出结果是：
HelloWorld
printf("Hello\n");
printf("World");
以上代码输出结果是：
Hello
World

代码取自课件 ch02.txt（第 17 页，转义字符 ）

例题／演示 3（00:27:26）｜ 转义字符 的作用（Hello/World）

题目：理解 \n 如何改变输出布局。

思路：对比「不加换行」与「加换行」两种情况。

步骤（代码见上）：第一段连续输出 HelloWorld；第二段在 Hello 后加 \n，于是 World 落到下一行。

结论：\n 把「输出位置」移到下一行起始。

易错点：\n 本身不可见，但会影响后续所有输出。

00:28:33—00:32:41 ｜ 分段函数与 if–else

老师以自来水公司「分段计算水费」为例引入分支：用水量 x 不同，计费公式不同——这正是 if–else 的用武之地。注意 4*x/3 不能写成 4/3*x（4/3 整数除法得 1），必须写 4.0/3 或 4*x/3。

例题／演示 4（00:28:33）｜ [2-4] 分段计算水费（if–else）

题目：用户用水量 x，水费 y=f(x)={4x3,x≤152.5x−17.5,x>15y = f(x) = \begin{cases} \frac{4x}{3}, & x \le 15\\ 2.5x - 17.5, & x > 15 \end{cases} 编程读入 x，输出 y。

思路：用关系表达式 x<=15 作为条件，成立走 if 分支，否则走 else 分支。

步骤（代码）：

#include <stdio.h>
int main(void)
{
double x, y;
printf("输入用水量x(x>=0): ");
scanf("%lf", &x);
if( x<=15 )
y = 4 * x / 3;
else
y = 2.5 * x - 17.5;
printf("水费y=f(%f)=%.2f\n", x, y);
return 0;
}

代码取自课件 ch02.txt（第 19 页，例[2-4] 分段计算水费）

运行结果：

输入用水量x ( x>=0): 9.5
水费y=f (9.500000)=12.67
输入用水量x ( x>=0): 15
水费y=f (15.000000)=20.00

结论：if–else 两条分支只有一条会被执行；用 %.2f 控制浮点数保留 2 位小数。

易错点：① 写成 4/3*x 会得到错误结果（整数除法）；② printf 中 %f 默认 6 位小数，题目要求 2 位要用 %.2f。

00:32:41—00:38:04 ｜ 关系表达式与区间特征函数

关系表达式由两个操作数和关系运算符组成，结果是逻辑值（真 = 1，假 = 0）。关系运算符：<、<=、>、>= 优先级高，==、!= 优先级低，均从左到右结合。关系运算的操作数可以是整数、浮点数、字符（字符按 ASCII 值比较）。

a > 3
x <= y
c == d
b != 5

代码取自课件 ch02.txt（第 22 页，关系表达式）

老师特别讲了一个经典错误：想表达「x 在 [0,1] 区间内」，新手会写 0 <= x <= 1。

例题／证明 5（00:35:40）｜ 区间 [0,1] 特征函数——错误写法 0<=x<=1 与纠正（反例）

题目：特征函数 f(x)={1,0≤x≤10,其它f(x) = \begin{cases} 1, & 0 \le x \le 1\\ 0, & \text{其它} \end{cases} 判断下面写法是否正确：

int f(float x)
{
if( 0 <= x <= 1 )
return 1;
else
return 0;
}

代码取自课件 ch02.txt（第 23 页，典型错误 0 <= x <= 1）

分析（反例证明错误）：0 <= x <= 1 由于左结合，等价于 (0 <= x) <= 1。0 <= x 的结果是一个逻辑值 0 或 1，而 0 或 1 都 <= 1，所以整个表达式恒为真，哪怕 x = 100 也返回 1——显然荒谬。

纠正：区间必须拆成「两个条件同时成立」，用逻辑与连接：

if( 0<=x && x<=1 )

代码取自课件 ch02.txt（第 23 页，纠正：0<=x && x<=1）

结论：数学上的「连写不等式」在 C 里不能直接写，必须拆成两个关系表达式并用 &&（逻辑与）连接。

易错点：关系表达式的值是整数 0/1；(0<=x)<=1 中第二个 <= 比较的是「逻辑值 ≤ 1」，永远成立。

00:38:25—00:46:00 ｜ if–else 执行流程与测试注意事项

if–else 一般形式：

if( 表达式)
语句1;
else
语句2;

代码取自课件 ch02.txt（第 25 页，if–else 语句）

当表达式为真执行语句 1，否则执行语句 2，永远只有一条分支被执行。关系表达式也用于循环条件判断（如 for( i=1; i<=n; i++ )）。

老师的调试忠告：因为两条分支只有一条会执行，测试时至少准备两组数据——一组使 if 条件成立，另一组使条件不成立——分别验证两条分支都逻辑正确。只测一条分支，另一条就是「没被调试过的代码」，是不行的。

三、格式化输入 scanf 与数学库函数（00:46:00—01:06:09）

00:46:00—00:53:33 ｜ scanf：格式符、取地址与普通字符

scanf 按格式读入数据，语法：scanf(格式控制字符串, 输入地址列表);。读整数用 %d，读 float 用 %f，读 double 用 %lf，读字符用 %c。最关键的一点：变量前必须加取地址运算符 &，因为 scanf 需要把读到的数据「按地址写进变量」。

double value; int times;
scanf("%lf%d", &value, &times);

代码取自课件 ch02.txt（第 27 页，scanf 输入地址列表）

老师用「淘宝收货」比喻：scanf 就像快递员，你必须把「收货地址 &x」给它，它才知道往哪送；只把变量的值 x 给它没用。

scanf 格式字符串里也可以有普通字符，但含义与 printf 相反——printf 的普通字符是「输出出来」，scanf 的普通字符是「要求你原样输入」：

scanf("用水量=%lf", &x);

代码取自课件 ch02.txt（第 28 页，包含普通字符的格式控制字符串）

要读入 50.0 到 x，你必须老老实实输入 用水量=50.0，而不能只输入 50.0。老师指出这是初学者常犯的误解：以为 scanf 里的普通字符会像提示语一样显示出来——不会，它只增加你的输入负担。它真正的用处在于「管道」：一个程序的输出（如 用水量=50.0）可以直接作为另一个程序的输入，此时普通字符用来做字段匹配。

{

scanf("%lf", &initial);
printf("Enter factor:");
scanf("%lf", &factor);
printf("Enter day:");
scanf("%d", &day);

}

四、for 循环、增量运算与温度转换表（01:07:03—01:22:05）

01:07:03—01:15:57 ｜ for 循环与华氏–摄氏温度转换表

当「相同的计算要重复多次」（如对每个华氏度做摄氏转换）时，应写循环。C 有三种循环，最简单、最适合「确定次数」的是 for。for 四要素：循环变量初值、循环条件、循环体、循环变量更新。

例题／演示 1（01:07:03）｜ [2-6] 华氏–摄氏温度转换表（for 循环）

题目：输入下界 lower 与上界 upper，输出 [lower, upper] 区间内每隔 1°F 的华氏–摄氏转换表，公式 c=5×(f−32)/9c = 5\times(f-32)/9。

思路：从 fahr = lower 开始，只要 fahr <= upper 就转换并输出，每次 fahr++，直到超过上界。

步骤（代码）：

#include <stdio.h>
int main(void)
{
int lower, upper, fahr; double celsius;
printf("Enter lower and upper: ");
scanf("%d%d", &lower, &upper);
if( lower>upper ) {
printf("Invalid values: lower > upper !\n");
return 1;
}
printf("Fahr celsius\n");// 打印表头
for( fahr = lower; fahr <= upper; fahr++ ) {
celsius = 5 * (fahr -32) / 9.0;
printf("%4d%6.1f\n", fahr, celsius);
}
return 0;
}

代码取自课件 ch02.txt（第 38 页，例[2-6] 温度转换表）

运行示例（输入 30 35）：

Enter lower and upper: 30 35
Fahr celsius
30 -1.1
31 -0.6
32  0.0
33  0.6
34  1.1
35  1.7

结论：%4d 表示整数最少占 4 位（不足左补空格，右对齐）；%6.1f 表示浮点数总宽至少 6、小数 1 位。负数（如 -1.1）的符号也占一位。

易错点：① 若 lower > upper 应输出错误提示并 return 1 提前结束；② 公式用 9.0 而非 9，否则整数除法丢小数；③ printf("%4d%6.1f\n", fahr, celsius); 中两个格式符与两个变量严格对应。

01:15:57—01:22:05 ｜ 增量运算符 ++/– 与 for 语句结构、常见错误

增量运算符：fahr++ 等价于 fahr = fahr + 1；fahr-- 等价于 fahr = fahr - 1。++fahr 与 fahr++ 结果相同，细微差别以后讲。老师提醒要举一反三但不要过头：x++/x-- 有意义，但「x*x」没有「x**」这种写法（那只是 x 乘 1，无意义）。

for 语句结构：

for( 表达式1; 表达式2; 表达式3 )
循环体语句

代码取自课件 ch02.txt（第 42 页，for 语句）

执行流程：先算表达式 1（仅一次，初始化循环变量）→ 算表达式 2（循环条件），真则执行循环体 → 算表达式 3（更新循环变量）→ 再判断表达式 2，直至为假。循环体若有多条语句，必须用一对 {} 包成复合语句。

常见错误（老师特别强调）：

  1. 在 for(...) 后多写分号：for(...); 语句; —— 分号本身成了空语句（循环体），后面的语句不再是循环体；

  3. 循环体多条语句却没加大括号——只有第一条算循环体，其余跑到循环外。

五、例题：前 n 项级数求和与程序调试（01:22:05—01:39:59）

01:22:05—01:35:46 ｜ 求前 n 项级数 1−1/3+1/5−1/7+⋯

这是确定次数（n 项）的循环。第 i 项绝对值是 1/(2i−1)1/(2i-1)，符号交替（奇数项正、偶数项负）。

例题／演示 1（01:22:05）｜ [2-8] 求 1−1/3+1/5−1/7+⋯ 前 n 项和（for + flag）

题目：输入整数 n，求 ∑i=1n(−1)i−112i−1\sum_{i=1}^{n}(-1)^{i-1}\frac{1}{2i-1} 的前 n 项和。

思路：用 flag 记录符号（初始 1，每轮变号 -flag），item = flag * 1.0 / (2*i-1) 计算第 i 项，累加到 sum。注意用 1.0 而非 1，避免整数除法。

步骤（代码）：

#include <stdio.h>
int main(void)
{
int dnominator = 1, flag = 1, n, i;
double sum = 0, item;
printf("Enter n:"); scanf("%d", &n);
for( i=1; i<=n; i++ ) {
item = flag * 1.0 / (2*i-1);
sum = sum + item;
flag = -flag;
}
printf("sum=%f\n", sum);
return 0;
}

代码取自课件 ch02.txt（第 46 页，例[2-8] 程序代码）

运行示例： - 输入 n=1：sum=1.000000 - 输入 n=2：sum=0.666667（即 1−1/31 - 1/3） - 输入 n=3：sum=0.866667（即 1−1/3+1/51 - 1/3 + 1/5）

结论：用 flag 变号法可优雅处理交替符号；另一种等价的写法是判断 i%2==1 为奇数则加、else 减。

易错点（老师现场调试重点）： - 必须给 sum 赋初值 0。若不初始化，局部变量是垃圾值，累加结果不可预测（老师比喻：篮子没清空就去装苹果）。即使某次「恰好」结果对，也是隐患，规范写法一定要 double sum = 0;。 - scanf("%d", &n) 不能漏掉 &。漏写 &n 是常见错误。 - 分母必须写 2*i-1（i 从 1 开始）或 2*i+1（i 从 0 开始），且分子用 1.0 保证浮点除法。

01:40:29—01:42:05 ｜ 函数定义、声明与链接错误

当要解决「阶乘表」这类问题，应把「求阶乘」封装成自定义函数 fact，实现一次定义、多次复用。但调用函数前，编译器必须知道它的返回类型、名字和参数类型——对库函数是 #include 头文件，对自己写的函数则要在调用前先定义或先声明。

老师现场演示了一个链接错误：只写了 double fact(int n);（声明），却忘了提供函数定义，编译链接时报 undefined reference to fact（找不到 fact 的实现）。比喻：你吹牛说「我有 1000 万」，结果两个口袋都空着——声明了却不定义，链接器抓不到人。

double fact(int n); //函数申明
double fact(int); // 参数名可以省略
double multiply(double a, double b); // 两个参数
double multiply(double , double);

老师提醒：声明时参数名可省略，但保留参数名（如 double fact(int n)）更有意义——例如两个参数的函数，名字能提示「先传高再传半径」还是相反。

01:49:06—01:50:15 ｜ 求组合数（函数复用）

组合数 C(n,m)=n!m!(n−m)!C(n,m)=\dfrac{n!}{m!(n-m)!}。有了 fact 函数，直接调用三次即可，不必写三个循环——这就是代码复用（reuse），复用率越高，代码质量越高。

例题／演示 3（01:49:06）｜ [练习2-18] 求组合数 C(n,m)（函数复用）

题目：输入整数 n、m（n>=m），计算并输出组合数 C(n,m)=n!m!(n−m)!C(n,m)=\dfrac{n!}{m!(n-m)!}。

思路：复用已定义的 fact，表达式为 fact(n)/fact(m)/fact(n-m)。

double fact(int n); //函数申明
int main(void)
{
int n, m;
printf("Enter n, m:"); scanf("%d%d", &n, &m);
if( n>=m )
printf("组合数C(%d,%d) = %.0f\n", n, m,
fact(n)/fact(m)/fact(n-m));
return 0;
}

代码取自课件 ch02.txt（第 56 页，练习[2-18] 求组合数）

结论：一次定义、多次使用——fact 被调用三次，避免重复写三个累乘循环。

易错点：组合数要求 n>=m，故用 if( n>=m ) 保护；若 n<m 不应计算（课件此处仅处理合法情况，输出相应结果）。

题目：让程序在屏幕上打印出一个 % 字符。

代码取自课件 ch02.txt（第 57 页，printf 输出% 的方法：%%）

讲解：printf("%%"); 输出一个 %；若要 5% 可写 printf("%d%%", 5);（%d 输出 5，紧接着 %% 输出 %）。老师现场演示：只写 printf("%d", 5); 之类若格式符配错（如把 %d 误写成孤立的 %），会导致后续格式符错位、输出混乱甚至把整数当浮点解读，得到毫无意义的结果。

01:57:07—02:01:48 ｜ 变量命名规范与数据类型大小

老师强调变量命名要有意义：不要通篇 a,b,c,i,j,k，而应叫 month、money、celsius 之类，就像路名用「南京路、浙江路」比「78 号公路」好记。有意义的名字让程序自解释。

数据类型大小（老师口述）：char 占 1 字节（8 比特），int 占 4 字节（约 ±21 亿），double 占 8 字节。int 与 double 同样是 32/64 个比特，但解释方式完全不同（符号位、阶码、尾数），所以「把 int 的值按 double 格式输出」会得到毫无意义的数——这解释了「整数变量按 %f 输出」为何错得离谱。

结论：int a = 012; 拿到的不是 12 而是 10（因为八进制 012 = 1×8+2 = 10）；0x12 = 1×16+2 = 18。正负号可加在进制前缀前。

02:03:16—02:10:30 ｜ 字符宽度控制（%5c、左右对齐、0 填充）与 scanf 字符细节

字符与宽度：字符也能做宽度控制，%5c 输出一个字符、至少占 5 位宽度、右对齐（左补 4 空格）；%-5c 则左对齐（右补空格）。老师提醒：字符常量必须用单引号 'A'，写成双引号 "A" 是错误的（那是字符串）。

scanf 读字符的细节（老师重点）：

  1. 读整数／浮点数时，scanf 会自动跳过前导空白；但读字符 %c 不会跳过空白——空格、回车都会被当成字符读入。
  2. scanf 返回值表示「成功读取的数据项数」：两项都读成返回 2，只读成一项返回 1，一项都没读成返回 0。例如输入 123abc，%d 读走 123，%f 遇到 a 读失败，整体返回 1。
  3. 格式串里的普通字符能匹配输入：count= 必须原样输入 count=；count=（等号后带空格）也能匹配，因为空格可匹配任意多个空白；但 count =（等号前带空格）会匹配失败。
  4. 若想读「非空白字符」，可用 " %c"（格式串里空格后跟 %c），空格会吃掉前面的空白，从而读到真正的字符。

02:11:03—02:14:09 ｜ 浮点数的相等比较（误差与 epsilon）

数学上「a == b」有意义，但编程里比较两个浮点数是否相等要特别小心：浮点数在计算机里是近似表示的（如 π\pi 是无理数，存不下精确值），且不同计算路径得到的「理论相等」值可能有微小误差，所以 a == b 几乎永远为假。

正确做法：设一个很小的误差阈值 eps（如 1e-5），当 |a-b| < eps 就认为相等。例如用二分法或下降法求多项式零点时，不要写 if( f(x) == 0 )，而应写 if( fabs(f(x)) < eps )。

if( fabs(a - b) < 1e-5 )   // 认为 a 与 b 相等  [补全：依课堂讲解的 epsilon 法]
    ...

代码说明：课件未给具体程序，此为依据课堂讲解「用阈值判断浮点相等」补出的示例。

结论：大于／小于比较没问题，但等于比较要用 fabs(a-b) < eps；eps 取太大误差大、取太小可能永远不满足，需依具体应用选取。

02:14:18—02:17:58 ｜ 逻辑运算与短路规则

C 用整数表示逻辑值：真 = 1，假 = 0。逻辑运算符：!（非，单目，优先级最高）、&&（与）、||（或）。关系运算优先于逻辑运算。经典表达式（课件第三章）：

ch >= 'a' && ch <= 'z'   // 小写字母
ch >= 'A' && ch <= 'Z'   // 大写字母
ch >= '0' && ch <= '9'   // 数字字符
ch == ' ' || ch <= '\n'  // 空格或回车
year%4==0 && year%100!=0 || year%400==0   // 闰年

代码取自课件 ch03.txt（第 34 页，经典的逻辑运算表达式）

老师重点讲了短路规则（short-circuit）： - 计算 A && B 时，若 A 已为假，则整个表达式必为假，不再计算 B； - 计算 A || B 时，若 A 已为真，则整个表达式必为真，不再计算 B。

例题／演示 2（02:14:18）｜ 逻辑运算符与经典表达式（&&、||、!）

题目：理解逻辑运算符与短路规则。

思路：用经典表达式说明如何组合关系运算；用短路规则说明「A && B 与 B && A 逻辑值相同，但执行效果可能不同」。

步骤（代码见上）：以判断小写字母 ch >= 'a' && ch <= 'z' 为例，&& 要求两边同真；若 ch 小于 'a'，左边已假，右边不再判断即短路。

结论：短路规则让程序更高效；但因为它可能跳过 B 的求值，当 B 里含有「副作用」（如赋值、函数调用）时，A && B 与 B && A 虽逻辑等价，实际行为可能不同——不可随意交换。

易错点：逻辑与的优先级低于关系运算；!、&&、|| 的优先级依次降低，必要时加括号明确。
