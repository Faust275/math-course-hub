课程讲义汇总站 · 使用说明
================================

【怎么打开】
双击本文件夹里的 index.html。不用装软件、不用联网、不用敲命令。
首页四门课并列 → 点课程看节次 → 点某一节直接阅读该节讲义全文（公式与例题推导齐全）。
节页顶部只有一条导航 / 检索细条，不做摘要或概括；点「纯净版」打开不带导航的讲义原文。
右上角搜索框（或按 Ctrl+K）可以跨课搜索概念、例题、图注，结果直接跳到对应节。

【怎么加新课】
增量导入（不会重做已导入的节，只增量加入新节并更新索引）：
1. 回到上一级目录，打开 content/ 文件夹；
2. 按 content/怎么放文件.txt 的约定，给每节课建一个文件夹，放进去 handout.md 等材料；
3. 在上一级目录运行一次：python3 build_site.py
4. 刷新浏览器。新节自动出现在对应课程页，检索索引一并更新。

【从字幕生成讲义正文（可选）】
若你手里是课堂字幕（docx）而非现成 handout.md，参考 增量导入指南.md 与 _精讲规范_v3.md：
用 _batch_prep3.py 切分字幕 → 按 _精讲规范_v3.md 的口径让分段助手整理成纯正文草稿 →
_batch_merge3.py 合并、重编号、去元叙事并生成 md/docx/html 三格式 → 放进 content/<课程id>/<节>/
再跑 build_site.py。规范保证新讲义与既有 15 节分析、各板块首节的颗粒度一致。

【文件都是什么】
index.html              首页
预览_单文件.html         资源全内联的预览副本，单独发一个文件也能看、能搜
course-*.html           四门课的课程页
lecture-*.html          每一节的讲义全文（顶部带返回 / 上下节 / 检索细条）
site.css / site.js      全站共用样式与逻辑
data/core.js            全站结构索引（课程、节、章、小节、例题、图注）
data/lecture-*.js       单节结构化内容，只在打开该节时加载
data/full-*.js          按课分片的摘要倒排索引，搜索时按需加载
assets/                 讲义插图与板书照片，已复制进站内，拷走不丢
full/                   讲义原文（公式齐全、不含导航），节页「纯净版 ↗」直达

【为什么不用起服务】
浏览器出于安全考虑，会拦截本地网页用 fetch 直接读本地数据文件。
本站在构建时就把索引生成为普通 .js 文件，页面用经典 <script src> 加载，
不属于被拦截的那类请求，因此双击也能检索。整站不含任何外部依赖。

【来源标记】
讲义正文中：[补全]＝整理者按标准学科知识补齐的内容，不是课堂板书；[?]＝语音转写存疑处；
[按图还原]＝把黑板图形文字化的描述。其余为课堂讲授内容的还原。节页只呈现讲义全文，不另做摘要或概括。

【C 程序设计的代码】
C 程讲义里的代码逐字符取自课件，不以字幕为准。字幕把 %d 念成「百分号 d」，缩进、
分号、大小写、引号全部丢失，不能当代码用。课件原文留档在 content/cprog/0915/slides_C01.txt。
