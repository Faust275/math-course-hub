第 1 题 混合积模长不等式与立方体体积几何意义 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#1
证明：|(a→,b→,c→)|≤|a→||b→||c→||(\vec a, \vec b, \vec c)| \le |\vec a||\vec b||\vec c|，并说明其几何意义；等号成立的充要条件是什么？
💡 课本提示：利用混合积定义 (a→,b→,c→)=(a→×b→)·c→(\vec a, \vec b, \vec c) = (\vec a \times \vec b) \cdot \vec c，结合外积模长 |a→×b→|=|a→||b→|sinθ|\vec a\times\vec b| = |\vec a||\vec b|\sin\theta 与内积 Cauchy 不等式逐步放缩。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
混合积的绝对值是以三个向量为棱的平行六面体的体积。三棱长之积是对应长方体的体积，因此只有当三向量两两垂直时，平行六面体的高才达到棱长最大值。
【详细推理与解答】

证明：

由混合积的定义：(a→,b→,c→)=(a→×b→)·c→(\vec a, \vec b, \vec c) = (\vec a \times \vec b) \cdot \vec c。

由内积的模长不等式：

|(a→,b→,c→)|=|(a→×b→)·c→|≤|a→×b→||c→||(\vec a, \vec b, \vec c)| = |(\vec a \times \vec b) \cdot \vec c| \le |\vec a \times \vec b| |\vec c|

由外积的模长定义：|a→×b→|=|a→||b→|sin∠(a→,b→)|\vec a \times \vec b| = |\vec a||\vec b|\sin\angle(\vec a, \vec b)。因为正弦函数满足 |sinθ|≤1|\sin\theta| \le 1：

|a→×b→|≤|a→||b→||\vec a \times \vec b| \le |\vec a||\vec b|

综合上述两步放缩，立即得到：

|(a→,b→,c→)|≤|a→||b→||c→||(\vec a, \vec b, \vec c)| \le |\vec a||\vec b||\vec c|

几何意义：

|(a→,b→,c→)||(\vec a, \vec b, \vec c)|

是以 a→,b→,c→\vec a, \vec b, \vec c

为共顶点的三棱所张成的平行六面体的体积 VV

。不等式表明：以给定三线段为棱张成的所有平行六面体中，长方体的体积最大，其体积等于三棱长之积 |a→||b→||c→||\vec a||\vec b||\vec c|。

等号成立充要条件：

两步放缩同时取等号当且仅当：

  • 第一步取等：a→×b→\vec a \times \vec b 与 c→\vec c 共线，即 c→⊥a→\vec c \perp \vec a 且 c→⊥b→\vec c \perp \vec b；
  • 第二步取等：sin∠(a→,b→)=1\sin\angle(\vec a, \vec b) = 1，即 a→⊥b→\vec a \perp \vec b。

综上，等号成立充要条件为：a→,b→,c→\vec a, \vec b, \vec c 两两正交（两两互相垂直），或者至少有一个向量为零向量。

第 5 题 中线向量混合积恒等式证明 必做题 📖 教材 第2章 🎬 09-16 课 🎬 09-21 课
#5
设 AD,BE,CFAD, BE, CF 是 △ABC\triangle ABC 的三条中线，PP 是空间任意一点，证明：(OP→,OA→,AD→)+(OP→,OB→,BE→)+(OP→,OC→,CF→)=0(\overrightarrow{OP}, \overrightarrow{OA}, \overrightarrow{AD}) + (\overrightarrow{OP}, \overrightarrow{OB}, \overrightarrow{BE}) + (\overrightarrow{OP}, \overrightarrow{OC}, \overrightarrow{CF}) = 0
💡 课本提示：利用中点公式 OD→=12(OB→+OC→)\overrightarrow{OD} = \frac{1}{2}(\overrightarrow{OB}+\overrightarrow{OC})，得 AD→=OD→−OA→=12(OB→+OC→)−OA→\overrightarrow{AD} = \overrightarrow{OD} - \overrightarrow{OA} = \frac{1}{2}(\overrightarrow{OB}+\overrightarrow{OC}) - \overrightarrow{OA}；代入混合积展开，利用第三分量关于自身为零及对调变号性质两两抵消。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
利用混合积的多重线性性质（对每个位置均满足加法可拆性）以及反对称性，复杂的几何恒等式在代数展开下自然化为零。
【详细推理与解答】

证明：

记 a→=OA→,b→=OB→,c→=OC→,p→=OP→\vec a = \overrightarrow{OA}, \vec b = \overrightarrow{OB}, \vec c = \overrightarrow{OC}, \vec p = \overrightarrow{OP}。

由中点公式，各中线向量可表示为：

AD→=12(b→+c→)−a→\overrightarrow{AD} = \frac{1}{2}(\vec b + \vec c) - \vec aBE→=12(c→+a→)−b→\overrightarrow{BE} = \frac{1}{2}(\vec c + \vec a) - \vec bCF→=12(a→+b→)−c→\overrightarrow{CF} = \frac{1}{2}(\vec a + \vec b) - \vec c

将 AD→\overrightarrow{AD} 代入第一项，利用混合积对第三项的线性性：

(p→,a→,AD→)=(p→,a→,12(b→+c→)−a→)=12(p→,a→,b→)+12(p→,a→,c→)−(p→,a→,a→)(\vec p, \vec a, \overrightarrow{AD}) = \left(\vec p, \vec a, \frac{1}{2}(\vec b + \vec c) - \vec a\right) = \frac{1}{2}(\vec p, \vec a, \vec b) + \frac{1}{2}(\vec p, \vec a, \vec c) - (\vec p, \vec a, \vec a)

因两项相同混合积为零 (p→,a→,a→)=0(\vec p, \vec a, \vec a) = 0，得：

(p→,a→,AD→)=12(p→,a→,b→)−12(p→,c→,a→)(\vec p, \vec a, \overrightarrow{AD}) = \frac{1}{2}(\vec p, \vec a, \vec b) - \frac{1}{2}(\vec p, \vec c, \vec a)

同理对第二、三项展开：(p→,b→,BE→)=12(p→,b→,c→)−12(p→,a→,b→)(\vec p, \vec b, \overrightarrow{BE}) = \frac{1}{2}(\vec p, \vec b, \vec c) - \frac{1}{2}(\vec p, \vec a, \vec b)(p→,c→,CF→)=12(p→,c→,a→)−12(p→,b→,c→)(\vec p, \vec c, \overrightarrow{CF}) = \frac{1}{2}(\vec p, \vec c, \vec a) - \frac{1}{2}(\vec p, \vec b, \vec c)

将三式相加，所有六项成对正负抵消：[12(p→,a→,b→)−12(p→,a→,b→)]+[−12(p→,c→,a→)+12(p→,c→,a→)]+[12(p→,b→,c→)−12(p→,b→,c→)]=0\left[\frac{1}{2}(\vec p, \vec a, \vec b) - \frac{1}{2}(\vec p, \vec a, \vec b)\right] + \left[-\frac{1}{2}(\vec p, \vec c, \vec a) + \frac{1}{2}(\vec p, \vec c, \vec a)\right] + \left[\frac{1}{2}(\vec p, \vec b, \vec c) - \frac{1}{2}(\vec p, \vec b, \vec c)\right] = 0

恒等式得证。证毕。
