一、最大公因式与 Bezout 等式
第 1 题 互素多项式 Bezout 乘子的次数约束与唯一性 (习题 3.4 第 6 题) 必做题 📖 教材 §3.4 🎬 09-21 课 🎬 09-24 课
#1
设F[x]中两个次数大于0的多项式 f(x)与g(x)互素.求证：存在唯一的 u(x),v(x)∈F[?]满足degu(x)
💡 课本提示：存在性利用一般 Bezout 等式结合带余除法控制余式次数；唯一性假设有两组解相减，利用多项式互素与次数矛盾。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
中国剩余定理（CRT）与部分分式展开（Partial Fraction Decomposition）的底层唯一性基石。
【详细推理与解答】

证明：

1. 存在性：因为 (f(x),g(x))=1(f(x), g(x)) = 1，由 Bezout 定理存在 u0(x),v0(x)∈F[x]u_0(x), v_0(x) \in F[x] 使得 u0(x)f(x)+v0(x)g(x)=1u_0(x)f(x) + v_0(x)g(x) = 1。对 u0(x)u_0(x) 作除以 g(x)g(x) 的带余除法：

u0(x)=q(x)g(x)+u(x), 其中degu(x)<degg(x)u_0(x) = q(x)g(x) + u(x), \quad \text{其中 } \deg u(x) < \deg g(x)

代入得：

(q(x)g(x)+u(x))f(x)+v0(x)g(x)=1⇒u(x)f(x)+(v0(x)+q(x)f(x))g(x)=1(q(x)g(x) + u(x))f(x) + v_0(x)g(x) = 1 \implies u(x)f(x) + (v_0(x) + q(x)f(x))g(x) = 1

令 v(x)=v0(x)+q(x)f(x)v(x) = v_0(x) + q(x)f(x)。由 u(x)f(x)+v(x)g(x)=1u(x)f(x) + v(x)g(x) = 1，得 v(x)g(x)=1−u(x)f(x)v(x)g(x) = 1 - u(x)f(x)。两边考察次数：

deg(v(x)g(x))=deg(1−u(x)f(x))≤degu(x)+degf(x)<degg(x)+degf(x)\deg(v(x)g(x)) = \deg(1 - u(x)f(x)) \le \deg u(x) + \deg f(x) < \deg g(x) + \deg f(x)

故 degv(x)<degf(x)\deg v(x) < \deg f(x)。存在性得证。

2. 唯一性：设另有一组 u′(x),v′(x)u'(x), v'(x) 满足同样条件。相减得：

(u(x)−u′(x))f(x)=(v′(x)−v(x))g(x)(u(x) - u'(x))f(x) = (v'(x) - v(x))g(x)

因为 (f(x),g(x))=1(f(x), g(x)) = 1，故 g(x)∣(u(x)−u′(x))f(x)⇒g(x)∣(u(x)−u′(x))g(x) \mid (u(x) - u'(x))f(x) \implies g(x) \mid (u(x) - u'(x))。但 deg(u(x)−u′(x))<degg(x)\deg(u(x) - u'(x)) < \deg g(x)，能被 g(x)g(x) 整除的低次多项式必为 0！故 u(x)=u′(x)u(x) = u'(x)，进而 v(x)=v′(x)v(x) = v'(x)。证毕。

第 2 题 两多项式互素与正整数次幂互素的等价性 (习题 3.4 第 8 题) 必做题 📖 教材 §3.4 🎬 09-21 课 🎬 09-24 课
#2
求证：多项式f(x)与g(x)互素的充要条件是，对任意正整数n,f(x)"与g(z)" 都互素.
💡 课本提示：若有不可约公因式 p(x)∣fnp(x) \mid f^n 且 p(x)∣gnp(x) \mid g^n，由素多项式性质直接推出 p(x)∣fp(x) \mid f 且 p(x)∣gp(x) \mid g。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
不可约因式是多项式环中的“素数”。多项式互素充要条件完全由不可约因式的集合交集是否为空决定。
【详细推理与解答】

证明：

充分性：若对任意正整数 nn 有 (f(x)n,g(x)n)=1(f(x)^n, g(x)^n) = 1，特别取 n=1n=1 即得 (f(x),g(x))=1(f(x), g(x)) = 1。

必要性：设 (f(x),g(x))=1(f(x), g(x)) = 1。反证法：假设存在某个正整数 nn 使得 (f(x)n,g(x)n)≠1(f(x)^n, g(x)^n) \neq 1。则它们必有至少一个不可约公因式 p(x)p(x)（degp(x)≥1\deg p(x) \ge 1）。

由 p(x)∣f(x)np(x) \mid f(x)^n，因为 p(x)p(x) 是不可约多项式，由不可约式的 Euclid 引理推论，必有 p(x)∣f(x)p(x) \mid f(x)。同理由 p(x)∣g(x)np(x) \mid g(x)^n 可得 p(x)∣g(x)p(x) \mid g(x)。这说明 p(x)p(x) 是 f(x)f(x) 和 g(x)g(x) 的公因式，与 (f(x),g(x))=1(f(x), g(x)) = 1 矛盾！故对任意正整数 nn 恒有 (f(x)n,g(x)n)=1(f(x)^n, g(x)^n) = 1。证毕。

第 3 题 多项式非奇异可逆线性组合的最大公因式不变性 (习题 3.4 第 9 题) 必做题 📖 教材 §3.4 🎬 09-21 课 🎬 09-24 课
#3
设F上多项式fi(x)= af(x)+bg(x),gi(x)=cf(x)+dg(x),其中a,b,c,d∈F 且ad-bc≠0.求证：(f(x),g(x))=(fi(x),g1(x)).
💡 课本提示：矩阵 (abcd)\begin{pmatrix} a & b \\ c & d \end{pmatrix} 可逆，从而 f(x),g(x)f(x), g(x) 也能反向线性表出为 f1(x),g1(x)f_1(x), g_1(x) 的线性组合。公因式集合完全一致。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
二维线性变换对最大公因式的作用。因可逆矩阵保持理想生成系不变：⟨f1,g1⟩=⟨f,g⟩\langle f_1, g_1 \rangle = \langle f, g \rangle。
【详细推理与解答】

证明：

1. 设 d(x)=(f(x),g(x))d(x) = (f(x), g(x))。因为 d(x)∣f(x)d(x) \mid f(x) 且 d(x)∣g(x)d(x) \mid g(x)，由线性组合性质，d(x)∣(af+bg)=f1(x)d(x) \mid (af + bg) = f_1(x) 且 d(x)∣(cf+dg)=g1(x)d(x) \mid (cf + dg) = g_1(x)。故 d(x)d(x) 是 f1(x),g1(x)f_1(x), g_1(x) 的公因式，因此 d(x)∣(f1(x),g1(x))d(x) \mid (f_1(x), g_1(x))。

2. 另一方面，因为 ad−bc≠0ad - bc \neq 0，行列式不为零，矩阵可逆。解方程组：

f(x)=df1(x)−bg1(x)ad−bc, g(x)=−cf1(x)+ag1(x)ad−bcf(x) = \frac{d f_1(x) - b g_1(x)}{ad - bc}, \quad g(x) = \frac{-c f_1(x) + a g_1(x)}{ad - bc}

设 d1(x)=(f1(x),g1(x))d_1(x) = (f_1(x), g_1(x))。同理可知 d1(x)d_1(x) 是 f(x),g(x)f(x), g(x) 的公因式，故 d1(x)∣d(x)d_1(x) \mid d(x)。

3. 两个首一多项式互相整除，必有 d(x)=d1(x)d(x) = d_1(x)。证毕。

#4
当正整数n取何值时，复多项式f(x)=(x+1)”-x-1有重因式?
💡 课本提示：f(x)f(x) 与 f′(x)=n(x+1)n−1−nxn−1f'(x) = n(x+1)^{n-1} - n x^{n-1} 有公共根。解 (1+1/x)n−1=1(1 + 1/x)^{n-1} = 1 并代入原方程。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
利用形式导数与单位根判别复多项式重根条件。根必须同时为原函数与一阶导数的零点。
【详细推理与解答】

解与证明：

1. f(x)=(x+1)n−xn−1f(x) = (x+1)^n - x^n - 1 有重因式当且仅当它与导数 f′(x)f'(x) 有公共根。求导：

f′(x)=n(x+1)n−1−nxn−1=0⇔(x+1)n−1=xn−1f'(x) = n(x+1)^{n-1} - n x^{n-1} = 0 \iff (x+1)^{n-1} = x^{n-1}

2. 显然 x≠0x \neq 0 且 x+1≠0x+1 \neq 0。两边同除 xn−1x^{n-1}：

(1+1x)n−1=1\left(1 + \frac{1}{x}\right)^{n-1} = 1

3. 设公共根为 α\alpha

。则 (α+1)n−1=αn−1(\alpha+1)^{n-1} = \alpha^{n-1}

。代入 f(α)=0f(\alpha) = 0：

(α+1)(α+1)n−1−ααn−1−1=(α+1)αn−1−αn−1=αn−1−1=0(\alpha+1)(\alpha+1)^{n-1} - \alpha \alpha^{n-1} - 1 = (\alpha+1)\alpha^{n-1} - \alpha^n - 1 = \alpha^{n-1} - 1 = 0

故 αn−1=1\alpha^{n-1} = 1，进而 (α+1)n−1=1(\alpha+1)^{n-1} = 1。即 α\alpha 与 α+1\alpha+1 均为 n−1n-1 次单位根！

4. 在复平面上，|α|=1|\alpha| = 1 且 |α−(−1)|=1|\alpha - (-1)| = 1，由等边三角形几何意义，α=e±2πi/3\alpha = e^{\pm 2\pi i / 3}。其为 6 次本原单位根，阶为 6。故必须 6∣(n−1)6 \mid (n-1) 或等价地 n≡1(mod6)n \equiv 1 \pmod 6（且 n>1n > 1）。此时 f(x)f(x) 恰有重因式 x2+x+1x^2 + x + 1。证毕。

求证：若域F特征为0,f(x)∈F[x]且n=degf(x)≥1,则如下陈述等价： (i)f'(x)|f(x); (ii)f'(x)的不可约因式也是f(x)的因式； (iii)f(x)有n-重根.
💡 课本提示：设首一多项式因式分解 f(x)=∏i=1k(x−αi)eif(x) = \prod_{i=1}^k (x - \alpha_i)^{e_i}。由 f′(x)∣f(x)f'(x) \mid f(x) 且 degf′=n−1\deg f' = n - 1，商式必须是一次多项式 1n(x−c)\frac{1}{n}(x - c)。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
完全由单一根生成的最高幂次多项式 c(x−a)nc(x - a)^n 的纯代数判定。

• (iii) ⇒\implies (i) 与 (ii) 是显然的：若 f(x)=c(x−α)nf(x) = c(x - \alpha)^n，则 f′(x)=nc(x−α)n−1f'(x) = nc(x - \alpha)^{n-1}，显然 f′(x)∣f(x)f'(x) \mid f(x) 且不可约因式相同。

• (i) ⇒\implies (iii)：设 f′(x)∣f(x)f'(x) \mid f(x)。因为 degf=n\deg f = n 且 degf′=n−1\deg f' = n - 1，必存在常数 cc 使得：

f(x)=1n(x−α)f′(x)f(x) = \frac{1}{n}(x - \alpha) f'(x)

代入微分方程形式解或比较系数：设 ff 在分裂域中有根 α1,…,αk\alpha_1, \dots, \alpha_k 重数分别为 e1,…,eke_1, \dots, e_k。利用恒等式 f′(x)f(x)=∑i=1keix−αi\frac{f'(x)}{f(x)} = \sum_{i=1}^k \frac{e_i}{x - \alpha_i}，必须与 nx−α\frac{n}{x - \alpha} 恒等，这要求只能有唯一的一个根 α1=α\alpha_1 = \alpha 且重数 e1=ne_1 = n。故 f(x)=an(x−α)nf(x) = a_n (x - \alpha)^n。同理可得三者等价。证毕。

第 7 题 有限域上二次与三次不可约多项式计数公式 (习题 3.5 第 8 题) 必做题 📖 教材 §3.5 🎬 09-21 课 🎬 09-24 课
#7
设F为q元有限域(例如F=Zp,q=p为素数).求F上二次和三次首一不 可约多项式的个数.
💡 课本提示：首一二次多项式总数 q2q^2，可约的由两一次因式 (x−a)(x−b)(x-a)(x-b) 组成，总数为 (q2)+q=q(q+1)2\binom{q}{2} + q = \frac{q(q+1)}{2}；三次类似排除含有一次因式的情形。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
高斯项公式（Gauss Necklaces Formula）在有限域多项式计数中的特例：利用 Möbius 反演公式可推广到任意 nn 次不可约多项式计数 Nq(n)=1n∑d∣nμ(d)qn/dN_q(n) = \frac{1}{n} \sum_{d \mid n} \mu(d) q^{n/d}。
【详细推理与解答】

解与推导：

1. 二次首一不可约多项式计数：

• Fq[x]\mathbb{F}_q[x] 中首一二次多项式形式为 x2+ax+bx^2 + ax + b，总共有 q2q^2 个。

• 一个二次多项式可约当且仅当它能分解为两个一次因式 (x−α)(x−β)(x - \alpha)(x - \beta)（α,β∈Fq\alpha, \beta \in \mathbb{F}_q）。

• 两根不同时有 (q2)=q(q−1)2\binom{q}{2} = \frac{q(q-1)}{2} 个；两根重合时有 qq 个。可约总数为 q(q−1)2+q=q(q+1)2\frac{q(q-1)}{2} + q = \frac{q(q+1)}{2}。

• 故不可约多项式个数为：

N2=q2−q(q+1)2=q2−q2=q(q−1)2N_2 = q^2 - \frac{q(q+1)}{2} = \frac{q^2 - q}{2} = \frac{q(q-1)}{2}

2. 三次首一不可约多项式计数：

• 首一三次多项式总共有 q3q^3 个。三次多项式可约当且仅当它至少含有一个一次因式。

• 可约情形包括：(1) 三个一次因式乘积，计数为 (q3)+2(q2)+q=q(q+1)(q+2)6\binom{q}{3} + 2\binom{q}{2} + q = \frac{q(q+1)(q+2)}{6}；(2) 一个一次因式与一个二次不可约多项式乘积，计数为 q·N2=q·q(q−1)2q \cdot N_2 = q \cdot \frac{q(q-1)}{2}。

• 相加后从 q3q^3 中扣除，或直接由 Gauss 周期计数公式：

N3=q3−q3=q(q2−1)3N_3 = \frac{q^3 - q}{3} = \frac{q(q^2 - 1)}{3}

证毕。

【详细推理与解答】

1. 多项式 f(x)=x3+px+qf(x) = x^3 + px + q 有重根当且仅当 gcd(f(x),f′(x))≠1\gcd(f(x), f'(x)) \neq 1。导数为 f′(x)=3x2+pf'(x) = 3x^2 + p。

2. 对 f(x)f(x) 作关于 f′(x)f'(x) 的辗转相除：

x3+px+q=x3(3x2+p)+(2p3x+q)x^3 + px + q = \frac{x}{3}(3x^2 + p) + \left(\frac{2p}{3}x + q\right)

  • 若 p=0p = 0，则 q=0q = 0（此时 f(x)=x3f(x) = x^3 有三重根 0）；
  • 若 p≠0p \neq 0，则公共根唯一可能为 x=−3q2px = -\frac{3q}{2p}。将其代入 f′(x)=0f'(x) = 0：3(−3q2p)2+p=0⇔3·9q24p2+p=0⇔27q2+4p3=03\left(-\frac{3q}{2p}\right)^2 + p = 0 \iff 3 \cdot \frac{9q^2}{4p^2} + p = 0 \iff 27q^2 + 4p^3 = 0
