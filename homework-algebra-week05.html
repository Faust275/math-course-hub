设F是域.证明Fn中的两个向量组 α={a1=(1,0,0,…,0),α2=(0,1,0,…,0),…,αn=(0,…,0,1)}, β={β1=(1,1,1,…,1),β2=(0,1,1,…,1),…,βn=(0,0…,0,1)} 可以互相线性表出，并用形式矩阵运算将向量组a和β互相表出.

【详细推理与解答】

#4
方阵A∈Fn×n的对角线元素之和称为A的迹，并记作tr(A).设A,B∈Fn×n. 求证： (i) tr(A+B)=tr(A)+tr(B); (ii) tr(λA)=λtr(A),λ∈F; (iii) tr(AB)=tr(BA).
💡 课本提示：利用双重求和指标对易 tr(AB)=∑i,kaikbki=∑k,ibkiaik=tr(BA)\text{tr}(AB) = \sum_{i,k} a_{ik}b_{ki} = \sum_{k,i} b_{ki}a_{ik} = \text{tr}(BA)。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
迹是矩阵代数上唯一的非平凡中心化线性泛函（Lie 代数中的 Killing 型基础）。
【详细推理与解答】

证明：

(i) 线性性：tr(A+B)=∑i=1n(aii+bii)=∑i=1naii+∑i=1nbii=tr(A)+tr(B)\text{tr}(A+B) = \sum_{i=1}^n (a_{ii} + b_{ii}) = \sum_{i=1}^n a_{ii} + \sum_{i=1}^n b_{ii} = \text{tr}(A) + \text{tr}(B)

(ii) 齐次性：tr(λA)=∑i=1n(λaii)=λ∑i=1naii=λtr(A)\text{tr}(\lambda A) = \sum_{i=1}^n (\lambda a_{ii}) = \lambda \sum_{i=1}^n a_{ii} = \lambda \text{tr}(A)

(iii) 对易乘积不变性：矩阵乘积 ABAB 的对角线第 ii 个元素为 (AB)ii=∑k=1naikbki(AB)_{ii} = \sum_{k=1}^n a_{ik} b_{ki}。因此：tr(AB)=∑i=1n(AB)ii=∑i=1n∑k=1naikbki=∑k=1n∑i=1nbkiaik=∑k=1n(BA)kk=tr(BA)\text{tr}(AB) = \sum_{i=1}^n (AB)_{ii} = \sum_{i=1}^n \sum_{k=1}^n a_{ik} b_{ki} = \sum_{k=1}^n \sum_{i=1}^n b_{ki} a_{ik} = \sum_{k=1}^n (BA)_{kk} = \text{tr}(BA) 证毕。

第 5 题 对易子方程 AB - BA = I 在有限维空间的不可能性 (习题 4.5 第 8 题) 必做题 教材习题 4.5.8
#5
求证：数域F上不存在n 阶方阵A,B满足AB-BA=In.
💡 课本提示：对等式两边取迹，左边利用 tr(AB−BA)=0\text{tr}(AB - BA) = 0，右边 tr(In)=n≠0\text{tr}(I_n) = n \neq 0。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
量子力学 Heisenberg 不确定性原理（[X,P]=ihbarI[X, P] = i\hbar I）在有限维矩阵空间中不可能实现的代数证明，说明位置与动量算符必须作用在无限维 Hilbert 空间上。
【详细推理与解答】

证明：

1. 反证法：假设存在数域 FF 上的 nn 阶方阵 A,BA, B 满足 AB−BA=InAB - BA = I_n。

2. 在方程两端同时应用迹运算 tr\text{tr}：tr(AB−BA)=tr(In)\text{tr}(AB - BA) = \text{tr}(I_n)

3. 由上一题已证的迹的线性性与对易乘积不变性：tr(AB−BA)=tr(AB)−tr(BA)=0\text{tr}(AB - BA) = \text{tr}(AB) - \text{tr}(BA) = 0

4. 另一方面，单位矩阵的迹为对角元之和：tr(In)=∑i=1n1=n\text{tr}(I_n) = \sum_{i=1}^n 1 = n 因为在任何数域（特征为 0 的域）中，正整数 n≠0n \neq 0。出现矛盾 0=n≠00 = n \neq 0！故有限维中不存在满足该式的方阵。证毕。

第 6 题 对称矩阵与幂等矩阵的代数性质 (习题 4.5 第 10 题) 必做题 教材习题 4.5.10
#6
设A,B∈Fn×n,求证： (i)若A,B对称，则AB对称当且仅当AB= BA; (ii)若A2=B2=In,则(AB)2=In当且仅当AB= BA; iii)若A,B幂等(即A2=A, B2=B),则(A+B)2=A+B当且仅当AB+BA=0.
💡 课本提示：利用矩阵转置公式 (AB)T=BTAT(AB)^T = B^T A^T 以及展开 (A+B)2=A2+AB+BA+B2(A+B)^2 = A^2 + AB + BA + B^2。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
自伴随算符与投影算符的代数性质：两投影算符之和仍为投影算符当且仅当它们相互正交消亡。
【详细推理与解答】

证明：

(i) 设 AT=A,BT=BA^T = A, B^T = B。则 (AB)T=BTAT=BA(AB)^T = B^T A^T = BA。故 ABAB 是对称矩阵 ⇔(AB)T=AB⇔BA=AB\iff (AB)^T = AB \iff BA = AB。

(ii) 设 A2=B2=InA^2 = B^2 = I_n。若 (AB)2=In(AB)^2 = I_n，则 ABAB=InABAB = I_n。左乘 AA 右乘 BB（注意 A2=I,B2=IA^2=I, B^2=I）：A(ABAB)B=AInB⇒BA=ABA(ABAB)B = A I_n B \implies B A = A B 反之若 AB=BAAB = BA，则 (AB)2=ABAB=A2B2=In(AB)^2 = A B A B = A^2 B^2 = I_n。充分必要性成立。

(iii) 展开 (A+B)2(A+B)^2：(A+B)2=A2+AB+BA+B2=A+(AB+BA)+B(A+B)^2 = A^2 + AB + BA + B^2 = A + (AB + BA) + B 故 (A+B)2=A+B⇔AB+BA=0(A+B)^2 = A + B \iff AB + BA = 0。证毕。

第 9 题 幂零矩阵与可逆逆阵 Neumann 级数 (习题 4.5 第 15 题) 必做题 教材习题 4.5.15
#9
设A∈Fn×n,求证：若存在正整数k≥2使得A?=0,则In-A可逆且 (In-A)-1=In+A+A2+…+Ak-1.
💡 课本提示：利用代数因式分解恒等式 (I−A)(I+A+A2+…+Ak−1)=I−Ak(I - A)(I + A + A^2 + \dots + A^{k-1}) = I - A^k，并代入 Ak=0A^k = 0。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
函数分析与数值代数中 Neumann 级数截断的有限步精确形式。在代数群中对应单极元（Unipotent）的可逆性。
【详细推理与解答】

证明：

1. 考虑多项式乘积展开：(In−A)(In+A+A2+⋯+Ak−1)=(In+A+⋯+Ak−1)−(A+A2+⋯+Ak)=In−Ak(I_n - A)(I_n + A + A^2 + \cdots + A^{k-1}) = (I_n + A + \cdots + A^{k-1}) - (A + A^2 + \cdots + A^k) = I_n - A^k

2. 同理从右侧相乘亦有：(In+A+A2+⋯+Ak−1)(In−A)=In−Ak(I_n + A + A^2 + \cdots + A^{k-1})(I_n - A) = I_n - A^k

3. 题设已知 Ak=0A^k = 0，故右端严格等于 In−0=InI_n - 0 = I_n。

4. 由可逆矩阵定义，方阵两端乘积为单位阵即证明 In−AI_n - A 可逆，且其逆矩阵恰为：(In−A)−1=In+A+A2+⋯+Ak−1(I_n - A)^{-1} = I_n + A + A^2 + \cdots + A^{k-1} 证毕。

#10
设A∈Fn×n,b∈Fn×1,b≠0.求证：若对非负整数k有A*b≠0,A*+1b=0, 则b,Ab,…,A*b线性无关.

【详细推理与解答】

证明：

#11
实方阵A=(aij)n×n∈Rn×n称为Markov(马尔可夫)矩阵，如果aij≥0, 当∑a=1,j=1,2, ,n.实向量x=(1,i2,,z) eRM×1称为概率向量，如果 ,≥0,∑z=1. Markov 矩阵在实际应用中非常重要.求证： (i) A∈Rn×n是Markov 矩阵当且仅当对任意概率向量x∈Rn×1,Ax仍为概率 向量； (ii)若A,B∈Rn×n 均为Markov 矩阵，则AB也是Markov 矩阵.特别地，A* (k≥1)是Markov矩阵.
💡 课本提示：概率向量满足分量非负且 ∑xi=1\sum x_i = 1（即 eTx=1e^T x = 1）。Markov 矩阵满足非负且列和为 1（即 eTA=eTe^T A = e^T）。利用结合律计算 eT(Ax)=(eTA)xe^T (Ax) = (e^T A)x。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
随机过程与马尔可夫链转移概率阵的代数基础。随机矩阵关于乘法构成一个紧半群。
【详细推理与解答】

证明：

(i) 充分必要性：

• 设 AA 为 Markov 矩阵，即 aij≥0a_{ij} \ge 0 且每列和 ∑i=1naij=1\sum_{i=1}^n a_{ij} = 1（即 eTA=eTe^T A = e^T）。对任意概率向量 x≥0x \ge 0（满足 eTx=1e^T x = 1）：

  • 非负性：(Ax)i=∑jaijxj≥0(Ax)_i = \sum_j a_{ij} x_j \ge 0（非负数的和）；
  • 归一化：全部分量之和为 eT(Ax)=(eTA)x=eTx=1e^T (Ax) = (e^T A)x = e^T x = 1。故 AxAx 仍为概率向量。

• 反之，分别取 x=ejx = e_j，则 Ax=A(j)Ax = A_{(j)} 必须是概率向量，从而每列非负且和为 1，即 AA 是 Markov 矩阵。

(ii) 乘积保持：若 A,BA, B 均是 Markov 矩阵，因非负矩阵之积非负，且 eT(AB)=(eTA)B=eTB=eTe^T (AB) = (e^T A)B = e^T B = e^T，故 ABAB 仍为 Markov 矩阵。归纳即得对任意正整数 k≥1k \ge 1，AkA^k 也是 Markov 矩阵。证毕。

三、替换定理与向量组等价
第 12 题 外加两向量线性相关的情形分类定理 (习题 4.7 第 4 题) 选做题 教材习题 4.7.4
#12
设线性空间V中向量组α1,a?,…,αm线性无关，α1,α2,…,αm,u,v线性相关. 求证：或者u,v中至少有一个可由α1,α2,…,am线性表示，或者向量组α1,α2,…,αm, u与α1,α2,…,αm,v等价.
💡 课本提示：设非平凡组合 c1α1+…+cmαm+au+bv=0c_1 \alpha_1 + \dots + c_m \alpha_m + a u + b v = 0。若 a,ba, b 中恰有一个为零，则另一个可由 α\alpha 线性表示；若均不为零，可将 vv 表为 α\alpha 与 uu 的线性组合。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
Steinitz 替换定理的核心推论：添加两向量后秩只增加 1 时，两个扩充子空间必然等价重合。
【详细推理与解答】

证明：

1. 因为 α1,…,αm,u,v\alpha_1, \dots, \alpha_m, u, v 线性相关，存在不全为零的标量使得：c1α1+⋯+cmαm+au+bv=0c_1 \alpha_1 + \cdots + c_m \alpha_m + a u + b v = 0

2. 考察标量 a,ba, b：若 a=0a = 0 且 b=0b = 0，则 ∑ciαi=0\sum c_i \alpha_i = 0。由 α\alpha 线性无关得所有 ci=0c_i = 0，与系数不全为零矛盾！因此 a,ba, b 不能同时为 0。

  • 情形一：若 b=0b = 0（此时必 a≠0a \neq 0），则 u=−a−1∑ciαiu = -a^{-1} \sum c_i \alpha_i，即 uu 可由 α\alpha 线性表示；
  • 情形二：若 a=0a = 0（此时必 b≠0b \neq 0），同理 vv 可由 α\alpha 线性表示；
  • 情形三：若 a≠0a \neq 0 且 b≠0b \neq 0。此时 v=−b−1(c1α1+…+au)v = -b^{-1}(c_1 \alpha_1 + \dots + a u)，说明 vv 可由 α1,…,αm,u\alpha_1, \dots, \alpha_m, u 线性表示；反之亦可解出 uu 由 α\alpha 与 vv 线性表示。故向量组 α1,…,αm,u\alpha_1, \dots, \alpha_m, u 与 α1,…,αm,v\alpha_1, \dots, \alpha_m, v 等价。

综上，命题成立。证毕。
