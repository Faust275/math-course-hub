第 2 题 截距倒数和为常数的定点证明 必做题 教材选编 2.2-3
#2
设动平面在三个坐标轴上的截距的倒数之和是一个常数 kk (k≠0k \neq 0)。
证明动平面必经过一定点，并求出该定点的坐标。
💡 课本提示：写出平面的截距式方程 xa+yb+zc=1\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1。已知条件为 1a+1b+1c=k\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = k。两式对比即可找出恒满足方程的坐标 (x,y,z)(x,y,z)。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】

【详细推理与解答】

证明与求解：

设动平面在三坐标轴上的截距分别为 a,b,ca, b, c（abc≠0abc \neq 0）。平面的截距式方程为：xa+yb+zc=1\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1

已知三截距的倒数之和为常数 kk (k≠0k \neq 0)：1a+1b+1c=k\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = k

两端同除以非零常数 kk：1/ka+1/kb+1/kc=1\frac{1/k}{a} + \frac{1/k}{b} + \frac{1/k}{c} = 1

将此式与平面的截距式方程对照，可知不论截距 a,b,ca, b, c 如何变动，恒有点 (x,y,z)=(1k,1k,1k)(x, y, z) = \left(\frac{1}{k}, \frac{1}{k}, \frac{1}{k}\right) 满足平面方程。

结论：动平面必经过空间定点 P(1k,1k,1k)P\left(\dfrac{1}{k}, \dfrac{1}{k}, \dfrac{1}{k}\right)。证毕。

第 6 题 等距动点轨迹（二面角平分面与平行平面中分面） 必做题 教材选编 2.2-10

(b) 解：

  • 令 x=z=0⇒y−2=0⇒y=2x = z = 0 \implies y - 2 = 0 \implies y = 2（截距 b=2b = 2）；
  • 令 x=y=0⇒λz−2=0⇒z=2λx = y = 0 \implies \lambda z - 2 = 0 \implies z = \frac{2}{\lambda}（截距 c=2λc = \frac{2}{\lambda}）。

该平面与三坐标平面围成的四面体为直角四面体，体积公式为：V=16|abc|=16|1×2×2λ|=23|λ|V = \frac{1}{6}|abc| = \frac{1}{6} \left| 1 \times 2 \times \frac{2}{\lambda} \right| = \frac{2}{3|\lambda|}

已知体积 V=2V = 2：23|λ|=2⇒3|λ|=1⇒|λ|=13⇒λ=±13\frac{2}{3|\lambda|} = 2 \implies 3|\lambda| = 1 \implies |\lambda| = \frac{1}{3} \implies \lambda = \pm \frac{1}{3}

将 λ=±13\lambda = \pm \frac{1}{3} 代入平面束方程：

  • 当 λ=13\lambda = \frac{1}{3} 时：2x+y+13z−2=0⇒6x+3y+z−6=02x + y + \frac{1}{3}z - 2 = 0 \implies 6x + 3y + z - 6 = 0；
  • 当 λ=−13\lambda = -\frac{1}{3} 时：2x+y−13z−2=0⇒6x+3y−z−6=02x + y - \frac{1}{3}z - 2 = 0 \implies 6x + 3y - z - 6 = 0。

结论：所求平面有两个，方程分别为 6x+3y+z−6=06x + 3y + z - 6 = 0 与 6x+3y−z−6=06x + 3y - z - 6 = 0。
