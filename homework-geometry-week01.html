二、向量的线性运算（第一次课）
本部分练习向量加法、数乘的基本运算及其在几何证明中的应用。
第 1 题 三角形中位线定理 必做题 📖 教材 第1章
#1
用向量法证明：任意三角形两边中点的连线平行于第三边，而且它的长等于第三边长的一半（三角形中位线定理）。
💡 课本提示：设 △ABC\triangle ABC 中 D,ED, E 分别为 AB,ACAB, AC 的中点。将中位线向量 DE→\overrightarrow{DE} 用基底向量 AB→,AC→\overrightarrow{AB}, \overrightarrow{AC} 表示，再与底边向量 BC→\overrightarrow{BC} 建立联系。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
本题考查向量减法与数乘的基本定义。通过引入三角形的两边作为基底，利用中点条件把动点向量拆解为基底的有理数乘，便能由数乘定义直接同时推出「共线平行」与「模长比例」两条几何结论。
【详细推理与解答】

证明：

设在 △ABC\triangle ABC 中，DD 为边 ABAB 的中点，EE 为边 ACAC 的中点。

由中点定义，有：AD→=12AB→, AE→=12AC→\overrightarrow{AD} = \frac{1}{2}\overrightarrow{AB},\quad \overrightarrow{AE} = \frac{1}{2}\overrightarrow{AC}

由向量减法的三角形法则，中位线向量为：DE→=AE→−AD→=12AC→−12AB→=12(AC→−AB→)\overrightarrow{DE} = \overrightarrow{AE} - \overrightarrow{AD} = \frac{1}{2}\overrightarrow{AC} - \frac{1}{2}\overrightarrow{AB} = \frac{1}{2}(\overrightarrow{AC} - \overrightarrow{AB})

又因底边向量 BC→=AC→−AB→\overrightarrow{BC} = \overrightarrow{AC} - \overrightarrow{AB}，故代入得：DE→=12BC→\overrightarrow{DE} = \frac{1}{2}\overrightarrow{BC}

由向量数乘的几何意义：

  • 因为 DE→=λBC→\overrightarrow{DE} = \lambda \overrightarrow{BC} 且 λ=12>0\lambda = \frac{1}{2} > 0，所以向量 DE→\overrightarrow{DE} 与 BC→\overrightarrow{BC} 同向共线，即 DE∥BCDE \parallel BC；
  • 取两端模长，得 |DE→|=|12BC→|=12|BC→||\overrightarrow{DE}| = |\frac{1}{2}\overrightarrow{BC}| = \frac{1}{2}|\overrightarrow{BC}|，即线段长度 DE=12BCDE = \frac{1}{2}BC。
证毕。

第 2 题 平行四边形中心向量恒等式 必做题 📖 教材 第1章
#2
设 PP 是平行四边形 ABCDABCD 的中心，OO 是任意一点。证明：OA→+OB→+OC→+OD→=4OP→\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD} = 4\overrightarrow{OP}
💡 课本提示：利用平行四边形对角线互相平分的性质，把左端每个向量通过点 PP 拆开：OX→=OP→+PX→\overrightarrow{OX} = \overrightarrow{OP} + \overrightarrow{PX}。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
平移或拆分参考原点是解析几何中最常用的技巧。平行四边形对角线互相平分意味着中心 PP 分别是对角线 ACAC 和 BDBD 的中点，即 PA→+PC→=0→\overrightarrow{PA}+\overrightarrow{PC}=\vec 0 且 PB→+PD→=0→\overrightarrow{PB}+\overrightarrow{PD}=\vec 0。
【详细推理与解答】

证明：

由向量加法首尾相接法则，对任意点 OO 均有：OA→=OP→+PA→\overrightarrow{OA} = \overrightarrow{OP} + \overrightarrow{PA}OB→=OP→+PB→\overrightarrow{OB} = \overrightarrow{OP} + \overrightarrow{PB}OC→=OP→+PC→\overrightarrow{OC} = \overrightarrow{OP} + \overrightarrow{PC}OD→=OP→+PD→\overrightarrow{OD} = \overrightarrow{OP} + \overrightarrow{PD}

四式相加，得：OA→+OB→+OC→+OD→=4OP→+(PA→+PB→+PC→+PD→)\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD} = 4\overrightarrow{OP} + (\overrightarrow{PA} + \overrightarrow{PB} + \overrightarrow{PC} + \overrightarrow{PD})

因为 PP 为平行四边形 ABCDABCD 的中心，对角线 ACAC 与 BDBD 互相平分且交于点 PP：

  • PP 是线段 ACAC 的中点 ⇒PA→+PC→=0→\implies \overrightarrow{PA} + \overrightarrow{PC} = \vec 0；
  • PP 是线段 BDBD 的中点 ⇒PB→+PD→=0→\implies \overrightarrow{PB} + \overrightarrow{PD} = \vec 0。

因此括号内向量和恒为零：(PA→+PC→)+(PB→+PD→)=0→+0→=0→(\overrightarrow{PA} + \overrightarrow{PC}) + (\overrightarrow{PB} + \overrightarrow{PD}) = \vec 0 + \vec 0 = \vec 0故原式成立：OA→+OB→+OC→+OD→=4OP→\overrightarrow{OA} + \overrightarrow{OB} + \overrightarrow{OC} + \overrightarrow{OD} = 4\overrightarrow{OP}。证毕。

第 3 题 正多边形中心的对称性与向量和 必做题 📖 教材 第1章
#3
设 OO 是平面上正多边形 A1A2⋯AnA_1A_2\cdots A_n 的中心。
(1) 证明：OA1→+OA2→+⋯+OAn→=0→\overrightarrow{OA_1} + \overrightarrow{OA_2} + \cdots + \overrightarrow{OA_n} = \vec 0；
(2) 设 PP 是任意一点，证明：PA1→+PA2→+⋯+PAn→=nPO→\overrightarrow{PA_1} + \overrightarrow{PA_2} + \cdots + \overrightarrow{PA_n} = n\overrightarrow{PO}。
💡 课本提示：(1) 利用旋转对称性：将整个多边形绕中心 OO 旋转角度 2πn\frac{2\pi}{n}，多边形与自身重合，和向量若非零必随之旋转，导出矛盾；(2) 类似第 2 题，将 PAi→\overrightarrow{PA_i} 拆成 PO→+OAi→\overrightarrow{PO} + \overrightarrow{OA_i}。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
正多边形具有严格的 CnC_n 阶旋转对称群。若一个几何向量在非恒等保距旋转下保持不变，该向量只能是零向量。第 (2) 问则是重心的仿射投影性质推广。
【详细推理与解答】

(1) 证明：

记向量和为 S→=∑i=1nOAi→\vec S = \sum_{i=1}^n \overrightarrow{OA_i}。

将整个正 nn 边形绕其外心 OO 逆时针旋转角 α=2πn\alpha = \frac{2\pi}{n}。由正多边形的旋转对称性，各顶点映射为下一个顶点：

OA1→↦OA2→,OA2→↦OA3→,…,OAn→↦OA1→\overrightarrow{OA_1} \mapsto \overrightarrow{OA_2},\ \overrightarrow{OA_2} \mapsto \overrightarrow{OA_3},\ \dots,\ \overrightarrow{OA_n} \mapsto \overrightarrow{OA_1}

由于向量加法满足交换律，旋转后的向量和仍等于各个像向量之和，即旋转前后的和向量相等：ℛα(S→)=S→\mathcal{R}_{\alpha}(\vec S) = \vec S。

若 S→≠0→\vec S \neq \vec 0，则将非零向量 S→\vec S 绕定点旋转非零角 α=2πn∈(0,2π)\alpha = \frac{2\pi}{n} \in (0, 2\pi) 后，其方向必定发生改变，不可能等于原向量 S→\vec S。矛盾！因此必有：

S→=OA1→+OA2→+…+OAn→=0→\vec S = \overrightarrow{OA_1} + \overrightarrow{OA_2} + \dots + \overrightarrow{OA_n} = \vec 0

(2) 证明：

对平面内任意点 PP，将每个向量通过中心点 OO 进行分解：PAi→=PO→+OAi→ (i=1,2,…,n)\overrightarrow{PA_i} = \overrightarrow{PO} + \overrightarrow{OA_i}\quad (i=1, 2, \dots, n)

两端对 ii 从 11 到 nn 求和：∑i=1nPAi→=∑i=1n(PO→+OAi→)=nPO→+∑i=1nOAi→\sum_{i=1}^n \overrightarrow{PA_i} = \sum_{i=1}^n (\overrightarrow{PO} + \overrightarrow{OA_i}) = n\overrightarrow{PO} + \sum_{i=1}^n \overrightarrow{OA_i}

由第 (1) 问结论，∑i=1nOAi→=0→\sum_{i=1}^n \overrightarrow{OA_i} = \vec 0，故立即得到：∑i=1nPAi→=nPO→\sum_{i=1}^n \overrightarrow{PA_i} = n\overrightarrow{PO}证毕。

第 4 题 向量三角不等式与等号充要条件 必做题 补充
#4
设 a→,b→\vec a, \vec b 为任意两个向量。
(1) 证明三角不等式 |a→+b→|≤|a→|+|b→||\vec a + \vec b| \le |\vec a| + |\vec b|；
(2) 给出上式等号成立的充要条件；
(3) 给出 |a→+b→|=||a→|−|b→|||\vec a + \vec b| = ||\vec a| - |\vec b|| 成立的充要条件。
💡 课本提示：利用向量加法的三角形法则，当 a→,b→\vec a, \vec b 不共线时，它们与和向量构成三角形三边（两边之和大于第三边）；当共线时退化为同向或反向的实数运算。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
欧氏空间赋范性质的核心公理。几何上由欧氏「三角形任意两边之和大于第三边」决定，代数上亦可通过数量积或柯西不等式证明。
【详细推理与解答】

解与证明：

(1) 证明：

  • 若 a→=0→\vec a = \vec 0 或 b→=0→\vec b = \vec 0，不妨设 b→=0→\vec b = \vec 0，则 |a→+0→|=|a→|=|a→|+0=|a→|+|b→||\vec a+\vec 0| = |\vec a| = |\vec a| + 0 = |\vec a| + |\vec b|，等式直接成立；
  • 若 a→,b→\vec a, \vec b 非零且不共线：由三角形法则，作 OA→=a→,AB→=b→\overrightarrow{OA}=\vec a, \overrightarrow{AB}=\vec b，则 OB→=a→+b→\overrightarrow{OB}=\vec a+\vec b。点 O,A,BO,A,B 构成不退化的三角形，由初等几何定理「三角形任意两边之和大于第三边」，线段长度满足 OB<OA+ABOB < OA + AB，即 |a→+b→|<|a→|+|b→||\vec a+\vec b| < |\vec a| + |\vec b|；
  • 若 a→,b→\vec a, \vec b 非零且共线：设 b→=ka→\vec b = k\vec a (k∈ℝ,k≠0k \in \mathbb{R}, k \neq 0)，则 |a→+b→|=|(1+k)a→|=|1+k||a→||\vec a+\vec b| = |(1+k)\vec a| = |1+k||\vec a|，而右边 |a→|+|b→|=(1+|k|)|a→||\vec a|+|\vec b| = (1+|k|)|\vec a|。由实数绝对值性质 |1+k|≤1+|k||1+k| \le 1+|k|，乘上 |a→|>0|\vec a|>0 得 |a→+b→|≤|a→|+|b→||\vec a+\vec b| \le |\vec a|+|\vec b|。

综上，对任意两个向量恒有 |a→+b→|≤|a→|+|b→||\vec a+\vec b| \le |\vec a|+|\vec b|。

(2) 等号成立的充要条件：

由上述讨论，等号成立当且仅当 |1+k|=1+|k||1+k| = 1+|k|，即 k≥0k \ge 0。因此充要条件为：a→\vec a 与 b→\vec b 同向共线（即存在非负实数 λ≥0\lambda \ge 0，使得 a→=λb→\vec a = \lambda\vec b 或 b→=λa→\vec b = \lambda\vec a，包含至少一个为零向量的情形）。

(3) |a→+b→|=||a→|−|b→|||\vec a+\vec b| = ||\vec a|-|\vec b|| 成立的充要条件：

充要条件为：a→\vec a 与 b→\vec b 反向共线（即存在非正实数 λ≤0\lambda \le 0，使得 a→=λb→\vec a = \lambda\vec b 或 b→=λa→\vec b = \lambda\vec a）。几何上此时点 BB 落在线段 OAOA 上或其延长线上，和向量的长度等于两模长之差的绝对值。

第 5 题 向量共线与线性相关性判断 必做题 📖 教材 第1章
#5
已知向量 a→=1e→−22e→+33e→\vec a = \vec e_1 - 2\vec e_2 + 3\vec e_3，b=21e→+3e→b = 2\vec e_1 + \vec e_3，c=61e→−22e→+63e→c = 6\vec e_1 - 2\vec e_2 + 6\vec e_3，其中 1e→,2e→,3e→\vec e_1, \vec e_2, \vec e_3 不共面。
判断 a→+b→\vec a + \vec b 与 c→\vec c 是否共线，并说明理由。
💡 课本提示：先求出 a→+b→\vec a + \vec b 在基底 1e→,2e→,3e→\vec e_1, \vec e_2, \vec e_3 下的坐标表示，再检查它与 c→\vec c 的对应分量是否成比例。利用不共面基向量表示的唯一性定理。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
空间向量分解定理保证了在给定的不共面基底 {1e→,2e→,3e→}\{\vec e_1, \vec e_2, \vec e_3\} 下，任何向量的线性表出系数都是唯一确定的。因此向量共线等价于三维坐标分量成常数比例。
【详细推理与解答】

解：

首先计算向量和 a→+b→\vec a + \vec b：

a→+b→=(1e→−22e→+33e→)+(21e→+02e→+3e→)=31e→−22e→+43e→\vec a + \vec b = (\vec e_1 - 2\vec e_2 + 3\vec e_3) + (2\vec e_1 + 0\vec e_2 + \vec e_3) = 3\vec e_1 - 2\vec e_2 + 4\vec e_3

设 a→+b→\vec a + \vec b 与 c→\vec c 共线，则必存在实数 kk，使得：c→=k(a→+b→)\vec c = k(\vec a + \vec b)

代入已知 c→=61e→−22e→+63e→\vec c = 6\vec e_1 - 2\vec e_2 + 6\vec e_3 与求得的 a→+b→\vec a + \vec b：61e→−22e→+63e→=k(31e→−22e→+43e→)=3k1e→−2k2e→+4k3e→6\vec e_1 - 2\vec e_2 + 6\vec e_3 = k(3\vec e_1 - 2\vec e_2 + 4\vec e_3) = 3k\vec e_1 - 2k\vec e_2 + 4k\vec e_3

移项整理：(3k−6)1e→+(−2k+2)2e→+(4k−6)3e→=0→(3k - 6)\vec e_1 + (-2k + 2)\vec e_2 + (4k - 6)\vec e_3 = \vec 0

因为基底向量 1e→,2e→,3e→\vec e_1, \vec e_2, \vec e_3 不共面（线性无关），由空间向量唯一性定理，各系数必须全为零，即联立方程组：{3k−6=0⇒k=2−2k+2=0⇒k=14k−6=0⇒k=32\begin{cases} 3k - 6 = 0 \implies k = 2 \\ -2k + 2 = 0 \implies k = 1 \\ 4k - 6 = 0 \implies k = \frac{3}{2} \end{cases}

显然该方程组无解（k=2k=2 与 k=1k=1 矛盾）。

因此，不存在实数 kk 使得 c→=k(a→+b→)\vec c = k(\vec a + \vec b)，且 a→+b→≠0→\vec a+\vec b \neq \vec 0。结论：a→+b→\vec a + \vec b 与 c→\vec c 不共线。

第 6 题 三向量共面性与线性关系求解 必做题 📖 教材 第1章
#6
已知向量 a→,b→,c→\vec a, \vec b, \vec c 关于三个不共面向量 1e→,2e→,3e→\vec e_1, \vec e_2, \vec e_3 的分解式为：
(1) a→=21e→−2e→−3e→\vec a = 2\vec e_1 - \vec e_2 - \vec e_3，b→=−1e→+22e→−3e→\vec b = -\vec e_1 + 2\vec e_2 - \vec e_3，c→=−1e→−2e→+23e→\vec c = -\vec e_1 - \vec e_2 + 2\vec e_3；
(2) a→=1e→+2e→+3e→\vec a = \vec e_1 + \vec e_2 + \vec e_3，b→=2e→+3e→\vec b = \vec e_2 + \vec e_3，c→=−1e→+3e→\vec c = -\vec e_1 + \vec e_3。
分别判断 a→,b→,c→\vec a, \vec b, \vec c 是否共面；如果共面，写出它们之间的一个（系数不全为零的）线性关系。
💡 课本提示：利用基底分解定理，三向量共面当且仅当其关于基底的 3×33\times 3 系数矩阵行列式等于 0；或尝试观察三向量的线性组合能否凑出 0→\vec 0。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
三向量共面定理是线性代数中线性相关性的几何直观来源。对于 (1)，注意到三个向量中各分量之和具有轮换对称性，三个向量相加恰好为零；对于 (2)，计算行列式非零即可判定空间张成。
【详细推理与解答】

(1) 分析与求解：

计算三个向量的直接和：a→+b→+c→=(2−1−1)1e→+(−1+2−1)2e→+(−1−1+2)3e→=01e→+02e→+03e→=0→\vec a + \vec b + \vec c = (2 - 1 - 1)\vec e_1 + (-1 + 2 - 1)\vec e_2 + (-1 - 1 + 2)\vec e_3 = 0\vec e_1 + 0\vec e_2 + 0\vec e_3 = \vec 0

存在一组不全为零的数（全取 11），使得 a→+b→+c→=0→\vec a + \vec b + \vec c = \vec 0。这表明 a→,b→,c→\vec a, \vec b, \vec c 线性相关。

根据空间共面定理，向量 a→,b→,c→\vec a, \vec b, \vec c 共面，它们之间的一个非平凡线性关系为：a→+b→+c→=0→ (或 c→=−a→−b→)\vec a + \vec b + \vec c = \vec 0\quad (\text{或 } \vec c = -\vec a - \vec b)

(2) 分析与求解：

设存在实数 x,y,zx, y, z 使得 xa→+yb→+zc→=0→x\vec a + y\vec b + z\vec c = \vec 0。代入基底分量：x(1e→+2e→+3e→)+y(2e→+3e→)+z(−1e→+3e→)=0→x(\vec e_1+\vec e_2+\vec e_3) + y(\vec e_2+\vec e_3) + z(-\vec e_1+\vec e_3) = \vec 0(x−z)1e→+(x+y)2e→+(x+y+z)3e→=0→(x - z)\vec e_1 + (x + y)\vec e_2 + (x + y + z)\vec e_3 = \vec 0

因 1e→,2e→,3e→\vec e_1, \vec e_2, \vec e_3 不共面，对应系数行列式为：|10−1110111|=1·(1−0)−0+(−1)·(1−1)=1≠0\begin{vmatrix} 1 & 0 & -1 \\ 1 & 1 & 0 \\ 1 & 1 & 1 \end{vmatrix} = 1\cdot(1-0) - 0 + (-1)\cdot(1-1) = 1 \neq 0

行列式不为零，齐次线性方程组只有零解 x=y=z=0x=y=z=0。这表明 a→,b→,c→\vec a, \vec b, \vec c 线性无关。

结论：a→,b→,c→\vec a, \vec b, \vec c 不共面。

第 7 题 循环轮换差值向量的共面性证明 必做题 📖 教材 第1章
#7
设 1e→,2e→,3e→\vec e_1, \vec e_2, \vec e_3 不共面，a,b,ca, b, c 为实数。证明三个向量：u→=a1e→−b2e→, v→=b2e→−c3e→, w→=c3e→−a1e→\vec u = a\vec e_1 - b\vec e_2,\quad \vec v = b\vec e_2 - c\vec e_3,\quad \vec w = c\vec e_3 - a\vec e_1共面。
💡 课本提示：直接将这三个向量相加，观察和向量的形式。

【解题思路分析】
典型的轮换对称构型。三个循环相减的向量其代数和恒为零，这意味着它们直接构成了一个平面内的闭合三角形首尾相接回路，因而是必然共面的。
【详细推理与解答】

证明：

直接计算这三个向量的线性组合（各取系数为 11）：u→+v→+w→=(a1e→−b2e→)+(b2e→−c3e→)+(c3e→−a1e→)\vec u + \vec v + \vec w = (a\vec e_1 - b\vec e_2) + (b\vec e_2 - c\vec e_3) + (c\vec e_3 - a\vec e_1)

#8
在四面体 OABCOABC 中，设点 PP 是 △ABC\triangle ABC 的重心（三条中线的交点）。求向量 OP→\overrightarrow{OP} 关于向量 OA→,OB→,OC→\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC} 的分解式。
💡 课本提示：利用第二次课讲义中的重心定理结论：平面或空间中，三角形重心 PP 的位置向量等于三个顶点位置向量的算术平均值。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
空间任意四面体中，底面重心的空间向量分解是计算体积、截面以及质心坐标的基础模型。本题通过中位线或定比分点两次展开即可严谨证明。
【详细推理与解答】

解与证明：

设 MM 为边 BCBC 的中点。由中点公式，有：OM→=12(OB→+OC→)\overrightarrow{OM} = \frac{1}{2}(\overrightarrow{OB} + \overrightarrow{OC})

由平面几何性质，重心 PP 位于中线 AMAM 上，且分中线所成比为 AP:PM=2:1AP : PM = 2 : 1（定比分点 λ=2\lambda = 2）。

根据定比分点向量公式（讲义例 1）：OP→=OA→+2OM→1+2=13OA→+23OM→\overrightarrow{OP} = \frac{\overrightarrow{OA} + 2\overrightarrow{OM}}{1 + 2} = \frac{1}{3}\overrightarrow{OA} + \frac{2}{3}\overrightarrow{OM}

将 OM→\overrightarrow{OM} 的表达式代入上式：OP→=13OA→+23[12(OB→+OC→)]=13OA→+13OB→+13OC→\overrightarrow{OP} = \frac{1}{3}\overrightarrow{OA} + \frac{2}{3}\left[\frac{1}{2}(\overrightarrow{OB} + \overrightarrow{OC})\right] = \frac{1}{3}\overrightarrow{OA} + \frac{1}{3}\overrightarrow{OB} + \frac{1}{3}\overrightarrow{OC}

结论：向量 OP→\overrightarrow{OP} 关于 OA→,OB→,OC→\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC} 的分解式为：OP→=13OA→+13OB→+13OC→\overrightarrow{OP} = \frac{1}{3}\overrightarrow{OA} + \frac{1}{3}\overrightarrow{OB} + \frac{1}{3}\overrightarrow{OC}

第 9 题 三角形内心的空间向量质点重心表达式 必做题 📖 教材 第1章
#9
设 DD 是 △ABC\triangle ABC 的内心，OO 是空间任意一点。求证：OD→=aOA→+bOB→+cOC→a+b+c\overrightarrow{OD} = \frac{a\overrightarrow{OA} + b\overrightarrow{OB} + c\overrightarrow{OC}}{a + b + c}其中 a=|BC→|a = |\overrightarrow{BC}|，b=|CA→|b = |\overrightarrow{CA}|，c=|AB→|c = |\overrightarrow{AB}|。
💡 课本提示：设 ∠A\angle A 的平分线交 BCBC 于 EE。先由角平分线性质 BE:EC=c:bBE : EC = c : b 用定比分点公式求出 OE→\overrightarrow{OE}；再由内心性质 AD:DE=(b+c):aAD : DE = (b + c) : a 对 A,EA, E 两点再用一次定比分点公式。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
解析几何中的经典优美定理。它表明内心不仅是三内角平分线的交点，也是在三个顶点分别放置质量为对边长 a,b,ca, b, c 时的物理质心系统重心。
【详细推理与解答】

证明：

1. 设 ∠A\angle A 的内角平分线交对边 BCBC 于点 EE。由初等几何角平分线定理：BEEC=ABAC=cb\frac{BE}{EC} = \frac{AB}{AC} = \frac{c}{b}即点 EE 分有向线段 BC→\overrightarrow{BC} 的比为 λ1=cb\lambda_1 = \frac{c}{b}。

由定比分点公式，点 EE 关于参考点 OO 的位置向量为：OE→=OB→+λ1OC→1+λ1=OB→+cbOC→1+cb=bOB→+cOC→b+c\overrightarrow{OE} = \frac{\overrightarrow{OB} + \lambda_1\overrightarrow{OC}}{1 + \lambda_1} = \frac{\overrightarrow{OB} + \frac{c}{b}\overrightarrow{OC}}{1 + \frac{c}{b}} = \frac{b\overrightarrow{OB} + c\overrightarrow{OC}}{b + c}

2. 在 △ABE\triangle ABE 中，BDBD 平分 ∠B\angle B。再次利用角平分线定理，内心 DD 在线段 AEAE 上的分点比为：ADDE=ABBE\frac{AD}{DE} = \frac{AB}{BE}由 BE=cb+caBE = \frac{c}{b+c}a，得：ADDE=ccab+c=b+ca\frac{AD}{DE} = \frac{c}{\frac{ca}{b+c}} = \frac{b + c}{a}即点 DD 分有向线段 AE→\overrightarrow{AE} 的比为 λ2=b+ca\lambda_2 = \frac{b+c}{a}。

3. 对线段 AEAE 及其上的分点 DD 再次应用定比分点公式：OD→=OA→+λ2OE→1+λ2=OA→+b+caOE→1+b+ca=aOA→+(b+c)OE→a+b+c\overrightarrow{OD} = \frac{\overrightarrow{OA} + \lambda_2\overrightarrow{OE}}{1 + \lambda_2} = \frac{\overrightarrow{OA} + \frac{b+c}{a}\overrightarrow{OE}}{1 + \frac{b+c}{a}} = \frac{a\overrightarrow{OA} + (b+c)\overrightarrow{OE}}{a + b + c}

将第 1 步求得的 (b+c)OE→=bOB→+cOC→(b+c)\overrightarrow{OE} = b\overrightarrow{OB} + c\overrightarrow{OC} 代入分子，立即得到：OD→=aOA→+bOB→+cOC→a+b+c\overrightarrow{OD} = \frac{a\overrightarrow{OA} + b\overrightarrow{OB} + c\overrightarrow{OC}}{a + b + c}证毕。

第 10 题 空间四点共面的零和充要条件 必做题 📖 教材 第1章
#10
设 OPi→=ir→\overrightarrow{OP_i} = \vec r_i（i=1,2,3,4i = 1, 2, 3, 4）。试证：P1,P2,P3,P4P_1, P_2, P_3, P_4 四点共面的充要条件是存在不全为零的实数 λi\lambda_i（i=1,2,3,4i = 1, 2, 3, 4），使得：∑i=14λiir→=0→, ∑i=14λi=0\sum_{i=1}^4 \lambda_i \vec r_i = \vec 0,\quad \sum_{i=1}^4 \lambda_i = 0
💡 课本提示：四点共面 ⇔P1P2→,P1P3→,P1P4→\iff \overrightarrow{P_1P_2}, \overrightarrow{P_1P_3}, \overrightarrow{P_1P_4} 共面（线性相关）。注意 P1Pi→=ir→−1r→\overrightarrow{P_1P_i} = \vec r_i - \vec r_1，并取 λ1=−(λ2+λ3+λ4)\lambda_1 = -(\lambda_2 + \lambda_3 + \lambda_4)。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
仿射空间中点集共面最本质的代数表征——仿射组合（Affine Combination）。该定理保证了共面性判定与空间坐标原点 OO 的选取完全无关。
【详细推理与解答】

证明：

必要性（若四点共面，则存在满足条件的 λi\lambda_i）：

由四点共面定义，向量 P1P2→,P1P3→,P1P4→\overrightarrow{P_1P_2}, \overrightarrow{P_1P_3}, \overrightarrow{P_1P_4} 共面。根据共面定理，这三个向量线性相关，即存在不全为零的实数 k2,k3,k4k_2, k_3, k_4，使得：k2P1P2→+k3P1P3→+k4P1P4→=0→k_2\overrightarrow{P_1P_2} + k_3\overrightarrow{P_1P_3} + k_4\overrightarrow{P_1P_4} = \vec 0

利用位置向量展开 P1Pi→=ir→−1r→\overrightarrow{P_1P_i} = \vec r_i - \vec r_1：k2(2r→−1r→)+k3(3r→−1r→)+k4(4r→−1r→)=0→k_2(\vec r_2 - \vec r_1) + k_3(\vec r_3 - \vec r_1) + k_4(\vec r_4 - \vec r_1) = \vec 0−(k2+k3+k4)1r→+k22r→+k33r→+k44r→=0→-(k_2 + k_3 + k_4)\vec r_1 + k_2\vec r_2 + k_3\vec r_3 + k_4\vec r_4 = \vec 0

令：

λ1=−(k2+k3+k4), λ2=k2, λ3=k3, λ4=k4\lambda_1 = -(k_2 + k_3 + k_4),\quad \lambda_2 = k_2,\quad \lambda_3 = k_3,\quad \lambda_4 = k_4

因为 k2,k3,k4k_2, k_3, k_4 不全为零，所以 λ1,λ2,λ3,λ4\lambda_1, \lambda_2, \lambda_3, \lambda_4 亦不全为零。且显然满足：∑i=14λi=λ1+λ2+λ3+λ4=−(k2+k3+k4)+k2+k3+k4=0\sum_{i=1}^4 \lambda_i = \lambda_1 + \lambda_2 + \lambda_3 + \lambda_4 = -(k_2+k_3+k_4) + k_2 + k_3 + k_4 = 0∑i=14λiir→=0→\sum_{i=1}^4 \lambda_i \vec r_i = \vec 0

充分性（若存在满足两式的 λi\lambda_i，则四点必共面）：

已知存在不全为零的 λi\lambda_i 满足 ∑i=14λi=0\sum_{i=1}^4 \lambda_i = 0 和 ∑i=14λiir→=0→\sum_{i=1}^4 \lambda_i\vec r_i = \vec 0。

不妨设 λ1≠0\lambda_1 \neq 0（若 λ1=0\lambda_1=0，可重排顶点记号使系数非零者为第 1 个）。由 ∑λi=0\sum \lambda_i = 0，有 λ1=−(λ2+λ3+λ4)\lambda_1 = -(\lambda_2 + \lambda_3 + \lambda_4)。

代入向量和式：−(λ2+λ3+λ4)1r→+λ22r→+λ33r→+λ44r→=0→-(\lambda_2 + \lambda_3 + \lambda_4)\vec r_1 + \lambda_2\vec r_2 + \lambda_3\vec r_3 + \lambda_4\vec r_4 = \vec 0λ2(2r→−1r→)+λ3(3r→−1r→)+λ4(4r→−1r→)=0→\lambda_2(\vec r_2 - \vec r_1) + \lambda_3(\vec r_3 - \vec r_1) + \lambda_4(\vec r_4 - \vec r_1) = \vec 0λ2P1P2→+λ3P1P3→+λ4P1P4→=0→\lambda_2\overrightarrow{P_1P_2} + \lambda_3\overrightarrow{P_1P_3} + \lambda_4\overrightarrow{P_1P_4} = \vec 0

因为 λ1≠0\lambda_1 \neq 0，由 λ1=−(λ2+λ3+λ4)\lambda_1 = -(\lambda_2+\lambda_3+\lambda_4) 知 λ2,λ3,λ4\lambda_2, \lambda_3, \lambda_4 不可能全为零。

这表明向量 P1P2→,P1P3→,P1P4→\overrightarrow{P_1P_2}, \overrightarrow{P_1P_3}, \overrightarrow{P_1P_4} 线性相关，因而它们必共面，即四点 P1,P2,P3,P4P_1, P_2, P_3, P_4 共面。

综上，充要性得证。证毕。

第 11 题 Ceva 定理的向量比值充要性证明 选做题 补充·选做
#11
（Ceva 定理）设 P,Q,RP, Q, R 分别在 △ABC\triangle ABC 的边 BC,CA,ABBC, CA, AB 所在直线上，且均不与顶点重合。
证明：直线 AP,BQ,CRAP, BQ, CR 共点的充要条件是：ARRB·BPPC·CQQA=1\frac{AR}{RB} \cdot \frac{BP}{PC} \cdot \frac{CQ}{QA} = 1其中 ARRB\frac{AR}{RB} 等表示有向线段的数量比。
💡 课本提示：仿照第二次课例 5（Menelaus 定理）的方法：在平面外取点 OO，设三线共点于 MM，把 OM→\overrightarrow{OM} 沿不同路径用 OA→,OB→,OC→\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC} 表出，利用表示的唯一性比较系数。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
Ceva 定理与 Menelaus 定理是射影几何与仿射几何中的双子星定理。利用空间三不共面向量基底分解的唯一性，可以将复杂的几何共点关系转化为纯代数比例恒等式。
【详细推理与解答】

证明：

设分点比分别为：p=BPPC, q=CQQA, r=ARRBp = \frac{BP}{PC},\quad q = \frac{CQ}{QA},\quad r = \frac{AR}{RB}

在平面外任取一点 OO，使 OA→,OB→,OC→\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC} 不共面，构成空间的一组基底。

由定比分点公式，各分点的位置向量为：OP→=OB→+pOC→1+p, OQ→=OC→+qOA→1+q, OR→=OA→+rOB→1+r\overrightarrow{OP} = \frac{\overrightarrow{OB} + p\overrightarrow{OC}}{1 + p},\quad \overrightarrow{OQ} = \frac{\overrightarrow{OC} + q\overrightarrow{OA}}{1 + q},\quad \overrightarrow{OR} = \frac{\overrightarrow{OA} + r\overrightarrow{OB}}{1 + r}

1. 必要性（若三线共点于 MM，证明 pqr=1pqr=1）：

设 AP,BQ,CRAP, BQ, CR 交于点 MM。

  • 因为 MM 在直线 APAP 上，存在实数 k1k_1 使得 OM→=(1−k1)OA→+k1OP→\overrightarrow{OM} = (1-k_1)\overrightarrow{OA} + k_1\overrightarrow{OP}，代入 OP→\overrightarrow{OP} 得：OM→=(1−k1)OA→+k11+pOB→+k1p1+pOC→\overrightarrow{OM} = (1-k_1)\overrightarrow{OA} + \frac{k_1}{1+p}\overrightarrow{OB} + \frac{k_1 p}{1+p}\overrightarrow{OC}
  • 同理，MM 在直线 BQBQ 上，存在实数 k2k_2 使得：OM→=k2q1+qOA→+(1−k2)OB→+k21+qOC→\overrightarrow{OM} = \frac{k_2 q}{1+q}\overrightarrow{OA} + (1-k_2)\overrightarrow{OB} + \frac{k_2}{1+q}\overrightarrow{OC}
  • MM 在直线 CRCR 上，存在实数 k3k_3 使得：OM→=k31+rOA→+k3r1+rOB→+(1−k3)OC→\overrightarrow{OM} = \frac{k_3}{1+r}\overrightarrow{OA} + \frac{k_3 r}{1+r}\overrightarrow{OB} + (1-k_3)\overrightarrow{OC}

由于 OA→,OB→,OC→\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC} 不共面，OM→\overrightarrow{OM} 的分解式系数唯一。设 OM→=xOA→+yOB→+zOC→\overrightarrow{OM} = x\overrightarrow{OA} + y\overrightarrow{OB} + z\overrightarrow{OC}（其中 x+y+z=1x+y+z=1），比较上述各式关于各基底的系数：yz=1p⇒p=zy\frac{y}{z} = \frac{1}{p} \implies p = \frac{z}{y}zx=1q⇒q=xz\frac{z}{x} = \frac{1}{q} \implies q = \frac{x}{z}xy=1r⇒r=yx\frac{x}{y} = \frac{1}{r} \implies r = \frac{y}{x}

将三者相乘：p·q·r=zy·xz·yx=1p \cdot q \cdot r = \frac{z}{y} \cdot \frac{x}{z} \cdot \frac{y}{x} = 1即：ARRB·BPPC·CQQA=1\dfrac{AR}{RB} \cdot \dfrac{BP}{PC} \cdot \dfrac{CQ}{QA} = 1。必要性得证。

2. 充分性（若 pqr=1pqr=1，证明三线共点）：

设直线 APAP 与 BQBQ 相交于点 MM，连结 CMCM 并延长交 ABAB 于 R'R'。由必要性，直线 AP,BQ,CR'AP, BQ, CR' 共点于 MM，故必满足：AR'R'B·BPPC·CQQA=1\frac{AR'}{R'B} \cdot \frac{BP}{PC} \cdot \frac{CQ}{QA} = 1

又已知条件为：

ARRB·BPPC·CQQA=1\frac{AR}{RB} \cdot \frac{BP}{PC} \cdot \frac{CQ}{QA} = 1

两式相比，得：AR'R'B=ARRB\frac{AR'}{R'B} = \frac{AR}{RB}

由直线上定比分点的唯一性，点 R'R' 与点 RR 必然重合。因此直线 CRCR 与 CR'CR' 是同一条直线，即 CRCR 也必过点 MM。

综上，三线 AP,BQ,CRAP, BQ, CR 共点。充分性得证。证毕。
