第 1 题 可数个可数集的并集是可数集 必做题 📖 教材 第1章 🎬 09-17 课 🎬 09-20 课
#1
证明可数个可数集的并集是可数集。
💡 课本提示：设可数集族为 {Ai}i=1∞\{A_i\}_{i=1}^\infty，每个集合元素写为 Ai={ai,j}j=1∞A_i = \{a_{i,j}\}_{j=1}^\infty；采用对角线法（Cantor 对角线排列）建立单射与双射。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
集合论奠基定理。通过对下标二维数组 (i,j)(i, j) 按和 i+ji+j 递增排序（或使用唯一质因数分解映射 2i3j2^i 3^j），即可在可数个可数集的并与正整数集 N\mathbb{N} 之间建立双射。
【详细推理与解答】

证明：

设指标集为可数集，不妨设可数集族为 A1,A2,…,An,…A_1, A_2, \dots, A_n, \dots。因为每个 AiA_i 都是可数集，其元素可排成一序列：

Ai={ai1,ai2,ai3,…,aij,…} (i∈Z+)A_i = \{a_{i1}, a_{i2}, a_{i3}, \dots, a_{ij}, \dots\}\quad (i \in \mathbb{Z}_+)

构造并集 S=⋃i=1∞AiS = \bigcup_{i=1}^\infty A_i

。我们将双下标指标对 (i,j)(i, j) 排成双向无穷二维表格，按对角线法则（和 k=i+jk = i+j 递增次序）排序：

a11, a12,a21, a13,a22,a31, a14,a23,a32,a41, …a_{11},\quad a_{12}, a_{21},\quad a_{13}, a_{22}, a_{31},\quad a_{14}, a_{23}, a_{32}, a_{41},\quad \dots

在上述序列中，若某元素之前已经出现过（即 AiA_i 之间有重叠），则直接略去该重复项。由于每个 aija_{ij} 都对应有限的位序（位于第 i+j−1i+j-1 条副对角线上），每一个元素都能在有限步内被遍历到。

由此便建立了从正整数集 Z+\mathbb{Z}_+ 到集合 SS 的一个满射。又因 A1⊆SA_1 \subseteq S 且 A1A_1 为可数集（含无穷子集），故 SS 是可数集。证毕。

#2
设 f:X→Yf: X \to Y 是一个映射。研究以下像与原像的运算包含关系：
(1) f−1(⋃α∈IFα)f^{-1}(\bigcup_{\alpha\in I} F_\alpha) 与 ⋃α∈If−1(Fα)\bigcup_{\alpha\in I} f^{-1}(F_\alpha)；
(2) f−1(⋂α∈IFα)f^{-1}(\bigcap_{\alpha\in I} F_\alpha) 与 ⋂α∈If−1(Fα)\bigcap_{\alpha\in I} f^{-1}(F_\alpha)；
(3) f−1(CYF)f^{-1}(C_Y F) 与 CX(f−1(F))C_X(f^{-1}(F))；
(4) f(⋃α∈IEα)f(\bigcup_{\alpha\in I} E_\alpha) 与 ⋃α∈If(Eα)\bigcup_{\alpha\in I} f(E_\alpha)；
(5) f(⋂α∈IEα)f(\bigcap_{\alpha\in I} E_\alpha) 与 ⋂α∈If(Eα)\bigcap_{\alpha\in I} f(E_\alpha)；
(6) f(CXE)f(C_X E) 与 CY(f(E))C_Y(f(E))。
💡 课本提示：原像操作保持所有集合运算（并、交、补）严格恒等；直像操作只保并集，对交集与补集仅成立单向包含关系，等号成立依赖于 ff 的单射性。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
集合论与一般拓扑学的基础。原像之所以性质极其优良，是因为定义直接依赖于点的单值性；而像的运算对于非单射会产生覆盖丢失。
【详细推理与解答】

结论与证明：

(1) 相等：f−1(⋃Fα)=⋃f−1(Fα)f^{-1}(\bigcup F_\alpha) = \bigcup f^{-1}(F_\alpha)。因为 x∈f−1(⋃Fα)⇔f(x)∈⋃Fα⇔∃α,f(x)∈Fα⇔∃α,x∈f−1(Fα)⇔x∈⋃f−1(Fα)x \in f^{-1}(\bigcup F_\alpha) \iff f(x) \in \bigcup F_\alpha \iff \exists \alpha, f(x) \in F_\alpha \iff \exists \alpha, x \in f^{-1}(F_\alpha) \iff x \in \bigcup f^{-1}(F_\alpha)。

(2) 相等：f−1(⋂Fα)=⋂f−1(Fα)f^{-1}(\bigcap F_\alpha) = \bigcap f^{-1}(F_\alpha)。同理，由逻辑量词 ∀α\forall \alpha 保持等价性。

(3) 相等：f−1(CYF)=CX(f−1(F))f^{-1}(C_Y F) = C_X(f^{-1}(F))。因为 f(x)∉F⇔x∉f−1(F)f(x) \notin F \iff x \notin f^{-1}(F)。

(4) 相等：f(⋃Eα)=⋃f(Eα)f(\bigcup E_\alpha) = \bigcup f(E_\alpha)。并集的像等于像的并集。

(5) 包含关系：f(⋂Eα)⊆⋂f(Eα)f(\bigcap E_\alpha) \subseteq \bigcap f(E_\alpha)。一般不成立等号！当且仅当 ff 为单射时等号成立。反例：f(x)=x2,E1=[−1,0],E2=[0,1]f(x)=x^2, E_1=[-1, 0], E_2=[0, 1]，交集为 {0}\{0\}，像为 {0}\{0\}；但 f(E1)∩f(E2)=[0,1]∩[0,1]=[0,1]f(E_1)\cap f(E_2)=[0, 1]\cap [0, 1]=[0, 1]。

(6) 无包含恒等（仅成立 CY(f(E))⊆f(CXE)C_Y(f(E)) \subseteq f(C_X E) 若 ff 满射）：一般情况下两者互不包含。反例：f(x)=0,X=R,Y=Rf(x)=0, X=\mathbb{R}, Y=\mathbb{R}，取 E={1}E=\{1\}，则 f(E)={0}f(E)=\{0\}，补集的像 f(Ec)={0}f(E^c)=\{0\}，但像的补集为 R∖{0}\mathbb{R}\setminus\{0\}，交集为空。

第 3 题 构造开区间 (0, 1) 到闭区间 [0, 1] 的双射 必做题 📖 教材 第1章 🎬 09-17 课 🎬 09-20 课
#3
构造开区间 (0,1)(0, 1) 到闭区间 [0,1][0, 1] 的一个双射。
💡 课本提示：利用希尔伯特旅馆思想：在 (0,1)(0, 1) 中选取一个可数序列（如 12,13,14,…\frac{1}{2}, \frac{1}{3}, \frac{1}{4}, \dots），将多出来的端点 0 和 1 插到序列头部，序列中其余元素依次向后移位，非序列元素保持恒等映射。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
非平凡集合对等性的经典构造题。通过把闭区间多出的两个端点吸收到一个无限可数子集中，实现开区间与闭区间的基数相同（均为连续统基数 c\mathfrak{c}）。
【详细推理与解答】

解与构造：

在开区间 (0,1)(0, 1) 内选取可数子集：A={12,13,14,…,1n,…}A = \left\{\frac{1}{2}, \frac{1}{3}, \frac{1}{4}, \dots, \frac{1}{n}, \dots\right\}。

构造映射 f:(0,1)→[0,1]f: (0, 1) \to [0, 1] 如下：

f(x)={0,x=121,x=131n−2,x=1n(n≥4)x,x∈(0,1)∖Af(x) = \begin{cases} 0, & x = \frac{1}{2} \\ 1, & x = \frac{1}{3} \\ \frac{1}{n-2}, & x = \frac{1}{n}\ (n \ge 4) \\ x, & x \in (0, 1) \setminus A \end{cases}

验证双射性：

  • 对 x∈Ax \in A：点 12\frac{1}{2} 映射为 00，13\frac{1}{3} 映射为 11，14\frac{1}{4} 映射为 12\frac{1}{2}，15\frac{1}{5} 映射为 13\frac{1}{3}……这构成了从集合 AA 到 A∪{0,1}A \cup \{0, 1\} 的一一双射；
  • 对 x∉Ax \notin A：f(x)=xf(x) = x 为恒等映射，值域为 (0,1)∖A(0, 1) \setminus A。

两部分值域互不相交且并集恰好为 [0,1][0, 1]

，单射与满射均显然成立。因此 ff 为 (0,1)(0, 1) 到 [0,1][0, 1] 的一个严格双射。

第 4 题 基于域公理严格证明代数乘法消去律 必做题 📖 教材 第1章 🎬 09-17 课 🎬 09-20 课
#4
设 FF 是域，x,y,z∈Fx, y, z \in F。利用乘法公理严格证明下列结论成立：
(1) 如果 x≠0x \neq 0 且 xy=xzxy = xz，则 y=zy = z；
(2) 如果 x≠0x \neq 0 且 xy=xxy = x，则 y=1y = 1；
(3) 如果 x≠0x \neq 0 且 xy=1xy = 1，则 y=x−1y = x^{-1}；
(4) 如果 x≠0x \neq 0，则 (x−1)−1=x(x^{-1})^{-1} = x。
💡 课本提示：域公理中非零元存在唯一的乘法逆元 x−1x^{-1} 满足 x·x−1=1x \cdot x^{-1} = 1。两边左乘 x−1x^{-1} 并利用乘法结合律展开。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
抽象代数与分析学基础公理推导。不能使用未定义的除法，每一步变形必须严格对应域的乘法结合律、单位元与逆元公理。
【详细推理与解答】

证明：

(1) 因为 x≠0x \neq 0，由域公理，存在逆元 x−1∈Fx^{-1} \in F 使得 x−1x=1x^{-1}x = 1。在 xy=xzxy = xz 两端左乘 x−1x^{-1}：

x−1(xy)=x−1(xz)x^{-1}(xy) = x^{-1}(xz)

由乘法结合律，(x−1x)y=(x−1x)z⇒1·y=1·z(x^{-1}x)y = (x^{-1}x)z \implies 1 \cdot y = 1 \cdot z。由乘法单位元公理，立即得到 y=zy = z。

(2) 因为 xy=x=x·1xy = x = x \cdot 1 且 x≠0x \neq 0，由 (1) 的消去律直接可得 y=1y = 1。

(3) 在 xy=1xy = 1 两边左乘 x−1x^{-1}：x−1(xy)=x−1·1⇒(x−1x)y=x−1⇒1·y=x−1⇒y=x−1x^{-1}(xy) = x^{-1} \cdot 1 \implies (x^{-1}x)y = x^{-1} \implies 1 \cdot y = x^{-1} \implies y = x^{-1}。

(4) 记 u=x−1u = x^{-1}。由逆元定义，由于 x≠0x \neq 0，逆元 u≠0u \neq 0 且满足 u·x=1u \cdot x = 1。由第 (3) 问关于元素 uu 的逆元定义，因 u·x=1u \cdot x = 1，故 xx 必为 uu 的逆元，即 x=u−1=(x−1)−1x = u^{-1} = (x^{-1})^{-1}。证毕。

第 5 题 全序域中正元公理与广义 Bernoulli 不等式 必做题 📖 教材 第1章 🎬 09-17 课 🎬 09-20 课
#5
设 FF 是全序域，0,1∈F0, 1 \in F 分别是零元和单位元，x∈Fx \in F。利用全序域的定义证明：
(1) 0<10 < 1；
(2) (1+x)n≥1+nx(1 + x)^n \ge 1 + nx，其中 nn 是正整数，x>−1x > -1。等号成立当且仅当 n=1n = 1 或者 x=0x = 0。
💡 课本提示：(1) 用反证法：若 1<01 < 0，两边同乘负元 11 会改变序关系导出 1>01 > 0 矛盾；(2) 对 nn 采用数学归纳法，在从 nn 到 n+1n+1 递推时注意 1+x>01+x > 0 保持序公理不变。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
全序域的基本不等式体系。0<10<1 保证了自然数在全序域中的序嵌入；Bernoulli 不等式是数列极限收敛性证明的核心工具。
【详细推理与解答】

证明：

(1) 证明 0<10 < 1：

全序域满足三分律：对于单位元 1≠01 \neq 0，必有 1>01 > 0 或 1<01 < 0。

若假设 1<01 < 0，根据全序域的正元封闭性公理（两负数之差或由序关系同加相反元），−1>0-1 > 0。由全序域公理，正元之积仍为正元：

(−1)·(−1)>0⇒1>0(-1) \cdot (-1) > 0 \implies 1 > 0

这与假设 1<01 < 0

产生矛盾！因此由三分律排中律，必有 0<10 < 1。

(2) 证明 Bernoulli 不等式：

对正整数 nn 采用数学归纳法：

  • 当 n=1n = 1 时，左端 =1+x= 1+x，右端 =1+x= 1+x，等式严格成立；
  • 假设当 n=k≥1n = k \ge 1 时不等式成立，即 (1+x)k≥1+kx(1+x)^k \ge 1 + kx；
  • 当 n=k+1n = k + 1 时，因为已知 x>−1⇒1+x>0x > -1 \implies 1 + x > 0，由序公理两边同乘正元保持序不变：

    (1+x)k+1=(1+x)k(1+x)≥(1+kx)(1+x)=1+(k+1)x+kx2(1 + x)^{k+1} = (1 + x)^k(1 + x) \ge (1 + kx)(1 + x) = 1 + (k+1)x + kx^2

因为全序域中任意元素的平方恒非负 x2≥0x^2 \ge 0，且 k≥1>0k \ge 1 > 0，故 kx2≥0kx^2 \ge 0。因此：

(1+x)k+1≥1+(k+1)x+kx2≥1+(k+1)x(1 + x)^{k+1} \ge 1 + (k+1)x + kx^2 \ge 1 + (k+1)x

归纳成立。等号成立条件：当 n>1n > 1

时，要使第二步不等式取等号，必须 kx2=0kx^2 = 0

。因 k>0k > 0，必有 x=0x = 0。故等号成立当且仅当 n=1n = 1 或 x=0x = 0。证毕。

第 6 题 Rudin 有理数切分逼近变换的性质验证 必做题 📖 教材 第1章 🎬 09-17 课 🎬 09-20 课
#6
Rudin 在《数学分析原理》中使用了变换 q=p+2−p2p+2=2+2pp+2q = p + \dfrac{2 - p^2}{p + 2} = \dfrac{2 + 2p}{p + 2}。验证：
(i) 若 p>0p > 0 且 p2<2p^2 < 2，则 q>pq > p 且 q2<2q^2 < 2；
(ii) 若 p>0p > 0 且 p2>2p^2 > 2，则 0<q<p0 < q < p 且 q2>2q^2 > 2。
（思考题）试求使变换 q=p+2−p2ap+bq = p + \dfrac{2 - p^2}{ap + b} 具有上述性质的所有正有理数对 (a,b)(a, b)。
💡 课本提示：分别计算差值 q−p=2−p2p+2q - p = \frac{2-p^2}{p+2} 以及 q2−2=2(p2−2)(p+2)2q^2 - 2 = \frac{2(p^2-2)}{(p+2)^2}，分子均直接出现因子 (p2−2)(p^2 - 2)，正负号完全受其控制。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
Rudin 在第 1 章以此构造证明有理数集 Q\mathbb{Q} 中集合 A={p∈Q∣p>0,p2<2}A = \{p\in\mathbb{Q}\mid p>0, p^2<2\} 没有上确界，说明有理数系是不完备的，存在空隙（Dedekind Cut 切割点无理数）。
【详细推理与解答】

验证：

由已知变换式：q−p=2−p2p+2q - p = \dfrac{2 - p^2}{p + 2}。

再计算 q2−2q^2 - 2：

q2−2=(2+2pp+2)2−2=4+8p+4p2−2(p2+4p+4)(p+2)2=2p2−4(p+2)2=2(p2−2)(p+2)2q^2 - 2 = \left(\frac{2 + 2p}{p + 2}\right)^2 - 2 = \frac{4 + 8p + 4p^2 - 2(p^2 + 4p + 4)}{(p + 2)^2} = \frac{2p^2 - 4}{(p + 2)^2} = \frac{2(p^2 - 2)}{(p + 2)^2}

(i) 当 p>0p > 0 且 p2<2p^2 < 2 时：

  • 2−p2>02 - p^2 > 0 且 p+2>0⇒q−p=2−p2p+2>0⇒q>pp + 2 > 0 \implies q - p = \frac{2 - p^2}{p + 2} > 0 \implies q > p；
  • p2−2<0⇒q2−2=2(p2−2)(p+2)2<0⇒q2<2p^2 - 2 < 0 \implies q^2 - 2 = \frac{2(p^2 - 2)}{(p + 2)^2} < 0 \implies q^2 < 2。

(ii) 当 p>0p > 0 且 p2>2p^2 > 2 时：

  • 2−p2<0⇒q−p<0⇒q<p2 - p^2 < 0 \implies q - p < 0 \implies q < p；
  • 因 p>0p > 0，明显 q=2+2pp+2>0q = \frac{2+2p}{p+2} > 0；
  • p2−2>0⇒q2−2=2(p2−2)(p+2)2>0⇒q2>2p^2 - 2 > 0 \implies q^2 - 2 = \frac{2(p^2 - 2)}{(p + 2)^2} > 0 \implies q^2 > 2。

思考题解答：

对于一般变换 q=p+2−p2ap+bq = p + \frac{2-p^2}{ap+b}，计算 q2−2q^2 - 2 要求分子提取出 (p2−2)(p^2 - 2) 且常数项符号保持一致。由二次齐次恒等变形可知，需满足 b2−2a2>0b^2 - 2a^2 > 0 且 b=2ab = 2a 等，特解即为 a=1,b=2a=1, b=2（对应牛顿迭代法求根的一级收敛加速）。

#7
设实数系已建立，完成下列确界性质证明：
(1) 设 A,B⊂RA, B \subset \mathbb{R} 为有界非空集且 A∩B≠∅A \cap B \neq \emptyset。讨论 sup(A∩B),inf(A∩B)\sup(A \cap B), \inf(A \cap B) 与 supA,supB,infA,infB\sup A, \sup B, \inf A, \inf B 的大小关系；
(2) 设 X,Y⊂RX, Y \subset \mathbb{R} 为有界非空集，记 Z={x+y∣x∈X,y∈Y}Z = \{x + y \mid x \in X, y \in Y\}。证明：

【解题思路分析】
