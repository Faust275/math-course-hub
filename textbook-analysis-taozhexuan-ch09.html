§9.10 在无限处的极限

到目前为止，我们已经讨论了如果 x0x_0 是实数，当 x→x0x \to x_0 时，函数 f:X→Rf: X \to \mathbf{R} 有极限是什么意思。现在我们简单地讨论一下，当 x0x_0 等于 +∞+\infty 或 −∞-\infty 时取极限的意思（这是拓扑空间上关于连续函数的更一般理论中的一部分，参见13.5节）。

首先，我们需要一个概念，它描述了 +∞+\infty 或 −∞-\infty 附着于一个集合是什么意思。

定义 9.10.1（无限附着点）设 X 是 R 的一个子集， +∞+\infty 是际附着于 X 的，当且仅当对于任意的 M∈RM \in R 都存在一个 x∈Xx \in X 使得 x > M。 −∞-\infty 是附着于 X 的，当且仅当对于任意的 M∈RM \in R 都存在一个 x∈Xx \in X 使得 x < M。

换言之， +∞+\infty 是附着于 X 的，当且仅当 X 没有上界，即当且仅当 sup(X)=+∞\sup(X)=+\infty 。类似地， −∞-\infty 是附着于 X 的，当且仅当 X 没有下界，或者当且仅当 inf(X)=−∞\inf(X)=-\infty 。所以，一个集合是有界的，当且仅当 +∞+\infty 和 −∞-\infty 都不是它的附着点。
