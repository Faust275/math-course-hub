§4.1 整数

在第 2 章中我们给出了自然数系的大部分基本性质，但目前只能局限于进行加法和乘法运算。现在我们将引入一种新的运算，即减法运算，但是为了能够真正地进行这种运算，我们必须从自然数系转向一个更大的数系，即整数系。

非正式地说，整数可以通过两个自然数相减得到。例如，就像6-2是整数一样，3-5也应该是一个整数。这并非整数的完整定义，因为(a)它没有指出什么时候两个差是相等的（例如，我们应该知道为什么3-5等于2-4，但不等于1-6），(b)它没有指明如何对这些差进行算术运算（怎么把3-5加到6-2上）。另外，(c)这个定义是循环的，因为它需要用到减法的概念，而减法只有在整数概念建立之后才能充分地被定义。幸运的是，由于之前对整数有一定的了解，所以我们知道这些问题的答案应该是什么。为了回答(a)，我们从代数学的高级知识中了解到，当 a+d=c+ba+d=c+b 时，恰好有a-b=c-d，于是我们可以只利用加法的概念来描述差的相等。类似地，为了回答(b)，从代数学中我们了解到 (a−b)+(c−d)=(a+c)−(b+d)(a-b)+(c-d)=(a+c)-(b+d) 和 (a−b)(c−d)=(ac+bd)−(ad+bc)(a-b)(c-d)=(ac+bd)-(ad+bc) 。因此我们将利用已有的知识来构造整数的定义，这正是我们很快要做的事情。

我们还必须回答 (c)。为了解决这个问题, 我们将采取以下措施: 暂时不把整数写成差 a−ba - b 的形式, 而是用一个新的符号 a−ba - b 来定义整数。其中, — 是一个无意义的占位符, 它与平面上点的笛卡儿坐标符号 (x,y)(x, y) 中的逗号类似。稍后当我们定义减法时将会看到 a−ba - b 事实上就等于 a−ba - b , 从而我们就可以废弃符号 —。现在它只是用来避免循环论证。(这些设计类似于建造一幢大厦时所用的脚手架, 脚手架对于确保大厦被正确地建造起来暂时是必不可少的, 但是一旦大厦建成, 它们就会被扔掉而且永远不会再被使用。) 对于定义那些我们已经非常熟悉的事物, 好像没必要那么复杂, 但是我们还将再次使用这些设计去构造有理数, 而且了解这些构造方法对于后面几章的学习会很有帮助。

定义 4.1.1概念定义

（整数）整数是形如 a—b 的表达式 ①^{①} ，其中 a 和 b 都是自然数。两个整数被看作是相等的， a−b=c−da - b = c - d ，当且仅当 a+d=c+ba + d = c + b 。令 Z\mathbf{Z} 表示由全体整数构成的集合。

所以例如，3—5 是一个整数，并且它等于 2—4，这是因为 3+4=2+53 + 4 = 2 + 5 。另外，3—5 不等于 2—3，因为 3+3≠2+53 + 3 \neq 2 + 5 。这个符号看起来有些奇怪，而且还有一些缺陷。例如，3 目前还不是整数，因为它不是形如 a—b 的表达式！后面我们将纠正这些问题。

我们必须验证上面定义中“相等”的概念是合理的，还需要证明自反性、对称性、传递性和替换公理（参见A.7节）。我们来证明传递性公理，而把自反性和对称性的证明留作习题4.1.1。假设已知 a−b=c−da - b = c - d 和 c−d=e−fc - d = e - f ，于是有 a+d=c+ba + d = c + b 和 c+f=d+ec + f = d + e 。把这两个等式相加得到 a+d+c+f=c+b+d+ea + d + c + f = c + b + d + e 。根据命题2.2.6，我们可以消去 cc 和 dd ，从而得到 a+f=b+ea + f = b + e ，也就是 a−b=e−fa - b = e - f 。因此消去律被用来确保我们所定义的“相等”的概念是有意义的。关于替换公理，目前还无法对其进行证明，因为我们还没有定义整数上的任何运算。但是，当我们定义整数上的基本运算时，如加法、乘法和排序运算，就必须证明替换公理从而来保证我们给出的定义是有效的。（我们只需要在定义基本运算时做这件事；整数上更加高级的运算，如指数运算，将由这些基本运算来定义，所以我们不需要对高级运算重新证明替换公理。）

现在我们定义整数上的两种基本算术运算：加法和乘法。

定义 4.1.2概念定义

两个整数的和 (a—b)+(c—d)(a—b)+(c—d) 由下面这个式子来定义：

(a−b)+(c−d):=(a+c)−(b+d)(a - b) + (c - d) := (a + c) - (b + d)

两个整数的乘积 (a−b)×(c−d)(a - b) \times (c - d) 被定义为：

(a−b)×(c−d):=(ac+bd)−(ad+bc)(a - b) \times (c - d) := (a c + b d) - (a d + b c)

于是例如， (3−5)+(1−4)(3 - 5) + (1 - 4) 等于 4−94 - 9 。但是在接受这些定义之前，我们必须证明一件事：如果我们把其中一个整数换成与它相等的另一个整数，那么加法的和以及乘积保持不变。例如， 3−53 - 5 等于 2−42 - 4 ，于是 (3−5)+(1−4)(3 - 5) + (1 - 4) 应该与 (2−4)+(1−4)(2 - 4) + (1 - 4) 有相同的值，否则无法给出统一的加法定义。幸运的是，此事确实成立。

引理 4.1.3命题/引理

（加法和乘法是定义明确的）设 a、b、 a′a' 、 b′b' 、c、d 是自然数。如果 (a−b)=(a′−b′)(a-b)=(a'-b') ，那么有 (a−b)+(c−d)=(a′−b′)+(c−d)(a-b)+(c-d)=(a'-b')+(c-d) 和 (a−b)×(c−d)=(a′−b′)×(c−d)(a-b)\times(c-d)=(a'-b')\times(c-d) ，还有 (c−d)+(a−b)=(c−d)+(a′−b′)(c-d)+(a-b)=(c-d)+(a'-b') 和 (c−d)×(a−b)=(c−d)×(a′−b′)(c-d)\times(a-b)=(c-d)\times(a'-b') 。因此加法和乘法是定义明确的运算（相等的输入给出相等的输出）。

证明

为了证明 (a−b)+(c−d)=(a′−b′)+(c−d)(a - b) + (c - d) = (a' - b') + (c - d) ，我们分别对等号两端求值可得 (a+c)−(b+d)(a + c) - (b + d) 和 (a′+c)−(b′+d)(a' + c) - (b' + d) 。于是我们要证明的是 a+c+b′+d=a + c + b' + d = a′+c+b+da'+c+b+d 。又因为 (a−b)=(a′−b′)(a-b)=(a'-b') ，所以有 a+b′=a′+ba+b'=a'+b ，进而两端同时加上 c+dc+d 就得到 a+c+b′+d=a′+c+b+da+c+b'+d=a'+c+b+d 。现在我们证明 (a−b)×(c−d)=(a′−b′)×(c−d)(a-b)\times(c-d)=(a'-b')\times(c-d) 。该等式两端分别为 (ac+bd)−(ad+bc)(ac+bd)-(ad+bc) 和 (a′c+b′d)−(a′d+b′c)(a'c+b'd)-(a'd+b'c) ，于是我们要证明的是 ac+bd+a′d+b′c=a′c+b′d+ad+bcac+bd+a'd+b'c=a'c+b'd+ad+bc 。然而左端等于 c(a+b′)+d(a′+b)c(a+b')+d(a'+b) ，同时右端等于 c(a′+b)+d(a+b′)c(a'+b)+d(a+b') 。由于 a+b′=a′+ba+b'=a'+b ，所以上述等式两端相等。剩下的两个等式也可以采取类似的方法证明。

整数 n−0n - 0 与自然数 nn 具有相同的性质。事实上，我们可以证明 (n−0)+(m−0)=(n+m)−0(n - 0) + (m - 0) = (n + m) - 0 和 (n−0)×(m−0)=nm−0(n - 0) \times (m - 0) = nm - 0 。另外， (n−0)=(m−0)(n - 0) = (m - 0) 当且仅当 n=mn = m （用数学语言来描述它就是在自然数 nn 和形如 n−0n - 0 的整数之间存在一个同构）。于是我们可以通过令 n≡n−0n \equiv n - 0 把自然数和整数等同起来，这并不会影响我们定义的加法、乘法或者相等的概念，因为它们彼此是一致的。例如，现在我们认为自然数3与整数3-0是相等的，于是 3=3−03 = 3 - 0 。特别地，0等于0-0，1等于1-0。当然，如果我们令 nn 等于 n−0n - 0 ，那么 nn 就与任何一个等于 n−0n - 0 的整数相等，例如3不仅等于3-0，它还等于4-1、5-2等。

现在我们可以把整数上的增量运算定义为 x++:=x+1x++:=x+1 ，其中 x 是任意整数。这当然与我们所定义的自然数上的增量运算是一致的。但是对我们而言，这已经不再是一个重要的运算，因为现在它已经被更一般的加法概念取代了。

现在我们考虑整数上其他的基本运算。

定义 4.1.4概念定义

（整数的负运算）如果 (a—b)(a—b) 是一个整数，那么我们定义它的负数 −(a—b)-(a—b) 为整数 (b—a)(b—a) 。特别地，如果 n=n-0 是一个正自然数，那么我们可以定义它的负数为 -n=0-n。

例如， −(3−5)=(5−3)-(3-5)=(5-3) 。我们能够证明这个定义是明确的（习题4.1.2）。

现在我们可以证明整数恰好满足我们的期望。

引理 4.1.5命题/引理

（整数的三歧性）设 x 是一个整数，那么下述三个命题中恰好有一个为真：(a) x 是零；(b) x 是正自然数 n；(c) x 是正自然数 n 的负数 -n。

证明

我们首先证明 (a)、(b) 和 (c) 中至少有一个为真。根据定义，存在自然数 aa 和 bb 使得 x=a−bx = a - b 。我们有如下三种情况： a>ba > b 、 a=ba = b 或 a<ba < b 。如果 a>ba > b ，那么存在某个正自然数 cc 使得 a=b+ca = b + c ，这表明 a−b=c−0=ca - b = c - 0 = c ，于是 (b) 为真；如果 a=ba = b ，那么 a−b=a−a=0−0=0a - b = a - a = 0 - 0 = 0 ，于是 (a) 为真；如果 a<ba < b ，那么 b>ab > a ，于是根据与前面同理可知，存在某个正自然数 nn 使得 b−a=nb - a = n ，从而 a−b=−na - b = -n ，于是 (c) 为真。

现在我们证明 (a)、(b) 和 (c) 中同时成立的命题不超过一个。根据定义，一个正自然数是非零的，所以 (a) 和 (b) 不能同时为真。如果 (a) 和 (c) 同时为真，那么存在某个正自然数 nn 使得 0=−n0 = -n ；于是 0−0=0−n0 - 0 = 0 - n ，则 0+0=0+n0 + 0 = 0 + n ，从而 n=0n = 0 ，这里出现了矛盾。如果 (b) 和 (c) 同时为真，那么存在两个正自然数 nn 和 mm 使得 n=−mn = -m ，于是 (n−0)=(0−m)(n - 0) = (0 - m) ，从而 n+m=0+0n + m = 0 + 0 ，这与命题2.2.8矛盾。因此，对于任意的整数 xx ，(a)(b)(c) 中恰好有一个为真。

如果 nn 是一个正自然数，那么我们称 −n-n 为一个负整数。因此每一个整数是正的、零或负的，但是不可能同时有多于一种可能。

有人可能会问，我们为什么不利用引理 4.1.5 来定义整数。也就是说，我们为什么不定义整数就是正的自然数，或者零，或者自然数的负数。因为如果我们这样做了，那么“加上整数”和“乘以整数”的法则将会有许多不同的情况（例如，负数乘以负数等于正数；负数加上正数要么是负数，要么是正数，要么是零，这取决于哪一项的数值更大，等等。）而且证明所有这些性质将会造成很大的混乱。

现在我们对整数的代数性质进行总结。

命题 4.1.6命题

（整数的代数定律）设 x,y,zx, y, z 是整数，那么我们有

x+y=y+x(x+y)+z=x+(y+z)x+0=0+x=xx+(−x)=(−x)+x=0xy=yx(xy)z=x(yz)x1=1x=xx(y+z)=xy+xz(y+z)x=yx+zx\begin{array}{r l} x + y & = y + x \\ (x + y) + z & = x + (y + z) \\ x + 0 & = 0 + x = x \\ x + (- x) & = (- x) + x = 0 \\ x y & = y x \\ (x y) z & = x (y z) \\ x 1 & = 1 x = x \\ x (y + z) & = x y + x z \\ (y + z) x & = y x + z x \end{array}

注4.1.7 上述九个等式有一个统称，它们断定全体整数构成一个交换环。（如果我们删掉等式 xy=yxxy = yx ，那么只能断定全体整数构成一个环。）注意，其中某些等式已经被证明对于自然数是成立的，但是这不自动地表明它们对于整数也成立，因为整数集是一个比自然数集更大的集合。另外，这个命题取代了许多早先被推导出的关于自然数的命题。

证明

有两种方法来证明这些等式。一种方法是利用引理4.1.5并根据 x,y,zx, y, z 是否为零、正数或者负数，分成很多种情况来考虑。这将变得非常繁琐。一种简洁的方法是记 x=a−b,y=c−dx = a - b, y = c - d 以及 z=e−fz = e - f ，其中 a,b,c,d,e,fa, b, c, d, e, f 是自然数，然后把这些等式展开成关于 a,b,c,d,e,fa, b, c, d, e, f 的表达式并对它们运用自然数的代数定律。这种方法使得每一个等式能够在几行内就被证明。我们只证明最长的等式，即 (xy)z=x(yz)(xy)z = x(yz) 。

(xy)z=[(a−b)(c−d)](e−f)=[(ac+bd)−(ad+bc)](e−f)\begin{array}{r l} (x y) z & = [ (a - b) (c - d) ] (e - f) \\ & = [ (a c + b d) - (a d + b c) ] (e - f) \end{array}
=(ace+bde+adf+bcf)−(acf+bdf+ade+bce)x(yz)=(a−b)[(c−d))(e−f)]=(a−b)[(ce+df)−(cf+de)]=(ace+adf+bcf+bde)−(acf+ade+bce+bdf)\begin{array}{r l} & = (a c e + b d e + a d f + b c f) - (a c f + b d f + a d e + b c e) \\ x (y z) & = (a - b) [ (c - d)) (e - f) ] \\ & = (a - b) [ (c e + d f) - (c f + d e) ] \\ & = (a c e + a d f + b c f + b d e) - (a c f + a d e + b c e + b d f) \end{array}

于是 (xy)z(xy)z 和 x(yz)x(yz) 是相等的。其余的等式可以按照类似的方式来证明，参见习题4.1.4。

现在我们定义两个整数的减法运算 x−yx - y 为下面这个式子：

x−y:=x+(−y)x - y := x + (- y)

我们不需要证明减法运算遵守替换公理，因为我们已经利用整数上的另外两种运算（即加法和负运算）定义了减法运算，并且已经证明这两种运算是定义明确的。

现在我们很容易证明，如果 aa 和 bb 是自然数，那么

a−b=a+(−b)=(a−0)+(0−b)=a−ba - b = a + (- b) = (a - 0) + (0 - b) = a - b

从而 a—b 与 a-b 就是一回事。因此我们现在可以丢弃符号 —，改用我们所熟悉的减法运算符号。（正如前面已经注释过的，我们不会马上使用减法运算，因为这会导致循环论证。）

我们现在可以把引理 2.3.3 和推论 2.3.7 从自然数的情形推广到整数的情形。

现在我们按照逐字重复定义的方法，把曾经定义在自然数上序的概念推广到整数上。

定义 4.1.10概念定义

（整数的排序）设 n 和 m 是整数，我们称 n 大于或等于 m，记作 n≥mn \geqslant m 或者 m≤nm \leqslant n ，当且仅当存在某个自然数 a 使得 n=m+an = m + a 。我们称 n 严格大于 m，并记作 n > m 或者 m < n，当且仅当 n≥mn \geqslant m 且 n≠mn \neq m 。

于是例如，5 > -3，因为 5=−3+85 = -3 + 8 并且 5≠−35 \neq -3 。这个定义显然与自然数上序的概念是一致的，因为我们使用的是同一个定义。

利用命题 4.1.6 中的代数定律，不难证明下列序的性质。

引理 4.1.11命题/引理

（序的性质）设 a,b,ca, b, c 是整数。

  1. a > b 当且仅当 a - b 是一个正的自然数。

(b)（加法保持序不变）如果 a>ba > b ，那么 a+c>b+ca + c > b + c 。

  1. （正的乘法保持序不变）如果 a>ba > b 并且 cc 是正的，那么 ac>bcac > bc 。
  2. （负运算反序）如果 a > b，那么 -a < -b。

(e)（序是可传递的）如果 a>ba > b 且 b>cb > c ，那么 a>ca > c 。

  1. （序的三歧性）命题 a>ba > b 、 a<ba < b 和 a=ba = b 中恰有一个为真。
