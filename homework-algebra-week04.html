一、有理多项式不可约性判别
第 1 题 平移变换保持本原多项式性质证明 (习题 3.8 第 1 题) 必做题 📖 教材 §3.8 🎬 09-21 课 🎬 09-24 课
#1
若f(x)是本原多项式，证明f(x+1)也是本原多项式.
💡 课本提示：若 f(x+1)f(x+1) 不是本原的，其系数有公共素因子 pp。在 ℤp[x]\mathbb{Z}_p[x] 中考察模化多项式，代入换元 y=x+1y = x+1 产生矛盾。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
系数约化模同态 ℤ[x]→ℤp[x]\mathbb{Z}[x] \to \mathbb{Z}_p[x] 的保同构性质。平移同构 x↦x+1x \mapsto x+1 保持理想与内容（Content）不变。
【详细推理与解答】

证明：

1. 设 f(x)∈ℤ[x]f(x) \in \mathbb{Z}[x] 是本原多项式，即其所有系数的最大公约数为 1。考虑自然模同态 πp:ℤ[x]→ℤp[x]\pi_p: \mathbb{Z}[x] \to \mathbb{Z}_p[x]，本原性等价于对任意素数 pp，πp(f(x))≠0\pi_p(f(x)) \neq 0。

2. 反证法：若 f(x+1)f(x+1) 不是本原多项式，则存在素数 pp 整除 f(x+1)f(x+1) 的所有系数，即在 ℤp[x]\mathbb{Z}_p[x] 中有 πp(f(x+1))=0\pi_p(f(x+1)) = 0。

3. 令新未定元 y=x+1y = x + 1。因自同构 x↦x−1x \mapsto x - 1 是可逆变量代换，若多项式在变量代换后恒为零多项式，则原多项式在 ℤp[y]\mathbb{Z}_p[y] 中也必须为零多项式：πp(f(y))=0\pi_p(f(y)) = 0

4. 这意味着素数 pp 整除 f(y)f(y) 的所有系数，与 f(x)f(x) 是本原多项式矛盾！故 f(x+1)f(x+1) 必为本原多项式。证毕。

代数数论与多项式因式分解的经典练习，结合 Eisenstein 判别法与待定系数法。
【详细推理与解答】

解与证明：

(ii) 对 x6+x3+1x^6 + x^3 + 1：

• 令 y=x3y = x^3，原式为 y2+y+1y^2 + y + 1。注意到 (x3−1)(x6+x3+1)=x9−1(x^3 - 1)(x^6 + x^3 + 1) = x^9 - 1。故其根为 9 次本原单位根（阶为 9），即 Φ9(x)=x6+x3+1\Phi_9(x) = x^6 + x^3 + 1 是第 9 个圆分多项式。

(iii) 对 f(x)=xp+px+2p−1f(x) = x^p + px + 2p - 1：

• 作变量平移或直接模 pp：在 ℤp[x]\mathbb{Z}_p[x] 中，f¯(x)=xp−1=(x−1)p\bar{f}(x) = x^p - 1 = (x - 1)^p。因此 f(x)f(x) 在 ℚ\mathbb{Q} 上的任何可能因式在模 pp 后都必须形如 (x−1)k(x - 1)^k。

• 平移 x=y+1x = y + 1，展开后常数项为 f(1)=1+p+2p−1=3pf(1) = 1 + p + 2p - 1 = 3p。由 Eisenstein 判别法（取素数 p≥5p \ge 5 时），p∣3pp \mid 3p 但 p2∤3pp^2 \nmid 3p，故在 ℚ\mathbb{Q} 上不可约。证毕。

5. 故假设不成立，必有 degg(x)≥k\deg g(x) \ge k。即 f(x)f(x) 必含一个次数不低于 kk 的不可约因式。证毕。

#4
设n次整系数多项式函数f(x)在多于 n个整数处取值为1或-1,其中n≥1. 求证：多项式f(x)在Q上不可约.
💡 课本提示：反证法：设 f(x)=g(x)h(x)f(x) = g(x)h(x)（degg,degh≥1\deg g, \deg h \ge 1）。若 f(ai)=±1f(a_i) = \pm 1，则必有 g(ai)=±1,h(ai)=±1g(a_i) = \pm 1, h(a_i) = \pm 1。考察多项式 g(x)−h(x)g(x) - h(x) 或 g(x)+h(x)g(x) + h(x) 的根的个数。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
Polya 不可约性定理的基石思路。利用代数基本定理对多项式零点个数的硬性上限与点集稠密性推导矛盾。
【详细推理与解答】

证明：

1. 设 f(x)∈ℤ[x]f(x) \in \mathbb{Z}[x] 为 nn 次多项式，若它在 ℚ\mathbb{Q} 上可约，由 Gauss 引理，存在整系数多项式分解 f(x)=g(x)h(x)f(x) = g(x)h(x)，其中 1≤degg=r<n1 \le \deg g = r < n 且 1≤degh=s<n1 \le \deg h = s < n（r+s=nr + s = n）。

2. 已知存在 m>nm > n 个相异整数 c1,c2,…,cmc_1, c_2, \dots, c_m 使得 f(ck)=±1f(c_k) = \pm 1。因为 g(ck),h(ck)g(c_k), h(c_k) 均为整数，其乘积为 ±1\pm 1，故必有：g(ck)=±1, h(ck)=±1g(c_k) = \pm 1, \quad h(c_k) = \pm 1

3. 考察这 mm 个点处 gg 与 hh 的取值关系：或者 g(ck)+h(ck)=0g(c_k) + h(c_k) = 0，或者 g(ck)−h(ck)=0g(c_k) - h(c_k) = 0。将这 mm 个点划分为两个子集：S1={k∣g(ck)=h(ck)}S_1 = \{k \mid g(c_k) = h(c_k)\} 与 S2={k∣g(ck)=−h(ck)}S_2 = \{k \mid g(c_k) = -h(c_k)\}。由抽屉原理，必有至少一个集合的元素个数 ≥⌈m/2⌉\ge \lceil m/2 \rceil。

4. 若考虑多项式 P(x)=g(x)2−1P(x) = g(x)^2 - 1：在这 m>nm > n 个点上恒有 P(ck)=0P(c_k) = 0。但 degP(x)=2r≤2(n−1)\deg P(x) = 2r \le 2(n-1)。若直接考察 g(x)−h(x)g(x) - h(x)，由于次数 ≤max(r,s)<n\le \max(r, s) < n，只要点数超过 nn，由代数基本定理即恒等为 0，推出 f(x)=g(x)2≥0f(x) = g(x)^2 \ge 0，与取 −1-1 矛盾；若取值全为 +1+1，则 g(x)=1g(x) = 1，推出 gg 为常数，与不可约矛盾！故 f(x)f(x) 必不可约。证毕。

二、线性空间公理与子空间
第 5 题 加群上有限域与有理域线性空间结构存在充要条件 (习题 4.1 第 6 题) 必做题 📖 教材 §4.1 🎬 10-15 课 🎬 10-19 课
#5
证明如下结论： (i)在加群(A,+)上可定义有限域Z上的线性空间结构，当且仅当对任意a∈A, 有pa=0; (ii)在加群(A,+)上可定义Q上的线性空间结构，当且仅当对任意非零元a∈ A 及正整数n,有na≠0并且方程nx=a在A中有解.
💡 课本提示：(i) 特征 pp 域数乘要求 1·a=a1 \cdot a = a 且 p·a=0p \cdot a = 0；(ii) ℚ\mathbb{Q}-线性空间要求加群可除（Divisible）且无挠（Torsion-free）。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
深刻揭示了模与线性空间的本质联系：模是环上的加群，而线性空间是域上的加群。代数学中将抽象阿贝尔群赋予向量空间结构的充要条件。
【详细推理与解答】

证明：

(i) ℤp\mathbb{Z}_p 结构：

• 必要性：若 (A,+)(A, +) 是 ℤp\mathbb{Z}_p-线性空间。由数乘公理：pa=(1+1+⋯+1)a=0ℤp·a=0pa = (1 + 1 + \cdots + 1)a = 0_{\mathbb{Z}_p} \cdot a = 0

• 充分性：若对任意 a∈Aa \in A 均有 pa=0pa = 0。定义模 pp 的数乘：对 k¯∈ℤp\bar{k} \in \mathbb{Z}_p，定义 k¯·a=ka\bar{k} \cdot a = ka。若 k1≡k2(modp)k_1 \equiv k_2 \pmod p，则 k1−k2=qpk_1 - k_2 = qp，从而 (k1−k2)a=q(pa)=0(k_1 - k_2)a = q(pa) = 0，数乘良定。易逐条验证数乘公理成立，故构成线性空间。

(ii) ℚ\mathbb{Q} 结构：

• 必要性：若 AA 是 ℚ\mathbb{Q}-线性空间。非零标量数乘单射性保证 na=0⇒a=0na = 0 \implies a = 0（无挠）；且对任意 aa，解方程 nx=anx = a 有唯一解 x=1na∈Ax = \frac{1}{n}a \in A（可除）。

• 充分性：若方程 nx=anx = a 始终有唯一解，记该解为 1na\frac{1}{n}a。对任意有理数 r=mnr = \frac{m}{n}，定义 ra=m(1na)ra = m(\frac{1}{n}a)。由于解唯一且加群无挠，该数乘良定且满足全部向量空间公理。证毕。

📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
代数拓扑与测度论的核心引理：无限域上的向量空间永远不可能被有限个真子空间覆盖（Birkhoff 定理）。
【详细推理与解答】

证明：

(i) 证明 W≠VW \neq V：

对子空间个数 kk 作归纳。k=1k=1 显然成立。假设对 k−1k-1 个真子空间成立，即它们不能覆盖全空间，且可假定没有多余冗余子空间。取向量 u∉⋃i=1kViu \notin \bigcup_{i=1}^k V_i（若已被覆盖则假设矛盾），考察两个向量：取 v1∈V1∖⋃i=2kViv_1 \in V_1 \setminus \bigcup_{i=2}^k V_i 及 v2∉V1v_2 \notin V_1。
