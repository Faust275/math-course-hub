二、柱面与圆柱面
本部分练习由准线与母线方向求柱面方程、切柱面与圆柱面的几何构造。
第 1 题 由准线与母线方向求柱面方程 必做题 📖 教材 §3.1
#1
求下列柱面的方程：
(1) 准线为 {x2=2zy=0\begin{cases} x^2 = 2z \\ y = 0 \end{cases}，母线平行于 yy 轴；
(2) 准线为 {x+y−z−1=0x−y+z=0\begin{cases} x + y - z - 1 = 0 \\ x - y + z = 0 \end{cases}，母线平行于直线 x=y=zx = y = z。
💡 课本提示：对于 (1)，母线平行于缺少的变量轴，方程直接为准线在坐标面上的曲线方程；对于 (2)，先求准线的方向向量，与母线方向对比。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
柱面母线方向平行于准线本身时，动直线沿自身移动退化为直线自身或平面。这是考查柱面定义退化判定的经典陷阱题。
【详细推理与解答】

(1) 解：

准线为 xOyxOy 面（y=0y=0）上的抛物线 x2=2zx^2 = 2z。母线平行于 yy 轴，因此曲面上任意点沿着平行于 yy 轴方向移动，其 xx 与 zz 坐标保持不变。

柱面方程中不含变量 yy，方程直接为：x2=2zx^2 = 2z（抛物柱面）。

(2) 解：

准线是两平面的交线：π1:x+y−z−1=0\pi_1: x+y-z-1=0，π2:x−y+z=0\pi_2: x-y+z=0。

求准线的方向向量：

Cv→=1n→×2n→=(1,1,−1)×(1,−1,1)=(0,−2,−2)=−2(0,1,1)\vec v_C = \vec n_1 \times \vec n_2 = (1, 1, -1) \times (1, -1, 1) = (0, -2, -2) = -2(0, 1, 1)

母线方向为 a→=(1,1,1)\vec a = (1, 1, 1)。两方向不平行，母线与准线相交生成柱面。

设面上动点为 M(x,y,z)M(x, y, z)，母线交准线于 M1(x1,y1,z1)M_1(x_1, y_1, z_1)，则 x1=x+t,y1=y+t,z1=z+tx_1 = x + t, y_1 = y + t, z_1 = z + t。

代入两平面方程：{(x+t)+(y+t)−(z+t)−1=0⇒x+y−z−1+t=0(x+t)−(y+t)+(z+t)=0⇒x−y+z+t=0\begin{cases} (x+t) + (y+t) - (z+t) - 1 = 0 \implies x + y - z - 1 + t = 0 \\ (x+t) - (y+t) + (z+t) = 0 \implies x - y + z + t = 0 \end{cases}

两式相减消去参数 tt：(x+y−z−1)−(x−y+z)=0⇒2y−2z−1=0(x + y - z - 1) - (x - y + z) = 0 \implies 2y - 2z - 1 = 0

结论：所求柱面方程为 2y−2z−1=02y - 2z - 1 = 0（这是一张平行于母线与准线的平面柱面）。

第 2 题 给定方向的球面外切柱面方程 必做题 📖 教材 §3.1
#2
已知球面 SS 的半径为 22，球心为 C(0,1,−1)C(0, 1, -1)。
求母线平行于向量 v→=(1,1,1)\vec v = (1, 1, 1) 且与球面 SS 相切的（切）柱面的方程。
💡 课本提示：母线与球面相切 ⇔\iff 经过球心作平行于 v→\vec v 的直线（轴），切柱面上任一点到轴的距离恒等于球半径 R=2R = 2。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
球面的切柱面本质上是以过球心且平行于母线方向的直线为轴、半径等于球半径的圆柱面。
【详细推理与解答】

解：

由几何性质，平行于 v→=(1,1,1)\vec v = (1, 1, 1) 且与球面相切的切柱面，其轴必过球心 C(0,1,−1)C(0, 1, -1)，且方向向量为 v→=(1,1,1)\vec v = (1, 1, 1)，柱面半径恒等于球半径 R=2R = 2。

设动点为 M(x,y,z)M(x, y, z)，从球心到动点的向量为 CM→=(x,y−1,z+1)\overrightarrow{CM} = (x, y - 1, z + 1)。

计算外积 CM→×v→\overrightarrow{CM} \times \vec v：CM→×v→=|i→j→k→xy−1z+1111|=(y−z−2,z−x+1,x−y+1)\overrightarrow{CM} \times \vec v = \begin{vmatrix} \vec i & \vec j & \vec k \\ x & y - 1 & z + 1 \\ 1 & 1 & 1 \end{vmatrix} = (y - z - 2,\ z - x + 1,\ x - y + 1)

动点到轴的距离公式为 d=|CM→×v→||v→|=R=2d = \frac{|\overrightarrow{CM} \times \vec v|}{|\vec v|} = R = 2：(y−z−2)2+(z−x+1)2+(x−y+1)212+12+12=22=4\frac{(y - z - 2)^2 + (z - x + 1)^2 + (x - y + 1)^2}{1^2 + 1^2 + 1^2} = 2^2 = 4(y−z−2)2+(z−x+1)2+(x−y+1)2=12(y - z - 2)^2 + (z - x + 1)^2 + (x - y + 1)^2 = 12

展开化简：(y2+z2+4−2yz−4y+4z)+(z2+x2+1−2zx+2z−2x)+(x2+y2+1−2xy+2x−2y)=12(y^2+z^2+4-2yz-4y+4z) + (z^2+x^2+1-2zx+2z-2x) + (x^2+y^2+1-2xy+2x-2y) = 122x2+2y2+2z2−2xy−2yz−2zx−6y+6z−6=02x^2 + 2y^2 + 2z^2 - 2xy - 2yz - 2zx - 6y + 6z - 6 = 0

同除以 2，得切柱面方程：x2+y2+z2−xy−yz−zx−3y+3z−3=0x^2 + y^2 + z^2 - xy - yz - zx - 3y + 3z - 3 = 0

第 3 题 由轴线与面上一点确定圆柱面方程 必做题 📖 教材 §3.1
#3
已知圆柱面的轴为 {x=ty=1+2tz=−3−2t\begin{cases} x = t \\ y = 1 + 2t \\ z = -3 - 2t \end{cases} (t∈ℝt \in \mathbb{R})，且点 M0(1,−2,1)M_0(1, -2, 1) 在此圆柱面上。
求该圆柱面的方程。
💡 课本提示：轴线上定点 P0(0,1,−3)P_0(0, 1, -3)，方向向量 v→=(1,2,−2)\vec v = (1, 2, -2)；先用点线距离公式求出 M0M_0 到轴的距离即圆柱面半径 RR，再对任意动点写出距离方程。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
圆柱面完全由其轴线与半径 RR 决定。已知轴线上点和面上一点，先计算半径，再用点线距离公式列出一般二次方程。
【详细推理与解答】

解：

1. 轴线参数方程给出定点 P0(0,1,−3)P_0(0, 1, -3)，方向向量 v→=(1,2,−2)\vec v = (1, 2, -2)，模长 |v→|=12+22+(−2)2=3|\vec v| = \sqrt{1^2+2^2+(-2)^2} = 3。

已知 M0(1,−2,1)M_0(1, -2, 1) 在面上，P0M0→=(1−0,−2−1,1−(−3))=(1,−3,4)\overrightarrow{P_0M_0} = (1 - 0, -2 - 1, 1 - (-3)) = (1, -3, 4)。

P0M0→×v→=|i→j→k→1−3412−2|=(−2,6,5)\overrightarrow{P_0M_0} \times \vec v = \begin{vmatrix} \vec i & \vec j & \vec k \\ 1 & -3 & 4 \\ 1 & 2 & -2 \end{vmatrix} = (-2, 6, 5) |P0M0→×v→|2=(−2)2+62+52=4+36+25=65|\overrightarrow{P_0M_0} \times \vec v|^2 = (-2)^2 + 6^2 + 5^2 = 4 + 36 + 25 = 65

求得半径平方为 R2=65|v→|2=659R^2 = \frac{65}{|\vec v|^2} = \frac{65}{9}。

2. 对圆柱面上任意动点 M(x,y,z)M(x, y, z)，P0M→=(x,y−1,z+3)\overrightarrow{P_0M} = (x, y - 1, z + 3)：

P0M→×v→=|i→j→k→xy−1z+312−2|=(−2y−2z−4,2x+z+3,2x−y+1)\overrightarrow{P_0M} \times \vec v = \begin{vmatrix} \vec i & \vec j & \vec k \\ x & y - 1 & z + 3 \\ 1 & 2 & -2 \end{vmatrix} = (-2y - 2z - 4,\ 2x + z + 3,\ 2x - y + 1)

由点线距离公式 d2=|P0M→×v→|2|v→|2=R2=659d^2 = \frac{|\overrightarrow{P_0M} \times \vec v|^2}{|\vec v|^2} = R^2 = \frac{65}{9}：(−2y−2z−4)2+(2x+z+3)2+(2x−y+1)2=65(-2y - 2z - 4)^2 + (2x + z + 3)^2 + (2x - y + 1)^2 = 65

展开各项并合并同类项，得到圆柱面方程：8x2+5y2+5z2−4xy+4xz+8yz+8x+14y+22z−39=08x^2 + 5y^2 + 5z^2 - 4xy + 4xz + 8yz + 8x + 14y + 22z - 39 = 0

第 4 题 两等半径球面的公共外切圆柱面 必做题 📖 教材 §3.1
#4
求同时外切于两个球面：
(x−2)2+(y−1)2+z2=25 与 x2+y2+z2=25(x - 2)^2 + (y - 1)^2 + z^2 = 25\quad \text{与}\quad x^2 + y^2 + z^2 = 25
的圆柱面的方程。
💡 课本提示：两球面半径均为 55，外切圆柱面的轴线就是两球心的连线，半径即球半径 R=5R = 5。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
两个等半径球面的外切圆柱面其轴线必为两球心连线所在的直线，轴方向向量为球心连线向量，半径等于球半径。
【详细推理与解答】

解：

两球面半径均为 R=5R = 5。球心分别为 C1(2,1,0)C_1(2, 1, 0) 与 C2(0,0,0)C_2(0, 0, 0)。

两球心的连线即圆柱面的对称轴，轴过原点 C2(0,0,0)C_2(0, 0, 0)，方向向量为 v→=C2C1→=(2,1,0)\vec v = \overrightarrow{C_2C_1} = (2, 1, 0)，模长 |v→|=22+12+02=5|\vec v| = \sqrt{2^2+1^2+0^2} = \sqrt{5}。

设面上动点为 M(x,y,z)M(x, y, z)，位移向量为 OM→=(x,y,z)\overrightarrow{OM} = (x, y, z)。

OM→×v→=|i→j→k→xyz210|=(−z,2z,x−2y)\overrightarrow{OM} \times \vec v = \begin{vmatrix} \vec i & \vec j & \vec k \\ x & y & z \\ 2 & 1 & 0 \end{vmatrix} = (-z, 2z, x - 2y)

由点线距离公式 d=|OM→×v→||v→|=R=5d = \frac{|\overrightarrow{OM} \times \vec v|}{|\vec v|} = R = 5：(−z)2+(2z)2+(x−2y)25=52=25\frac{(-z)^2 + (2z)^2 + (x - 2y)^2}{5} = 5^2 = 255z2+(x−2y)2=1255z^2 + (x - 2y)^2 = 125

展开得圆柱面方程：x2−4xy+4y2+5z2−125=0x^2 - 4xy + 4y^2 + 5z^2 - 125 = 0

三、锥面与圆锥面（第十次课）
本部分练习由顶点与准线建立锥面方程、齐次方程与圆锥面方程构造。
第 5 题 由顶点与准线求一般锥面方程及齐次性验证 必做题 📖 教材 §3.1
#5
求下列锥面的方程：
(1) 顶点为 (0,1,1)(0, 1, 1)，准线为 {x2−2y2=1z=2\begin{cases} x^2 - 2y^2 = 1 \\ z = 2 \end{cases}；
(2) 顶点为原点，准线为 {x2+y2+z2=4x+y+z=1\begin{cases} x^2 + y^2 + z^2 = 4 \\ x + y + z = 1 \end{cases}。
💡 课本提示：(1) 设面上动点 MM，写出母线 VMVM 的参数方程并与平面 z=2z=2 联立消参；(2) 顶点在原点的锥面方程必为关于 x,y,zx, y, z 的二次齐次方程，利用平面方程 x+y+z=1x+y+z=1 对球面方程进行齐次化代换。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
顶点在原点的锥面与坐标多项式的齐次性之间存在一一对应关系。利用准线的一次方程代入二次方程常数项，是实现快速齐次化的经典解析几何技巧。
【详细推理与解答】

(1) 解：

顶点 V(0,1,1)V(0, 1, 1)。设曲面上动点为 M(x,y,z)M(x, y, z)。连接 VMVM 的母线参数方程为：X=0+xt, Y=1+(y−1)t, Z=1+(z−1)tX = 0 + xt,\quad Y = 1 + (y - 1)t,\quad Z = 1 + (z - 1)t

该母线与准线所在平面 Z=2Z = 2 相交：1+(z−1)t=2⇒(z−1)t=1⇒t=1z−11 + (z - 1)t = 2 \implies (z - 1)t = 1 \implies t = \frac{1}{z - 1}

将 tt 代入交点坐标：X=xz−1, Y=1+y−1z−1=y+z−2z−1X = \frac{x}{z - 1},\quad Y = 1 + \frac{y - 1}{z - 1} = \frac{y + z - 2}{z - 1}

交点落在双曲线 X2−2Y2=1X^2 - 2Y^2 = 1 上：(xz−1)2−2(y+z−2z−1)2=1\left(\frac{x}{z - 1}\right)^2 - 2\left(\frac{y + z - 2}{z - 1}\right)^2 = 1x2−2(y+z−2)2=(z−1)2x^2 - 2(y + z - 2)^2 = (z - 1)^2

展开整理得锥面方程：x2−2y2−3z2−4yz+8y+10z−9=0x^2 - 2y^2 - 3z^2 - 4yz + 8y + 10z - 9 = 0

(2) 解（齐次化法）：

顶点在原点 (0,0,0)(0, 0, 0)。由锥面齐次性定理，其方程必为关于 x,y,zx, y, z 的二次齐次方程。

准线方程为：x2+y2+z2=4x^2 + y^2 + z^2 = 4 且 x+y+z=1x + y + z = 1。将常数 44 改写为 4×124 \times 1^2 并代入 1=x+y+z1 = x+y+z：x2+y2+z2=4(x+y+z)2x^2 + y^2 + z^2 = 4(x + y + z)^2x2+y2+z2=4(x2+y2+z2+2xy+2yz+2zx)x^2 + y^2 + z^2 = 4(x^2 + y^2 + z^2 + 2xy + 2yz + 2zx)

移项整理得锥面方程：3x2+3y2+3z2+8xy+8yz+8zx=03x^2 + 3y^2 + 3z^2 + 8xy + 8yz + 8zx = 0

该方程关于 x,y,zx, y, z 严格二次齐次，完全符合顶点在原点的锥面特征。

第 6 题 由顶点、轴与半顶角建立圆锥面方程 必做题 📖 教材 §3.1
#6

📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾

设圆锥面上动点为 M(x,y,z)M(x, y, z)，母线向量为 VM→=(x−1,y,z−2)\overrightarrow{VM} = (x - 1, y, z - 2)。

两端平方：4(2x+2y−z)2=27[(x−1)2+y2+(z−2)2]4(2x + 2y - z)^2 = 27[(x - 1)^2 + y^2 + (z - 2)^2]4(4x2+4y2+z2+8xy−4xz−4yz)=27(x2−2x+1+y2+z2−4z+4+1)4(4x^2 + 4y^2 + z^2 + 8xy - 4xz - 4yz) = 27(x^2 - 2x + 1 + y^2 + z^2 - 4z + 4 + 1)

展开合并整理，得圆锥面方程：11x2+11y2+23z2−32xy+16yz+16zx−54x−108z+135=011x^2 + 11y^2 + 23z^2 - 32xy + 16yz + 16zx - 54x - 108z + 135 = 0

第 7 题 包含三条坐标轴的圆锥面方程与轴线确定 必做题 📖 教材 §3.1
#7
求以原点为顶点、包含三条坐标轴的圆锥面的方程。
💡 课本提示：三条坐标轴都在面上，由空间对称性，圆锥面的轴与三坐标轴夹角必须相等，故轴方向向量必为 v→=(1,1,1)\vec v = (1, 1, 1)（或其对称象限方向），半顶角余弦为 cosα=13\cos\alpha = \frac{1}{\sqrt{3}}。
📝 解题思路与详细证明 / 解析 自测模式可折叠 ▾
【解题思路分析】
利用三坐标轴在圆锥面上的等地位性确定其旋转对称轴，再由轴与任意一条坐标轴的夹角求出半顶角，最后用内积公式展开。
【详细推理与解答】

解：
