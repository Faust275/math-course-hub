一、判断题（15 题）

1判断题
表达式 !x 等价于 x != 1。
正确答案：×
该说法错误。!x 等价于 x==0；x 为 2 时 !x 为 0 而 x!=1 为 1，二者不等价。
2判断题
运算符 + 不能作为单目运算符。
正确答案：×
该说法错误。+ 可作单目正号运算符，如 +3。
3判断题
s(s-a)(s-b)(s-c) 是合法的 C 语言表达式。
正确答案：×
该说法错误。C 不支持省略乘号的隐式相乘，s(s-a) 会被当成函数调用。
4判断题
表达式 !!6 的值是 6。
正确答案：×
该说法错误。!!6 先得 1 再取反得 0？实际 !6=0、!0=1，故 !!6=1，不是 6。
5判断题
表达式 ~(~2<<1) 的值是 5。
正确答案：√
该说法正确。~2 = -3，-3<<1 = -6，~(-6) = 5，结果为 5。
6判断题
表达式 !(x>0||y>0) 等价于 !(x>0)&&!(y>0)。
正确答案：√
该说法正确。按德摩根律，!(A||B) 等价于 !A && !B。
7判断题
若表达式 sizeof(int) 的值为 4，则 int 类型数据可以表示的最大整数为 2³¹ − 1。
正确答案：√
该说法正确。4 字节有符号 int 的最大值是 2³¹−1。
8判断题
表达式 (z=0, (x=2)||(z=1), z) 的值是 1。
正确答案：×
该说法错误。逗号表达式取最后一项 z；(x=2)||(z=1) 因左侧为真而短路，z 仍为 0，结果是 0。
9判断题
C 语言的运算符只有单目运算符和双目运算符两种。
正确答案：×
该说法错误。C 还有三目 ?:、逗号、sizeof、下标、成员等多种运算符。
10判断题
在所有的关系运算符（>=、>、==、!=、<=、<）中，优先级最低的运算符是 ==、!=。
正确答案：√
该说法正确。关系运算符中 ==、!= 的优先级低于 >、<、>=、<=。
11判断题
C 的 double 类型数据可以精确表示任何实数。
正确答案：×
该说法错误。double 只有有限位有效数字，无法精确表示任意实数。
12判断题
在 C 语言中，常量和变量都有数据类型。
正确答案：√
该说法正确。常量和变量都有确定的数据类型。
13判断题
与 float 型数据相比，double 型数据的精度高，取值范围大。
正确答案：√
该说法正确。double 比 float 精度更高、取值范围更大。
14判断题
08 是正确的整型常量。
正确答案：×
该说法错误。以 0 开头是八进制常量，数字 8 不是合法八进制数字。
15判断题
表达式 0195 是一个八进制整数。
正确答案：×
该说法错误。0195 含数字 9，不是合法的八进制整数。

二、单选题（18 题）

1单选题
已知字符 'c' 的 ASCII 码为 99，语句 printf("%d,%c", 'c', 'c'+1); 的输出为（　）。
正确答案：C
正确答案 C。%d 输出 'c' 的码值 99，%c 输出 'c'+1 即字符 d。
2单选题
阅读以下程序段，如果从键盘上输入 1234567 回车，则程序的运行结果是（　）。
int i, j;
scanf("%3d%2d", &i, &j);
printf("i = %d, j = %d\n", i, j);
正确答案：D
正确答案 D。%3d 读 123，%2d 从剩下的 4567 中读 45，故 i=123、j=45。
3单选题
阅读以下程序段，如果从键盘上输入 abc 回车，则程序的运行结果是（　）。
char ch;
scanf("%3c", &ch);
printf("%c", ch);
正确答案：A
正确答案 A。%3c 读取 3 个字符但只给 ch 一个字节空间，实际按字符输出为 a。
4单选题
已知字母 A 的 ASCII 码为十进制的 65，下面程序段的输出是（　）。
char ch1, ch2;
ch1 = 'A' + '5' - '3';
ch2 = 'A' + '6' - '3';
printf("%d,%c\n", ch1, ch2);
正确答案：A
正确答案 A。ch1='A'+('5'-'3')=65+2=67，ch2=65+3=68 即 'D'，输出 67,D。
5单选题
设整型变量 a=2，则执行下列语句后，浮点型变量 b 的值不为 0.5 的是（　）。
正确答案：B
正确答案 B。1/a 先做整数除法得 0，再转 float 仍是 0，不等于 0.5。
6单选题
若 int n; float f = 13.8;，则执行 n = (int)f % 3 后，n 的值是（　）。
正确答案：A
正确答案 A。(int)13.8 = 13，13 % 3 = 1。
7单选题
下面（　）表达式的值为 4。
正确答案：D
正确答案 D。11.0/3≈3.666，加 0.5 后取整得 4。
8单选题
若有定义 int x=3, y=2 和 float a=2.5, b=3.5，则表达式 (x+y)%2 + (int)a/(int)b 的值是（　）。
正确答案：D
正确答案 D。(3+2)%2=1，(int)2.5/(int)3.5 = 2/3 = 0，合计 1。
9单选题
计算变量 x（x 大于 1）整数部分位数的表达式，可以写作（　）。
正确答案：D
正确答案 D。位数为 ⌊log10(x)⌋+1，即 (int)log10(x)+1。
10单选题
C 语言中，关系表达式和逻辑表达式的值是（　）。
正确答案：C
正确答案 C。关系和逻辑表达式的结果只能是 0 或 1。
11单选题
判断变量 x、y 中有且只有 1 个值为 0 的表达式为（　）。
正确答案：A
正确答案 A。x*y 为 0 说明至少一个为 0，再用 x+y 非零排除两者都为 0。
12单选题
若变量已经被正确定义，为表示“变量 x 和 y 都能被 3 整除”，应使用的 C 表达式是（　）。
正确答案：D
正确答案 D。两者都能被 3 整除要用 && 连接两个 %3==0。
13单选题
为表示“a 和 b 都不等于 0”，应使用的 C 语言表达式是（　）。
正确答案：D
正确答案 D。a && b 恰好表示 a、b 都非 0。
14单选题
执行下面程序中的输出语句后，输出结果是（　）。
int a;
printf("%d\n", (a=3*5, a*4, a+5));
正确答案：B
正确答案 B。逗号表达式取最后一项 a+5 = 15+5 = 20。
15单选题
下面合法的 C 语言字符常量是（　）。
正确答案：A
正确答案 A。'\t' 是转义字符常量；"A" 是字符串，'xx' 非法，A 是标识符。
16单选题
下面程序段的输出是（　）。
int x = 023;
printf("%d\n", --x);
正确答案：B
正确答案 B。023 是八进制即 19，前缀 --x 先自减为 18 再输出。
17单选题
下面的程序段输出是（　）。
int k = 11;
printf("k=%d,k=%o,k=%x\n", k, k, k);
正确答案：D
正确答案 D。11 的八进制是 13、十六进制是 b，故输出 k=11,k=13,k=b。
18单选题
下面的程序段输出是（　）。
short int a;
int b = 65536;
a = b;
printf("%d\n", a);
正确答案：B
正确答案 B。65536 超出 short 表示范围，截断后低 16 位为 0。
