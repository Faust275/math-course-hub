§11.4 泰勒级数

上节中我们看到,幂级数有很多优良的性质.这使我们想到,若能把函数表示成幂级数,定会给各方面的讨论和研究带来方便.由第五章讲过的泰勒公式,特别是由上节例11.3.2可知,这种愿望在某些情况下是可以变成现实的.

设函数 f(x)f(x) 在某点 x0x_0 的某个邻域 N(x0,δ)=(x0−δ,x0+δ)N(x_0, \delta) = (x_0 - \delta, x_0 + \delta) 中可以表示成幂级数，亦即当 x∈N(x0,δ)x \in N(x_0, \delta) 时有

f(x)=∑n=0∞an(x−x0)n.f (x) = \sum_ {n = 0} ^ {\infty} a _ {n} (x - x _ {0}) ^ {n}.

于是由定理11.3.6的推论知 f(x)f(x) 在 N(x0,δ)N(x_0, \delta) 中无穷次可导且对所有 k∈Nk \in \mathbb{N} , 均有

f(k)(x)=∑n=k∞n(n−1)…(n−k+1)an(x−x0)n−k.f ^ {(k)} (x) = \sum_ {n = k} ^ {\infty} n (n - 1) \dots (n - k + 1) a _ {n} (x - x _ {0}) ^ {n - k}.

在上式中令 x=x0x = x_0 ，得到

an=f(n)(x0)n!, n=0,1,2,…a _ {n} = \frac {f ^ {(n)} (x _ {0})}{n !}, \quad n = 0, 1, 2, \dots

从而得到

f(x)=∑n=0∞f(n)(x0)n!(x−x0)n.(11.4.1)f (x) = \sum_ {n = 0} ^ {\infty} \frac {f ^ {(n)} (x _ {0})}{n !} (x - x _ {0}) ^ {n}.\tag{11.4.1}
注意深入诠释

(11.4.1)式是在假设 f(x)f(x) 可以表示为幂级数的前提下得到的。现在我们要问，如果去掉这个前提而仅仅假设 f(x)f(x) 在点 x0x_0 的某邻域 N(x0,δ)N(x_0, \delta) 中无穷次可导，(11.4.1)式是否仍然成立？答案是否定的。

考察函数

f(x)={e−1x2,x≠0.0,x=0.(11.4.2)f (x) = \left\{ \begin{array}{l l} \mathrm{e} ^ {- \frac {1}{x ^ {2}}}, & x \neq 0. \\ 0, & x = 0. \end{array} \right.\tag{11.4.2}

容易验证, f(x)f(x) 在任何形如 (−R,R)(-R,R) 的区间中无穷次可导且有

f(n)(0)=0, n=1,2,…f ^ {(n)} (0) = 0, \quad n = 1, 2, \dots

若(11.4.1)式成立,则有

f(x)≡0, x∈(−R,R).f (x) \equiv 0, \quad x \in (- R, R).

但由定义式(11.4.2)知当 x≠0x \neq 0 时, f(x)≠0f(x) \neq 0 , 矛盾. 这表明为使(11.4.1)式成立, 还需要对 f(x)f(x) 提出进一步的要求.

按级数收敛的定义,为使(11.4.1)式成立,右端幂级数的部分和 Sn(x)S_{n}(x) 应收敛于 f(x)f(x) ,亦即应有

limn→∞Rn(x)=limn→∞(f(x)−Sn(x))=0.\lim _ {n \rightarrow \infty} R _ {n} (x) = \lim _ {n \rightarrow \infty} (f (x) - S _ {n} (x)) = 0.

这里的 Rn(x)R_{n}(x) 不是别的，正是泰勒公式中的余项. 换句话说，当 f(x)f(x) 相应的泰勒公式的余项 Rn(x)R_{n}(x) 于 n→∞n \to \infty 时趋于0时，(11.4.1)式成立. 这时称(11.4.1)式右端的幂级数为函数 f(x)f(x) 的幂级数展开式，或称为函数 f(x)f(x) 的泰勒级数.

在怎样的条件下才能保证 Rn(x)R_{n}(x) 在 N(x0,δ)N(x_0, \delta) 上趋于0呢？对此，我们给出一个充分条件。

定理 11.4.1核心定理

设函数 f(x)f(x) 的导函数列 {f(n)(x)}\{f^{(n)}(x)\} 在点 x0x_0 的邻域 N(x0,δ)N(x_0, \delta) 中一致有界，则 f(x)f(x) 在 N(x0,δ)N(x_0, \delta) 中可展开为泰勒级数.

证明

由于 {f(n)(x)}\{f^{(n)}(x)\} 在 N(x0,δ)N(x_0, \delta) 中一致有界，故存在常数 M>0M > 0 ，使对所有非负整数 nn 和所有 xx ，均有

∣f(n)(x)∣≤M.\mid f ^ {(n)} (x) \mid \leqslant M.

于是由拉格朗日余项有

∣Rn(x)∣=|f(n+1)(ξ)(n+1)!(x−x0)n+1|≤Mδn+1(n+1)!→0 (n→∞).\mid R _ {n} (x) \mid = \left| \frac {f ^ {(n + 1)} (\xi)}{(n + 1) !} (x - x _ {0}) ^ {n + 1} \right| \leqslant M \frac {\delta^ {n + 1}}{(n + 1) !} \rightarrow 0 \quad (n \rightarrow \infty).

所以 f(x)f(x) 在 N(x0,δ)N(x_0, \delta) 中可以展开为泰勒级数.

下面讨论一些基本初等函数的泰勒展开式.

  1. 指数函数 f(x)=exf(x) = \mathrm{e}^x . 因为
f(n)(x)=ex,f(n)(0)=1, n=0,1,2,…f ^ {(n)} (x) = \mathrm{e} ^ {x}, f ^ {(n)} (0) = 1, \quad n = 0, 1, 2, \dots

∣f(n)(x)∣=ex≤er, n=0,1,2,…\mid f ^ {(n)} (x) \mid = \mathrm{e} ^ {x} \leqslant \mathrm{e} ^ {r}, \quad n = 0, 1, 2, \dots

由定理11.4.1及 r>0r > 0 的任意性知 ex\mathrm{e}^x 可在 (−∞,+∞)(-\infty, +\infty) 上展开为泰勒级数：

ex=∑n=0∞xnn!.\mathrm{e} ^ {x} = \sum_ {n = 0} ^ {\infty} \frac {x ^ {n}}{n !}.
  1. 三角函数 f(x)=sinxf(x) = \sin x 和 g(x)=cosxg(x) = \cos x . 因为
∣f(n)(x)∣=∣sin(x+nπ2)∣≤1, x∈(−∞,+∞),n=0,1,2,…\mid f ^ {(n)} (x) \mid = \mid \sin \left(x + \frac {n \pi}{2}\right) \mid \leqslant 1, \quad x \in (- \infty , + \infty), n = 0, 1, 2, \dots

由定理11.4.1知 sinx\sin x 可在 (−∞,+∞)(-\infty, +\infty) 上展开为泰勒级数，同理可证 cosx\cos x 亦然.这时有

sinx=∑n=0∞(−1)n(2n+1)!x2n+1, cosx=∑n=0∞(−1)n(2n)!x2n.\sin x = \sum_ {n = 0} ^ {\infty} \frac {(- 1) ^ {n}}{(2 n + 1) !} x ^ {2 n + 1}, \quad \cos x = \sum_ {n = 0} ^ {\infty} \frac {(- 1) ^ {n}}{(2 n) !} x ^ {2 n}.
  1. 二项式函数 f(x)=(1+x)αf(x) = (1 + x)^{\alpha} ，其中 α∈R−N0\alpha \in \mathbb{R} - \mathbb{N}_0 ，即 α\alpha 为不是非负整数的任意实数。这时， f(x)f(x) 的泰勒公式的柯西余项为
Rn(x)=f(n+1)(θx)(1−θ)nn!xn+1=α(α−1)⋯(α−n)(1+θx)α−n−1n!(1−θ)nxn+1=α(α−1)⋯(α−n)xn+1n!(1+θx)α−1(1−θ1+θx)n,(11.4.3)\begin{array}{r l} R _ {n} (x) & = \frac {f ^ {(n + 1)} (\theta x) (1 - \theta) ^ {n}}{n !} x ^ {n + 1} \\ & = \frac {\alpha (\alpha - 1) \cdots (\alpha - n) (1 + \theta x) ^ {\alpha - n - 1}}{n !} (1 - \theta) ^ {n} x ^ {n + 1} \\ & = \frac {\alpha (\alpha - 1) \cdots (\alpha - n) x ^ {n + 1}}{n !} (1 + \theta x) ^ {\alpha - 1} \left(\frac {1 - \theta}{1 + \theta x}\right) ^ {n}, \end{array}\tag{11.4.3}

其中 0<θ<10 < \theta < 1 . 为证 Rn(x)R_{n}(x) 趋于 0, 考察幂级数

∑n=0∞α(α−1)⋯(α−n)n!xn+1.(11.4.4)\sum_ {n = 0} ^ {\infty} \frac {\alpha (\alpha - 1) \cdots (\alpha - n)}{n !} x ^ {n + 1}.\tag{11.4.4}

因为

limn→∞|α(α−1)⋯(α−n)n!α(α−1)⋯(α−n)(α−n−1)(n+1)!|=limn→∞|n+1α−n−1|=1,\lim _ {n \rightarrow \infty} \left| \frac {\frac {\alpha (\alpha - 1) \cdots (\alpha - n)}{n !}}{\frac {\alpha (\alpha - 1) \cdots (\alpha - n) (\alpha - n - 1)}{(n + 1) !}} \right| = \lim _ {n \rightarrow \infty} \left| \frac {n + 1}{\alpha - n - 1} \right| = 1,

故知幂级数(11.4.4)的收敛半径为1,即幂级数(11.4.4)在(-1,1)中收敛.由收敛的必要条件知,当 |x|<1|x|<1 时,

limn→∞α(α−1)⋯(α−n)n!xn+1=0.(11.4.5)\lim _ {n \rightarrow \infty} \frac {\alpha (\alpha - 1) \cdots (\alpha - n)}{n !} x ^ {n + 1} = 0.\tag{11.4.5}

对于(11.4.3)式右端第2个因式 (1+θx)α−1(1 + \theta x)^{\alpha - 1} , 虽然其中的 θ\theta 与 nn 有关, 但由于 0<θ<10 < \theta < 1 , 故有

这表明当固定 x∈(−1,1)x \in (-1, 1) 时，第2个因式 (1+θx)a−1(1 + \theta x)^{a-1} 对 nn 来说是有界数列.

对于(11.4.3)式右端第3个因式 (1−θ1+θx)n\left(\frac{1-\theta}{1+\theta x}\right)^{n} ，由于0<θ<1，故当 |x|<1|x|<1 时， 0<1-θ<1+θx，从而有

将(11.4.3)，(11.4.5)，(11.4.6)和(11.4.7)式结合起来即得

从而知函数 (1+x)a(1 + x)^{a} 在 (−1,1)(-1, 1) 中可展开为泰勒级数.

因为

f(n)(x)=α(α−1)…(α−n+1)(1+x)α−n, n=0,1,2,…f(n)(0)=α(α−1)…(α−n+1), n=0,1,2,…\begin{array}{l} {f ^ {(n)} (x) = \alpha (\alpha - 1) \dots (\alpha - n + 1) (1 + x) ^ {\alpha - n}, \quad n = 0, 1, 2, \dots} \\ {f ^ {(n)} (0) = \alpha (\alpha - 1) \dots (\alpha - n + 1), \quad n = 0, 1, 2, \dots} \end{array}

所以有

(1+x)a=∑n=0∞α(α−1)⋯(α−n+1)n!xn, |x|<1.(1 + x) ^ {a} = \sum_ {n = 0} ^ {\infty} \frac {\alpha (\alpha - 1) \cdots (\alpha - n + 1)}{n !} x ^ {n}, \quad | x | < 1.

附带指出,二项式函数在收敛区间端点±1的敛散性较为复杂,这里不再加以讨论.

除了上述四个泰勒级数之外, 还有两个重要的泰勒级数就是上节例 11.3.2 所给出的两个展开式:

以上六个展开式是常用的,应该记住.

有些书上将函数在点0的展开式称为麦克劳林级数或麦克劳林展开，而把在点 x0x_0 的展开称为泰勒展开. 本书为简单起见，一律称之为泰勒展开或泰勒级数.
