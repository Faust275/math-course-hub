1判断题

2判断题
C 语言中默认的参数传递方式是值传递，此时函数内部修改形参值不会影响实参。
正确答案：√
该说法正确。默认是值传递，改形参不影响实参。
3判断题
如果函数不需要返回任何值，其返回值类型应声明为 void。
正确答案：√
该说法正确。不返回值时类型写 void。
4判断题
函数的形参在函数调用结束后会被销毁，不再占用内存空间。
正确答案：√
该说法正确。形参在函数调用结束后被销毁、释放空间。
5判断题
函数体中定义的局部变量可以作为调用其它函数的参数，传递给被调用函数。
正确答案：√
该说法正确。局部变量可作为实参传给其他函数。
6判断题

正确答案：×
该说法错误。全局变量未显式初始化时系统自动置 0，不是随机值。
7判断题
在 C 语言中，若要在一个 .c 文件中使用另一个 .c 文件定义的全局变量，必须先用 extern 关键字声明该变量。
正确答案：√
该说法正确。跨文件使用全局变量需先用 extern 声明。
8判断题
C 语言中，用 static 修饰的变量统称为静态变量，其存储在静态存储区。
正确答案：√
该说法正确。static 变量存放在静态存储区。
9判断题
C 语言函数内部的静态局部变量，其生命周期与整个程序一致，不会随函数调用结束而释放。
正确答案：√
该说法正确。静态局部变量生命周期与整个程序一致，不随调用结束释放。
10判断题

11判断题
C 语言全局变量的生命周期是从程序开始运行到程序结束。
正确答案：√
该说法正确。全局变量生命周期从程序开始到结束。
12判断题
在 C 语言中，函数 func1 内部定义的普通局部变量 x，函数 func2 可以通过 extern 声明直接访问 x。

13判断题
C 语言中，普通局部变量存储在栈区，静态局部变量存储在静态存储区。
正确答案：√
该说法正确。普通局部变量在栈区，静态局部变量在静态存储区。
14判断题

正确答案：√
该说法正确。静态局部变量可在多次调用之间保留中间结果，如累计调用次数。
