一、if-else 语句和分支结构（00:04:06—00:23:21）

00:04:06—00:04:48 ｜ 本节内容预告与第三周作业安排

00:05:02—00:06:45 ｜ if-else 分支语句回顾（双分支与无 else 的单分支）

流程回顾：if(表达式) 语句1 else 语句2，有 if 和 else 两个分支，有且仅有一个分支被执行。也可以只有 if 没有 else（“一条腿的”条件语句）：表达式成立就执行那条语句，不成立就什么都不做。这种形式也叫条件语句。

printf 不仅可以输出变量，还可以输出常量、表达式（如 total/n）。下面几个教科书例题都只用到 if / if-else，属于单分支或双分支。

例题/证明 1（00:05:48）｜ 例3-2 统计奇数和偶数的个数

题目／任务：读入一个整数，判断它是奇数还是偶数，分别累加到 count_odd（奇数计数）或 count_even（偶数计数）。

思路：整数除以 2 看余数。余数为 0 是偶数，否则是奇数。

代码（取自课件 ch03.txt 第 4 页）：

scanf("%d", &number);
if( number%2!=0 )
count_odd ++;
else
count_even ++;

代码取自课件 ch03.txt

说明：number%2!=0 表示”除以 2 余数不为 0”，即是奇数，走 if 分支让 count_odd 加 1；否则是偶数，走 else 分支让 count_even 加 1。

易错点：判断奇偶用 %2，不要写成除以 2 看商；count_odd、count_even 定义时应初始化为 0，否则初值不确定。

例题/证明 2（00:06:18）｜ 例3-3 统计不及格人数

题目／任务：读入学生成绩，若成绩小于 60，则不及格人数加 1。

代码（取自课件 ch03.txt 第 4 页）：

if( score <60 )
count ++;

代码取自课件 ch03.txt

说明：这里没有 else 分支，是一条”单腿”的条件语句。条件成立才执行 count++，不成立就什么也不做。

易错点：把”统计不及格”误写成双分支（else 里去加及格人数）会让逻辑变复杂；本题只在”不及格”这一种情况做事，单分支即可。

例题/证明 3（00:06:54）｜ 例3-3 计算并输出平均成绩（含特殊情况处理）

题目／任务：输出班级平均成绩。若人数为 0，平均成绩无意义，要做特殊处理。

代码（取自课件 ch03.txt 第 5 页）：

if( n!=0 )
printf("平均成绩=%.2f\n", total/n);
else
printf("平均成绩=%.2f\n", 0);

代码取自课件 ch03.txt

说明：当 n!=0 时才用 total/n 求平均并保留 2 位小数输出；当 n==0 时直接输出 0（避免除以 0 导致结果异常）。这正体现了”考虑特殊情况”的鲁棒性思想。同时注意：printf 的输出对象既可以是变量，也可以是表达式（这里 total/n 就是一个表达式，先算值再传给 printf）。

易错点：不加判断直接 printf("平均成绩=%.2f\n", total/n);，当 n==0 时得到异常结果（除以 0）。

00:06:54—00:09:14 ｜ printf 输出表达式与 else if 多路分支

printf 的输出项可以是变量、常量，也可以是表达式——三者共同点：最终都会得到一个数值传给 printf 函数（表达式会先被求值）；常量则不需要从内存取值。所以 printf 不仅能输出变量/常量，还能输出表达式的值，甚至一个函数调用的返回值。

多路分支：if … else if … else，可以最少做 3 路及以上的分支。

例题/证明 4（00:12:25）｜ 例3-4 分段计算水费（四种写法对比）

题目／任务：居民用水量 x，水费按下式计算，写出对应的 C 代码并判断写法是否正确：

公式
y=f(x)={0,x<04x3,0≤x≤152.5x−10.5,x>15y = f(x) = \begin{cases} 0, & x<0 \\ \dfrac{4x}{3}, & 0\le x\le 15 \\ 2.5x-10.5, & x>15 \end{cases}

代码写法 1（取自课件 ch03.txt 第 9 页）：

if( x < 0 )
y = 0;
else if( x>=0 && x <= 15 )
y = 4 * x / 3;
else if( x>15 )
y = 2.5 * x - 10.5;

代码取自课件 ch03.txt

代码写法 2（取自课件 ch03.txt 第 9 页）：

if( x < 0 )
y = 0;
else if ( x <= 15 )
y = 4 * x / 3;
else
y = 2.5 * x - 10.5;

代码取自课件 ch03.txt

代码写法 3（取自课件 ch03.txt 第 10 页）：

if( x>=0 && x <= 15 )
y = 4 * x / 3;
else if( x < 0 )
y = 0;
else if( x>15 )
y = 2.5 * x - 10.5;

代码取自课件 ch03.txt

代码写法 4（取自课件 ch03.txt 第 10 页）：

if ( x <= 15 )
y = 4 * x / 3;
else if( x < 0 )
y = 0;
else
y = 2.5 * x - 10.5;

代码取自课件 ch03.txt

逐步分析与结论：

  1. 写法 1 正确：依次判断 x<0、<0且≤15、>15，三个区间互不重叠、覆盖完整。
  2. 写法 2 正确且更简洁：进入 else 时已隐含 x>=0，所以第二个条件只需写 x<=15 即可；进入最后的 else 时隐含 x>15，无需再写 x>15。这是利用了前面分支已经排除掉的部分，做了”优化”。
  3. 写法 3 正确：把”中间段”提到最前判断，再分别判断 x<0 与 x>15。只要各区间不重不漏，调整判断顺序结果仍然等价。
  4. 写法 4 错误：第一个条件 x<=15 会把负数（x<0）也包含进去，导致负数走了 y=4*x/3 而不是 y=0，逻辑出错。

老师的提醒：

  • 区间判断里连续不等式不能写成 0<=x<=15 这种数学连写，必须用逻辑与 && 连接：x>=0 && x<=15。
  • 写分支时如果拿不准，先用”最笨”的完整写法（像写法 1），保证正确，再做优化；要清楚自己做了优化、判断顺序是有关系的。
  • 多分支调试要设计测试数据覆盖所有条件，让每个分支都能被测到。

易错点：写法 4 那种”把优化后的顺序再反过来”会打乱逻辑；连续区间必须用 && 连接，不能写数学式连等号。

00:09:14—00:12:17 ｜ else if 多路分支的结构与流程控制

if(表达式1) 语句1 else if(表达式2) 语句2 … else 语句n：从上往下依次判断，哪个表达式为真就执行对应语句，有且仅有一条语句被执行；若全为假则执行最后的 else 语句（无 else 时什么都不做）。

老师强调两点：

  • 这是流程控制语句，它只管”流程往哪走”，不管你这些表达式之间有什么逻辑关系。表达式的先后顺序、逻辑好坏是程序员自己的事，编译器不会帮你处理。
  • 每个分支对应的语句有且仅有一条；如果没有 else，相当于 else 后面是一个空语句。若把中间的某个 else if 的语句省掉是不允许的——else 必须跟在某个 if 之后，否则就成了另一条独立的语句。

调试多路分支：要设计测试数据覆盖所有测试条件，才能测试到所有分支。

00:12:25—00:16:11 ｜ 例3-4 分段函数（水费）的多种写法与优化

（例题/证明 4 已完整展开。本节补充老师的口语讲解脉络：先判断 <0、再判断中间段、再判断 >15；指出写法 1、2 都正确，写法 2 更”啰嗦变简洁”——因为 else 分支里 x>=0 已成立，不必再写；写法 3 调换顺序也正确；写法 4 因 x<=15 包含了负数而错误。重点落在”优化建立在判断顺序之上，顺序不能乱”以及”区间必须用 && 连接”。）

00:16:11—00:17:48 ｜ 写分支语句的要点与多分支调试

  • 条件可能很复杂（出现两个变量联合判断），一定要把条件写清楚；拿不准就先用最完整、最笨的写法，保证正确后再优化。
  • 多分支调试：设计测试数据，覆盖所有测试条件，让所有分支都能被执行到。

00:17:48—00:19:09 ｜ if-else if 的本质是嵌套的 if-else

if … else if … else if … else 看起来是并列的多路，本质上还是 if-else：最后一个 else if 其实是”前面所有 if 都不成立时”的那个 else 分支里又嵌套了一个 if。C 语言的排版（换行、空格、缩进）不重要，多一个少一个空格都不影响，所以上面那一串在编译器看来等价于”一层层嵌套在 else 里面的 if“。

00:19:09—00:23:21 ｜ if-else 嵌套与”悬空 else”（为何要加括号）

嵌套示例（取自课件 ch03.txt 第 12 页）：

if( 表达式1 )
if( 表达式2 ) 语句1;
else 语句2;
else
if( 表达式3 ) 语句3;
else 语句4;

代码取自课件 ch03.txt

“悬空 else”问题（取自课件 ch03.txt 第 14 页）：

if( 表达式1 )
if( 表达式2 ) 语句1;
else
if( 表达式3 ) 语句3;
else 语句4;

代码取自课件 ch03.txt

规则：else 总是与前面最近的、尚未配对的 if 结合成 if-else。上面这段不加括号时，那个 else（对应 语句2）其实是跟内层 if(表达式2) 配对的，而不是跟外层 if(表达式1) 配对——这往往和程序员”想让它与外层 if 配对”的直觉相反，从而产生逻辑错误。

老师比喻：就像家里有院子，围墙（大括号）一围，结构就清清楚楚。

解决办法（取自课件 ch03.txt 第 14—15 页）：

if( 表达式1 ) {
if( 表达式2 ) 语句1;
else {
if( 表达式3 ) 语句3;
else 语句4;
}
}

代码取自课件 ch03.txt

加上 {} 后，else 的配对关系被大括号固定住，不会”跑”到最近的 if 上，逻辑就正确了。所以建议凡是 if / else 分支，都加上 {}，万无一失——即使只有一条语句也加，修改代码时也不容易出错。

易错点：漏写 {} 导致 else 与内层 if 错误配对（悬空 else）；这种写法没有语法错误，编译器不会报错，但运行结果不对，最难发现。

二、字符类型和逻辑运算（00:23:21—01:33:02）

00:23:21—00:25:10 ｜ 字符类型概述与 ASCII 码表（附录 B）

字符类型（char）是 C 语言的一种数据类型，本质上是一种整数类型——字符变量肚子里装的就是一个整数。字符常量包括：小写字母 'a'…'z'、大写字母 'A'…'Z'、数字 '0'…'9'、括号/标点/运算符，以及特殊字符（空格、换行等）。

书上附录 B（教材第 349—350 页）有一张 ASCII 码表，共 127 个字符。例如大写字母 P 在表中是第 80 个（从 0 开始数），所以字符 P 的编码就是整数 80；大写字母 S 是第 83 个，编码为整数 83。这就是”字符类型就是整数类型”的原因——整数能出现的地方，字符都能出现。

00:25:10—00:32:54 ｜ ASCII 码详解：编码范围、汉字与扩展字符、字符的运算

  • ASCII 全称：American Standard Code for Information Interchange（美国信息交换标准代码）。
  • 范围 0~127，一个字节（8 个 bit）存储一个 ASCII 码，最高位固定为 0，用来区分标准 ASCII 码和其他非标准字符码；最多表示 127 个不同字符。
  • 码值为 0 的字符 [null] 是”不是字符的字符”，它不代表任何可见字符，但常被用作字符串结束标志（读到字符 '\0' 就表示字符串到此为止）。
  • 汉字问题：常用汉字有 3500 个，总汉字数达 3 万多，一个字节最多表示 255 个，存不下，所以一个汉字要用两个字节（两个字符）表示。判断方法：读到的字节如果最高位是 1，就知道这是一个扩展/非 ASCII 字符，要把连续两个字节合起来解释成一个汉字（类似 Unicode 的双字节思路）。这不是本课考试范围，但作为浙大学生应该懂得其原理。
  • 字符的运算：字符是整数，可以做四则运算和大小比较，但通常”两个字符相乘/相加”没有实际意义；有意义的是：
    • 字符加 1：'A'+1 得到 'B'，'a'+1 得到 'b'，'0'+1 得到 '1'；
    • 大小写转换：大写字母加 32 变成小写字母（'A'+32 = 'a'），小写字母减 32 变成大写字母（'a'-32 = 'A'）；
    • 字符比较：比的是 ASCII 码值，例如 'B' < 'D' 为真。
  • ASCII 码的三个连续性（判断字母/数字的基础）：0~9、A~Z、a~z 在表中都是连续、依次递增存放的（中间 Z 和 a 之间夹了其他字符，所以大小写并不直接相接）。

00:40:04—00:48:11 ｜ 字符输入输出函数现场演示（缓冲区、回车与权限错误排障）

老师现场用 getchar/putchar 演示，并讲解若干排障要点（本节为调试/工具提醒，保留）：

  1. 输入要按回车才进缓冲区：键盘敲的字符先停在键盘缓冲，按回车后整行才进入系统的 I/O 缓冲区，程序里的 getchar() 才真正读到字符。例如输入 W 后不按回车，程序会一直停在等待输入；按回车后 W 才被读走。
  2. putchar 的参数是”无参数、靠返回值”：getchar() 不需要参数，它从缓冲区取一个字符作为返回值；调用时把它的返回值赋给变量即可：a = getchar();。即使不把返回值赋给变量（如单独写一句 getchar();），它也会执行、读走一个字符，只是被”浪费”掉了。
  3. 返回值存在函数返回值里：getchar() 返回读到的字符（实际是 int 类型，见下节）。
  4. cannot open output file ... permission denied（权限被拒绝）排障：编译时要生成 .exe 可执行文件，若该 .exe 正被占用（上一轮运行异常没退出、进程还挂着），编译器就无法覆盖它，报 permission denied。解决：打开任务管理器（在任务栏右键 → 任务管理器），找到那个残留的 *.exe 进程，结束任务（“杀死”），再重新编译运行。老师演示时正是这样通过任务管理器杀掉卡住的进程后程序才正常。

易错点：没退出的上一轮程序占用了 .exe 导致无法重新编译；忘记按回车字符进不了缓冲区。

01:14:19—01:15:28 ｜ 逻辑值：真/假、非零即真、= 与 == 的区别

逻辑值只有两个：真、假。关系运算（如 3<5、a>=b、x!=y、c==17）的结果就是逻辑值（成立为真，不成立为假）。C 语言用整数表示逻辑值：1 表示真，0 表示假；而且任何值都能自动转成逻辑值：非 0 即真，0 即假（不只有 1 才是真）。

01:15:28—01:26:09 ｜ 逻辑运算（非/与/或、优先级）与经典表达式

逻辑运算符（取自课件 ch03.txt 第 33 页）：

运算符 名称 优先级
! 逻辑非 最高（单目）
&& 逻辑与 高
|| 逻辑或 低
  • 逻辑与 &&：a && b 为真当且仅当 a 和 b 都为真。
  • 逻辑或 ||：a || b 为假当且仅当 a 和 b 都为假（即”至少有一个为真”则为真）。

01:33:02—01:38:11 ｜ switch 语句：格式、关键字与整型表达式要求

switch 是多路选择流程控制语句，关键字有 switch、case、default 三个。

格式（取自课件 ch03.txt 第 39 页）：

switch(表达式)
{
case 常量1: 语句段1;
case 常量2: 语句段2;
...
case 常量n: 语句段n;
default:
语句段n+1;
}

代码取自课件 ch03.txt

要点（取自课件 ch03.txt 第 40 页）：

  • 每个 case 对应一个常量，定义了一个程序执行入口；default 定义了缺省入口（谁都能进）。
  • 每个语句段可以包含 0 到多条语句（空语句段也允许）。
  • 表达式和 case 常量必须是整数类型：包括 char、int 等可自动转为整数的类型；不能是 float、double 或其他结构类型。
  • case 中的常量可以是常量表达式（如 2*5），但不能是含变量的表达式（因为编译器要在编译期确定值、生成跳转表）。

01:43:20—01:46:14 ｜ switch 执行流程、空语句段与常量表达式

（课间休息约 5 分钟，01:38:11—01:43:20。）

执行流程（取自课件 ch03.txt 第 41 页）：

  1. 首先计算 switch(表达式) 的值；
  2. 把它与各个 case 常量比较；
  3. 若等于某个常量 k，就从该 case 对应的语句段开始，一直往下执行所有后续语句段（像拿一把钥匙从某一道门进去后一路走到底）；
  4. 若和所有 case 都不等，则只执行 default 对应的语句段。

老师强调：上面”依次比较”只是逻辑上的理解；真正运行时编译器会生成一个跳转表，直接按值跳到对应位置，效率更高（见后文）。正因它会”一直往下执行”，所以通常需要用 break 来提前终止。

空语句段：若多个 case 要做同样的事，可让前面的 case 语句段为空，自然”落到”下一个 case。例如两个值对应同一处理，就把前一个 case 留空，二者共用后续语句段。

例题/证明 1（01:46:14）｜ 例3-10 统计字符（switch 实现）

题目／任务（取自课件 ch03.txt 第 43 页）：输入一个正整数 n，再输入 n 个字符，统计其中空格或回车、数字字符、其他字符的个数。用 switch 语句实现。

{

case ' ':
case '\n':
blank++; break;
case '0':case '1':case '2':case '3':
case '4':case '5':case '6':case '7':
case '8':case '9':
digit++; break;
default:
other++; break;
}//switch
}//for

blank, digit, other);
return 0;
}

代码取自课件 ch03.txt

运行展示（取自课件 ch03.txt 第 48—51 页）：

  • 输入 6 后输入 123456（末位回车被 getchar() 吞掉）→ blank = 0, digit = 6, other = 0 ✓
  • 未加 getchar() 时：输入 6 后输入 123456 → 输出 blank = 1, digit = 5, other = 0 ✗。原因：scanf("%d",&n) 留下的回车被 for 里第一次 getchar() 读到，被算作一个 blank。修正办法就是 scanf 之后加一句 getchar(); 把回车读走丢弃。

易错点：漏写 break 导致贯穿执行；漏写 getchar() 吞掉 scanf 留下的回车；case 常量必须是整型/字符型，不能写字符串或浮点。

case 2:
price = 2.5; break;
case 3:
price = 4.0; break;
case 4:
price = 3.5; break;
default: price = 0.0; break;
}
printf("price = %f\n\n", price);
}
return 0;
}

代码取自课件 ch03.txt

要点：

  • for( ; ; ) 的三个表达式全为空，约定循环条件永远为真，即无限循环（死循环）。只有执行到 break 才跳出。
  • break 在循环里正常都应藏在一个 if 里（这里 if(choice==0) break;），满足条件才退出；若无条件地直接 break，循环只做一遍，就失去了循环意义。
  • 每个 case 后都有 break，使只执行对应分支，实现多路分支。
  • switch 里的 break 只跳出 switch；由于 break 更”亲近” switch，它不会去终止外层的 for 循环（跳出循环要靠循环里的那个 if(choice==0) break;）。

比较与优缺点（取自课件 ch03.txt 第 59 页）：

  • 缺点一堆：格式复杂、语法死板、限制多（只适用于整数类变量的比较判断），还要配合 break，新手容易漏。
  • 唯一优点——运行效率高：switch 编译时会生成一个跳转表（jump table），直接按 case 值查表得到偏移量、跳到对应分支；而 if-else if 要按顺序逐个比较，越靠后的分支比较次数越多。switch 的跳转次数是固定的（查表一次），因此更快。

老师补充（跳转表的直观解释）：代码都在内存里。用 if-else 时，要拿表达式的值依次和各个常量比较，第 N 个分支往往要比较 N 次才到达；switch 则根据 choice 的值直接到跳转表里查到一个偏移量，一步跳到对应语句段。这一点在 GPU 这类”分支不友好”的环境里尤其重要（if-else 各分支执行长度不一会导致线程同步等待最慢分支），而跳转表不受此影响。

考试提示：只要程序运行结果对，用 switch 还是 if-else 都给分；实际开发中 if-else 用得更多（适用范围广，可为浮点等），switch 适用面窄但效率高。

02:12:29—02:15:20 ｜ 例3-9 用 switch 实现四则运算与本节收束

例题/证明 3（02:12:29）｜ 例3-9 用 switch 实现四则运算

题目／任务（取自课件 ch03.txt 第 63 页）：输入形如”整数 运算符 整数”的表达式，计算并输出结果；运算包括加、减、乘、除、取余，并处理除数为零的情况。用 switch 实现（对比之前用 if-else 做的例3-5）。

完整代码（取自课件 ch03.txt 第 63—65 页）：

#include <stdio.h>
int main(void)
{
int value1 , value2;
char op;
printf("输入一个表达式：");
scanf("%d%c%d", &value1 , &op , &value2);
switch( op ) {
case '+':
printf ("=%d\n", value1 + value2 );
break ;
case '-':
printf ("=%d\n", value1 - value2 );
break ;
case '*':
printf ("=%d\n", value1 * value2 );
break ;
case '/':
if( value2!=0 )
printf ("=%d\n", value1 / value2 );
else
printf("除数不能为0\n");
break ;
case '%':
if( value2!=0 )
printf ("=%d\n", value1 % value2 );
else
printf("除数不能为0\n");
break ;
default :
printf (" Unknown operator \n");
break;
}
return 0;
}

代码取自课件 ch03.txt

要点：

  • 运算符 op 存为 char，case '+': 等用的是字符常量（之前 if(op=='+') 用关系运算，这里是 switch 的常量入口，二者等价）。
  • 除法 / 与取余 % 的 case 里嵌套 if-else 处理除零；最后 default 处理”不认识的运算符”，输出 Unknown operator。
  • default 后的 break 可省略（已是最后一段），但写上无害。
  • 若希望输入时允许运算符前后有空格，可在 scanf 的 %c 前加一个空格（如 scanf("%d %c%d", ...)）。

本节收束（02:15:04）：今天内容就是 if-else 多路分支、switch 开关语句、break 在循环与 switch 中的应用、它们的嵌套，以及字符类型。第三章内容较少，本周请务必完成第二章作业。

易错点：switch 的 case 常量只能是整型/字符型；嵌套 if-else 时务必加 {} 防止悬空 else；% 取余只对整数有效，除数也不能为 0。
